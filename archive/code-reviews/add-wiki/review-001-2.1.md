**Мутационные пробы (обе пойманы):**
1. Убран `IF NOT EXISTS` (temp-копия модуля) → повторный запуск падает `sqlite3.OperationalError: table pages already exists` — идемпотентность «повтор → no-op» без IF NOT EXISTS не выполняется, критерий задачи ловит.
2. `ON DELETE RESTRICT` → `CASCADE` в DDL (temp-копия) → автосверка: `FAIL: pages: нет/не те FK: [('parent_id','pages','RESTRICT')] (факт: … 'CASCADE')`, exit 1. Сверка FK+ON DELETE реально работает, не декоративна.
