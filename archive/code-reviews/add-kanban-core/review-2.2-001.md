## Что НЕ проверено (честно)

- **Реальный HTTPS-контур nginx** (Secure-флаг в бою, proxy_pass) — вне дифа, задача 1.4/развертывание.
- **Статика через nginx** — design §8: до приложения не доходит; в middleware не обрабатывается (корректно по спеке), но боевой путь не воспроизводился.
- **Страница /login как HTML** — ее еще нет (задача 2.3); проверена только 302-логика middleware.
- **Многопроцессный uvicorn/workers > 1** — deployment рассчитан на 1 процесс (design §1 «Приложение — один процесс»); гонка оценивалась в потоках одного процесса.
- **Поведение HEAD/OPTIONS-запросов** к защищенным путям — не в спеке, не в сценариях; spot-check не делал (не влияет на сценарии задачи).
- **Инвалидация `expires_at` при рестарте** — NFR-3 гарантирует данные, не сессии; инвалидация сессий при рестарте спекой допущена.
