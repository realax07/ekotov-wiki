### 6. Доступность и качество кода
- `disabled` — корректный механизм: поле исключается из tab-порядка целиком
  (правильное поведение для реально недоступного для правки поля; фокус не
  «теряется» — при снятии fast поле снова фокусируемо).
- Label «Приоритет» — обертывающий `<label>` вокруг select (board.html:77–79),
  доступное имя сохраняется при disabled.
- Программная установка `checked` не возбуждает `change` — сброс блокировки
  явно выполнен через `setPriorityLock(false)` в `fillTaskForm` (комментарий в
  коде фиксирует причину). Ветка `is_fast` неприменима к редактированию
  (`currentTaskId !== null`), при редактировании приоритет правится штатно.
- best practices: без секретов/инъекций, глобальное состояние не мутируется,
  имена по домену, дубли не размножены.
