- **«Поля ввода оформлены по токенам полей V3»**: input/textarea — радиус 0 + нижняя линия 2px (бумажный прием мокапа V3), hover/focus — `--focus-ring`; критерий «фокус отображается кольцом» покрыт существующим `:focus` паттерном (app.css) + новые правила. Изменения — только CSS/разметка.
- **«Выбранные теги отображаются по дизайну V3»**: чипы `.chips/.chip` с крестиком удаления — дословно структура мокапа (span.chip + button[aria-label="Убрать тег X"]); синхронизация с input «Теги» (input → перерисовка, крестик → правка строки input). **Источник истины — input, collectTaskForm и payload не менялись** — «логика и валидация форм не меняются» соблюдено.
- **«Выбранный приоритет отображается по дизайну V3»**: SVG-иконка в пилюле (createPriorityIcon, currentColor — цвет дает пилюля по `:has(:checked)`), пустой выбор — иконки нет (`:empty` прячет бокс); disabled при fast line — приглушение 0.45. value/события селекта не тронуты (нативный select сохранен — контракт e2e select_option).
- **«Форма редактирования соответствует мокапу V3»**: заголовок «Редактирование задачи», fast-row скрыт целиком (весь ряд .fast-row, улучшение против прежнего скрытия одного label), значения/чипы/иконка перерисовываются в fillTaskForm. Dev заявляет сквозное сохранение PATCH — кодовых препятствий нет.
- **«Негативный: все интерактивные элементы покрыты стилями» (DEF-004)**: чеклист по дифу — title/description (нижняя линия+фокус), priority (пилюля+иконка+disabled), category, due, tags (поле+чипы+крестик с focus-visible кольцом), is-fast (.fast-row плашка на голубых токенах), submit/cancel (.btn, существующие), close (40px крестик, существующий).
