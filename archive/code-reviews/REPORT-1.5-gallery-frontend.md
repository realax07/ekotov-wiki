## Сверка с мокапами по пунктам (design/gallery-grid.html, -lightbox.html, -upload.html)

**(а) Маршрут в ядре** — `GET /gallery` в `pages.py`; страница наследует base.html
(сессия/редирект — общий механизм). Проверено: без сессии 302→/login (middleware),
с сессией 200 (TestClient + живой стенд).

**(б) Сайдбар** — «Галерея» 4-м пунктом после «Wiki», иконка inline-SVG 16px
currentColor — дословно из мокапа; виден на ВСЕХ страницах функционала
(board/search/wiki/settings проверены), без role-рендера (ОВ-4).

**(в) JS-модуль**:
- сетка адаптивная 2/3/4 колонки (<880/≥880/≥1280px) — мокап 1:1;
- карточка-ссылка: превью в ячейке 4:3 **object-fit: contain** (уточнение
  Заказчика 1.1), бейдж формата jpeg/png/webp/gif (из `mime` списка),
  название серифом с ellipsis, пилюля категории (`.task-category`),
  счетчики лайк/дизлайк/комментарии + дата, бейдж «мой голос»
  (`.stat.my-vote`, мягкая терракота — различим без цвета);
- фильтры категория/тег — селекты в паттерне конструктора поиска (нижняя
  линия 2px), «Сбросить», счетчик «Найдено: N»; **категория — по ИМЕНИ**
  (эскалация Э-2 ревьюера 1.2 принята: `?category=<имя>`, значения опций —
  фактические категории из данных, не из фантазии);
- форма загрузки: dropzone (drag&drop + клик, `dragover`-состояние),
  превью выбранного файла (имя/размер/тип + «убрать»), категория — select
  фактических + «+ Новая категория…» с раскрытием текстового поля, теги —
  через запятую с чипами (крестик удаления), ошибки 422 человекочитаемо
  («Файл больше 10 МБ…», «Тип не поддерживается. Разрешены JPEG, PNG, GIF,
  WebP.»), прогресс-бар после сабмита, после успеха форма закрывается и
  карточка появляется в сетке (по мокапу).

## Эскалации (E-N)

- **Э-3 (расхождение мокапа с API, вне зоны dev)**: список `GET /api/images`
  НЕ возвращает теги изображений (и `GET /api/images/{id}` тоже), а мокап
  карточки предусматривает пилюли тегов, и фильтр «Тег» — select значений.
  Реализация: на карточке теги не рисуются (рисовать неоткуда, выдумывать
  поля запрещено — истина gallery.py); фильтр/форма тегов работают, но
  селект фильтра наполняется по мере накопления известных тегов (сейчас —
  только после детальных просмотров/загрузок). **Предложение оркестратору**:
  либо дополнить API списка полем tags (малая дельта сервиса images), либо
  зафиксировать как осознанное упрощение у СА (мокап поправит ui_designer).
- **Э-4 (состав /api/auth/me)**: «свой комментарий» определяется по паре
  (user_id комментария → login через `GET /api/users`) + мой login из
  `/api/auth/me`; поля `id` в /api/auth/me нет. Работает корректно (логины
  уникальны), но мост через /api/users — лишний запрос; предложение: добавить
  `id` в состав /api/auth/me (малая дельта ядра, вне зоны 1.5).
- (К передаче design_validator, не эскалация): бейдж «мой голос» на карточке
  и подпись реакции в aria-label — реализованы по мокапу; расхождений
  токенов не найдено.
