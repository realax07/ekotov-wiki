   (gallery MODIFIED: rename-операция + превью-поведение; navigation MODIFIED:
   иконки/favicon; tasks MODIFIED: шапка комментария; board: модалка по макету).
2. **ui_designer: мокапы** (дизайн-фаза): (а) модалка просмотра тикета (B),
   (б) сетка галереи — варианты превью для выбора Заказчиком (J), по Д-паттерну
   (2–3 контрастных варианта в одном HTML).
3. **Развилка Заказчика:** утверждение мокапов.
4. **Dev-волна** (зоны не пересекаются): fastline+багфикс (A+D+H), модалка (B),
   комментарии (C), кнопки+иконки+favicon (E+F+G+H), галерея (I+J).
5. **QA:** impact → чеклист → кейсы → автоматизация (web-сьют с новыми проверками,
   design_validator по мокапам B/J) → ревью-волна.
6. **Релиз:** r8-polish, стандартный deploy.sh, бамп static_v.
