# TC-GAL-117 — e2e: лайк с подсветкой и комментарий через UI

- **Change:** add-gallery-service
- **Источник:** gallery (ADDED): «Лайк/дизлайк — один голос пользователя» (FR-81) — UI-сторона; «Комментарии к изображениям» (FR-82) — UI-сторона; tasks 1.5(в/г), 2.1(в); CHK-GAL-16, CHK-GAL-19
- **Тип:** ФТ, web/e2e, поз. + нег. | **Приоритет:** Must
- **Маркер:** ручной/стендовый — REPORT-2.1 (web/e2e); юнит-базис — `::test_reaction_flow`, `::test_comment_add_and_visible_to_both`
- **Предусловия:** стенд поднят; сессии owner и PE; изображение без голосов/комментариев
- **Шаги:**
  1. owner: клик лайк на карточке/в модалке — подсветка «мой голос», счетчик +1; перезагрузка страницы — состояние сохранено (persisted).
  2. owner: клик дизлайк — подсветка переместилась, счетчики сместились; повторный клик того же знака — голос снят, подсветка исчезла.
  3. owner: добавить комментарий через UI (поле в карточке/модалке) — комментарий появился с автором и временем.
  4. owner: попытка отправить пустой/из пробелов комментарий — UI показывает ошибку 422, комментарий не создан.
  5. PE: открыть ту же карточку — чужой комментарий виден, кнопки удаления у него НЕТ; у своего комментария — есть.
  6. owner: удалить свой комментарий через UI — исчез; XSS-проверка: комментарий со скриптовым текстом (`<script>`/`<img onerror>`) отображается как текст (createElement+textContent, без исполнения).
- **Ожидаемый результат:** лайк/дизлайк через UI ставится с подсветкой собственного голоса, снятие работает, состояние переживает перезагрузку; комментарий добавляется, пустой → человекочитаемая ошибка 422; удаление доступно только своему комментарию; скриптовый ввод не исполняется (XSS-дисциплина 1.5).
