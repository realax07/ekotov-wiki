# Архив

Промежуточные артефакты закрытых релизов/изменений (убраны из рабочих деревьев
2026-10-10). Рабочие контуры конвейера (flow_check/pr_validate) эти пути не
сканируют; артефакты активных change остаются на рабочих местах.

- `code-reviews/` — review-файлы закрытых change-пакетов и баг-фиксов
  (P11–R7, BUG-001…015). Артефакты активных change (add-responsive-mobile,
  add-ui-polish-r8) — в code-reviews/.
- `plans/` — планы релизов R4, R5, R7, p12-ui-polish.
- `release-logs/` — релизные логи и walkthrough (docs/releases, releases/).
- `test-model/` — чеклисты/approved/impact/reviews закрытых change
  (add-containerization, add-gallery-service, add-microservices-full,
  add-netdata-monitoring).

История изменений — в git; каталог можно чистить безболезненно, если репо
распухнет (контент восстановим из истории).
