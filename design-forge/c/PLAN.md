# Направление C — Таблица-рабочий стол

Продукт: Трекер задач ekotov-wiki · режим: Работать (приложение, кабинет, админка). Сгенерировано deal.mjs — заполни все пропуски **до вёрстки** (lint.mjs не пропустит незаполненный план).

## Оси направления

| Ось | Значение |
|---|---|
| UX-архетип | **Таблица-рабочий стол** — Главное — большая таблица: фильтры, группировка, массовые действия, как в электронной таблице. Навигация: верхняя строка с представлениями и фильтрами |
| Палитра | Полночный бирюзовый (тёмная, cool, vivid); акцент #3fd0c9 |
| Типографика | Literata / Literata — книжный, для долгого чтения |
| Форма | Острая: радиусы 0px / 2px / 4px |
| Плотность | Плотная: база 14px, шаг шкалы 1.2, колонка текста 68ch |
| Движение | Сдержанное — Короткие переходы состояний 120–200 мс, только transform и opacity |
| Смелость режима | сдержанно: привычные паттерны, плотность, скорость, характер — в деталях |

Таблицу осей не переписывай — её пишет deal.mjs. Токены — `tokens.css`, гигиена — `base.css`. В вёрстке — только переменные.

## Идея

Доска как «пульт диспетчера»: полночный экран, плотные колонки-регистры, Book Literata в заголовках задач придаёт строкам читаемость, а бирюзовый горит только на активном статусе и действии. Фастлайн — верхний регистр с LED-строкой «выполняется сейчас». От A — холодная точность и компактная плотность вместо тёплого документа, от B — тёмная плотность вместо светлого листа.

## Для кого и сценарий

Пользователь-диспетчер: пробегает регистр задач сверху вниз, снимает сделанное, двигает статусы. Путь: доска (регистр) → выбрать строку → карточка задачи в раскрытой панели → комментарий → статус изменён, регистр пересобрался.

## Каркас экранов

Опора архетипа (типовой порядок для «Таблица-рабочий стол» — адаптируй под продукт, лишнее выкинь, недостающее добавь):
строка представлений → фильтры и поиск → таблица с выбором строк → панель массовых действий → пагинация.

### board.html — Доска

```
[строка состояния: «Доска» Literata · дата mono · ACT/DONE счётчики mono · [+ Задача] (бирюза)]
[ФАСТЛАЙН-регистр: строка LED «RUN» · FST-01 · задача · статус] — один ряд, прижат к шапке
[линейка]
[РЕГИСТР: 3 колонки-таблицы: Ожидает / В работе / Выполнено]
  шапка колонки: капс Literata 12px + счётчик mono + линейка снизу
  строки-задачи: приоритет (буквенная метка H/M/L mono, цвет) · заголовок Literata 14px ·
  срок mono справа; сепараторы 1px; строка «Выполнено сегодня» — приглушена
[пустая колонка: mono-текст «— нет записей —»]
```

### task.html — Карточка задачи

```
[шапка: ← Доска · mono-код задачи · [Закрыть задачу] (бирюзовая кнопка)]
[заголовок Literata 20px]
[регистр-таблица полей: Приоритет | Категория | Срок | Создана — 2 колонки mono-метки]
[теги-чипы острые 2px]
[описание Literata 14px, 68ch]
[КОММЕНТАРИИ: таблица-лента: автор mono · время mono · текст Literata; поле ввода]
[Удалить — кнопка-призрак с бордовой… нет, с красноватой обводкой 1px]
```

### kit.html — UI-кит

Заготовка уже лежит в папке (из assets/kit.template.html): все детали и состояния с именами `data-part`.
Острота 0/2/4px: кнопки 2px, панели 4px, модалка 4px. Кнопка-действие — бирюзовая заливка, Literata 600; вторичная — бирюзовая обводка 1px. Поля — тёмные, рамка 1px, фокус — бирюзовая рамка. Плотность: базы 14px, отступы компактные, строки таблиц 32px. Метки — mono капс 11px. Таблица — только горизонтальные линейки, строки без фонов.

## Принципы

1. Регистр, не витрина: плотность 14px, линейка 1px, ни одной декоративной поверхности.
2. Бирюза = «текущее»: активный статус, фокус ввода, главное действие — остальное монохром.
3. Literata только в содержимом (заголовки, тексты задач), служебное — mono капс.

## Отраслевые правила — Инструменты разработчика, API, инфраструктура

- Код и команды — моноширинным, с кнопкой копирования
- Документация и цены — в одном клике с главной
- Тёмная тема ожидаема: сделай её равноправной (--themes both)

## Вторая тема

Светлая тема включается `<html data-theme="light">` — переменные в tokens.css. lint.mjs проверяет экраны в обеих темах.

## Что тут дефолтное — и что изменено

- Дефолт: канбан карточками → заменён колонками-регистрами со строками (карточка = строка с линейкой).
- Дефолт: скруглённые плитки с тенями → заменены острыми 2px поверхностями без теней вообще.
- Дефолт: серые muted-подписи → заменены mono капс 11px с трекингом, служебный голос «пульта».
- Дефолт: синий акцент → полночный бирюзовый #3fd0c9 только на активном.
- Принятое предупреждение «eyebrow» (badge, mlabel, th — mono капс 11px с разрядкой): служебный голос «пульта» —
  основная идея направления (см. «Принципы»); это не надзаголовки над контентными заголовками, а статусы, счётчики
  и служебные подписи регистра. Капс-лейблы оставлены сознательно, предупреждение принято.

## Плюсы

- Максимум задач на экран: компактная плотность показывает весь день без прокрутки
- Литературный Literata делает длинные заголовки читаемыми даже в 14px
- Тёмный «пульт» с бирюзовым активом выглядит как рабочий инструмент, а не витрина

## Минусы

- Плотная тёмная таблица требует точной вёрстки: сбой ритма сразу виден
- Literata — спорный выбор для служебных подписей: держать mono для служебного
