# Направление A — Доска и поток

Продукт: Трекер задач ekotov-wiki · режим: Работать (приложение, кабинет, админка). Сгенерировано deal.mjs — заполни все пропуски **до вёрстки** (lint.mjs не пропустит незаполненный план).

## Оси направления

| Ось | Значение |
|---|---|
| UX-архетип | **Доска и поток** — Работа видна как движение по этапам: колонки-статусы, карточки задач, перетаскивание. Навигация: верхняя полоса с переключателем досок |
| Палитра | Бордо и золото (тёмная, warm, calm); акцент #d6a85c |
| Типографика | PT Serif / Golos Text — строгий, госсервисы и финансы (кириллица) |
| Форма | Округлая: радиусы 10px / 18px / 28px |
| Плотность | Обычная: база 16px, шаг шкалы 1.25, колонка текста 66ch |
| Движение | Сдержанное — Короткие переходы состояний 120–200 мс, только transform и opacity |
| Смелость режима | сдержанно: привычные паттерны, плотность, скорость, характер — в деталях |

Таблицу осей не переписывай — её пишет deal.mjs. Токены — `tokens.css`, гигиена — `base.css`. В вёрстке — только переменные.

## Идея

Канбан как «архив решений»: каждая задача — документ с весом (serif-заголовок), а доска — тёмный кабинет с бордовыми стенами, где золотом отмечено только то, что требует действия. Фастлайн — золотая линия штаба: одна задача, которой позволено светиться. От B отличается температурой и весом типографики, от C — округлостью и «документной» подачей вместо табличной.

## Для кого и сценарий

Владелец проекта открывает доску утром: фастлайн отвечает «что делать прямо сейчас», канбан — «что движется». Путь: доска → создать задачу или открыть карточку → комментарий в карточке → назад на доску, перетащив задачу в «Выполнено».

## Каркас экранов

Опора архетипа (типовой порядок для «Доска и поток» — адаптируй под продукт, лишнее выкинь, недостающее добавь):
шапка доски с фильтрами → колонки статусов → карточки с метками и исполнителями → боковая панель карточки.

### board.html — Доска

```
[шапка: «Доска» serif крупно · дата · ACT n · DONE n · кнопка «Создать задачу» (золото)]
[ФАСТЛАЙН — панель с золотой верхней кромкой, метка FST-01]
  [Ожидает][В работе][Выполнено] — 3 узкие колонки; карточка с золотой кромкой
[тонкий разделитель с подписью «Основная доска»]
[КАНБАН: три равные колонки на поверхности чуть светлее фона]
  шапка колонки: LED-точка статуса · название (Golos 600, caps) · счётчик mono
  карточка: кромка приоритета слева 3px · serif-заголовок · мета-строка:
  категория · чипы тегов · срок (просрочен — бордовый)
[пустая колонка — тихая подпись «Пусто», без иллюстраций]
```

### task.html — Карточка задачи

```
[шапка: ← Доска · бейдж статуса · действие «Выполнено» (золотая кнопка)]
[заголовок задачи — PT Serif крупно, до 2 строк]
[мета-таблица: Приоритет · Категория · Теги · Срок · Создана]
[описание — Golos Text, колонка 66ch]
[КОММЕНТАРИИ: лента (автор · время · текст) + поле ввода с кнопкой]
[подвал карточки: «Удалить» — тихая кнопка с бордовой обводкой]
```

### kit.html — UI-кит

Заготовка уже лежит в папке (из assets/kit.template.html): все детали и состояния с именами `data-part`.
Округлость 10/18/28: кнопки и поля — 10px, карточки/панели — 18px, модалка — 28px. Кнопка-действие — золото на бордовом, Golos 600; вторичная — бордовая обводка без заливки. Поля чуть светлее поверхности, фокус — золотая рамка 2px. Чипы и метки без капса, Golos 500. Таблица — строковые сепараторы 1px, без зебры.

## Принципы

1. Золото = действие и фастлайн, больше нигде: взгляд всегда знает, где кнопка.
2. Задача — документ: serif-заголовок даёт вес, мета — Golos, строгая типографская иерархия.
3. Доска тёмная и тихая: движение 120–200 мс только transform/opacity, глубина — цветом поверхности, не тенями.

## Отраслевые правила — Инструменты разработчика, API, инфраструктура

- Код и команды — моноширинным, с кнопкой копирования
- Документация и цены — в одном клике с главной
- Тёмная тема ожидаема: сделай её равноправной (--themes both)

## Вторая тема

Светлая тема включается `<html data-theme="light">` — переменные в tokens.css. lint.mjs проверяет экраны в обеих темах.

## Что тут дефолтное — и что изменено

- Дефолт: карточка с тенью на каждый ховер → заменено кромкой приоритета слева и поднятием поверхности цветом; тень только у drag-призрака.
- Дефолт: ALL-CAPS-надзаголовок секции → заменено: капс только в шапках колонок (код статуса), заголовки секций — serif без надзаголовков.
- Дефолт: бейдж приоритета с молнией → заменён цветной кромкой 3px и словом «Высокий» в мете цветом.
- Дефолт: синий акцент → заменён бордо/золотом; ссылки — золотые с underline-offset.
- Принятое предупреждение «карточка внутри карточки»: колонка доски — контейнер канбана, карточка задачи — запись в нём;
  это суть паттерна «доска», а не плитка-«фича» внутри карточки, поэтому вложенность оставлена сознательно.
- Принятое предупреждение «eyebrow» (h2.col-title «ОЖИДАЕТ / В РАБОТЕ / ВЫПОЛНЕНО»): это функциональные шапки колонок
  канбана со счётчиком, а не декоративный надзаголовок над контентными заголовками; капс здесь — код статуса колонки.

## Плюсы

- Мгновенно отличается от типовых синих канбанов; статус читается кромкой без чтения бейджей
- Serif-заголовки дают задачам вес — доска не выглядит «тудушкой»
- Тёплая тёмная тема спокойна при ежедневной работе

## Минусы

- Бордо/золото требовательны к дисциплине: лишний золотой элемент рушит иерархию
- Serif в мелких подписях проигрывает гротеску — держать правило «serif только заголовки»
