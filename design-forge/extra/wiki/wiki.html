Вёрстка канбана

Автор: А. Ekotov Обновлено: 18.11.2026 Чтение: 6 мин css kanban

Доска задач в трекере — это три-четыре колонки, внутри которых карточки перетаскиваются мышью и пальцем. Первая версия держала колонки на flexbox и теряла ширину при переполнении; финальная — на CSS Grid с minmax(0, 1fr), поэтому длинные заголовки карточек переносятся, а не растягивают колонку.

Сетка колонок

Каждая колонка — min-width: 0 плюс внутренний скролл по вертикали. Без min-width: 0 грид-элемент не сжимается ниже контента, и доска уезжает за горизонт уже на среднем экране.

css 
.board {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(260px, 1fr));
  gap: var(--space-3);
  align-items: start;
}
.col { min-width: 0; max-height: 70vh; overflow-y: auto; }

Перетаскивание

Перетаскивание — нативные dragstart/drop: карточка получает draggable="true", колонка слушает dragover и отменяет preventDefault() только когда курсор над допустимой зоной. Порядок карточек сохраняется полем position с шагом 1024, чтобы вставка между соседями не требовала перенумерации всей колонки.

  • на тач-устройствах нативный DnD не работает — длинное нажатие эмулирует pointer-событиями;
  • во время drag колонка-цель подсвечивается золотой левой границей;
  • отмена перетаскивания по Escape возвращает карточку на место.

Доступность

Мышь — не единственный путь: у каждой карточки есть кнопка «В колонку», открывающая меню выбора целевой колонки. Скринридер читает доску как список колонок со счётчиками, а не как облако абсолютных координат.

Частые ошибки

Три ловушки, на которые потратили больше всего времени: overflow: hidden на колонке убивает drag-призрак; position: sticky заголовка требует фон карточки, иначе сквозь него видно прокрутку; и тач-эмуляция без touch-action: none — страница скроллится вместе с карточкой.

Правки попадают в историю — статью можно откатить к любой из трёх ревизий.
