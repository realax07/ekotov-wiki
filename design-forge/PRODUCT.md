# PRODUCT.md — бриф редизайна таск-трекера

## Продукт
**Доска задач (task tracker)** личного проекта ekotov-wiki — канбан-доска для управления
задачами разработки (личный wiki-проект + конвейер агентов).

## Аудитория
Один основной пользователь — владелец проекта (технический руководитель, PM-роль),
работает ежедневно с десктопа; изредка с телефона. Плюс фоновое чтение статусов.

## Главная задача пользователя
Быстро увидеть состояние работы: что в очереди, что в работе, что сделано сегодня,
что горит по срокам — и за пару кликов создать/подвинуть/закрыть задачу.

## Режим поверхности
**operate** — рабочий инструмент ежедневной эксплуатации (не лендинг, не витрина).

## Ключевые экраны
1. **Доска** (`board.html`) — главная: зона «Фастлайн» (одна задача в работе,
   приоритетная линия над канбаном, 3 столбца-этапа) + основной канбан
   (Ожидает / В работе / Выполнено) со счетчиками; создание задачи.
2. **Карточка задачи** (`task.html`) — полный вид задачи: заголовок, описание,
   приоритет, категория, теги, срок, комментарии (лента + ввод), перемещение,
   удаление; форма создания с валидацией.

## Функционал (фиксирован, редизайну не подлежит)
- 3 неизменяемых столбца: Ожидает / В работе / Выполнено; drag&drop перемещение
- Фастлайн: ровно одна задача, зона с 3 столбцами-этапами, гейт «занята»
- Приоритеты (низкий/средний/высокий), категории (select из справочника),
  теги (чипы), срок (дата), описание, комментарии (лента)
- «Выполнено сегодня» в третьем столбце

## Ограничения
- Язык: русский (весь UI)
- Бренд-цвета не зафиксированы — свободная рука
- Данные карточек — реалистичные задачи разработки (без lorem)
- Иконки: авторские SVG, единый вес; без emoji

## Допущения (не подтверждены Заказчиком)
- Стиль — свободный, без привязки к текущей эстетике сайта («переосмыслить»)
- Нужны обе темы: светлая и тёмная (operate-стандарт)
- Трекер остается частью сайта wiki, но дизайн-контекст после утверждения
  масштабируется на трекер как продукт
- Плотность: компактная рабочая, не «витринная»
