Авторизация — middleware (путь вне exempt-списка), без сессии 401. (FR-15, FR-16, FR-17, FR-18) — **реализовано**: `backend/app/suggestions.py` @ `1f11011`.

(FR-15) — **реализовано**: `frontend/templates/search.html`, `frontend/static/js/search.js` @ `1f11011`.
- [x] 1.3 Тесты: автотесты API (200 + множество, 401, set-семантика, сортировка, объединение источников) и UI (datalist на обоих полях, set-семантика/сортировка), 1 кейс = 1 тест, в регрессионном наборе `tests/`. (FR-15…FR-18) — **реализовано**: `tests/api/test_suggestions.py` (TC-API-SUGG-001…005), `tests/web/test_search_suggestions_ui.py` (TC-UI-SUGG-001…002) @ `1f11011`.
