# Proposal: add-suggestions

## Change ID

`add-suggestions`

## Why

Ретроспективный change-пакет (Флоу 5, урок 2026-09-20): поведение R1.3 (P4 — подсказки тегов и категорий в поиске) уже реализовано (коммит `1f11011`, PR#1, main) и покрыто автотестами, но оформлено было по Флоу 2 без БА/СА-этапа. Требования утверждены пост-фактум (`test-model/requirements-p4.md`, r1, УТВЕРЖДЕН, FR-15…FR-18). Пакет оформляет **существующее** поведение как формальную дельту спеки для замыкания Флоу 1 по R1.3; новой функциональности не предлагает.

Источник — дословная цитата Заказчика: «я например хочу чтобы саджест формировался по двум столбцам, теги и категории, и выбирался типом set(), множество, только из уже заведенных вариантов».

## What Changes

- `specs/search/spec.md` — **ADDED**: Requirement «Подсказки тегов и категорий в поиске» + сценарии по FR-15…FR-18: ответ 200 — множество значений (set-семантика, отсортировано), отказ 401 без сессии, только уже заведенные варианты, datalist привязан к обоим полям фильтра-конструктора.

После утверждения дельта сливается в master-spec `openspec/specs/search/spec.md` (контракт 7), пакет — в `changes/archive/`.

## Scope

### In scope

- FR-15 (Should): подсказки для полей «Теги» и «Категория» фильтра-конструктора, один общий список на оба поля.
- FR-16 (Should): множество = объединение тегов и категорий существующих задач, без дублей, отсортировано по возрастанию.
- FR-17 (Should): только уже заведенные варианты; новые значения через подсказки не создаются.
- FR-18 (Must): без валидной сессии — 401 (следствие NFR-7 основного ТЗ).

### Out of scope

- Автономные (per-field) списки подсказок — Заказчиком не заказаны.
- Подсказки для прочих признаков (приоритет, срок) — вне ТЗ P4.
- Создание новых значений из списка подсказок — противоречит FR-17.

## Approach

Ретроспективная фиксация: дельта описывает наблюдаемое поведение, сверенное с арбитром фактического поведения — `backend/app/suggestions.py` @ `1f11011` (роут GET /api/suggestions), `frontend/templates/search.html` (datalist), `frontend/static/js/search.js` (loadSuggestions). Трассировка FR → реализация → TC зафиксирована в requirements-p4.md §3; автотесты TC-API-SUGG-001…005, TC-UI-SUGG-001…002 в регрессионном наборе `tests/`.
