# Proposal: add-ui-polish-r8

## Change ID

`add-ui-polish-r8`

## Why

Пакет **P12 «UI-полировочный»** — заметки Заказчика после QA-прогона галереи
(PRODUCT_BACKLOG.md, P12, пп.1–12, дословно 2026-10-06). Решение Заказчика:
**«Погнали полировку»** (2026-10-06, Telegram DM; план
`docs/plans/p12-ui-polish-plan.md`, декларация **Флоу 1** — БА-фаза не нужна:
требования сформулированы Заказчиком дословно, спека существует). Заметки
Заказчика (дословно, выборка; полный список — PRODUCT_BACKLOG P12):

1. «Починить кнопку настройки (при нажатии название кнопки уезжает влево)».
2. «Привести дизайн окна просмотра тикета на борде к общему дизайну (нужен
   дизайн и макеты — кандидат на дизайн-фазу)».
3. «В шапке каждого комментария сейчас id и timestamp — ID заменить на автора
   комментария, timestamp на человекочитаемую дату и время».
4. «Теги: после ввода тег применялся, но оставался текстом в поле — должен
   убираться из текста поля (остается только визуальная метка с крестиком
   ниже). Проверить множественное добавление и удаление тегов по одному».
5. «Fastline красит весь столбец в синий цвет — убрать эту логику, синяя
   только сама плитка».
6. «В создании задачи блок fastline не до конца соответствует макету».
7. «В редактировании задачи отсутствует галочка fastline».
8. «Кнопка «Найти» в advanced-поиске: добавить отступов и привести к общему
   стилю… проверить кнопки поиска/фильтрации во всех разделах».
9. «Добавить иконки всем разделам сайдбара (доска, поиск, wiki, настройки) —
   аналогичные по стилю иконке «Мониторинг»… чтобы сайдбар выглядел целостно».
10. «Добавить favicon — симпатичная иконка в закладке браузера (в стиле V3
    «Бумага»/терракотового акцента; inline-SVG data-URI, чтобы без внешних
    файлов — ОГР-8; поправку на кеш учесть)».
11. «Галерея: возможность переименовать загруженный файл (original_name)».
12. «Галерея: плитка сетки растягивается при загрузке изображений разного
    размера — пересмотреть поведение превью в макетах… зафиксировать высоту
    ячейки/кроп превью, чтобы сетка держала ритм».

Прод — действующий матричный стек p12-rc1; правки — фронтенд ядра + одна
новая API-операция сервиса images. Существующие capabilities: `gallery`,
`navigation`, `tasks`, `board` (все — master-спеки).

## What Changes

Дельты по **4 capability**: `gallery` MODIFIED (rename-операция в лайтбоксе) +
ADDED (поведение превью сетки), `navigation` MODIFIED (иконки разделов) +
ADDED (favicon), `tasks` MODIFIED (шапка комментария; сброс поля
таг-combobox), `board` MODIFIED (модалка просмотра по утвержденному мокапу).
Группы A (fastline-UI), E (кнопки действий), H (кнопка настроек) — CSS/JS-полировка
в рамках действующих спек **без дельт** (поведение уже описано: подсветка
fast line, токены V3; сверка ассертов QA).

## Scope

### In scope

- Полировка fastline-UI (группа A): подсветка только плитки (без окраски
  столбца), блок fastline формы создания — по макету V3, галочка fastline в
  форме редактирования (серверная поддержка is_fast при редактировании —
  техпункт design §2; существующие инварианты fast — priority=high, одна
  fast-задача — сохраняются).
- Модалка просмотра тикета по утвержденному мокапу (B; дизайн-фаза
  обязательна, read-only семантика сохраняется).
- Шапка комментария: автор + человекочитаемая дата/время (C; автор —
  join users к существующему author_id, API комментариев расширяется
  ответом, контракт записи не меняется).
- Таг-combobox: сброс текста поля после выбора/создания тега + проверка
  множественного добавления/удаления (D).
- Кнопки действий (E): «Найти» и кнопки поиска/фильтрации всех разделов —
  единый стиль токенов V3, отступы.
- Иконки всех разделов сайдбара inline-SVG в едином стиле (F; эталон —
  иконки «Мониторинг» и «Галерея»).
- Favicon — inline-SVG data-URI в base.html, стиль V3, без внешних файлов
  (G; кеш-политика — design §3).
- Кнопка настроек: текст не смещается при active/focus (H).
- Rename файла галереи (I): `PUT /api/images/{id}/name` + форма в лайтбоксе.
- Поведение превью сетки галереи по утвержденному варианту мокапа (J;
  варианты фикс-высота/кроп/masonry — на дизайн-фазе).
- Дизайн-фаза (Д-паттерн): [design] ui_designer — мокап модалки тикета (B) +
  2–3 контрастных варианта сетки галереи (J) → утверждение Заказчиком.
- QA-волна (web-сьют + design_validator по мокапам B/J) и релиз r8-polish.

### Out of scope

- Адаптивная верстка P14 — отдельный второй этап (решение Заказчика: «вторым
  этапом, после полировки»; связь учтена: сетка галереи решается здесь).
- Удаление изображений, управление категориями галереи — вне ТЗ
  (закрыто/отклонено в пакете add-gallery-service).
- SPA-фреймворки, внешние библиотеки/шрифты/CDN — ОГР-8.
- Изменение контрактов записей задач/комментариев (author_id из сессии —
  как прежде); изменение DOM-идентификаторов форм — ОГР-28.
- Новые разделы/пункты сайдбара — только иконки у существующих.

## Impact

- **Код:** `frontend/templates/base.html` (иконки разделов, favicon),
  `frontend/static/css/{board,app,search,gallery}.css`,
  `frontend/static/js/board/{task-form.js,tag-combobox.js,task-detail.js}`,
  `frontend/static/js/gallery.js`, `backend/app/comments.py` (join автора в
  ответе списка), `services/images/app/*` (PUT name — сервис images,
  паттерн существующих операций).
- **Спеки:** дельты `gallery` (MODIFIED «Full-screen просмотр с листанием» +
  ADDED «Сетка галереи держит ритм…»), `navigation` (MODIFIED «Навигация
  через сайдбар» + ADDED «Favicon…»), `tasks` (MODIFIED «Признаки задачи»,
  «Кастомный комбобокс подсказок тегов»), `board` (MODIFIED «Просмотр
  карточки задачи — модальное окно read-only»).
- **Данные:** без миграций (колонка `original_name` существует; author_id в
  comments существует).
- **Пользователи:** визуальные изменения во всех разделах для обоих
  пользователей паритетно; единственная новая API-операция — rename.
- **Риски:** агрессивный кеш favicon браузеров (менять URL при изменении —
  design §3); визуальный регресс сайдбара/кнопок (регресс-QA волна);
  DOM-контракты id форм не менять (ОГР-28, e2e-сьют цепляется по id).
