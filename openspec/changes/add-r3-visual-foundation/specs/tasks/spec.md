# Delta: tasks

## ADDED Requirements

### Requirement: Формы создания и редактирования по дизайну V3

Формы создания и редактирования задачи MUST быть приведены к дизайну V3 по всем зонам расхождения (FR-34, DEF-005): (1) вид выбранных тегов в форме; (2) оформление полей ввода (input/textarea) по токенам полей V3 — радиус, рамки, фокус-кольцо; (3) отображение выбранного приоритета (селект/иконки/цвет); (4) форма редактирования целиком — сверка с мокапом V3. Критерий приемки: формы создания/редактирования соответствуют мокапу V3 по токенам — цвета, радиусы, типографика, состояния; все интерактивные элементы форм MUST быть покрыты стилями (урок DEF-004). Соответствие не вводит новых функций и не меняет валидацию — только визуал и состояния.

#### Scenario: Поля ввода оформлены по токенам полей V3

- **GIVEN** пользователь авторизован и открыл форму создания задачи
- **WHEN** пользователь осматривает поля ввода (input/textarea) и фокусируется на поле
- **THEN** поля оформлены по токенам полей V3 — радиус, рамки, фокус-кольцо; фокус отображается фокус-кольцом

#### Scenario: Выбранные теги отображаются по дизайну V3

- **GIVEN** пользователь открыл форму задачи и выбрал в поле «Теги» значения
- **WHEN** пользователь осматривает выбранные теги
- **THEN** выбранные теги отображаются по дизайну V3 (оформление выбранных значений — одна из зон расхождения DEF-005 устранена)

#### Scenario: Выбранный приоритет отображается по дизайну V3

- **GIVEN** пользователь открыл форму задачи
- **WHEN** пользователь выбирает приоритет (low/medium/high)
- **THEN** выбранный приоритет отображается по дизайну V3 (селект/иконки/цвет)

#### Scenario: Форма редактирования соответствует мокапу V3

- **GIVEN** пользователь открыл форму редактирования существующей задачи
- **WHEN** форма сверяется с мокапом V3 по токенам
- **THEN** цвета, радиусы, типографика и состояния формы соответствуют мокапу V3

#### Scenario: Негативный: все интерактивные элементы покрыты стилями

- **GIVEN** открыта форма создания или редактирования задачи
- **WHEN** пользователь осматривает все интерактивные элементы формы (поля, кнопки, крестики, селекты)
- **THEN** ни один интерактивный элемент не остался с дефолтным браузерным оформлением без стилей (урок DEF-004)
