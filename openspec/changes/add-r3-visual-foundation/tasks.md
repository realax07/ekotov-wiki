## 2. Drag-and-drop (FR-31) — cards.js

- [x] 2.1 Frontend: перетаскивание карточек мышью между столбцами (HTML5 DnD, нативно) — `dragstart`: карточка прикрепляется к курсору (drag-образ клона) и исчезает с исходного места; `dragover`: подсветка зоны-приемника; `drop` над столбцом: `POST /api/tasks/{id}/move` с целевым статусом (тот же API, что прежний перевод, ОГР-14); отпускание вне зон: карточка на исходном месте, статус не меняется; touch-устройства не затрагиваются (перенос прежним способом); при деплое — бамп `static_v` (урок DEF-002, З-2 ревью-001). (FR-31, ОГР-14 → board: Перемещение карточки перетаскиванием — сценарии «в другой столбец», «вне зоны», «touch»)
- [x] 2.2 Frontend: обработка отказа перевода при drop — 409 (fast line занята, Д-6) и иные 4xx: показать ошибку в UI, вернуть плитку на исходное место, инварианты сервера не нарушены; перерисовка доски после успеха. (FR-31, Д-6 → board: сценарий «равнозначен переводу» / Д-6)
