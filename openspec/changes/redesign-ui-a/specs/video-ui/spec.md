# Дельта specs: video-ui — экран «Видео» на токенах направления A (ЧЕРНОВИК)

> Заголовок requirement сохранен дословно; оба сценария мастера перенесены.

## MODIFIED Requirements

### Requirement: Экран «Видео» в стиле «Пульт» (FR-126)

Экран «Видео» MUST следовать токенам направления A «Доска и поток»
(`design-forge/a/tokens.css`) при неизменной действующей функциональности
видео-раздела: карточки/список видео — панели `--color-surface` с границей
`--color-border` и радиусом `--radius-md`, hover — золотой акцент границы;
продолжительность/даты/размеры — mono (`--font-family-data`, tabular-nums);
статусы обработки — LED-точки (`--color-success` готово / `--color-warning`
в обработке / `--color-danger` ошибка); заголовок страницы — pagehead с
mono-readout; первичные действия — золотые кнопки `--color-accent`; плеер/
просмотр — поверхность `--color-raised` с тенью `--shadow-2`. DOM-хуки экрана
сохраняются (ОГР-28).

#### Scenario: Список видео в визуале «Пульта»

- **GIVEN** в видео-разделе есть записи в разных статусах обработки
- **WHEN** открывается экран «Видео»
- **THEN** карточки — панели `--color-surface` с границей `--color-border` и
  hover-акцентом золота; длительности/даты mono; статусы LED-точками
  (success готово / warning в обработке / danger ошибка); заголовок —
  pagehead с mono-readout; вид соответствует токенам направления A

#### Scenario: Функциональность видео не деградировала

- **GIVEN** редизайн применен
- **WHEN** прогоняются тесты видео (test_video_ui, test_video_convert_ui,
  test_video_rename_ui, test_video_social_ui — нецветовые ассерты)
- **THEN** загрузка, конвертация, переименование, комментарии работают как
  прежде
