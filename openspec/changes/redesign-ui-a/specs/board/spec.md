# Дельта specs: board — эффекты доски на токенах направления A (ЧЕРНОВИК)

> Заголовок requirement сохранен дословно (машинное слияние по заголовку, flow_check контракт 7).

## MODIFIED Requirements

### Requirement: Визуальные эффекты доски на токенах «Пульт» (FR-132)

Декоративные эффекты доски MUST выполняться на токенах направления A «Доска и
поток» (источник `design-forge/a/tokens.css`): hover-состояния — золотым акцентом
(заголовок карточки → `--color-accent`, граница →
`color-mix(in srgb, var(--color-accent) 45%, var(--color-border))`) без смены фона;
HUD-уголки и фоновая микро-сетка удалены, глубина — поверхностями
(`--color-bg`/`--color-surface`/`--color-raised`) и `--shadow-1/2`; выделение
fast-карточки — только золотой сигнал (`--color-accent`: кромка/граница),
окраска столбца запрещена (преемственность P12 п.5); бордо `--color-accent-2`
на доске используется только кромкой high-приоритета; анимации переходов
отключаются при prefers-reduced-motion.

#### Scenario: Нет окраски столбца и cyan-декора

- **GIVEN** доска с fast-задачей в столбце «В работе»
- **WHEN** инспектируются столбец и карточки
- **THEN** столбец не окрашивается (псевдоэлементы столбца без контента), HUD-уголки
  и glow-декор отсутствуют; золото/бордо встречаются только на сигналах карточек
  (кромки приоритета, fast-граница) и панели фастлайна

#### Scenario: Hover карточки — ступенями фона

- **GIVEN** карточка на доске
- **WHEN** курсор наводится на карточку
- **THEN** заголовок карточки меняется на `--color-accent`, граница на
  `color-mix(in srgb, var(--color-accent) 45%, var(--color-border))`; фон
  `--color-raised` сохраняется; мета-текст остается читаемым (контраст ≥ 4.5:1
  на подложке raised)
