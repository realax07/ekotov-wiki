# Дельта specs: accessibility — контраст и фокус на токенах направления A (ЧЕРНОВИК)

> Заголовки requirements сохранены дословно (включая «cyan-фокус-ринг» — машинное
> слияние по заголовку; содержание переключается на золото); все сценарии мастера
> (2 + 2) перенесены. NFR-43/44 не меняются.

## MODIFIED Requirements

### Requirement: Контраст WCAG 2.1 AA на токенах «Пульт» (NFR-41)

Все текстовые пары «текст/фон» фронта MUST иметь контраст ≥ 4.5:1 (WCAG 2.1
AA) на токенах направления A «Доска и поток» В ОБОИХ темах — тёмной базовой и
светлой (`data-theme="light"`, значения light-блока `design-forge/a/tokens.css`).
Проверка MUST выполняться программно (скрипт WCAG-формулы) при переносе токенов
и в QA, отдельно для каждой темы. Текст на золотых заливках —
`--color-on-accent` (`--color-text-on-accent`).

#### Scenario: Программная проверка всех пар

- **GIVEN** токены направления A перенесены в app.css (dark `:root` + light
  `:root[data-theme="light"]`)
- **WHEN** скрипт контраста прогоняет все текстовые пары токенов и ключевые
  составные поверхности (hover-подложки, бейджи, кнопки) для каждой из двух тем
- **THEN** каждая пара ≥ 4.5:1 в обеих темах (контрольные: `--color-text` на
  `--color-bg`/`--color-surface`/`--color-raised`, `--color-muted` на
  `--color-surface`, `--color-on-accent` на `--color-accent`); REPORT с числами
  приложен к QA-волне

#### Scenario: Подписи на hover-подложке не проседают

- **GIVEN** карточка задачи с мета-подписью на `--color-text-muted`
- **WHEN** курсор наведен (поверхность raised, граница gold-mix)
- **THEN** подпись остается на контрасте ≥ 4.5:1 на `--color-raised`
  (при необходимости поднимается до `--color-muted`)

### Requirement: Фокус с клавиатуры — cyan-фокус-ринг (NFR-42)

Любой интерактивный элемент MUST показывать видимый фокус ТОЛЬКО при
клавиатурной навигации (`:focus-visible`): `outline` отключен, вместо него
`--focus-ring` (двойное кольцо: `--color-bg` 2px + золото `--color-accent` 4px +
мягкое золотое свечение color-mix) и радиус 4px; `::selection` — золото
`--color-accent` фон с текстом `--color-on-accent`. Мышной клик НЕ показывает
фокус-ринг (семантика focus-visible), таб-навигация последовательно проходит все
интерактивные элементы без ловушек (действующее поведение сохраняется).

#### Scenario: Таб-навигация видит фокус

- **GIVEN** пользователь навигирует табом по сайдбару и доске
- **WHEN** фокус попадает на пункт меню, кнопку, поле, спойлер, переключатель темы
- **THEN** каждый элемент показывает золотой фокус-ринг `--focus-ring`; порядок
  табов логичный, skip-link — первый

#### Scenario: Клик мышью без ринга

- **GIVEN** пользователь кликает мышью по кнопке «Новая задача»
- **WHEN** кнопка получает фокус
- **THEN** фокус-ринг не отображается (focus-visible не сработал), действие
  выполняется
