# Delta: board

## ADDED Requirements

### Requirement: Отображение канбан-доски
Приложение MUST показывать авторизованному пользователю страницу канбан-доски со всеми его задачами, разложенными по столбцам (FR-1).

#### Scenario: Открытие доски с задачами
- **GIVEN** пользователь авторизован и в системе есть задачи в разных столбцах
- **WHEN** пользователь открывает страницу доски
- **THEN** все задачи отображаются в столбцах, соответствующих их текущему статусу

#### Scenario: Открытие пустой доски
- **GIVEN** пользователь авторизован и в системе нет ни одной задачи
- **WHEN** пользователь открывает страницу доски
- **THEN** доска отображается с тремя пустыми столбцами без ошибок

### Requirement: Три фиксированных столбца
Доска MUST содержать ровно три столбца: «Ожидает», «В работе», «Выполнено» (FR-2). Состав столбцов MUST быть неизменяемым пользователем (ОГР-3).

#### Scenario: Состав столбцов доски
- **GIVEN** пользователь авторизован
- **WHEN** пользователь открывает страницу доски
- **THEN** доска содержит ровно три столбца с названиями «Ожидает», «В работе», «Выполнено» и никакие другие

### Requirement: Перемещение задач между столбцами
Пользователь MUST иметь возможность перемещать задачу между столбцами «Ожидает» → «В работе» → «Выполнено» и обратно (FR-6). После перевода в «Выполнено» задача MUST исчезать с доски и попадать в архив (FR-4).

#### Scenario: Прямое перемещение по цепочке столбцов
- **GIVEN** задача находится в столбце «Ожидает»
- **WHEN** пользователь перемещает задачу в «В работе», затем в «Выполнено»
- **THEN** задача последовательно занимает целевые столбцы, а после «Выполнено» исчезает с доски

#### Scenario: Обратное перемещение
- **GIVEN** задача находится в столбце «В работе»
- **WHEN** пользователь перемещает задачу обратно в «Ожидает»
- **THEN** задача отображается в столбце «Ожидает»

### Requirement: Быстрый доступ к действию «Выполнено»
Перевод задачи в «Выполнено» MUST быть доступен из любого столбца доски, так как он завершает задачу и отправляет ее в архив (FR-4).

#### Scenario: Завершение задачи из столбца «Ожидает»
- **GIVEN** задача находится в столбце «Ожидает»
- **WHEN** пользователь выполняет действие перевода задачи в «Выполнено»
- **THEN** задача исчезает с доски и попадает в архив, не проходя промежуточный столбец
