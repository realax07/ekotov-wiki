# Дельта specs: settings — настройки и профиль «Пульт»

## MODIFIED Requirements

### Requirement: Страница настроек

Страница настроек (справочник категорий и общие настройки) MUST работать как
прежде (действующий контракт — без изменений) на токенах «Пульт» (заявка 1
«весь фронт»): секции — панели `--p-bg-200` с границей `--p-border`
и HUD-уголками на главных панелях, заголовки секций — капс-микро-лейблы,
таблица/список категорий — на токенах wiki-таблиц (границы `--p-border`,
th капсом, hover строки bg1); действия (создать/переименовать/удалить) —
кнопки «Пульта» (янтарные первичные, контурные вторичные, деструктив —
coral); поля форм — bg2 с cyan-фокусом.

#### Scenario: Авторизованный пользователь открывает настройки

- **GIVEN** пользователь авторизован
- **WHEN** пользователь переходит в раздел «Настройки»
- **THEN** открывается страница настроек

#### Scenario: Негативный: неавторизованный доступ к настройкам

- **GIVEN** вызывающий не имеет действующей сессии
- **WHEN** вызывающий открывает страницу настроек
- **THEN** доступ отклоняется редиректом на страницу входа; содержимое настроек не отображается
#### Scenario: Настройки на темной теме

- **GIVEN** пользователь открыл /settings
- **WHEN** страница отображается
- **THEN** секции-панели на токенах, категории в таблице стиля «Пульта»,
  действия различимы (первичное/вторичное/деструктив), контраст AA

#### Scenario: Управление категориями не деградировало

- **GIVEN** редизайн применен
- **WHEN** прогоняется test_settings_categories_ui (нестилевые ассерты)
- **THEN** создание/переименование/удаление категорий работают как прежде

### Requirement: Страница настроек пользователя

Страница настроек пользователя (профиль, смена пароля, аватар с кроп-виджетом)
MUST работать как прежде (действующие контракты — без изменений) на токенах
«Пульт»: карточка профиля — панель `--p-bg-200` (преемственность R5:
поверхность из токена, акценты из токена), аватар и кроп-виджет — на темной
подложке (`--p-bg-000`) с рамками `--p-border`, ручки кропа различимы на dark
и hit-targets ≥ 44px на тач (преемственность дельты жестов/доступности кропа);
форма смены пароля и загрузки аватара — поля bg2, cyan-фокус, янтарные
первичные кнопки, сообщения об успехе/ошибке — статусные токены (teal/coral).

#### Scenario: Единая карточка V3

- **GIVEN** пользователь авторизован и открывает страницу настроек пользователя
- **WHEN** пользователь просматривает страницу
- **THEN** аватар, display_name, роль, bio и смена пароля находятся в одной
  визуальной карточке «Пульта» (единые токены/отступы/типографика на
  `--p-bg-200`, панельные границы и HUD-приемы; FR-55, СЦ-7); разнобоя секций
  нет. Имя сценария сохранено как якорь трассировки master-спеки; V3-темы
  после редизайна не существует — содержание заменено на токены «Пульта»

#### Scenario: Все функции Релиза 4 сохранены

- **GIVEN** пользователь находится на странице настроек пользователя
- **WHEN** пользователь редактирует display_name/роль/bio, меняет пароль и загружает аватар с выбором области
- **THEN** все операции выполняются успешно — состав и поведение полей Релиза 4 не потеряны (FR-40, FR-41, FR-42; СЦ-7)

#### Scenario: Открытие страницы настроек пользователя

- **GIVEN** пользователь авторизован
- **WHEN** пользователь переходит на страницу настроек пользователя (клик по профилю внизу сайдбара, FR-39)
- **THEN** открывается страница с единой карточкой профиля — данными своего аккаунта

#### Scenario: Негативный: неавторизованный доступ

- **GIVEN** вызывающий не имеет действующей сессии
- **WHEN** вызывающий открывает страницу настроек пользователя
- **THEN** доступ отклоняется редиректом на страницу входа; содержимое не отображается (NFR-7)

#### Scenario: Настройки пользователя — только свои данные

- **GIVEN** пользователь авторизован (логин «owner»)
- **WHEN** пользователь открывает страницу настроек пользователя
- **THEN** на странице отображаются и редактируются данные профиля «owner»; профиль второго пользователя недоступен с этой страницы

#### Scenario: Адаптив одной колонкой

- **GIVEN** пользователь авторизован
- **WHEN** страница открывается на узком экране (ширина ~375px)
- **THEN** карточка перестроена в одну колонку, горизонтальной прокрутки нет; кроп-виджет (маска, перемещение, зум) полнофункционален (FR-56, СЦ-8)

#### Scenario: Независимость от общих настроек

- **GIVEN** пользователь находится на странице настроек пользователя
- **WHEN** пользователь просматривает состав страницы
- **THEN** управление справочником категорий на странице отсутствует — оно остается в общем разделе «Настройки» сайдбара (FR-23, ОГР-20)

#### Scenario: Карточка профиля на токенах «Пульта»

- **GIVEN** пользователь открыл настройки пользователя
- **WHEN** страница отображается
- **THEN** поверхность карточки = `--color-bg-surface` (bg2), акценты из токенов,
  поля с cyan-фокусом; вид соответствует «Пульту», AA соблюден

#### Scenario: Кроп-виджет работает на dark

- **GIVEN** пользователь загружает новый аватар
- **WHEN** открывается кроп-виджет
- **THEN** область выделения и ручки различимы на темной подложке, жесты и
  доступность кропа (действующие) работают; существующие тесты кропа
  (test_r5_crop_ui) проходят без правок селекторов
