# Дельта specs: gallery — галерея «Пульт»

## ADDED Requirements

### Requirement: Сетка галереи и лайтбокс в стиле «Пульт» (FR-106)

Сетка галереи и лайтбокс MUST следовать токенам «Пульт» (заявка 1 «весь
фронт»; приемы мокапа board-console.html / tokens-console.html; действующее
поведение сетки (ритм плиток, masonry-вариант P12), загрузки, лайков,
комментариев и переименования — без изменений): плитка — поверхность
`--p-bg-200` с границей `--p-border`, hover — `--p-bg-300` + граница
`--p-border-2`, подписи — `--p-text-600`, служебные значения (размеры, даты,
счетчики) — mono; теги/категории — контурные бейджи на токенах; первичные
действия (загрузить, сохранить) — янтарные кнопки; лайтбокс — затемнение
поверх страницы, фон просмотра `--p-bg-000`, `--shadow-modal` 0 24px 56px
rgba(0,0,0,.55), элементы управления — контролы «Пульта» (cyan-фокус,
минимум декора). DOM-хуки плиток и лайтбокса сохраняются (ОГР-28).

#### Scenario: Сетка галереи на темной теме

- **GIVEN** в галерее есть изображения
- **WHEN** открывается раздел «Галерея»
- **THEN** плитки на `--p-bg-200` с hover-ступенью bg3, подписи читаемы (AA),
  ритм сетки не изменился (действующее поведение masonry/фикс-высота)

#### Scenario: Лайтбокс в визуале «Пульта»

- **GIVEN** пользователь кликнул по плитке
- **WHEN** открывается full-screen просмотр
- **THEN** фон `--p-bg-000` с модальной тенью, управление (закрытие, листание,
  лайк, комментарий, переименование) работает как прежде; фокусируемые
  элементы показывают cyan-фокус-ринг

#### Scenario: Тесты галереи без цветовых правок проходят

- **GIVEN** редизайн применен
- **WHEN** прогоняются test_qa21_gallery_ui, test_p12_gallery_rename_masonry_r8,
  test_p14_41_lightbox_swipe (нецептовые и нецветовые ассерты)
- **THEN** проходят без правок (DOM-хуки и поведение сохранены)
