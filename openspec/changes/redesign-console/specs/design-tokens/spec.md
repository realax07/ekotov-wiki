# Дельта specs: design-tokens — единый источник токенов «Пульт» (редизайн, итерация 2)

## ADDED Requirements

### Requirement: Единый источник дизайн-токенов «Пульт» (FR-99)

Прод-источником дизайн-токенов фронта MUST быть блок `:root` файла
`frontend/static/css/app.css` — дословный перенос значений из утвержденного
`design/redesign-pro/tokens-console.html` (базлайн PR #242, коммит b5a1475;
заявка Заказчика 2 «более хайтек дизайна»). Примитивы: фоны `--p-bg-000
#0e1621 / --p-bg-100 #172335 / --p-bg-200 #1d2b40 / --p-bg-300 #26354d`, границы
`--p-border #33435c / --p-border-2 #4d607c`, текст `--p-text-900 #e7edf4 /
--p-text-600 #a7b7c8 / --p-text-500 #8496a8`, янтарь `--p-amber-400 #f0b45c` +
подложка `--p-amber-900 #3a2c12`, cyan `--p-cyan-300 #4fd8eb`, статусы
`--p-teal-400 #57c4b0 / --p-coral-400 #ef7b6a / --p-violet-300 #b9a8e8`.
`color-scheme: dark` MUST быть объявлен. Семантические имена токенов
(`--color-bg-page`, `--color-accent`, `--fastline`, `--priority-*`, …) MUST
сохраниться с новыми привязками (research §3). Значения V3 «Бумага»
(`--p-paper-*`, `--p-ink-*`, `--p-clay-*`, `--p-blue-*`, `--p-red-*`,
`--p-olive-*`, `--p-amber-700`) MUST быть удалены вместе с привязками; ни один
селектор фронта не ссылается на отсутствующий токен. Токены glow
(`--glow-amber`, `--glow-cyan`), фоновая микро-сетка (`--texture-grid`,
ячейка 32px), mono-стек данных (`--font-family-data`), tracking капса
(`--tracking-caps`, `--tracking-micro`), cyan-фокус-ринг (`--focus-ring`)
и скорости (`--speed-fast` 140ms, `--speed-modal` 200ms) MUST быть определены.

#### Scenario: Перенос токенов без изменения значений

- **GIVEN** утвержденный tokens-console.html (базлайн b5a1475)
- **WHEN** dev переносит блок `:root` в app.css
- **THEN** каждое значение (hex, rgba, ms, px, stacking focus-ring) совпадает с
  мокапом-источником; `color-scheme: dark` объявлен; рендер страницы темный
  (фон `--p-bg-000`, текст `--p-text-900`)

#### Scenario: Нет ссылок на удаленные V3-токены

- **GIVEN** V3-примитивы удалены из `:root`
- **WHEN** выполняется grep по `frontend/static/css/**` и `frontend/templates/**`
  на `--p-paper-`, `--p-ink-`, `--p-clay-`, `--p-blue-`, `--p-red-`,
  `--p-olive-`, `--p-amber-700`
- **THEN** ни одного вхождения (в CSS и в inline-стилях шаблонов) нет; кроме
  того, в файлах статики нет hex-значений вне токенов (токен-дисциплина)

#### Scenario: Кеш статики инвалидирован

- **GIVEN** редизайн меняет содержимое статики при неизменных путях
- **WHEN** первая dev-волна смержена
- **THEN** `static_v` в `backend/app/pages.py` = `redesign-1` (бамп ОБЯЗАТЕЛЕН);
  все CSS/JS-подключения base.html получают `?v=redesign-1`

### Requirement: Роли акцентов — янтарь сигнал, cyan актив/фокус (FR-100)

Акцентные цвета MUST иметь разведенные роли (tokens-console.html §Semantics):
янтарь `--p-amber-400` — сигнальный цвет фастлайна (единственный), включая
glow `--glow-amber`; cyan `--p-cyan-300` — ТОЛЬКО актив/фокус: активный пункт
навигации, `:focus-visible`-ринг, `::selection`, открытый спойлер, включая glow
`--glow-cyan`; teal/coral/violet — только статусы и приоритеты (не декор).
Градиенты MUST использоваться только на данных (трек отсчета фастлайна
amber→cyan), не на декоративных поверхностях.

#### Scenario: Cyan не используется как декор

- **GIVEN** страница любого раздела открыта в обычном состоянии (без фокуса)
- **WHEN** инспектируются поверхности (панели, кнопки, фон)
- **THEN** cyan отсутствует на декоративных элементах; cyan появляется только
  у активного пункта навигации, элемента в фокусе и выделения текста

#### Scenario: Янтарный glow только на сигнале

- **GIVEN** доска с fast-задачей
- **WHEN** инспектируются элементы с янтарным свечением
- **THEN** это только фастлайн (панель), fast-карточка и кнопка «Новая задача»
  на hover — элементов с янтарным glow вне сигнала фастлайна нет

### Requirement: Техноязык «Пульт» — HUD, LED, микро-лейблы, сетка (FR-101)

Панельные поверхности MUST использовать паттерн HUD-уголков (8 отрезков 12×1px /
1×12px по углам через `::after`, цвет `--p-border-2`; на фастлайне — янтарь),
где мокап это задает (фастлайн, колонки доски, спойлер). Статусные точки
(LED 6–8px со свечением) MUST применяться: бренд сайдбара (teal), заголовки
колонок доски (t500/amber-blink/teal), readout заголовка страницы, статусы
строк таблиц, метка фастлайна (amber, blink 2s step-end). Микро-лейблы капсом
MUST набираться mono 10–11px с `letter-spacing .14em` (SYS/FST/CODE-метки,
`.wiki .path`, `.brand-sub`). Данные (счетчики, даты, id, отсчеты, uptime)
MUST набираться `--font-family-data`. Фон страницы MUST включать микро-сетку
`--texture-grid` (1px, ячейка 32px).

#### Scenario: Панель с HUD-уголками

- **GIVEN** страница доски открыта
- **WHEN** инспектируются фастлайн и колонки
- **THEN** у каждой панели отрисованы угловые метки HUD (8 отрезков) цветом
  `--p-border-2`; у фастлайна — янтарные

#### Scenario: LED отражает состояние

- **GIVEN** доска с колонками «Ожидает», «В работе», «Выполнено»
- **WHEN** инспектируются LED заголовков колонок
- **THEN** «Ожидает» — нейтральная точка t500, «В работе» — янтарная с
  свечением и blink, «Выполнено» — teal со свечением; анимация blink
  отключается при prefers-reduced-motion

#### Scenario: Данные — моноширинно

- **GIVEN** открыты доска (счетчики колонок, даты карточек) и заголовок страницы
- **WHEN** проверяется font-family счетчиков, дат, readout-строки
- **THEN** используется `--font-family-data` (mono), микро-лейблы — uppercase
  с letter-spacing .14em
