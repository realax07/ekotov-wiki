# Дельта specs: video-ui — экран «Видео» «Пульт» (новая capability)

## ADDED Requirements

### Requirement: Экран «Видео» в стиле «Пульт» (FR-107)

Экран «Видео» MUST следовать токенам «Пульт» и приемам техноязыка (заявка 1
«весь фронт»; приемы мокапа board-console.html / tokens-console.html;
действующая функциональность видео-раздела — без изменений): карточки/список
видео — панели `--p-bg-200` с границей `--p-border` и hover-ступенью bg3;
продолжительность/даты/размеры — mono (данные); статусы обработки — LED-точки
(teal готово / янтарь blink в обработке / coral ошибка); заголовок страницы —
pagehead с readout (mono-счетчики); первичные действия — янтарные кнопки;
плеер/просмотр — темная поверхность `--p-bg-000` c `--shadow-modal`. DOM-хуки
экрана сохраняются (ОГР-28).

#### Scenario: Список видео в визуале «Пульта»

- **GIVEN** в видео-разделе есть записи в разных статусах обработки
- **WHEN** открывается экран «Видео»
- **THEN** карточки на `--p-bg-200`, длительности/даты mono, статусы
  LED-точками (teal/amber blink/coral), вид соответствует токенам «Пульта»

#### Scenario: Функциональность видео не деградировала

- **GIVEN** редизайн применен
- **WHEN** прогоняются тесты видео (test_video_ui, test_video_convert_ui,
  test_video_rename_ui, test_video_social_ui — нецветовые ассерты)
- **THEN** загрузка, конвертация, переименование, комментарии работают как
  прежде
