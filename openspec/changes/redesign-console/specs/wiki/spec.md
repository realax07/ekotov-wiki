# Дельта specs: wiki — страница и rich-контент «Пульт»

## MODIFIED Requirements

### Requirement: Breadcrumb на странице статьи

Breadcrumb статьи wiki MUST отображаться как прежде (действующий контракт пути
и ссылок — без изменений) в визуале «Пульта» (мокап board-console.html
§wiki-head): цепочка — микро-лейбл mono 11px, uppercase, letter-spacing .08em,
цвет `--p-text-500`; заголовок статьи h1 26px `--p-text-900`, лид-абзац —
`--p-text-600`; статья отделена от доски/шапки разделителем-треком (пунктирная
линия 1px, repeating-linear-gradient) вместо сплошной.

#### Scenario: Полная цепочка предков

- **GIVEN** существует страница третьего уровня вложенности (корень →
  раздел → статья)
- **WHEN** пользователь открывает страницу статьи
- **THEN** breadcrumb показывает цепочку «корень → раздел → статья»; каждый
  элемент — кликабельная ссылка на соответствующую страницу (FR-109)

#### Scenario: Breadcrumb корневой страницы

- **GIVEN** пользователь открыл корневую страницу wiki
- **WHEN** пользователь просматривает breadcrumb
- **THEN** цепочка состоит из одного элемента — текущей страницы (без
  ссылки на саму себя) (FR-109)

#### Scenario: Breadcrumb в стиле микро-лейбла

- **GIVEN** открыта страница wiki по адресу «wiki / серверы / домашний кластер»
- **WHEN** проверяется шапка статьи
- **THEN** breadcrumb набран mono капсом цветом `--p-text-500`, ссылки ведут
  как прежде, заголовок 26px на токенах «Пульта»

## ADDED Requirements

### Requirement: Отображение rich-контента в стиле «Пульт» (FR-104)

Rich-контент страниц wiki (h2/h3, спойлер, код-блок, таблица — существующая
функциональность p12-rich-tools; санитизация и редактор — без изменений) MUST
отображаться в визуале утвержденного мокапа (board-console.html §wiki):

- **h2** — 17px 650, слева inset-полоса teal 3px (`box-shadow: inset 3px 0 0
  var(--status-success)`), отступ 28px сверху;
- **h3** — 15px 600, цвет `--p-text-600`;
- **спойлер** (`details.spoiler`) — панель `--p-bg-100` с границей
  `--p-border` и HUD-уголками; summary — 14px 600, hit-target ≥ 40px; открытый
  спойлер — cyan-рамка rgba 45% + glow `--glow-cyan` и разделительная граница
  под summary; тело спойлера — `--p-text-600`; спойлер свернут по умолчанию
  (преемственность p12-rich-2);
- **код-блок** (`pre`) — mono 13px, фон `--p-bg-100`, граница `--p-border`,
  радиус 8px, горизонтальный скролл;
- **таблица** — границы `--p-border`, заголовки th капсом 11px на
  `--p-bg-100`, caption сверху слева капсом 12px `--p-text-600`; числовые
  ячейки — mono с выравниванием вправо; статусные ячейки — LED-точка перед
  текстом (teal со свечением «активен» / нейтральная «спит»); hover строки —
  фон `--p-bg-100`.

#### Scenario: Заголовки h2/h3 по мокапу

- **GIVEN** страница wiki содержит h2 и h3
- **WHEN** страница отображается
- **THEN** h2 с teal-полосой слева, h3 приглушен (`--p-text-600`); размеры и
  отступы соответствуют мокапу

#### Scenario: Спойлер — сигнализация открытия

- **GIVEN** страница wiki со спойлером
- **WHEN** пользователь раскрывает спойлер
- **THEN** рамка становится cyan (rgba 45%), появляется glow `--glow-cyan`,
  содержимое читаемо (AA); повторное закрытие возвращает нейтральный вид

#### Scenario: Код-блок и таблица на темной теме

- **GIVEN** страница wiki содержит код-блок и таблицу со статусной колонкой
- **WHEN** страница отображается
- **THEN** код на `--p-bg-100` mono с горизонтальным скроллом; таблица с
  капс-заголовками, числа mono вправо, статусы с LED-точками (teal/нейтраль),
  hover строки — `--p-bg-100`; контраст всех текстов ≥ 4.5:1

#### Scenario: Rich-контент не ломается санитизацией и редактором

- **GIVEN** редизайн применен
- **WHEN** прогоняются тесты rich-контента (test_rich_tools, p15_wiki_page,
  p15_wiki_editor — нецветовые ассерты)
- **THEN** создание/просмотр h2/h3, спойлера, код-блока, таблицы работают как
  прежде (меняется только CSS отображения)

### Requirement: Визуальный стиль страниц Wiki «Пульт» (FR-105)

Все страницы wiki (дерево, чтение, редактор, история) MUST следовать токенам
«Пульт» и паттернам каркаса (заявка 1 «весь фронт»): дерево страниц — панель на
`--p-bg-100`, активная вкладка/узел — cyan по общему паттерну активности;
подсветка найденного в дереве — инверсная янтарная (фон `--p-amber-900`, текст
`--p-amber-400`); редактор и история — те же поля/панели, что и весь фронт
(bg2-поля, cyan-фокус, янтарные первичные кнопки); wiki не использует внешних
зависимостей (действующее требование сохраняется).

#### Scenario: Дерево страниц в визуале «Пульта»

- **GIVEN** открыт раздел Wiki с деревом страниц
- **WHEN** проверяется дерево
- **THEN** панель на `--p-bg-100`, активный узел с cyan-сигнализацией, поиск
  подсвечивает совпадения янтарной инверсией; контраст AA

#### Scenario: Редактор и история на токенах «Пульта»

- **GIVEN** пользователь открывает редактор статьи и историю версий
- **WHEN** страницы отображаются
- **THEN** поля, кнопки и панели на общих токенах (cyan-фокус, янтарные
  первичные действия); функциональные тесты editor/history проходят без
  правок селекторов
