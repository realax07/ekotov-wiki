# Дельта specs: weather-ui — экран «Погода» «Пульт» (новая capability)

## ADDED Requirements

### Requirement: Экран «Погода» в стиле «Пульт» (FR-108)

Экран «Погода» MUST следовать токенам «Пульт» и mission-control-приемам
утвержденной итерации 2 (заявки 1–2; приемы мокапа board-console.html /
tokens-console.html; действующая функциональность сервиса погоды — без
изменений): страница — pagehead с h1 и терминальным readout (mono: точка
наблюдения, время обновления, teal-LED); основная карточка текущей погоды —
панель `--p-bg-100` с HUD-уголками, значение температуры — крупно
(`--font-size-display`) mono, служебные параметры (ветер, влажность, давление)
— микро-лейблами капсом с mono-значениями; прогноз — ряд/таблица на токенах
(границы `--p-border`, mono-числа); экстремальные значения (порывы, осадки)
могут подсвечиваться статусными цветами (coral/amber) — не декоративно.
DOM-хуки экрана сохраняются (ОГР-28).

#### Scenario: Текущая погода как readout панели

- **GIVEN** сервис погоды возвращает актуальные данные
- **WHEN** открывается экран «Погода»
- **THEN** карточка на `--p-bg-100` с HUD-уголками, температура крупно mono,
  параметры микро-лейблами капсом, readout в pagehead с teal-LED; вид
  соответствует токенам «Пульта»

#### Scenario: Ошибка/пустые данные в стиле «Пульта»

- **GIVEN** сервис погоды недоступен или данных нет
- **WHEN** открывается экран «Погода»
- **THEN** существующее сообщение о недоступности отображается на токенах
  (`--status-error`, AA), без «поломанной» верстки

#### Scenario: Тесты погоды без цветовых правок проходят

- **GIVEN** редизайн применен
- **WHEN** прогоняется test_weather_ui (нецептовые и нецветовые ассерты)
- **THEN** проходит без правок селекторов
