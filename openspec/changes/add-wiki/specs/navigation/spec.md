# Дельта specs: navigation — раздел Wiki становится полноценным (P15)

## MODIFIED Requirements

### Requirement: Пустой раздел Wiki с пометкой todo

> **Дельта P15 (add-wiki)**: прежняя редакция («Сайдбар MUST содержать раздел
> «Wiki» — пустой, с пометкой todo (FR-13). Wiki-функционал в этом релизе
> MUST отсутствовать (Won't)…») ЗАМЕНЯЕТСЯ приведенной ниже — Won't
> снимается, раздел становится полноценным.

Сайдбар MUST содержать раздел «Wiki» (FR-13), ведущий на рабочую страницу
`/wiki` — полноценный раздел wiki-функционала (FR-107…FR-116; функции
определены в capability `wiki`). Won't прежнего релиза («пустой раздел с
пометкой todo, wiki-функционал отсутствует») СНИМАЕТСЯ данным пакетом:
раздел больше НЕ является заглушкой. Для авторизованного пользователя пункт
«Wiki» MUST открывать `/wiki` — список корневых страниц с поддеревьями
(дерево страниц, capability wiki). Для неавторизованного пользователя
страница `/wiki` MUST выполнять редирект на `/login` (как остальные страницы
функционала). Порядок разделов сайдбара НЕ меняется: «Wiki» остается третьим
пунктом, перед «Галереей» (преемственность FR-85). Вид пункта — существующий,
без редизайна (мокапы дизайн-фазы пакета покрывают страницы Wiki, не пункт
сайдбара).

#### Scenario: Раздел Wiki отображается как заглушка

> Имя сценария сохранено из прежней редакции для непрерывности трассировки;
> содержание инвертировано — заглушки больше нет.

- **GIVEN** пользователь авторизован и видит сайдбар
- **WHEN** пользователь просматривает сайдбар и раздел Wiki
- **THEN** раздел «Wiki» присутствует в сайдбаре (пометки «todo» нет) и
  ведет на рабочую страницу `/wiki` со списком корневых страниц (FR-107);
  прежняя заглушка отсутствует

#### Scenario: Раздел Wiki не дает wiki-функций

> Имя сценария сохранено из прежней редакции; содержание инвертировано —
> функции теперь есть.

- **GIVEN** пользователь авторизован
- **WHEN** пользователь выбирает раздел «Wiki» в сайдбаре
- **THEN** wiki-страницы можно создавать, редактировать и находить поиском —
  раздел предоставляет полный функционал capability `wiki`
  (FR-108…FR-114); прежний Won't («никаких функций — заглушка») снят

#### Scenario: Переход в Wiki через сайдбар

- **GIVEN** пользователь авторизован и находится на любой странице функционала
- **WHEN** пользователь выбирает в сайдбаре раздел «Wiki»
- **THEN** открывается страница `/wiki` — список корневых страниц с
  поддеревьями (FR-107); заглушки «todo» нет

#### Scenario: Пункт Wiki в существующем порядке сайдбара

- **GIVEN** пользователь авторизован и просматривает сайдбар
- **WHEN** пользователь проверяет порядок разделов
- **THEN** «Wiki» — третий пункт, перед «Галереей» (порядок: Доска, Поиск,
  Wiki, Галерея — как прежде, FR-85); существующие разделы и блок профиля
  работают без изменений

#### Scenario: Неавторизованный доступ к Wiki

- **GIVEN** сессия отсутствует
- **WHEN** пользователь открывает `/wiki` напрямую
- **THEN** выполняется редирект на `/login` (паттерн остальных страниц
  функционала, FR-115)

#### Scenario: Wiki-функции доступны из раздела

- **GIVEN** пользователь авторизован и находится на `/wiki`
- **WHEN** пользователь работает с разделом
- **THEN** создание/редактирование страниц, история версий и поиск по статьям
  ДОСТУПНЫ в соответствии с capability `wiki` (FR-108…FR-114) — прежний
  Won't («функции отсутствуют») больше не действует
