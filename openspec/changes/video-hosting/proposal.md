# Proposal: video-hosting

## Change ID

`video-hosting`

## Why

Пакет P11 «Видеохостинг wiki» (PRODUCT_BACKLOG P11; PLAN-video-hosting.md,
решения Заказчика 2026-10-17). Вводные Заказчика (ОВ-1…ОВ-4, все развилки
решены — блокирующих вопросов нет):

- **ОВ-1** = лимит размера **500 МБ** на файл;
- **ОВ-2** = доступ **только авторизованные** пользователи wiki, **без
  публичных ссылок**;
- **ОВ-3** = отдельный сервис **«Видео» в сайдбаре**, в статьи wiki видео
  НЕ вставляем;
- **ОВ-4** = принимаем **любой** видеоформат → серверная конвертация в
  **mp4** (ffmpeg, фоновая задача со статусами «загружено → конвертируется →
  готово»); оригинал после успешной конвертации удаляется (экономия диска;
  Заказчик уведомлен).

Полное ТЗ — `requirements.md` пакета (статус DRAFT r1 — на утверждении
Заказчиком). Паттерны-прецеденты: `services/images` (контейнерный сервис,
том вне БД, лимит до записи, сессионный middleware), master-spec `gallery`
(nginx-маршрутизация, управляемая деградация 503), FR-84/85 (паритет
доступа, пункт сайдбара).

## Scope

### In scope

- Контейнерный сервис `video` (FastAPI, `services/video/`, порт 8380,
  по образцу `services/images`): upload multipart с лимитом 500 МБ
  (проверка ДО записи на диск), список с поиском/сортировкой по имени,
  удаление, отдача mp4/превью только по сессии; healthcheck `/api/health`;
  сессионный middleware (паттерн images/search, без права писать в
  sessions).
- Фоновая конвертация в mp4: subprocess ffmpeg (статический бинарь
  в образе), статусы в БД, один автоматический ретрай, удаление оригинала
  после успеха, превью первого кадра. Без брокера очередей (вне скоупа,
  PLAN).
- deploy: сервис в `deploy/compose.yaml` (mem_limit, healthcheck,
  ротация логов, без публикуемых портов), том `videos-data`, nginx:
  `/api/videos*` + аутентифицированная отдача `/videos/` (auth_request),
  деградация 503 по паттерну images.
- Миграция ядра: таблица `video_videos` (метаданные) — one-shot,
  владелец — сервис `video`.
- Фронтенд: страница `/video` (список, загрузка, плеер `<video>`,
  удаление с подтверждением), пункт «Видео» в сайдбаре — по утвержденным
  мокапам (дизайн-фаза ДО dev, Д-паттерн).
- Замеры NFR-35/37 на стенде до прод-выкатки (REPORT).

### Out of scope

- HLS / несколько разрешений, очереди воркеров-конвертеров (брокер),
  каналы/комментарии/лайки, публичные ссылки по токену (Уровень 2+,
  PLAN).
- Вставка видео в статьи wiki (ОВ-3 — запрещено).
- Таблицы ядра, editor, доска, поиск, галерея — без изменений.

## Approach

Три куска PLAN с живой приемкой каждого (A ядро → B конвертация →
C полировка), дизайн-фаза ui_designer + утверждение Заказчика ДО
dev-задач куска A. Техрешения — `design.md`; декомпозиция модулей
монолита `services/video` и швы нарезки — `sdd.md`. tasks.md пишет
архитектор после ревью пакета (Флоу 1).
