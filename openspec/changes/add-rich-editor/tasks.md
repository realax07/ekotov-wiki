# tasks.md — add-rich-editor

Флоу 1 (СА → архитектор → dev → QA → ревью). Формат задач: задача =
наблюдаемый результат + критерий проверки + зона файлов + трассировка.
Зоны задач не пересекаются (швы — в конце файла, проверка
`skills/service-decomposition/scripts/seam_checker.py`); [P] — только для
задач с доказанно непересекающимися зонами. Директива Заказчика: декомпозиция
модулей обязательна (design §2, §3) — НЕТ задачи «сделать editor.js», есть
задачи по модулям. Два контейнера задач = две волны dev (design §5): волна 2
не стартует до зеленого регресс-теста 1.7 волны 1.
