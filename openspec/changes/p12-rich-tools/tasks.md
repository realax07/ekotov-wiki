# tasks.md — p12-rich-tools (P12 «rich-контент wiki», переделка с нуля)

Формат: волны по design.md §9. Каждая задача — проверяемый шов с указанием
файлов и сценария приемки. Мокапы-эталоны: `design/p12-rich/tool-N-*.png`
(edit+view) — соответствие вида проверяется в волнах 2–5 и финально в 6.

## Волна 1. Фундамент: словарь, санитайзер, round-trip

- [ ] 1.1 `rich/model.js`: константы словаря блоков (design.md §1: enum
  `data-block`/`data-block-part`/`data-lang`, лимит вкладок 8, лимит
  глубины 5). Проверка: модуль импортируется editor.js/page.js без циклов.
- [ ] 1.2 Санитайзер: `backend/app/sanitize.py` — whitelist data-атрибутов
  div'ов с enum-валидацией, счетчик глубины 5 (unwrap глубже), код-блок —
  только pre/code/текст внутри (design.md §2). Проверка:
  `tests/api/test_sanitize.py` — новые кейсы (валидные блоки проходят;
  `data-block="evil"` снимается; глубина 6 → unwrap; script в спойлере
  режется с содержимым; страница без блоков — байт-в-байт).
- [ ] 1.3 Round-trip через API (`tests/api/test_wiki_rich.py`): PUT контента
  со всеми блоками и вложенностями матрицы §6 → GET идентичен; revert
  версии с блоками возвращает контент. Проверка: pytest зелен.
- [ ] 1.4 Каркас активации в page.js: per-block try/catch, неизвестный
  `data-block` пропускается (деградация NFR-39). Проверка: web-тест
  деградации.

## Ворота и правила
