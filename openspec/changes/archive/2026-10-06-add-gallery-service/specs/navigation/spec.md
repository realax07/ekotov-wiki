# Дельта specs: navigation — раздел «Галерея» в сайдбаре (ADDED)

## ADDED Requirements

### Requirement: Раздел «Галерея» в сайдбаре для всех

Сайдбар MUST содержать раздел «Галерея» — **ЧЕТВЕРТЫМ пунктом**, после
раздела «Wiki» (ОВ-3, FR-85). Раздел MUST вести на страницу галереи
(`/gallery`) и MUST отображаться **всем** авторизованным пользователям —
owner и PE паритетно, без рендера по роли (ОВ-4; преемственность
navigation: разделы сайдбара доступны на страницах функционала). Вид
пункта (иконка, состояния) — по мокапам ui_designer, утвержденным
Заказчиком ДО dev; после dev соответствие мокапам проверяет
design_validator (FR-86).

#### Scenario: Пункт «Галерея» — четвертый в сайдбаре

- **GIVEN** пользователь авторизован и находится на любой странице
  функционала
- **WHEN** пользователь просматривает сайдбар
- **THEN** присутствует раздел «Галерея» четвертым пунктом, после «Wiki»
  (порядок: Доска, Поиск, Wiki, Галерея); существующие разделы и блок
  профиля работают как прежде

#### Scenario: Оба пользователя видят раздел паритетно

- **GIVEN** владелец (owner) и второй пользователь (PE) авторизованы в
  своих сессиях
- **WHEN** каждый просматривает сайдбар
- **THEN** раздел «Галерея» присутствует у обоих — без разделения по
  роли (ОВ-4)

#### Scenario: Переход в галерею через сайдбар

- **GIVEN** пользователь авторизован
- **WHEN** пользователь выбирает раздел «Галерея» в сайдбаре
- **THEN** открывается страница галереи (`/gallery`): сетка превью,
  фильтры категория/тег, форма загрузки

#### Scenario: Вид пункта по утвержденным мокапам

- **GIVEN** мокапы интерфейса галереи утверждены Заказчиком (дизайн-фаза
  пакета)
- **WHEN** dev внедряет интерфейс
- **THEN** фактический вид сетки, карточек, full-screen просмотра, формы
  загрузки и пункта сайдбара соответствует утвержденным мокапам;
  соответствие проверяет design_validator (ревью против мокапов, FR-86)
