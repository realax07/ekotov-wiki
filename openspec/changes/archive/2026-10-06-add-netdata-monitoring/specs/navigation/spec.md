# Дельта specs: navigation — ссылка на мониторинг (ADDED)

## ADDED Requirements

### Requirement: Ссылка «Мониторинг» в сайдбаре для owner

Сайдбар MUST содержать ссылку «Мониторинг» в нижнем левом блоке
(`sidebar-footer`), рядом с разделом «Настройки» и кнопкой выхода (вводные
Заказчика: «В UI в нижнем левом углу сделай просто ссылку на нее»). Ссылка
MUST вести на `/netdata/` и открывать дашборд в новой вкладке
(`target="_blank"`). Ссылка MUST отображаться только пользователю с ролью
owner — рендер выполняется по роли из `GET /api/auth/me` (серверная
проверка доступа остается за nginx, см. capability monitoring); до получения
ответа и при 401 ссылка MUST NOT отображаться (паттерн блока профиля).
Пользователи с ролью PE и неавторизованные ссылку MUST NOT видеть.

#### Scenario: Owner видит ссылку и открывает дашборд

- **GIVEN** владелец (роль owner, логин `owner`) авторизован в wiki и
  находится на любой странице функционала
- **WHEN** он смотрит нижний левый блок сайдбара
- **THEN** присутствует ссылка «Мониторинг» рядом с «Настройки»/«Выйти»;
  клик открывает дашборд мониторинга в новой вкладке (FR-78)

#### Scenario: PE и неавторизованный ссылку не видят

- **GIVEN** пользователь с ролью PE авторизован (или сессии нет)
- **WHEN** любая страница функционала отрисована
- **THEN** ссылки «Мониторинг» в сайдбаре нет — существующие разделы и блок
  профиля работают как прежде (ОВ-2, FR-78)

#### Scenario: Скрытие ссылки не является границей доступа

- **GIVEN** пользователь PE знает адрес `/netdata/`
- **WHEN** он открывает его напрямую
- **THEN** доступ закрывает nginx basic auth (401 без кредов owner) —
  скрытие ссылки только удобство интерфейса (OV-2, преемственность
  monitoring: «Доступ к дашборду — только учетка owner через nginx»)

#### Scenario: Вид ссылки по утвержденному мокапу

- **GIVEN** мокап пункта сайдбара утвержден Заказчиком (дизайн-фаза пакета)
- **WHEN** dev внедряет ссылку
- **THEN** фактический вид (место, иконка, состояния hover/focus/active)
  соответствует утвержденному мокапу; соответствие проверяет design_validator
  (ревью против мокапа)
