# Proposal: redesign-console

## Change ID

`redesign-console`

## Why

Профессиональный редизайн всего фронта ekotov-wiki (Флоу 1). Заявки Заказчика
(дословно, Telegram DM):

1. «давай сделаем профессиональный редизайн фронта ekotov» → представлены 3
   направления (Типографская / Пульт / Керамика) с мокапами.
2. «мне нравится вариант Б. Но хотелось бы более хайтек дизайна» → итерация 2
   направления Б «Пульт»: high-tech / mission-control (HUD-уголки, glow, фоновая
   микро-сетка, LED-статусы, микро-лейблы, терминальные readouts, второй акцент
   cyan #4fd8eb).
3. «Давай» + «Qa и вадидацию не забудь» → утверждение итерации 2 + обязательный
   полный QA-контур.

**Утвержденный базлайн (источник правды по визуалу):**
`design/redesign-pro/board-console.html` + `design/redesign-pro/tokens-console.html`
(коммит b5a1475, слияние PR #242; фиксация утверждения —
`design/redesign-pro/README.md` § «Утверждение направления (2026-10-23)»,
коммит a2685ee). Дальнейшие итерации визуала — только через новый change-пакет.

Требования = утвержденные заявки: полный редизайн ВСЕХ экранов на токены «Пульт»
с сохранением функционального поведения (это визуальная дельта, не behavioral).

Сопровождающие технические изменения (design.md, impact.md): замена блока

перевод всех CSS-файлов фронта на семантические токены, редизайн favicon в
палитре «Пульта» (бамп cache-маркера `?v=`), **обязательный бамп `static_v` →
`redesign-1`** (единственная точка в `backend/app/pages.py:57`; логика бэкенда,
openapi-контракты и деплой-матрица НЕ меняются — проверено grep-ом, см. impact.md).
Существующие web-тесты с цветовыми ассертами на V3-токены СЛОМАЮТСЯ — полный
список с причинами в impact.md и задаче QA-контура.

Сквозная нумерация требований: новые требования пакета получают **FR-123…FR-132
и NFR-41…NFR-44** — свободные значения: мастер-спеки уже используют FR-107…FR-116

и NFR-23…NFR-26, video-hosting — FR-116/FR-117, p12-rich-tools — NFR-39/40.
Ссылки дельт на существующие требования мастеров (FR-44/45/109 и др.) сохранены
без изменений.

## Scope

### In scope

- Весь фронт: base-каркас/сайдбар, login, доска, фастлайн, wiki (+rich-контент),
  галерея, видео, погода, поиск, настройки/профиль.
- Мобильная раскладка (брейкпоинты ≤860px каркас/доска, ≤900px таблицы — как в
  утвержденных мокапах).
- Доступность: контраст WCAG 2.1 AA (программная проверка пар), `:focus-visible`
  с cyan-фокус-рингом, `prefers-reduced-motion`, skip-link.
- Favicon в палитре «Пульта» (inline SVG data-URI, ОГР-8 — без внешних файлов).
- Полный QA-контур: qa_impact_analysis → qa_checklist → qa_author +
  qa_case_reviewer → qa_automation (TC-redesign-NNN) + правка сломавшихся
  существующих web-тестов.
- Бамп `static_v` = `redesign-1`.

### Out of scope

- Любые изменения backend-логики, API-контрактов, openapi, деплой-матрицы
  (кроме однострочного бампа `static_v` в `pages.py`).
- Новые функции экранов (только визуал/тема; поведение по действующим спекам).
- Смена DOM-id и структурных CSS-хуков, на которых держатся тесты и JS
  (ОГР-28) — классы-хуки (`.nav-item`, `.task-card`, `.fastline` и т.п.)
  сохраняются.
- Токены V3 «Бумага» как параллельная тема (переключателя тем нет — полная
  замена, решение «редизайн» из заявки 1).
- games-раздел (внутренние страницы мини-игр) — каркасные стили прилетают через
  base; собственные стили игр вне дельты.

## Approach

1. Токены `tokens-console.html` переносятся dev-ом в `:root` `app.css` (снимок
   без изменений значений; прод-источник токенов с этого момента — app.css,
   design/tokens.html V3 архивируется вместе с пакетом).
2. Волны dev по экранам (см. tasks.md), каждая на семантических токенах, без
   хардкода цветов; DOM-хуки сохранены; static_v бампится один раз в первой
   dev-волне.
3. После dev — полный QA-контур (J39, H5): impact-анализ по MODIFIED-дельтам
   (весь фронт), чеклист, кейсы из дельт (не из кода), автоматизация
   TC-redesign-NNN, фикс/замена сломавшихся V3-ассертов.
4. Финал — regress-final на всех наборах (api → web-desktop → web-mobile →
   смок) и валидация Заказчиком («Qa и вадидацию не забудь»).

## Capabilities

### New capabilities

- `design-tokens`: единый источник дизайн-токенов «Пульт», роли акцентов, техноязык.
- `video-ui`: визуальный контракт экрана «Видео».
- `weather-ui`: визуальный контракт экрана «Погода».
- `accessibility`: сквозные требования доступности фронта.

### Modified capabilities

- `navigation`, `auth`, `board`, `fastline`, `wiki`, `gallery`, `search`, `settings`.
