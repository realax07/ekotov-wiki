## Приемы техноязыка (design §«Приемы» 1–7)

1. **HUD-уголки** ✅ `app.css:155–173` — 8 отрезков 12×1/1×12, `--hc`=border-2; янтарные на фастлайне `board.css:1862–1863`; применены к фастлайну/колонкам (`board.html:67,101,110,119`), login (`login.css:42`).
2. **Glow только на сигнале/активе** ✅ `--glow-amber`: `board.css:271,808,828,1860`; `--glow-cyan`: спойлер `wiki.css:1749`, фокус-ринг `app.css:96`. Неона/декоративного glow нет (grep подтверждает только перечисленные точки).
3. **Микро-сетка** ✅ `app.css:135–138` (body, 32px), login `login.css:32–35`.
4. **LED-статусы** ✅ бренд/колонки (t500/amber-blink/teal, `led-blink 2s step-end`), readout `board.html:48–53` (aria-hidden, заполняется cards.js из реальных данных — «читаемость состояния», не фейк).
5. **Микро-лейблы** ✅ mono 10–11px + `--tracking-micro` (.14em): FST/CODE-метки (`board.css:257`, `board.html:70`), `.brand-sub`.
6. **Терминальные readouts** ✅ «SYS NOM · дата · ACT N · DONE N» `board.html:48–53`; mono-счетчики колонок (cards.js).
7. **Роли акцентов** ✅ amber — только фастлайн/сигнал; cyan — только актив/фокус (`app.css:303–322`: bg2 + cyan-border 45% + cyan-LED + cyan-иконка); teal/coral/violet — статусы/приоритеты; градиент только на данных — трек отсчета `board.css:302` `linear-gradient(90deg, var(--fastline), var(--accent-cyan))`.
