# Delta: board

## ADDED Requirements

### Requirement: Отображение канбан-доски
Приложение MUST показывать авторизованному пользователю страницу канбан-доски со всеми его задачами, разложенными по столбцам (FR-1).

#### Scenario: Открытие доски с задачами
- **GIVEN** пользователь авторизован и в системе есть задачи в разных столбцах
- **WHEN** пользователь открывает страницу доски
- **THEN** все задачи отображаются в столбцах, соответствующих их текущему статусу

#### Scenario: Открытие пустой доски
- **GIVEN** пользователь авторизован и в системе нет ни одной задачи
- **WHEN** пользователь открывает страницу доски
- **THEN** доска отображается с тремя пустыми столбцами без ошибок

### Requirement: Три фиксированных столбца
Доска MUST содержать ровно три столбца: «Ожидает», «В работе», «Выполнено» (FR-2). Состав столбцов MUST быть неизменяемым пользователем (ОГР-3).

#### Scenario: Состав столбцов доски
- **GIVEN** пользователь авторизован
- **WHEN** пользователь открывает страницу доски
- **THEN** доска содержит ровно три столбца с названиями «Ожидает», «В работе», «Выполнено» и никакие другие

### Requirement: Столбец «Выполнено» показывает задачи текущего МСК-дня
Столбец «Выполнено» MUST отображать задачи в статусе done, момент перевода которых в done приходится на текущий календарный день по МСК (UTC+3). Задачи, выполненные в предыдущие календарные дни по МСК, MUST НЕ отображаться на доске (автоархивация, FR-4). Архивные задачи MUST НЕ отображаться ни в одном столбце (без изменений).

#### Scenario: Выполненная сегодня задача видна в столбце «Выполнено»
- **GIVEN** пользователь авторизован и сегодня по МСК перевел задачу в «Выполнено»
- **WHEN** пользователь открывает страницу доски
- **THEN** задача отображается в столбце «Выполнено»

#### Scenario: Выполненная вчера задача не видна на доске
- **GIVEN** пользователь авторизован и задача была переведена в «Выполнено» вчера по МСК (или ранее)
- **WHEN** пользователь открывает страницу доски
- **THEN** задача отсутствует во всех столбцах доски (архивирована автоматически)

### Requirement: Перемещение задач между столбцами
Пользователь MUST иметь возможность перемещать задачу между столбцами «Ожидает» → «В работе» → «Выполнено» и обратно (FR-6). Перевод в «Выполнено» НЕ удаляет задачу с доски: она остается в столбце «Выполнено» до следующего календарного дня по МСК, после чего автоматически архивируется (FR-4; изменение Заказчика).

#### Scenario: Прямое перемещение по цепочке столбцов
- **GIVEN** задача находится в столбце «Ожидает»
- **WHEN** пользователь перемещает задачу в «В работе», затем в «Выполнено»
- **THEN** задача последовательно занимает целевые столбцы и остается видимой в столбце «Выполнено»

#### Scenario: Обратное перемещение
- **GIVEN** задача находится в столбце «В работе»
- **WHEN** пользователь перемещает задачу обратно в «Ожидает»
- **THEN** задача отображается в столбце «Ожидает»

### Requirement: Быстрый доступ к действию «Выполнено»
Перевод задачи в «Выполнено» MUST быть доступен из любого столбца доски (FR-4); действие завершает рабочий цикл задачи — задача остается в столбце «Выполнено» до автоархивации следующим МСК-днем.

#### Scenario: Завершение задачи из столбца «Ожидает»
- **GIVEN** задача находится в столбце «Ожидает»
- **WHEN** пользователь выполняет действие перевода задачи в «Выполнено»
- **THEN** задача занимает столбец «Выполнено» (без прохода через промежуточный столбец) и остается на доске до наступления следующего календарного дня по МСК
