# Delta: archive

## ADDED Requirements

### Requirement: Автоархивация выполненных задач
Задача, переведенная в «Выполнено», MUST оставаться видимой на доске в столбце «Выполнено» до наступления следующего календарного дня по МСК (UTC+3) относительно момента перевода в done. С наступлением следующего календарного дня по МСК задача MUST архивироваться автоматически: проставляется `archived_at`, задача исчезает с доски и попадает в архив (FR-4; изменение Заказчика — мгновенная архивация из прежней редакции заменена отложенной на следующий МСК-день).

#### Scenario: Задача, выполненная сегодня, остается на доске до полуночи МСК
- **GIVEN** задача находится в столбце «В работе», текущий момент — сегодня по МСК
- **WHEN** пользователь переводит задачу в «Выполнено»
- **THEN** задача отображается в столбце «Выполнено» и остается на доске до 00:00 МСК следующего календарного дня

#### Scenario: С наступлением следующего дня МСК задача архивируется автоматически
- **GIVEN** задача находится в столбце «Выполнено», момент перевода в done приходится на предыдущий календарный день по МСК
- **WHEN** наступает следующий календарный день по МСК и доска открывается/обновляется
- **THEN** задаче проставлен `archived_at` и задача исчезает с доски

#### Scenario: Архивная задача не возвращается на доску сама
- **GIVEN** задача находится в архиве
- **WHEN** пользователь открывает доску
- **THEN** архивная задача не отображается ни в одном столбце

## ADDED Requirements

### Requirement: Архивация фиксирует момент перевода в done
Система MUST фиксировать момент перевода задачи в «Выполнено» (`done_at`): он проставляется при переводе в done и служит точкой отсчета календарной границы автоархивации; при обратном переводе из done `done_at` MUST сниматься. До автоархивации задача со статусом done имеет `archived_at` пустым (FR-4).

#### Scenario: Момент перевода в done зафиксирован
- **GIVEN** задача находится в столбце «В работе»
- **WHEN** пользователь переводит задачу в «Выполнено»
- **THEN** у задачи зафиксирован момент перевода в done, при этом задача не является архивной

#### Scenario: Обратный перевод из done снимает фиксацию
- **GIVEN** задача находится в столбце «Выполнено» и еще не архивирована
- **WHEN** пользователь перемещает задачу обратно в «В работе»
- **THEN** задача отображается в столбце «В работе» без зафиксированного момента перевода в done и без признака архивности

### Requirement: Доступ к архивным задачам через поиск
Архивные (старые) задачи MUST оставаться доступными для просмотра: архивная задача MUST находиться через вкладку поиска (FR-10, FR-4).

#### Scenario: Просмотр архивной задачи на вкладке поиска
- **GIVEN** задача переведена в «Выполнено» и автоматически архивирована после смены календарного дня по МСК
- **WHEN** пользователь открывает вкладку поиска и находит эту задачу
- **THEN** карточка архивной задачи открывается с ее признаками

#### Scenario: Активные задачи не смешиваются с архивом
- **GIVEN** в системе есть и активные (на доске), и архивные задачи
- **WHEN** пользователь открывает вкладку поиска и выполняет поиск по всем задачам
- **THEN** в результатах отображаются как архивные, так и активные задачи с различимым статусом/признаком архивности
