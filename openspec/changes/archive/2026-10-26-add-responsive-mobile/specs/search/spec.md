# Дельта specs: search — мобильный вид P14

## ADDED Requirements

### Requirement: Поиск на мобильном — одна колонка

На ширинах ≤480px страница поиска MUST перестраиваться в одну колонку:
инпут поиска, фильтр-конструктор (поля условий), advanced-режим и выдача —
вертикально, полной шириной (FR-103). Страница MUST NOT иметь горизонтальной
прокрутки; строка выдачи MUST читаться без обрезки и без зума (минимальный
вьюпорт 375px, NFR-26). Инпуты и селекты на ≤480px MUST иметь font-size
≥16px (NFR-24); интерактивные элементы (кнопки «Найти», добавление условия,
селекты) — тач-таргет ≥44×44px (NFR-23). Вид — по утвержденным мокапам
дизайн-фазы (FR-106). На ширинах >480px вид поиска НЕ меняется (NFR-29).

#### Scenario: Перестройка в одну колонку

- **GIVEN** пользователь авторизован; вьюпорт ≤480px (проверка 375×812,
  device-эмуляция)
- **WHEN** пользователь открывает вкладку поиска
- **THEN** инпут, фильтры и выдача расположены вертикально полной шириной;
  горизонтальной прокрутки страницы нет (NFR-26)

#### Scenario: Выдача читается без обрезки

- **GIVEN** поиск выполнен; в выдаче есть строки с задачами (assigned,
  creator, признаки)
- **WHEN** пользователь просматривает выдачу на вьюпорте 375px
- **THEN** каждая строка читается без обрезки и без зума (FR-103)

#### Scenario: Инпут без авто-зума и тач-таргеты

- **GIVEN** вкладка поиска открыта на вьюпорте ≤480px
- **WHEN** пользователь фокусирует инпут поиска и нажимает кнопки/селекты
- **THEN** инпут имеет font-size ≥16px — авто-зум iOS не включается
  (NFR-24); тач-таргеты интерактивных элементов ≥44×44px (NFR-23)

#### Scenario: Функции поиска не деградировали

- **GIVEN** вьюпорт ≤480px
- **WHEN** пользователь выполняет поиск фильтром, advanced-запросом и по
  подсказкам
- **THEN** все функции поиска работают как на desktop (поведение не
  меняется — меняется только представление, FR-103)

#### Scenario: Desktop-вид поиска не меняется

- **GIVEN** ширина вьюпорта >480px (проверка ≥1024px)
- **WHEN** пользователь открывает поиск
- **THEN** вид и поведение совпадают с существующими (NFR-29)
