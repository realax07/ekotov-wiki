# Delta: board

## ADDED Requirements

### Requirement: Перемещение карточки перетаскиванием (drag-and-drop)

Пользователь MUST иметь возможность переместить карточку задачи между столбцами доски перетаскиванием мышью (FR-31, ОВ-19): при зажатии карточка прикрепляется к курсору и исчезает с исходного места на доске; при отпускании над столбцом карточка попадает в этот столбец; при отпускании вне зоны столбца (зона-приемник отсутствует) карточка возвращается на исходное место, статус задачи НЕ меняется. Результат перетаскивания MUST быть равнозначен переводу задачи существующим способом: применяются те же серверные проверки, правила столбцов, fast line (ОГР-5) и архивации (FR-4) — серверные правила перетаскиванием не меняются (ОГР-14). Перетаскивание MUST быть доступно мышью на десктопе; на touch-устройствах перенос задачи остается прежним способом (ОВ-19: «принимаю»). Отпускание fast-карточки в активную фазу («Ожидает»/«В работе») при занятой fast line MUST отклоняться сервером (409) с показом ошибки в UI и возвратом плитки на исходное место (Д-6).

#### Scenario: Перетаскивание карточки в другой столбец

- **GIVEN** пользователь авторизован; задача находится в столбце «Ожидает»
- **WHEN** пользователь зажимает карточку мышью и отпускает ее над столбцом «В работе»
- **THEN** карточка прикрепляется к курсору и исчезает с исходного места при зажатии, а после отпускания отображается в столбце «В работе»; статус задачи изменен так же, как при переводе существующим способом

#### Scenario: Отпускание вне зоны столбца возвращает карточку

- **GIVEN** пользователь зажал карточку мышью (карточка прикреплена к курсору, с исходного места исчезла)
- **WHEN** пользователь отпускает карточку вне зоны какого-либо столбца
- **THEN** карточка возвращается на исходное место, статус задачи не меняется

#### Scenario: Результат перетаскивания равнозначен переводу прежним способом

- **GIVEN** пользователь авторизован; в активных статусах находится fast-задача (fast line занята)
- **WHEN** пользователь перетаскивает другую задачу с флагом fast в активную фазу («Ожидает»/«В работе»)
- **THEN** сервер отклоняет перевод (409), UI показывает ошибку, плитка возвращается на исходное место; инвариант «не более одной fast-задачи в активных статусах» сохранен (Д-6)

#### Scenario: Перетаскивание в «Выполнено» подчиняется правилам архивации

- **GIVEN** пользователь авторизован; задача находится в столбце «В работе»
- **WHEN** пользователь перетаскивает карточку в столбец «Выполнено»
- **THEN** результат тот же, что при переводе существующим способом: задача остается в столбце «Выполнено» до автоархивации следующим МСК-днем (FR-4, ОГР-14)

#### Scenario: На touch-устройстве перенос выполняется прежним способом

- **GIVEN** пользователь открывает доску на устройстве с сенсорным экраном (touch)
- **WHEN** пользователь переносит задачу между столбцами
- **THEN** перенос выполняется прежним способом (существующим элементом управления); touch-перетаскивание не требуется (ОВ-19)

### Requirement: Визуальные эффекты доски поверх токенов V3

Доска MUST быть оформлена визуальными эффектами и стилями поверх действующих дизайн-токенов V3 «Бумага» (FR-32, ОГР-12 — эффекты являются надстройкой над токенами, а не новой темой). Обязательный минимум: hover-переходы карточек и оформленный пустой state пустого столбца. При утвержденном Заказчиком пресете (выбор из 2–3 пресетов ПМ, ОВ-20) — полный состав пресета: плавное отображение перемещения карточки между столбцами, связанное с перетаскиванием (карточка не «телепортируется», а перемещается видно), анимация появления карточек, тени/глубина. При включенной у пользователя системной настройке уменьшения движения анимации MUST отключаться.

#### Scenario: Обязательный минимум — hover-переходы карточек

- **GIVEN** пользователь авторизован и на доске есть карточки
- **WHEN** пользователь наводит курсор на карточку
- **THEN** карточка визуально реагирует на наведение (hover-переход по токенам V3)

#### Scenario: Обязательный минимум — оформленный пустой state столбца

- **GIVEN** пользователь авторизован; один из столбцов доски не содержит задач
- **WHEN** пользователь открывает доску
- **THEN** пустой столбец отображается с оформленным пустым state («красивый пустой state» — слово Заказчика), а не как пустая неоформленная область

#### Scenario: Плавное перемещение карточки по пресету

- **GIVEN** утвержден пресет эффектов с плавным перемещением; пользователь авторизован
- **WHEN** пользователь перемещает карточку между столбцами (перетаскиванием или прежним способом)
- **THEN** карточка перемещается между столбцами плавно и видимо, без мгновенного «телепорта»

#### Scenario: Анимация появления карточек по пресету

- **GIVEN** утвержден пресет эффектов с анимацией появления; пользователь авторизован
- **WHEN** пользователь создает задачу или обновляет доску
- **THEN** карточки появляются с анимацией в рамках утвержденного пресета

#### Scenario: Уменьшение движения отключает анимации

- **GIVEN** в системе пользователя включена настройка уменьшения движения (prefers-reduced-motion)
- **WHEN** пользователь открывает доску и перемещает карточки
- **THEN** анимации эффектов отключены; функциональность доски (столбцы, перемещение, hover-состояние переходов) сохраняется
