# Дельта specs: fastline (линия — отдельная зона FASTLINE, не подсветка канбана)

## MODIFIED Requirements

### Requirement: Выделенная линия fast line

Доска MUST иметь fast line — отдельную зону FASTLINE над основным канбаном
(вариант A: подложка + рамка + заголовок FASTLINE, ОВ-1), а не подсветку
внутри столбцов канбана (FR-3). Fast-задачи MUST отображаться только в зоне
и MUST быть исключены из столбцов канбана (заявка P23: «таски фастлайна
только на нем»); детали зоны — домен p23-fastline.

#### Scenario: Fast line отображается на доске

- **GIVEN** пользователь авторизован и открыл доску
- **WHEN** пользователь просматривает доску
- **THEN** над основным канбаном присутствует отдельная зона FASTLINE
  (подложка + рамка + заголовок), отличимая от обычных столбцов канбана

#### Scenario: Fast-задачи исключены из канбана

- **GIVEN** в зоне есть fast-задача, в канбане — обычные задачи
- **WHEN** пользователь просматривает столбцы основного канбана
- **THEN** fast-задач среди них нет — все fast-задачи находятся только в
  зоне FASTLINE (до этого изменения fast-задача стояла первой в столбце
  канбана с подсветкой task-card-fast)
