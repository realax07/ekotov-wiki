# design-tokens Specification

## Purpose
Дизайн-токены Пульта: палитра, типографика, свечение и spacing редизайна как единый источник визуальных констант.

## Requirements

### Requirement: Единый источник дизайн-токенов «Пульт» (FR-128)

Прод-источником дизайн-токенов фронта MUST быть блок `:root` `app.css` —
дословный перенос значений из утвержденного
`design/redesign-pro/tokens-console.html`; `color-scheme: dark` MUST быть
объявлен. Семантические имена токенов MUST сохраниться с новыми привязками.
Значения V3 «Бумага» MUST быть удалены к концу пакета (deprecated-алиасы —
design §D1, задача 2.7); ни один селектор фронта не ссылается на
отсутствующий токен. Служебные токены техноязыка MUST быть определены
(сценарии).

#### Scenario: Перенос токенов без изменения значений

- **GIVEN** утвержденный tokens-console.html (базлайн b5a1475)
- **WHEN** dev переносит блок `:root` в app.css
- **THEN** каждое значение (hex, rgba, ms, px, stacking focus-ring) совпадает с
  мокапом-источником, включая примитивы: фоны `--p-bg-000 #0e1621`…`--p-bg-300
  #26354d`, границы `--p-border #33435c`/`--p-border-2 #4d607c`, текст
  `--p-text-900 #e7edf4`/`600`/`500`, янтарь `--p-amber-400 #f0b45c` +
  подложка `--p-amber-900 #3a2c12`, cyan `--p-cyan-300 #4fd8eb`, статусы
  `--p-teal-400`/`--p-coral-400`/`--p-violet-300`; `color-scheme: dark`
  объявлен; рендер страницы темный (фон `--p-bg-000`, текст `--p-text-900`)

#### Scenario: Служебные токены техноязыка определены

- **GIVEN** блок `:root` app.css перенесен
- **WHEN** проверяется набор служебных токенов
- **THEN** определены: glow `--glow-amber`/`--glow-cyan`, фоновая микро-сетка
  `--texture-grid` (ячейка 32px), mono-стек данных `--font-family-data`,
  tracking капса `--tracking-caps`/`--tracking-micro`, cyan-фокус-ринг
  `--focus-ring`, скорости `--speed-fast` 140ms / `--speed-modal` 200ms

#### Scenario: Нет ссылок на удаленные V3-токены

- **GIVEN** редизайн завершен: deprecated-алиасы V3 удалены из `:root`
  (конец ЭТАПА 2, задача 2.7)
- **WHEN** выполняется grep по `frontend/static/css/**` и `frontend/templates/**`
  на `--p-paper-`, `--p-ink-`, `--p-clay-`, `--p-blue-`, `--p-red-`,
  `--p-olive-`, `--p-amber-700`
- **THEN** ни одного вхождения (в CSS и в inline-стилях шаблонов) нет; кроме
  того, в файлах статики нет hex-значений вне токенов (токен-дисциплина)

#### Scenario: Кеш статики инвалидирован

- **GIVEN** редизайн меняет содержимое статики при неизменных путях
- **WHEN** первая dev-волна смержена
- **THEN** `static_v` в `backend/app/pages.py` = `redesign-1` (бамп ОБЯЗАТЕЛЕН);
  все CSS/JS-подключения base.html получают `?v=redesign-1`

### Requirement: Роли акцентов — янтарь сигнал, cyan актив/фокус (FR-129)

Акцентные цвета MUST иметь разведенные роли (tokens-console.html §Semantics):
янтарь `--p-amber-400` — сигнальный цвет фастлайна (единственный); cyan
`--p-cyan-300` — ТОЛЬКО актив/фокус (активный пункт навигации, focus-visible,
`::selection`, открытый спойлер); teal/coral/violet — только статусы и
приоритеты, не декор. Градиенты MUST использоваться только на данных, не на
декоративных поверхностях.

#### Scenario: Cyan не используется как декор

- **GIVEN** страница любого раздела открыта в обычном состоянии (без фокуса)
- **WHEN** инспектируются поверхности (панели, кнопки, фон)
- **THEN** cyan отсутствует на декоративных элементах; cyan появляется только
  у активного пункта навигации, элемента в фокусе и выделения текста

#### Scenario: Янтарный glow только на сигнале

- **GIVEN** доска с fast-задачей
- **WHEN** инспектируются элементы с янтарным свечением
- **THEN** это только фастлайн (панель), fast-карточка и кнопка «Новая задача»
  на hover — элементов с янтарным glow вне сигнала фастлайна нет

### Requirement: Техноязык «Пульт» — HUD, LED, микро-лейблы, сетка (FR-130)

Панельные поверхности MUST использовать паттерн HUD-уголков (8 отрезков по
углам через `::after`) там, где мокап это задает. Статусные точки LED со
свечением MUST применяться к бренду сайдбара, заголовкам колонок доски,
readout заголовка страницы, статусам строк таблиц и метке фастлайна.
Микро-лейблы MUST набираться mono капсом с трекингом; данные — mono-стеком
`--font-family-data`. Фон страницы MUST включать микро-сетку `--texture-grid`.

#### Scenario: Панель с HUD-уголками

- **GIVEN** страница доски открыта
- **WHEN** инспектируются фастлайн и колонки
- **THEN** у каждой панели отрисованы угловые метки HUD (8 отрезков) цветом
  `--p-border-2`; у фастлайна — янтарные

#### Scenario: LED отражает состояние

- **GIVEN** доска с колонками «Ожидает», «В работе», «Выполнено»
- **WHEN** инспектируются LED заголовков колонок
- **THEN** «Ожидает» — нейтральная точка t500, «В работе» — янтарная с
  свечением и blink, «Выполнено» — teal со свечением; анимация blink
  отключается при prefers-reduced-motion

#### Scenario: Данные — моноширинно

- **GIVEN** открыты доска (счетчики колонок, даты карточек) и заголовок страницы
- **WHEN** проверяется font-family счетчиков, дат, readout-строки
- **THEN** используется `--font-family-data` (mono), микро-лейблы — uppercase
  с letter-spacing .14em
