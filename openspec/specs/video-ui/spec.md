## Requirements

### Requirement: Экран «Видео» в стиле «Пульт» (FR-126)

Экран «Видео» MUST следовать токенам «Пульт» и приемам техноязыка при
неизменной действующей функциональности видео-раздела: карточки/список видео —
панели на bg-токенах с hover-ступенью; продолжительность/даты/размеры — mono;
статусы обработки — LED-точки; заголовок страницы — pagehead с readout;
первичные действия — янтарные кнопки; плеер/просмотр — темная поверхность с
модальной тенью. DOM-хуки экрана сохраняются (ОГР-28).

#### Scenario: Список видео в визуале «Пульта»

- **GIVEN** в видео-разделе есть записи в разных статусах обработки
- **WHEN** открывается экран «Видео»
- **THEN** карточки — панели `--p-bg-200` с границей `--p-border` и
  hover-ступенью bg3; длительности/даты mono; статусы LED-точками (teal
  готово / янтарь blink в обработке / coral ошибка); заголовок — pagehead с
  mono-readout; вид соответствует токенам «Пульта»

#### Scenario: Функциональность видео не деградировала

- **GIVEN** редизайн применен
- **WHEN** прогоняются тесты видео (test_video_ui, test_video_convert_ui,
  test_video_rename_ui, test_video_social_ui — нецветовые ассерты)
- **THEN** загрузка, конвертация, переименование, комментарии работают как
  прежде
