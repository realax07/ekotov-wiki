2. **major — self-host шрифты: подключены не все начертания из sdd §1.2; ~40 правил просят weight 600 при наличии только 400.**
   Подключено 18 @font-face (все 18 woff2 из пула design-context/assets/fonts,
   unicode-range, font-display: swap — сверка файл↔@font-face 1:1): PT Serif 400/700,
   **Golos Text только 400** (4 сабсета), **JetBrains Mono только 400** (6 сабсетов).
   sdd §1.2 требует «Golos Text 400/**500/600**, JetBrains Mono 400/**600**».
   Пул дизайн-артефактов сам содержит только эти 18 файлов — но отклонение от sdd
   нигде не записано. В прод-CSS font-weight: 600 запрашивают, например:
   `board.css:69,701,731,791,833,1134,1222,1240,1284,1314,1497,1832,1890`,
   `gallery.css:228,282,434,505,613,670,694,944,963`, `wiki.css:325`,
   `templates/video.html` (.v-card-title) — браузер дает синтетический bold
   (или фолбэк-стек), метрики/ширины текстов отличаются от мокапа, tabular-счетчики
   на синтетике «дышат». **Рекомендация**: долить Golos Text 500/600 и JetBrains Mono
   600 woff2 (OFL, тот же гугл-пайплайн сабсетов) + @font-face; либо зафиксировать
   отклонение решением в sdd §1.2/§6 с обоснованием «синтетический bold приемлем» —
   но тогда и переснять визуальные ассерты QA, опирающиеся на точные computed-метрики.
