## 2. Дефолты БА по непринципиальным пунктам (ОВ-1…ОВ-4) — право возражения

Принципиальных вопросов к Заказчику НЕТ — все ключевые развилки закрыты
решениями 1–7. По четырем непринципиальным пунктам БА зафиксировал дефолты
(в ТЗ — раздел 7 requirements.md); молчание до утверждения = согласие,
возражение в любой момент до dev меняет пункт одной правкой:

- **ОВ-1 URL страниц** — дефолт: `/wiki/{id}` (числовой id), без slug-ов.
- **ОВ-2 удаление страницы с дочерними** — дефолт: запрещено до переноса/
  удаления дочерних (FR-116, Should). Альтернатива: каскад с подтверждением.
- **ОВ-3 охват поиска** — дефолт: только текущий контент страниц, не версии.
- **ОВ-4 главная страница wiki** — дефолт: НЕ вводится; `/wiki` показывает
  дерево от корневых страниц.
