## 1. Общее описание

Релиз 4 добавляет в систему профиль пользователя с настройками и просмотр карточки задачи:

- **Профиль пользователя (P3, расширенный):** у пользователя появляются display_name, роль, «о себе» и аватарка (png/jpg с серверным автосжатием). Внизу сайдбара — блок профиля (Релиз 3, FR-33) развивается: клик по нему открывает **страницу настроек пользователя** (форма профиля + смена пароля + загрузка аватара); при наведении на блок — всплывашка (tooltip) с информацией о пользователе.
- **Assigned и creator у задач:** у каждой задачи появляются исполнитель (assigned, nullable) и создатель (creator, заполняется при миграции). Новые поля отображаются **во всех карточках** задач и учитываются **в поиске** (фильтры и выдача); при наведении на карточку — всплывашка с assigned/creator.
- **Просмотр тикета (P9):** просмотр карточки задачи — отдельное **модальное окно read-only**, отличное от форм создания/редактирования. В тот же пакет входит закрытие **DEF-005**: формы создания/редактирования приводятся к мокапу V3 (pixel-consistent по токенам).
- **Отмена ОГР-13:** ограничение Релиза 3 «в профиле НЕТ аватарок и смены пароля» (Won't) больше не действует (решение Заказчика 2026-09-28, решение 1 и 2) — см. ОГР-15.

Назначение системы, аудитория и модель «общая доска» не меняются (основное ТЗ, разделы 1–2); пользователей по-прежнему двое (ОГР-6). Дизайн-направление не меняется: база — токены V3 «Бумага» (ОГР-12/ОГР-18).

**Следствия для change-пакета (справочно, решает СА — не зона БА):** ожидаемые дельты спек — navigation (MODIFIED: кликабельный профиль, отмена ОГР-13), auth (MODIFIED: профиль/пароль, расширение `/api/auth/me`), tasks (MODIFIED: creator/assigned), search (MODIFIED: фильтры/выдача), board (MODIFIED: tooltips, view-модалка); settings/fastline/categories — по итогам проработки СА.

## 2. Аудитория и варианты использования

Пользователи те же, что в основном ТЗ (раздел 2): владелец (Заказчик) и его жена, роли идентичны — модель «общая доска» без разграничения прав сохраняется.

| Кто | Новые сценарии Релиза 4 |
|---|---|
| Владелец (Заказчик) | заполнить свой профиль (имя, роль, о себе, аватар); сменить свой пароль; навести на свой профиль внизу слева и увидеть всплывашку; кликнуть по профилю и попасть в настройки пользователя; навести на карточку задачи и увидеть, кто создал и кому назначена; открыть карточку задачи на просмотр (read-only); найти задачи по исполнителю/создателю в поиске |
| Жена владельца | те же сценарии для своего профиля и любых задач (общая доска) |

Все новые функции доступны только авторизованным пользователям (следствие NFR-7 основного ТЗ; изменений авторизация не требует).
