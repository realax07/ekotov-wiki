# Дельта specs: design-tokens — источник токенов направления A (ЧЕРНОВИК, сопровождающая)

> Вне минимального списка задачи, но логически обязательна: мастер-спека дословно
> требует tokens-console.html/cyan/HUD — без этой дельты мастер становится ложной
> сразу после dev-Волны 3. Заголовки сохранены дословно; сценарии мастера (3 + N
> FR-129/130 — сверить при переносе) перенесены.

## MODIFIED Requirements

### Requirement: Единый источник дизайн-токенов «Пульт» (FR-128)

Прод-источником дизайн-токенов фронта MUST быть блок `:root` `app.css` —
дословный перенос значений из утвержденного `design-forge/a/tokens.css`
(направление A «Доска и поток»); тёмная тема объявлена в `:root`
(`color-scheme: dark`), светлая — блоком `:root[data-theme="light"]` со
значениями light-блока источника. Семантические имена токенов MUST сохраниться
с новыми привязками; примитивы `--p-*` «Пульта» сохраняются как legacy-слой для
страниц вне объема. Ни один селектор фронта не ссылается на отсутствующий
токен. Шрифты направления (PT Serif / Golos Text / JetBrains Mono) MUST быть
self-host (woff2 в `frontend/static/fonts/`, `@font-face` в app.css) — без
внешних зависимостей (ОГР-8); Google-Fonts `@import` мокапа в прод не
переносится. Новые hex вне токен-блока app.css запрещены.

#### Scenario: Перенос токенов без изменения значений

- **GIVEN** утвержденный design-forge/a/tokens.css
- **WHEN** dev переносит значения в app.css
- **THEN** каждое значение dark- и light-блоков совпадает с источником (bg
  #1e0f14, surface #2a161d, raised #371f28, text #f7ece4, muted #c6ad9f, border
  #3d2229, accent #d6a85c, accent-2 #c4505c, warning #f0aa42, warning-soft
  #4e3124, success #5ad88e, danger #e9817f, радиусы 10/18/28, тени shadow-1/2);
  derived-тоны выражены color-mix() от канон-токенов без новых hex;
  `color-scheme` соответствует теме; рендер страницы тёмный по умолчанию

#### Scenario: Служебные токены определены

- **GIVEN** блоки токенов перенесены в app.css
- **WHEN** проверяется набор служебных токенов
- **THEN** определены: mono-стек данных `--font-family-data` (JetBrains Mono),
  display-стек `--font-family-display` (PT Serif), золотой фокус-ринг
  `--focus-ring`, `::selection` на золоте, скорости `--speed-fast` 160ms
  (`--dur`) / `--speed-modal` 200ms, `--ease` cubic-bezier(.2,.7,.2,1);
  legacy-токены техноязыка «Пульта» (`--tracking-*`, `--p-*`) сохранены для
  страниц вне объема

#### Scenario: Нет ссылок на удаленные токены направления A-зоны

- **GIVEN** редизайн применен к объему A (board/task/wiki/gallery/video/base)
- **WHEN** выполняется grep по CSS объема A на декор «Пульта»
  (--texture-grid, --glow-amber, --glow-cyan, --accent-cyan, --cyan-border,
  --led-glow-*) и на hex вне токен-блока
- **THEN** в CSS объема A ни одного вхождения; hex только в токен-блоке
  (токен-дисциплина, гейт test_qa21_gallery_design)

#### Scenario: Кеш статики инвалидирован

- **GIVEN** редизайн меняет содержимое статики при неизменных путях
- **WHEN** первая dev-волна смержена
- **THEN** `static_v` в `backend/app/pages.py` = `redesign-a` (бамп ОБЯЗАТЕЛЕН);
  все CSS/JS-подключения base.html получают `?v=redesign-a`; favicon-маркер
  внутри data-URI бампнут `cache:v=2`→`v=3`

### Requirement: Роли акцентов — янтарь сигнал, cyan актив/фокус (FR-129)

Акцентные цвета MUST иметь разведенные роли направления A: золото
`--color-accent` (#d6a85c) — сигнальный цвет фастлайна, первичные действия,
актив/фокус/selection (единственный акцент взаимодействия); бордо
`--color-accent-2` (#c4505c) — кромка high-приоритета, danger-кромки и
drop-target; `--color-warning` — medium-приоритет и LED «в работе»;
`--color-success` — «выполнено»; лайк «мой голос» — золото. Cyan на декоративных
поверхностях не используется (удален из объема A).

#### Scenario: Разведенные роли акцентов

- **GIVEN** доска с задачами разных приоритетов и fastline-зоной
- **WHEN** инспектируются акцентные применения
- **THEN** золото: fastline (кромка/граница панели), primary-кнопки, фокус,
  активный пункт навигации, лайк; бордо: кромка high, drop-target; warning/
  success — только статусы; ни один элемент не использует cyan

### Requirement: Техноязык «Пульт» — HUD, LED, микро-лейблы, сетка (FR-130)

Декоративный техноязык «Пульта» (HUD-уголки, фоновая микро-сетка 32px,
cyan-glow) в объеме A MUST быть удален; сохраняются и переосмысляются на
токенах A: LED-точки статусов (mute/warning/success — статичные цвета,
blink «в работе» сохраняется с отключением при prefers-reduced-motion),
mono-readout с tabular-nums, капс-микро-лейблы там, где эталоны направления A
их задают. Классы-хуки DOM (`hud`, `col-led*`, `brand-led`, `readout-led`)
сохраняются (ОГР-28) без визуальных правил HUD.

#### Scenario: Декор «Пульта» удален, статусы различимы

- **GIVEN** страницы объема A отображаются
- **WHEN** инспектируются декоративные поверхности и статусы
- **THEN** HUD-уголков, микро-сетки и glow нет; LED-точки различимы цветом
  (mute/warning/success), blink отключается при prefers-reduced-motion с
  сохранением информативности (статичный цвет); readout — mono tabular-nums
