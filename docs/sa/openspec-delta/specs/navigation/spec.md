# Дельта specs: navigation — переключатель темы (ЧЕРНОВИК, сопровождающая ADDED)

> Вне минимального списка задачи; новый каркасный элемент обязан иметь требование
> (решение СА, sdd-redesign-ui-a.md §1.6, §2.3). Единственная ADDED-дельта пакета.

## ADDED Requirements

### Requirement: Переключатель темы в каркасе

Каркас MUST предоставлять переключатель темы: кнопка `#theme-toggle` — первый
элемент `.sidebar-footer` (ДО «Настройки»), 44×44 (NFR-23), иконки луны/солнца
inline-SVG (ОГР-8: без внешних файлов), состояние — `aria-pressed="true"` в
светлой теме; на ≤860px кнопка доступна внутри drawer'а (тот же узел, дубликат
в mobile-header не создается). Тема применяется атрибутом `data-theme="light"`
на `<html>`; выбор персистится в localStorage (ключ `theme`, значения
`light`/`dark`); при отсутствии записи применяется
`prefers-color-scheme: light` (fallback). Инициализация — инлайн-скрипт в
`<head>` ДО подключения стилей (без вспышки неверной темы); JS-переключение —
в app.js: flip атрибута, запись localStorage, синхронизация aria-pressed.
Обе темы удовлетворяют контрасту AA (NFR-41).

#### Scenario: Переключение темы без перезагрузки

- **GIVEN** пользователь открыл любую страницу каркаса
- **WHEN** кликает `#theme-toggle`
- **THEN** атрибут `data-theme="light"` ставится/снимается на `<html>`,
  палитра меняется без перезагрузки и без вспышки, `aria-pressed`
  синхронизирован, выбор записан в localStorage и переживает перезагрузку

#### Scenario: Первый вход — системная тема

- **GIVEN** пользователь с пустым localStorage и системной светлой темой
- **WHEN** открывается любая страница
- **THEN** инлайн-инициализатор применяет `data-theme="light"` до отрисовки
  стилей (вспышки тёмной темы нет); при системной тёмной теме атрибут не
  ставится

#### Scenario: localStorage недоступен

- **GIVEN** браузер блокирует localStorage (private mode)
- **WHEN** переключается тема
- **THEN** тема меняется до перезагрузки, ошибка записи молча игнорируется,
  никаких JS-ошибок в консоли
