Приемка браузером выявила: ссылка «Мониторинг» не появлялась — прод-пользователь

стенд скрыто тестами по определению). Решение Заказчика вживую: UPDATE
`users.role='Product manager'` для `owner` (значение из замысла ОВ-21 «owner =
Product manager»); исполнено Заказчиком через docker exec app sqlite; ссылка
появилась, дашборд открывается — подтверждено Заказчиком («работает»).

Урок в конвейер: prod-приемка вживую ловит расхождения данных (роли/креды),
которые стенд-тесты по построению не видят; чек «фактическая роль прод-юзера
vs ожидаемая фичей» — кандидат в RUNBOOK pre-deploy чеклист.
