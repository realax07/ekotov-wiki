## 3. XSS / инъекции

- Названия категорий попадают в option **только** через фабрику `el("option", null, name)` → `textContent` (dom.js); `innerHTML` в задетых файлах не используется. Имя `<script>alert(1)</script>` создано через API и хранится как есть — при рендере в DOM оно становится текстовым узлом, исполнения нет. XSS-минимум соблюден (ОГР-11).
- SQL: фронтовый дифф запросов не содержит; серверные запросы параметризованы (проверено в рамках смоука категорий).
