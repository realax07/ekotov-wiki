## Проверка 2: ассерты p12n004 — не ослаблены ли безосновательно

**Ослабления нет — это инверсия на новые корректные условия, каждое с валидной причиной.**

| Ассерт | Было (эпоха #50) | Стало (6daf970) | Оценка |
|---|---|---|---|
| precondition документа | `scroll <= inner + 1` (документ НЕ растянут — «иначе фикс не работает») | `scroll > inner` (документ растянут) | Обоснованная инверсия: превconditions кейса TC-P12N-004 требуют длинного документа (буква шага 1), что вновь достижимо после фикса. Двусторонний контроль скролло-механики теперь в шаге 3 |
| precondition контента | `cScroll > cClient` (внутренний скролл обязателен) | `cScroll >= cClient` («контент не пуст») | Единственное место с формальным ослаблением `>` → `>=`. Не безосновательно: проверка «прокручиваемости .content» более не является смыслом кейса — прокрутка ушла документу, а пустой контент (cScroll=cClient=0) по-прежнему отсекается. Сильный эквивалент старой проверки — `winY > 0` в шаге 3. Не блокер |
| механика скролла | `winY == 0` + `contentTop > 0` (скролл ВНУТРИ .content) | `winY > 0` + `contentTop == 0` (скролл ДОКУМЕНТОМ, .content не скроллится сам) | Точная инверсия под документный скролл; вторая часть (`contentTop == 0`) — усиление: прямо ловит возврат внутреннего скролла #50 |
| кликабельность footer | elementFromPoint «Настройки»/«Выйти», bbox до/после ≤1px | без изменений | Сила сохранена |

Замечание на качество: тест теперь связывает оба свойства разом (документ скроллится И .content не скроллится И footer sticky) — мутационная проверка (проверка 4) подтверждает, что тест ловит именно регресс 9b1e4f1, а не «что-нибудь».

## Проверка 4: мутационная проверка (обязательна по карточке)

В рабочем дереве worktree (без коммита) возвращены оба элемента 9b1e4f1. Важная находка мутационной пробы: `height:100vh` только на body НЕ глушит документный скролл (при overflow:visible контент переполняет body и растягивает документ — проба: docH 962 > 720, scrollY 242). Глушилкой является связка `.content { height:100vh; overflow-y:auto }`. Поэтому корректная мутация = полный откат 9b1e4f1:

```
# Мутация в frontend/static/css/app.css worktree:
#   body.app-shell: + height:100vh (min-height удален)
#   .content:       + height:100vh; overflow-y:auto
curl http://…/static/css/app.css | grep -c MUTATION2 → 2  (стенд отдал мутацию)

env … EKOTOV_WIKI_BASE_URL=http://127.0.0.1:48815 … pytest \
  tests/web/test_r5_crop_ui.py::test_page_scroll_outside_widget_not_broken -q --tb=short
→ FAILED … assert scrolled > 0, scrolled
E   AssertionError: 0
1 failed in 2.65s
```

Фиксатор ловит регресс — защита реальная. Откат: `git checkout -- frontend/static/css/app.css`; после отката `git status` по коду чист, sha256 app.css совпал с 6daf970 (`2016ea74…`), контрольный прогон фиксатора — **passed**.
