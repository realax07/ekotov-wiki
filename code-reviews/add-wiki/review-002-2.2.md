**Открытые вопросы ПМ — исполнение:**
1. **201 на create** — исполнено: `status_code=201`, тест фиксирует точное значение (`_create` assert 201). Задокументировано в docstring модуля с указанием, что таблица §3 говорит 200, а ТЗ задачи — 201. Несоответствие design §3 — на синхронизации ПМ (вне return-критериев, согласовано).
2. **v1 при create** — исполнено: `_insert_version` сразу после INSERT страницы; мутационная проба №8 (снятие записи v1) валит 6 тестов — тесты фиксируют поведение. Мутация №12 (автор версии жестко = 1 вместо сессии) — НЕ ловится тестами (единственный сессионный пользователь), см. M-3.
3. **data:image/ в img src** — исполнено как одобрил ПМ: `_safe_url` пропускает `data:image/` только для `img src` (проверено: `<a href="data:image/png…">` режется, `<img src="data:image/png…">` проходит); юнит TC-san-006 и TC-san-005 фиксируют обе стороны.
4. **Кириллица LIKE** — известное ограничение SQLite (LIKE регистронезависим только для ASCII) подтверждено на стенде: `борщ` находит «борщ и блины», `БОРЩ` — нет; экранирование `%_\` при этом работает полноценно (см. §2). Вне return-критериев, согласовано; тест TC-wiki-021 честно документирует ограничение в комментарии.
