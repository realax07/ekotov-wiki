З-4 учтено: анимация строго на CSS — media-переключение работает, JS-анимаций нет.
- **«Анимация появления карточек по пресету»**: v-in on render — создание задачи и обновление доски дают появление с пружинкой.
- **«Уменьшение движения отключает анимации»**: media-блок гасит animation+transition (!important), наклон призрака, transition колонки — все анимации пресета; hover-состояния сохраняются мгновенными. Соответствует сценарию.
- **Соответствие мокапу (p8-presets.html, пресет В)**: hover `translateY(-4px) scale(1.01)` + тень `0 10px 24px rgba(61,54,48,.2)` + заголовок `--p-clay-700`; drop-target `--p-clay-050` + dashed `--p-clay-600` outline-offset -4px; drag-ghost `opacity .35 + rotate(3deg) scale(1.02)`; empty-градиент `rgba(168,67,44,.04)` — все значения сверены с мокапом построчно, дословное совпадение (кроме двух задокументированных отклонений — замечания 1-2).
