## Суть дифа

`onDragOver`: вместо `COLUMNS.forEach(column.classList.toggle("drop-target", status === column.dataset.status))` — `clearDropHighlight(); column.classList.add("drop-target");` плюс комментарий с диагнозом BUG-003.
