## Находки

### Blocker — нет

Blocker #49 устранен на всех путях:

- **fillTaskForm** — `resetTagLedger()` первой строкой (обе ветки: create
  через clearTaskForm → fillTaskForm, и edit). Единственная точка, где
  task-form знает о подмене задачи; закрывает главный сценарий утечки
  «сохранил A → открыл B».
- **openCreateForm / openEditForm** — безусловный дублирующий сброс
  (страховка на путь «форма открыта, сабмит не прошел (422/сеть) →
  переоткрытие без closeTaskForm»).
- **closeTaskForm** — безусловный сброс после closeTagHints; closeTaskForm
  — подтвержденная единая точка выхода: submit (успех → колбэк api),
  «Отмена» и крестик (board-init.js:49,55), Escape (task-form.js:791),
  клик по оверлею (board-init.js:58-64 → closeTaskForm). Ни один путь
  выхода из формы леджер не переживает.
- **Сабмит** — flushCommittedToInput (capture на submit) выполняется ДО
  collectTaskForm, успешный сабмит завершается closeTaskForm → сброс.
  Путь «сабмит не прошел» покрыт сбросом в open*Form при переоткрытии.
- Сам механизм дефекта подтвержден на коде: после сабмита input непуст
  (flushCommittedToInput: «Z, X, Y,») → условие
  `splitTags(...).length === 0` в resetCommittedFromInput ложно → старый
  путь сброса не срабатывал; fix устраняет причину, а не симптом.
- resetTagLedger сбрасывает и committedTags, и lastAnnounced — последний
  важен для NFR-18 (переоткрытие с тем же числом подсказок озвучивается).
