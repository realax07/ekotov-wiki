| Проба | Результат |
|---|---|

| sha256 строки (base.html:22 == login.html:12) | `cc44627121866e88…08861c8` — идентичны |
| data-URI | `data:image/svg+xml,<svg …>` — тот же inline SVG |

| Терракотовый акцент `%23a8432c` | присутствует (следствие побайтности) |

Trade-off осознанный, компенсирован комментарием в шаблоне и ассертом одинаковости URI в TC-P12N-003. Если бампы маркера станут регулярными — вернуться к варианту (а) (partial/include).
