Пустое состояние (1.1а) — демо, не часть страницы

Показывается, когда GET /api/wiki/pages вернул пустой список: тихая dashed-плашка + первичная кнопка «Создать первую страницу» (ведет в редактор, мокап wiki-editor.html).

В Wiki пока нет страниц

Создайте первую страницу — она станет корнем дерева раздела.

Состояния узла дерева — демо

Строка узла — hover (подложка paper-100); фокус на шевроне — focus-visible focus-ring; шеврон поворачивается на 90° при aria-expanded="true"; у листа вместо шеврона — спейсер (выравнивание сохраняется). Клавиатура: Tab — шевроны и ссылки, Enter — открыть страницу / развернуть узел.

  • hover: строка с подложкой paper-100
  • focus-visible: focus-ring на шевроне

Примечания для dev (3.1): дерево из GET /api/wiki/pages — плоский список → вложенность по parent_id за один запрос; поиск — GET /api/wiki/search?q=, подсветка <mark> по оффсету из ответа (HTML сниппет в клиент не вставляется — санитизация сервером); пустое состояние — при пустом списке страниц; 401 при протухшей сессии — редирект на /login.
