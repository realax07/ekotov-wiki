## Реализации по спеке (трассировка)

- **FR-85 / FR-86 (сайдбар)**: «Галерея» — 4-й пункт `sidebar-nav` ПОСЛЕ «Wiki», до «Настройки» (footer не тронут). Виден всем авторизованным (ОВ-4) — в отличие от «Мониторинга» пакета 1, рендерится **серверно в `base.html`**, без role-проверки в `profile.js` (отмечено в примечаниях для dev).
- **FR-80 (фильтры)**: два селекта над сеткой; комбинируются, пустые = «все»; сброс; счетчик найденного. Значения — из справочника категорий галереи и словаря тегов (НЕ категории задач — hint в мокапе).
- **FR-83 (просмотр)**: карточка → full-screen модалка; листание кнопками и клавишами, циклично по текущей отфильтрованной выдаче (design §6); Esc/крестик; никаких связей с трекером (ОВ-3).
- **FR-81 (реакции)**: ровно один голос: клик по своей кнопке снимает голос, по второй — переносит; состояние «мой голос» различимо без цвета (заливка иконки + вес + фон).
- **FR-82 (комментарии)**: список с автором/временем; «удалить» рендерится только у своих (чужое удаление — 403 по API); пустой комментарий — кнопка отправки disabled.
- **FR-79 / NFR-21 (загрузка)**: drag&drop + кнопка; лимиты 10 МБ и типы показаны ДО выбора и в ошибке; превью до отправки; прогресс после сабмита.
- **Токены V3**: все цвета/отступы/типографика — только через custom properties из `app.css :root` (paper/ink/clay, Georgia display, радиусы 6/10px, focus-ring, 8px-сетка, speed-fast/modal); сырые значения — только внутри `:root`-блоков.
- **Контраст AA**: paper-050 на ink-900 ~11:1; clay-600 на бумаге — AA (проверено в пакете 1); бейдж «мой голос» — clay-700 (#93391f) на clay-050 (#f7e8e4) ≈ 6.4:1 ✓; ошибки red-700 на red-050 ✓.
