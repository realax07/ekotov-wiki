# Design: варианты визуального стиля формы задачи (Д-5)

Мокапы для выбора Заказчиком до старта задачи 2.5 (FR-29, FR-28, FR-21, FR-26; ОГР-8 — inline CSS/SVG, без внешних зависимостей). Каждый файл — самодостаточный standalone HTML: открывается в браузере без сборки.

**Файлы:**

| Файл | Вариант | Суть |
|---|---|---|
| `form-style-v1.html` | V1 «Эволюция» | Развитие текущего стиля приложения (палитра Flat-UI #2c3e50/#1abc9c сохранена), токенизация, focus-visible, состояния ошибок |
| `form-style-v2.html` | V2 «Контраст» | Светлая тема повышенного контраста: тёмная шапка окна, почти прямоугольные поверхности, утяжелённые рамки полей, акцент — глубокий синий |
| `form-style-v3.html` | V3 «Бумага» | Приглушённая тёплая «бумажная» тема: серифные заголовки (системный Georgia), подчёркнутые поля (только нижняя линия), мягкие тени, акцент — терракота |

## Состав каждого варианта (идентичен по требованиям, различен по стилю)

- Форма задачи целиком: название, категория (select из справочника), теги с автодополнением (set из тегов+категорий, FR-26), приоритет (low/medium/high), чекбокс fast line (FR-27 — блокирует приоритет «высокий»).
- Крестик закрытия в правом верхнем углу, зона клика 40×40px (FR-28).
- Состояние ошибки на категории: подсветка поля + текст рядом (aria-describedby, aria-invalid) — FR-21.
- Приоритеты: цвет + inline SVG-иконка + текст/бейдж — различимы без цвета в форме и на мини-карточке (FR-29).
- Focus-visible на всех контролах; hover/disabled; анимация открытия окна + `prefers-reduced-motion`.
- Дизайн-токены: CSS custom properties в шапке каждого файла (`:root`, primitives → semantic).

## Доступность (все варианты)

- WCAG 2.1 AA: текст ≥4.5:1, крупный текст/иконки ≥3:1. Акценты затемнены относительно «сырых» брендовых цветов ради контраста (в V1 teal `#1abc9c` для текста/кнопок заменён на `#0f8b70`).
- Приоритеты различимы без цвета: иконка (↓ / = / ↑) + текст всегда.
- Крестик 40×40px, aria-label; окно: role=dialog, aria-modal, aria-labelledby (в мокапе; поведение Esc/overlay/focus-trap — задача dev 2.5, в спеке FR-28).
- Ошибки: aria-invalid + aria-describedby, текст рядом с полем.

## Что покрыто из дельты specs/tasks

- Requirement «Визуал формы» — форма, приоритеты, состояния ошибок, единый стиль, анимация.
- Requirement «Крестик» — правый верхний угол, 40px зона.
- Requirement «Автодополнение» — подсказки из тегов+категорий, «work» один раз (set), новое значение допустимо (подпись DECISION в V1).

## Вне скоупа мокапов (задача dev 2.5)

Esc/клик по подложке, focus trap, возврат фокуса на триггер, живая логика подсказок.
