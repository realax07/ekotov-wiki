Primitives

  • bg: 000 #0e1621 / 100 #172335 / 200 #1d2b40 / 300 #26354d; border #33435c / strong #4d607c
  • text: 900 #e7edf4 / 600 #a7b7c8 / 500 #8496a8
  • fast line: amber 400 #f0b45c, подложка #3a2c12
  • второй акцент: cyan 300 #4fd8eb — только актив/фокус
  • status: teal 400 #57c4b0, coral 400 #ef7b6a, violet 300 #b9a8e8

Semantics

Глубина — ступенями фона (000→300), тени минимальны. Два акцента с разведёнными ролями: янтарь — сигнальный цвет фастлайна (+glow), cyan — актив/фокус (+glow, focus-ring). teal/coral/violet — только статусы и приоритеты. Градиенты — только на данных (трек отсчёта фастлайна amber→cyan), не на декоре. Панели — HUD-уголки (--p-border-2, на фастлайне янтарные), фон страницы — микро-сетка --texture-grid (1px, ячейка 32px). Микро-лейблы капсом — mono + --tracking-micro. Данные (счётчики, даты, id, readouts) — --font-family-data. color-scheme: dark объявлен — нативные контролы рендерятся тёмными.
