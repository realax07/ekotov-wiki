# Редизайн ekotov-wiki — три направления (flow 1, design/redesign-pro)

Профессиональный редизайн: три **различимых** эстетических направления, каждое —
манифест + токены + самодостаточный мокап (доска с сайдбаром/фастлайном + фрагмент wiki).
Без CDN, системные шрифты, сетка 8px, inline SVG-иконки, WCAG 2.1 AA по тексту,
мобильная версия в каждом мокапе (≤ 900/860px).

**Статус: предложения.** Прод-источник токенов по-прежнему `design/tokens.html` (J47);
при выборе направления — change-пакет на замену, dev переносит в `app.css :root` отсюда.

## Манифесты

### A «Типографская»
Личная wiki как собственное периодическое издание: холодная газетная бумага `#f4f3ee`,
чернила `#1f1e1b`, оксблад `#772f2f` как единственный акцент, slate-синий `#2b4a5a` —
фастлайн. Georgia-стек несёт и дисплей, и текст; mono — только даты и счётчики.
Композиция вместо карточек: колонки разделены hairline-линейками, шапки — двойной
линейкой, буквица и врезка в wiki. Дифференциация: сайт читается как верстка
личной газеты, а не как SaaS-дашборд. Сознательно НЕ текущая «Бумага+терракота» и
не тёплый крем-дефолт — база холодная.

### B «Пульт»
Вечерний рабочий инструмент: глубокий сине-графитовый `#0e1621` со ступенями фона
вместо теней, один сигнальный цвет — янтарь `#f0b45c` для фастлайна; teal/коралл/фиолет —
только статусы. Sans для UI, mono для всех данных (счётчики, даты, uptime), kbd-подсказки
в подвале сайдбара, LED-индикаторы колонок. Никакого неона и глоттерминл-эстетики —
спокойная приборная панель. Дифференциация: клавиатурная оперативность и «читаемость
состояния» (LED, tabular numerals) вместо декора.

### C «Керамика»
Мягкая современность с характером: грейдж-база `#f2f1ed`, дуэт акцентов слива `#66336b` +
мох `#2c564d` (rust/honey — только приоритеты), иерархические радиусы 8/14/20, тёплая
мягкая тень, humanist display-стек Candara/Seravek/Trebuchet. Поверхности — «глиняные»
карточки с воздухом, фастлайн — спокойное морское течение `#3d5a66`. Дифференциация:
тактильность и дуэт акцентов вместо одиночного синего; wiki-фрагмент как аккуратный
«рецепт на карточке».

## Как сравнивать
1. **Сценарий чтения** — откройте wiki-фрагмент каждого мокапа: A выигрывает в длинном
   чтении, B — в быстрой диагностике, C — в бытовых заметках.
2. **Сценарий «утро на доске»** — где быстрее считывается статус фастлайна и колонок:
   B (LED+янтарь) > A (полоса объявлений) > C (тихая плашка).
3. **Совместимость с продом** — C ближе всего к V3 «Бумага» (миграция дёшево),
   A — средний шаг (смена типа-голоса), B — полная смена сцены (нужна тёмная тема).
4. **Контраст** — все текстовые пары всех направлений проверены скриптом на ≥ 4.5:1
   (AA), крупные значения в комментариях tokens-*.html.

## Верификация (выполнено)
- каждый HTML открывается: `python3 -m http.server` + curl → 200;
- валидность: все файлы парсятся html.parser без ошибок, единственный doctype/голова;
- контраст текста: ≥ 4.5:1 по WCAG-формуле (программная проверка пар из токенов);
- мобильная раскладка: брейкпоинты 860/900px в каждом мокапе (nav перестраивается,
  колонки складываются в столбец, hit-targets ≥ 44px на тач-размерах);
- `prefers-reduced-motion`, `:focus-visible`, skip-link — во всех трёх.
