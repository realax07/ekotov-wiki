# Мокапы P12 — rich-редактор wiki (волна 1, дизайн-фаза)

5 инструментов, каждый в двух состояниях: **режим редактирования** (внутри
`.editor-card` с тулбаром) и **отрендеренный вид** (внутри статьи).
Эталон стиля — V3 «Бумага»: токены дословно из `frontend/static/css/app.css`
и `frontend/templates/base.html`, паттерны статьи/тулбара — из
`frontend/static/css/wiki.css` (швы 3.2/3.3). Референс — design/p18-weather/.

## Файлы

| Инструмент | HTML | Рендеры |
|---|---|---|
| 1. Спойлер | `tool-1-spoiler.html` | `tool-1-spoiler-{edit,view}.png` |
| 2. Блок кода | `tool-2-code.html` | `tool-2-code-{edit,view}.png` |
| 3. Табуляция | `tool-3-tabs.html` | `tool-3-tabs-{edit,view}.png` |
| 4. H-заголовки (toggle) | `tool-4-headings.html` | `tool-4-headings-{edit,view}.png` |
| 5. Таблица | `tool-5-table.html` | `tool-5-table-{edit,view}.png` |

Общая база токенов/каркаса — `p12-base.css` (подключается `<link>`, ОГР-8
соблюдено: без внешних зависимостей). Перерендер: `../venvs/wiki/bin/python
render.py` из этой папки (playwright, device_scale_factor=2, viewport 1180).

Интерактив: у таб-виджета (мокап 3) переключение вкладок работает прямо в
браузере — Заказчик может пощупать до внедрения.

## Принятые дизайн-решения

1. **Спойлер** — карточка поверхности с терракотовой левой чертой 3px
   (паттерн blockquote из wiki.css) — читается как «родной» блок, а не
   чужой виджет. Шапка: шеврон + название; клик по шапке — свернуть/
   развернуть, клик по названию — инлайн-редактирование (input с focus-ring).
   Внутри — зона для любого контента. В ячейке таблицы — компактный вариант
   (без внешних отступов, micro-шрифт названия). В рендере — те же два
   состояния без подсказок; шапка кликабельна.
2. **Блок кода** — фон `--p-ink-900` (как существующий `.article-body pre`),
   шапка `#4a423a` с терракотовой линией 2px снизу. Слева — выбор языка
   (дропдаун: python/js/bash/json/sql/plain), справа — «Копировать», после
   клика 1,5 с — «✓ Скопировано» (оливковый light). Подсветка — приглушенная
   «бумажная» палитра: ключевые — терракота light, строки — олива light,
   числа — amber light, функции — blue light, комментарии — ink-600 italic.
3. **Табуляция** — вкладки в стиле тулбара: активная — поверхность карточки +
   терракотовая черта 2px снизу + clay-700 текст; неактивные — secondary.
   Редактор: «+» добавляет вкладку, «×» (виден на hover неактивной) удаляет,
   двойной клик — переименование (input внутри вкладки с focus-ring).
   Последнюю вкладку удалить нельзя. Контент каждой вкладки — своя
   contenteditable-зона.
4. **H-заголовки** — H1/H2/H3 работают как toggle: активная кнопка нажата
   (aria-pressed, accent-soft), повторный клик снимает формат (текст →
   обычный абзац, все кнопки отжаты), клик по соседней — замена уровня.
   DON'T-состояние (одновременно нажаты H1+H2, красная рамка) показано как
   визуализация текущей проблемы. CLEAR-состояние: текст не теряется.
5. **Таблица** — управление контекстное, только при фокусе внутри таблицы:
   «+»/«−» столбцов — над шапкой у границы целевого столбца, «+»/«−» строк —
   справа за краем таблицы. Целевой столбец вставки подсвечивается голубым
   тинтом (--p-blue-050), фокус ячейки — терракотовое inset-кольцо.
   Внизу — строка-подсказка (Tab — следующая ячейка, Enter — перенос внутри
   ячейки, удаление последней строки/столбца запрещено). Рендер —
   существующие стили `.article-body table` (зебра, th paper-100).

## Открытые вопросы Заказчику

1. Спойлер в рендере: оставляем ли «шапку-кнопку» (весь заголовок кликабелен)
   или нужна отдельная кнопка-стрелка справа?
2. Блок кода: какой список языков в дропдауне финальный (предложено
   python/js/bash/json/sql/plain)? Нужна ли нумерация строк?
3. Табуляция: ограничивать ли число вкладок (например, ≤8) и что делать при
   переполнении таб-бара (горизонтальный скролл или выпадающий список)?
4. Таблица: нужна ли кнопка «выделить всю таблицу → удалить» или удаление
   только через «−» у краев (с запретом удаления последней строки/столбца)?
5. H-заголовки: должен ли Backspace в пустом заголовке тоже снимать формат
   (поведение как в Notion), или снятие только через повторный клик по кнопке?
