### 1. Композиция A — MATCH
- Карточка «Сегодня» сверху: «Москва» + «Сегодня, понедельник, 19 октября», крупная температура +6°, иконка, описание «Ясно», «Ощущается как +2°», ряд из 6 колонок метрик: МАКСИМУМ / МИНИМУМ / ОСАДКИ / ВЕТЕР (м/с + румб «СВ») / ВЛАЖНОСТЬ / ДАВЛЕНИЕ («мм рт. ст.») — 8 метрик суммарно, как в задании и design §.
- Сетка «Прогноз на неделю»: ровно 7 карточек (Пн 19.10 — Вс 25.10), 4 в ряд, у карточки дня: дата, иконка, описание, макс/мин, «Осадки: N%», ветер румб+м/с.
- Карточка сегодняшнего дня выделена терракотовым датой и левой рамкой — как в мокапе.

### 2. Стилевые токены — MATCH (проверено computed style)
- Карточки: rgb(255,253,249) = #fffdf9 ✓
- Акцент (активный пункт сайдбара, даты, кнопки): rgb(168,67,44) — терракотовый ✓
- Заголовки: Georgia/"Times New Roman", serif ✓; текст карточек — system-ui.

### 3. Сайдбар — MATCH
Порядок: Доска, Поиск, Wiki, Галерея, Видео, **Погода**, Мониторинг, Настройки — «Погода» сразу после «Видео», активная (терракотовая заливка + светлый текст).

### 4. Данные — MATCH
/api/weather отдаёт живой Open-Meteo (stale: false), значения реалистичны для Москвы 19.10: +6°, ясно, max +12/min +2, ветер СВ 4 м/с, влажность 57–59%, давление 765 мм рт. ст.

1. Термины ветра/давления совпадают с мокапом; румб дневного ветра берётся из wind_direction_10m_dominant (эскалация E1, коммит 6b2727f) — семантика соответствует отображаемой.
2. В мокапе блок «Сегодня» без видимой рамки карточки, в реализации он в карточке w-card (#fffdf9, рамка #e9e1d4) — консистентно с системой карточек сайта, визуально не спорит с мокапом; расцениваю как допустимую интерпретацию.
