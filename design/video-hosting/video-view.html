Пояснения к макету (вне продукта)

Для статусов загружено / конвертируется / ошибка вместо <video> показывается блок статуса — плеер не запускается (Scenario «Не готовое видео не проигрывается»). Кнопка «Удалить» доступна во всех статусах — удаление недоконченного отменяет конвертацию и чистит артефакты.
  • отдача файла — только по сессии (NFR-36), прямой ссылке/скачиванию нет;
  • подтверждение удаления — модалка ниже (Esc / клик по фону = отмена).
Кусок D (социальный слой, по образцу галереи — паттерны gallery-lightbox.html):
  • лайк/дизлайк — пилюли с счетчиками; ровно один голос: повторный клик снимает, клик по второй — переносит; «мой голос» = мягкая терракота + заливка иконки (различимо без цвета);
  • комментарии — список (автор/дата), «удалить» — только у СВОИХ (у чужого кнопки нет, 403 по API);
  • «Отправить» неактивна, пока поле пусто; реакции и комментарии — только авторизованные (NFR-36).
