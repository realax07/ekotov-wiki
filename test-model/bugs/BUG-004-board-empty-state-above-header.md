# BUG-004 (OPEN 2026-10-25): пустой state доски рисуется НАД шапкой колонки

- **ID:** BUG-004
- **Кейс:** визуальная регрессия после релиза redesign-1 (ПР #244, Флоу 1)
- **Дата:** 2026-10-25
- **Обнаружено:** Заказчик, прод-скриншот доски (/board, пустые колонки «В работе»/«Выполнено»)

## Ожидание

У пустой колонки доски порядок сверху вниз: **шапка колонки** (LED, название «В работе», mono-код RUN-02, счетчик) → **пустой state** («Пока пусто — задачи появятся здесь»). Логика чтения: сначала заголовок секции, потом её содержимое.

## Факт

Текст «Пока пусто — задачи появятся здесь» отображается **выше** шапки колонки: пустой state визуально перекрывает/загораживает заголовок (скриншот Заказчика: в «В работе» и «Выполнено» подсказка стоит НАД строкой «● В РАБОТЕ RUN-02»).

## Причина (диагноз ПМ)

`cards.js:273` вешает класс `board-column-empty` на всю `<section class="board-column">`, а CSS (board.css:322) рисует пунктирную рамку и `::before` с текстом прямо на секции: псевдоэлемент рендерится первым боксом секции — **до** `.col-head`. Порядок DOM при этом корректный (шапка → контейнер карточек) — дефект чисто презентационный, в CSS/JS.

## Фикс (направление)

Привязать рамку и текст пустого state к контейнеру карточек, а не к секции:

- CSS: селекторы `.board-column-empty { … }` и `.preset-v .board-column-empty::before { … }` → таргетить `.board-column.board-column-empty .board-column-cards` (рамка+`::before` на контейнере);
- либо cards.js:273 — класс на `container` (`.board-column-cards`), не на `column` (проверить, не завязаны ли другие селекторы на `section.board-column-empty`).

ОГР-28: классы/id/data-атрибуты колонок не менять (кроме добавления класса на контейнер, если выбран путь cards.js).

## Проверка

- Новый веб-тест: пустая колонка — `.col-head` визуально выше текста пустого state (bounding-box: y шапки < y текста/контейнера), текст присутствует, рамка пунктиром на контейнере.
- Сторожи: непустая колонка — класс снят, рамки нет; fastline-зона (P23) — пустые столбцы зоны без подсказки (ОВ-3), не сломать.
