# BUG-013: окно просмотра задачи — признаки прижаты к краю окна (отступы не по мокапу)

- **ID:** BUG-013
- **Статус:** ОТКРЫТ (2026-10-08, приемка Заказчика r8-polish, п.1)
- **Дата:** 2026-10-08
- **Окружение:** прод r8-polish (все образы, main 7e00a1b); окно просмотра задачи (board).
- **Severity:** minor→major (визуальный дефект приемки; мокап polish-ticket-modal.html задает отступы)
- **Автотест:** отсутствует (визуальный; после фикса — computed-styles проверка по мокапу)

## Жалоба Заказчика (приемка r8-polish, п.1)

«Окно просмотра задачи — посмотри отступы у признаков задачи, они прямо по краю
окна. Выровняй их (в макете нормально было)».

## Факты ПМ

- Новый просмотр: frontend/static/js/board/task-detail.js строит .task-view,
  признаки — .attr-grid/.attr (board.css:1007–1035, по мокапу). Шапка —
  .modal-head padding var(--space-3) var(--space-4) var(--space-2); тело —
  .modal-body padding var(--space-2) var(--space-4) (мокап design/polish-ticket-modal.html:180,205).
- Подозрение: секция признаков рендерится вне .modal-body padding-контейнера
  (собственная секция без горизонтального отступа) — сверить фактически на стенде:
  computed styles секции признаков vs .modal-body.
- Мокап-арбитр: design/polish-ticket-modal.html (.attr-grid gap var(--space-1)
  var(--space-2); .attr padding var(--space-1) var(--space-2); сетка внутри
  .modal-body с его паддингами).

## Критерий закрытия

Признаки имеют горизонтальные отступы, идентичные остальному содержимому окна
(не по краю); сверка computed styles с мокапом (арбитр). Смоук просмотра green.
