# BUG-017: тач-таргеты футера редактора wiki < 44px на мобильном (NFR-23)

- **Набор:** add-wiki 4.3 web-mobile (playwright, 375×812, has_touch, chromium)
- **Дата:** 2026-10-10 · **Ветка:** pipeline/p15-stage-a
- **REPORT:** `test-model/reports/add-wiki/REPORT-4.3-web-mobile.md`
  (скриншот: `screenshots-43/04-wiki-editor-375.png`)

## Кейс / ожидание / факт

- **Кейс:** задача 4.3 add-wiki — «редактор юзабелен (тулбар доступен,
  тач-таргеты ≥44px — преемственность NFR-23)» на viewport 375×812.
- **Ожидание:** все интерактивные элементы редактора ≥44×44px
  (NFR-23; прецеденты: `board.css:1536`, `app.css:625`).
- **Факт:** тулбар — 14/14 кнопок ровно **44×44** (PASS), но кнопки футера
  **«Отмена» 86×33** и **«Сохранить» 111×33** — ниже минимума.

## Локализация

`frontend/static/css/wiki.css:1373` — `#wiki-editor .btn` без `min-height`;
мобильная media-ветка `wiki.css:1573` (`@media (max-width: 480px)`)
переопределяет только `.tb-btn` (44×44), футерные `.btn` не затрагивает.

## Рецепт фикса

```css
@media (max-width: 480px) {
  #wiki-editor .btn { min-height: 44px; }
}
```

Опционально в ту же ветку: `.article-actions .btn` (wiki.css:779) и
`#wiki-history .btn` — те же пилюли, на 375px вероятно та же проблема
(в объем 4.3 замер редактора входил, статья/история — нет).

## Серьезность и влияние

- **minor**: тач-юзабельность (главное действие «Сохранить» ~33px ловится
  пальцем хуже), функциональность, desktop и остальные экраны не задеты.
- **Блокер по процессу пакета**: правило add-wiki — падение набора
  останавливает следующий (4.4 смок не стартует до фикса и зеленого
  перегона 4.3).

## Статус: FIXED / VERIFIED (2026-10-10)

- **Фикс:** `frontend/static/css/wiki.css`, media-ветка `@media (max-width: 480px)`
  (конец файла) — добавлено `#wiki-editor .btn { min-height: 44px; }`.
- **Верификация:** ре-проба тем же методом (стенд по tests/README: tmp-БД схема +
  seed + `migrate_wiki`, playwright 375×812 has_touch, логин owner,
  `/wiki?create=1`, boundingBox). Замеры: «Отмена» **86×44**, «Сохранить»
  **111×44** — обе ≥44px. Контроль: тулбар 15/15 кнопок 44×44 (не задеты),
  scrollWidth=375/clientWidth=375 (X-прокрутки нет), JS-ошибок 0.
  Детали — REPORT-4.3, секция «Верификация фикса BUG-017».
- **Вердикт: fixed, verified.** Прецедент NFR-23 соблюден; блокер снят —
  набор 4.3 зеленый (12/12), следующий набор (смок 4.4) может стартовать.

## Воспроизведение

Стенд по tests/README (tmp-БД + seed + `python -m app.migrate_wiki`),
логин owner → `/wiki/{id}?edit=1` при viewport 375×812 → boundingBox кнопок
«Сохранить»/«Отмена» → height 33.
