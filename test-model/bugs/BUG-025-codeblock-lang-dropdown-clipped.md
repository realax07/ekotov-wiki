# BUG-025: дропдаун выбора языка код-блока обрезается рамкой код-блока — выбор языка не работает

- **Источник:** решение Заказчика 2026-10-26 (скриншот прод-стенда в DM, тот же домен rich editor) — включен в волну bugfix/rich-editor-022-023-024 (маркер [BUG-022])
- **Домен:** rich editor — код-блок (FR-119, ОВ-2: выбор языка в шапке блока)

## Кейс / ожидание / факт

- **Кейс:** раскрыть дропдаун «python ▾» в шапке код-блока и выбрать другой язык.
- **Ожидание:** список языков виден целиком, опция кликабельна, клик меняет
  язык блока (FR-119/ОВ-2).
- **Факт:** дропдаун раскрывается, но список уезжает за фрейм внутри —
  обрезается контейнером код-блока, выбор языка не работает. Слова
  Заказчика: «выбор языка не работает, уехал за фрейм внутри».

## Локализация

`frontend/static/css/wiki.css` — `.codeblock { overflow: hidden }` (рамка и
скругления pre) клиппит `.lang-menu` (`position: absolute; z-index: 3`),
который строится ВНУТРИ шапки блока
(`frontend/static/js/wiki/rich/codeblock.js` — `wrap.appendChild(menu)`).
Меню открывается вниз и уходит под `overflow: hidden` контейнера —
обрезанная часть не получает события (hit-testing обрезанной области
уходит контейнеру).

## Рецепт фикса (реализовано)

Меню позиционируется ВНЕ clip-контекста код-блока: portal в
`document.body`, `position: fixed` от `getBoundingClientRect()` кнопки
(координаты ставит JS при открытии), z-index слоя 20 — над контентом и
панелями, под диалогами редактора (40). `onDocClick` учитывает, что меню
больше не внутри `wrap` (клик по опции не закрывает меню до срабатывания
обработчика опции). `.codeblock { overflow: hidden }` не трогается — рамка
и скругления pre остаются.

## Тест

`tests/web/test_coverage_rich_tools.py::test_bug025_codeblock_lang_menu_not_clipped`:
раскрыть дропдаун, bounding box списка целиком в viewport и продолжается
за нижнюю границу фрейма код-блока (не клиппится), опция кликабельна —
клик «sql» меняет `data-lang` блока. Существующие выборы языка в
TC-rich-006 / test_rich_tools переведены на поиск меню от `page`
(меню теперь вне поддерева блока).

## Серьезность и влияние

- **major** (функциональность FR-119): выбор языка код-блока недоступен,
  если список открывается вниз и обрезается — пользователь не может
  сменить язык подсветки.
