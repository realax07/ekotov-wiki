# BUG-015: в окнах просмотра виден старый dl-список признаков — прижат к краю, дублирует attr-grid

- **ID:** BUG-015
- **Статус:** ЗАКРЫТ (2026-10-08: review-001 APPROVE SHA 0096ed4 — sr-only паттерн, contract TC-UI-009 сохранен; PR #91 влит ce4c952; деплой r8-polish-3)
- **Дата:** 2026-10-08
- **Окружение:** прод r8-polish-2 (main a8dff23); окна просмотра (board и search — одинаково).
- **Severity:** major (видимый дубликат признаков без отступов — прямое нарушение мокапа)
- **Автотест:** TC-view-110 (tests/web/test_bug013_attrs_padding.py) проверяет ТОЛЬКО новую attr-grid — dl не покрывает (добавить ассерт: dl скрыт визуально).

## Жалоба Заказчика (повторная приемка, п.1)

«Отступы не поправил. Вот эти признаки начинаются прямо с края модального окна
во всех вариантах карточки просмотра: Описание / Приоритет / Категория / Срок /
Статус / Теги / Fast line / Исполнитель / Создатель» — перечислены ровно ряды
старого dl (addDetailRow).

## Корень (установлен ПМ по коду, 2026-10-08)

Рендер board/task-detail.js (renderTaskDetail): новое тело .task-view-body
(attr-grid/секции по мокапу) вставляется ПЕРЕД существующим
dl#task-detail-attrs (ensureViewBody:402-409), но сам **dl остается видимым**
и ЗАПОЛНЯЕТСЯ рядами (dl.textContent=""; addDetailRow(...)) — «контракт
TC-UI-009 / ОГР-28» (task-detail.js:479-506). Стили .task-view-attrs
(board.css:873: margin: 10px 0, dt/dd видимы) → старый список отображается
ниже нового тела, прижатый к краю (без горизонтальных отступов).
Заказчик видит его как «признаки по краю» — в обоих окнах (board и search,
разметка унифицирована в BUG-014).

Прошлая квалификация BUG-013 («не воспроизводится, дубль BUG-014») — ОШИБОЧНА:
TC-view-110 проверял только attr-grid, скрытый dl никто не проверял.

## Фикс (за dev)

dl#task-detail-attrs — скрытый носитель данных контракта (ОГР-28 id сохранен):
класс sr-only/hidden-паттерн (визуально скрыт, доступен скринридерам) ЛИБО
visibility-скрытие с сохранением в DOM содержимого (тест TC-UI-009 читает
textContent — контракт не ломать). Видимые признаки — только attr-grid.
+ Ассерт в TC-view-110: dl визуально скрыт (computed: display:none/absolute+clip
по паттерну), attr-grid видим.

## Критерий закрытия

В окнах board и search виден ТОЛЬКО attr-grid (старый dl не отображается);
TC-UI-009 зеленый (контракт данных не сломан); TC-view-110 расширен ассертом
скрытия dl; мутационная проверка (вернуть dl видимым → ассерт красный).
