# BUG-029: UI галереи не может снять реакцию — sendReaction всегда PUT (после BUG-026 toggle упразднен)

## Симптом
В лайтбоксе галереи повторный клик по активной реакции (лайк/дизлайк) не
снимает голос: `frontend/static/js/gallery.js::sendReaction` безусловно шлет
`PUT /api/images/{id}/like|/dislike`, который после BUG-026 (PR #266)
идемпотентен — same-sign повтор = 200 no-op. Пользователь не может убрать
свой голос из UI, при этом aria-метки кнопок обещают «Снять голос»
(aria-pressed=true + «ваш голос учтен. Снять голос»), т.е. UX рассчитан на
упраздненную toggle-семантику (докстринг gallery.js :18 «повторное —
снятие»).

## Root cause
BUG-026 изменил API-контракт (PUT = идемпотентный set, снятие — DELETE
/like | /dislike), но gallery.js не обновлен. Видео-аналог закрыт полностью:
TD-B2 (PLAN-TD-CLOSEOUT) — `video.js::sendReaction` по клику на АКТИВНОЙ
реакции шлет DELETE /api/videos/{id}/reaction, по неактивной — PUT.

## Решение (предложение, вне зон BUG-028)
Паритет TD-B2 для галереи: в `gallery.js::sendReaction` по состоянию
`img.my_reaction` различать установку (PUT) и снятие (DELETE /like |
/dislike по активной реакции); обновить докстринг :18. Хинт/aria уже
соответствуют целевому UX.

## Связь с красным TC-GAL-117 (базлайн tests/web)
Известный фоновый фейл полного сериала tests/web
`test_tc_gal_117_like_highlight_comment_ui_xss` падает ровно здесь: шаг
«повторный same-sign — снятие» (`gallery.js` клик по активной реакции →
ожидание `aria-pressed=false`) — красный с волны BUG-026, т.к. UI-семантика
toggle рассчитана на упраздненный контракт. Починка BUG-029 (паритет TD-B2)
закроет и TC-GAL-117; до этого он остается известным фоном (базлайн ПМ).
