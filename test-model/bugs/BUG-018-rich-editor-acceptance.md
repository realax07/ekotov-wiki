# BUG-018: rich-редактор — тулбар таблицы/колонок попадает в контент

- **Источник:** живая приемка p15-wiki-8 (Заказчик, 2026-10-16, скриншот)
- **Серьезность:** major — дефект виден на каждой таблице/колонках, загрязняет контент
- **Флоу:** 2 (багфикс, общий PLAN ниже)

## Статус

- 2025-10-16: исправлено (фиксы ae1a136-系列, code_review approve review-002-bugfix); деплой p15-wiki-9; CLOSED — после повторной живой приемки Заказчика

## Суть

Кнопки тулбара блока («+ строка», «− строка», «+ столбец», «− столбtw») висят
внутри редактируемого контента как элементы: их текст редактируется, при
добавлении строк они уезжают вниз как часть текста. Тулбар должен жить ВНЕ
редактируемой области (крепиться к обертке блока, исключаться из сериализации,
contenteditable=false).

## Дефект-2 (туда же)

Опечатка на кнопке: «− столбtw» → «− столбец».

## Критерии исправления

- Тулбар не сериализуется в контент (сохранение/перечитывание — кнопок в тексте нет)
- Тулбар не сдвигается при редактировании таблицы
- Текст кнопки исправлен; кнопки не редактируются как текст
- Регресс: тест roundtrip таблицы с тулбаром

# BUG-020: код-блок — режим «править код» не нужен, контент не сохраняется

- **Источник:** та же приемка. «Код когда пишу, он не сохраняется (+ непонятная
  кнопка править код). Нам по идее нужна только подсветка синтаксиса и
  графический фон».
- **Серьезность:** major — потеря контента пользователя + лишний UX-слой

## Решение Заказчика (дословно)

«Нужна только подсветка синтаксиса и графический фон» — режим «править код»
убрать; текст кода редактируется прямо в блоке; подсветка и фон остаются.

## Критерии исправления

- Набранный код сохраняется (roundtrip 1:1, переносы/пробелы — FR-122)
- Кнопка/режим «править код» удалена
- Подсветка + графический фон сохранены
- Регресс-тест roundtrip код-блока
