# BUG-026: PUT реакции не идемпотентен — сетевой повтор меняет результат

## Симптом
Повторный (ретрай сети/двойной клик) `PUT /api/images/{id}/like` снимает только что
поставленный голос. PUT по семантике HTTP обязан быть идемпотентным.

## Root cause
`services/images/app/gallery.py` — PUT like/dislike реализован как toggle
(upsert → повторное = снятие, задокументировано в докстринге :10-12), что
нарушает идемпотентность PUT (TD-5, аудит Kimi 2026-10-31).

## Решение
PUT = установить голос (idempotent set): тот же голос → 200 без изменения;
противоположный → перенос (как сейчас). Снятие — отдельный DELETE. Обновить
докстринг и тесты.

## Статус
OPEN → фикс через пилот оркестратора (package_runner, pipeline-манифест).
