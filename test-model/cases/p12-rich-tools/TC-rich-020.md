# TC-rich-020 — Удаление таблицы отдельной кнопкой (ОВ-4)

- **Change:** p12-rich-tools
- **Источник:** p12-rich-tools: «Редактирование таблиц — строки и столбцы (FR-122)» / Scenario: Удаление таблицы отдельной кнопкой
- **Тип:** позитивный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); тестовая страница wiki, созданная через `POST {BASE_URL}/api/wiki/pages`; Playwright (Python): `page`, `expect`, `api_request_context`; страница открыта в режиме редактирования (WYSIWYG-редактор)
- **Шаги:**
  1. Между двумя абзацами-сторожами вставить таблицу 2×2 с заполненными ячейками.
  2. Курсор в таблицу; нажать отдельную кнопку «Удалить таблицу» панели.
  3. Сохранить, открыть статью.
  4. Повторить шаг 1 и попробовать удалить таблицу кнопками «−».
- **Ожидаемый результат:** шаг 2 — таблица удалена целиком одним действием; шаг 3 — в статье таблицы нет, оба абзаца-сторожа не затронуты; шаг 4 — кнопки «−» строк/столбцов таблицу целиком не удаляют (удаление целиком — только отдельная кнопка, ОВ-4).
- **Тестовые данные:** абзацы-сторожа до/после таблицы
