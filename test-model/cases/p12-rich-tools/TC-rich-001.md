# TC-rich-001 — Вставка спойлера и инлайн-переименование

- **Change:** p12-rich-tools
- **Источник:** p12-rich-tools: «Спойлер (FR-118)» / Scenario: Вставка и переименование спойлера
- **Тип:** позитивный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); тестовая страница wiki, созданная через `POST {BASE_URL}/api/wiki/pages`; Playwright (Python): `page`, `expect`, `api_request_context`; страница открыта в режиме редактирования (WYSIWYG-редактор)
- **Шаги:**
  1. Войти как owner, открыть редактор тестовой страницы, курсор в конец абзаца.
  2. Нажать кнопку «Спойлер» тулбара.
  3. Кликнуть по названию вставленного спойлера, ввести «Скрытые детали», в зону содержимого ввести «Тело спойлера».
  4. Сохранить страницу (PUT), открыть статью.
  5. Осмотреть сохраненный контент через `GET {BASE_URL}/api/wiki/pages/<id>`.
- **Ожидаемый результат:** шаг 2 — вставлены шапка (шеврон + название) и зона содержимого, фокус в зоне содержимого; шаг 3 — название переименовывается инлайн; шаг 4 — в статье спойлер «Скрытые детали» с телом, вид соответствует мокапу tool-1-spoiler-edit.png; шаг 5 — контент содержит `data-block="spoiler"` + `data-title="Скрытые детали"`, служебных узлов редактора (`data-editor`) в контенте нет.
- **Тестовые данные:** текст названия «Скрытые детали»; мокап design/p12-rich/tool-1-spoiler-edit.png
