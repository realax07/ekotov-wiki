# TC-rich-016 — Backspace в пустом заголовке снимает формат (ОВ-5)

- **Change:** p12-rich-tools
- **Источник:** p12-rich-tools: «H-заголовки как переключатель (FR-121)» / Scenario: Backspace в пустом заголовке снимает формат
- **Тип:** граничный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); тестовая страница wiki, созданная через `POST {BASE_URL}/api/wiki/pages`; Playwright (Python): `page`, `expect`, `api_request_context`; страница открыта в режиме редактирования (WYSIWYG-редактор)
- **Шаги:**
  1. В редакторе поставить курсор в конец существующего абзаца, нажать Enter — новая пустая строка.
  2. Оформить пустую строку как H2 (не вводя текст).
  3. Нажать Backspace.
  4. Осмотреть блок под курсором и состояние H-кнопок.
- **Ожидаемый результат:** формат снят: строка стала пустым абзацем с курсором в нем; ни один символ существующего контента не удален (предыдущий абзац цел — перехват keydown сработал вместо штатного слияния); кнопки H1/H2/H3 отжаты (ОВ-5, канон Notion/GDocs).
- **Тестовые данные:** сторожевой текст в предыдущем абзаце для проверки целостности
