# TC-rich-008 — Код-блок внутри спойлера — подсветка и копирование, toggle без потерь

- **Change:** p12-rich-tools
- **Источник:** p12-rich-tools: «Блок кода с подсветкой синтаксиса (FR-119)» / Scenario: Код-блок внутри спойлера
- **Тип:** позитивный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); тестовая страница wiki, созданная через `POST {BASE_URL}/api/wiki/pages`; Playwright (Python): `page`, `expect`, `api_request_context`; страница открыта в режиме редактирования (WYSIWYG-редактор)
- **Шаги:**
  1. Вставить спойлер, в его тело — код-блок с кодом на 5+ строк, сохранить, открыть статью.
  2. Свернуть и развернуть спойлер.
  3. Нажать «Копировать» в код-блоке, сравнить буфер с исходным кодом.
  4. Сверить `GET`-контент.
- **Ожидаемый результат:** подсветка и копирование работают внутри спойлера; toggle спойлера не теряет ни символа кода (textContent до/после идентичен); в контенте код-блок вложен в тело спойлера (`data-block="code"` внутри `data-block-part="body"`).
- **Тестовые данные:** исходный код-эталон для сравнения буфера
