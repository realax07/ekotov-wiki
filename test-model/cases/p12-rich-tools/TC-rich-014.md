# TC-rich-014 — Повторный клик H2 снимает заголовок без потери текста, undo жив (F4)

- **Change:** p12-rich-tools
- **Источник:** p12-rich-tools: «H-заголовки как переключатель (FR-121)» / Scenario: Повторный клик снимает заголовок без потери текста
- **Тип:** позитивный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); тестовая страница wiki, созданная через `POST {BASE_URL}/api/wiki/pages`; Playwright (Python): `page`, `expect`, `api_request_context`; страница открыта в режиме редактирования (WYSIWYG-редактор)
- **Шаги:**
  1. Оформить абзац «Текст заголовка» как H2.
  2. Повторно нажать кнопку H2.
  3. Осмотреть состояние кнопок H1/H2/H3 (aria-pressed).
  4. Нажать Ctrl+Z.
- **Ожидаемый результат:** шаг 2 — кнопка H2 отжалась, текст стал обычным абзацем без изменения символов; шаг 3 — ни одна кнопка H1/H2/H3 не нажата (CLEAR-состояние мокапа tool-4-headings.html); шаг 4 — Ctrl+Z откатывает снятие (текст снова H2) — undo-стек contenteditable жив (находка F4: замена через execCommand('formatBlock')).
- **Тестовые данные:** мокап tool-4-headings.html, CLEAR-состояние
