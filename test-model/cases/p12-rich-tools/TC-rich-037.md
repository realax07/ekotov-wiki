# TC-rich-037 — Enter в код-блоке: round-trip переносов без br-мусора (фикс F-1)

- **Change:** p12-rich-tools
- **Источник:** p12-rich-tools: «Блок кода с подсветкой синтаксиса (FR-119)» + design §2/§3; ревью находка F-1 (Enter/br в коде: санитайзер br→\n в code-контексте, normalizeCodeInput) — дискриминатор фикса
- **Тип:** граничный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); тестовая страница wiki, созданная через `POST {BASE_URL}/api/wiki/pages`; Playwright (Python): `page`, `expect`, `api_request_context`; страница открыта в режиме редактирования (WYSIWYG-редактор)
- **Шаги:**
  1. Вставить код-блок, ввести три строки кода, нажимая Enter между ними; в одной строке — намеренный перенос.
  2. Сохранить страницу, осмотреть `GET`-контент (внутренности `pre/code`).
  3. Переоткрыть страницу в редакторе, осмотреть текст кода в DOM, снова сохранить.
  4. Отдельно: вставить пустой код-блок, не вводя текст, сохранить и осмотреть `GET`.
  5. Открыть статью, сверить построчный вид.
- **Ожидаемый результат:** шаг 2 — внутри `pre/code` переносы сохранены как `\n` в тексте; `<br>` внутри code-контекста не сохраняется (санитайзер переводит br→\n), текст посимвольно равен введенному; шаг 3 — повторное открытие/сохранение НЕ задваивает переносы (normalizeCodeInput идемпотентен: нет `\n\n` на месте одного Enter), второй round-trip без искажений; шаг 4 — пустой код-блок не содержит мусорных `\n`/`<br>`; шаг 5 — построчный вид статьи совпадает с введенным.
- **Тестовые данные:** код из 3 строк с контролируемыми переносами; эталон текста; два round-trip прогона
