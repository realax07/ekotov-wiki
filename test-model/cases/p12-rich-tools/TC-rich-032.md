# TC-rich-032 — Undo/redo, включая undo после H-toggle (F4)

- **Change:** p12-rich-tools
- **Источник:** p12-rich-tools: wiki: «WYSIWYG-редактор страниц» / Scenario: Undo/redo
- **Тип:** позитивный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); тестовая страница wiki, созданная через `POST {BASE_URL}/api/wiki/pages`; Playwright (Python): `page`, `expect`, `api_request_context`; страница открыта в режиме редактирования (WYSIWYG-редактор)
- **Шаги:**
  1. В редакторе последовательно: вставить спойлер, снять формат H2 повторным кликом, заменить H1→H3.
  2. Нажать Ctrl+Z три раза, фиксируя состояние после каждого.
  3. Нажать redo (Ctrl+Y / кнопка) три раза.
  4. Сохранить и открыть статью.
- **Ожидаемый результат:** шаг 2 — правки отменяются в обратном порядке, ВКЛЮЧАЯ снятие и замену заголовка (H-toggle через execCommand('formatBlock') держит нативный undo-стек — находка F4; после undo текст не теряется и не дублируется); шаг 3 — redo повторно применяет; шаг 4 — финальное состояние корректно (FR-110).
- **Тестовые данные:** последовательность из 3 правок разных типов
