# TC-rich-011 — Добавление, dblclick-переименование и запрет удаления последней вкладки

- **Change:** p12-rich-tools
- **Источник:** p12-rich-tools: «Табуляция (FR-120)» / Scenario: Добавление, переименование и ограничение удаления
- **Тип:** позитивный + негативный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); тестовая страница wiki, созданная через `POST {BASE_URL}/api/wiki/pages`; Playwright (Python): `page`, `expect`, `api_request_context`; страница открыта в режиме редактирования (WYSIWYG-редактор)
- **Шаги:**
  1. Открыть редактор таб-виджета с одной вкладкой «Обзор».
  2. Нажать «+» в таб-баре.
  3. Двойным кликом по новой вкладке переименовать её в «Детали».
  4. Удалить вкладку «Обзор» крестиком (осталась одна).
  5. Попытаться удалить оставшуюся вкладку «Детали».
  6. Сохранить и открыть статью.
- **Ожидаемый результат:** шаги 2–3 — вкладка создана и переименована; шаг 4 — удаление «Обзор» возможно (стало 1); шаг 5 — удаление единственной вкладки заблокировано (крестик неактивен/disabled с подсказкой), виджет не исчезает; шаг 6 — в статье вкладки «Обзор» нет, «Детали» на месте.
- **Тестовые данные:** названия «Обзор», «Детали»
