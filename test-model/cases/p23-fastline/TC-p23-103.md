- **Тип:** позитивный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!` (seed); доска без активных fast-задач (занятый слот освобождить: выполнить/выключить fast либо дождаться автоархивации МСК-дня); созданные кейсом задачи удаляются в cleanup (`web_cleanup_created`); Playwright (Python): `page`, `expect`, `api_request_context`; хелперы `tests/web/pages/board.py` (зона-агностик `BoardPage.card_in_column`), `tests/web/dnd_helpers.py` (`dnd_dispatch`, общий DataTransfer)
- **Шаги:**
  1. Создать fast-задачу (`FL-слот`), перевести в «В работе».
  2. Выполнить: селект/кнопка карточки → «Выполнено» зоны (POST `/api/tasks/{{id}}/move` status=done).
  3. Осмотреть шапку зоны и столбец «Выполнено» зоны; проверить `GET /api/board`.
  4. Создать новую fast-задачу кнопкой «+ Fast-задача».
- **Ожидаемый результат:** шаг 2 — карточка в «Выполнено» ЗОНЫ (не канбана), `status=done`, `done_at` проставлен; шаг 3 — кнопка «+ Fast-задача» снова активна (слот свободен: инвариант ≤1 считает только todo/in_progress), выполненная карточка остается видимой в «Выполнено» зоны до автоархивации МСК-дня (Э1); шаг 4 — новая fast создается (201) и встает в «Ожидает» зоны.
- **Тестовые данные:** ГРАНИЦА: две fast-карты в зоне одновременно — разрешено только в паре «активная + выполненная»; `done_at` = msk_now_iso
