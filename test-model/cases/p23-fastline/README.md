## Приоритеты

- **Must** — 21 кейс: все 18 сценарных (100–115, 117) и доп. негативы/границы (118 Э2, 119, 120 гонка вкладок, 121 XSS).
- **Should** — 1 кейс: TC-p23-116 (цвета приемников — DOM-ассерты плюс визуальная сверка с мокапами).

## Готовность к автоматизации

- Уровни: web-сьют Playwright `tests/web/` (jsdom-совместимая обвязка, `pytest.mark.web`) для UI/DnD-кейсов (100–111, 113–121); чистый API pytest (`api_request_context` / `requests`) для 112 (и серверных частей 103/110/115) — существующий `tests/api/test_tasks.py` уже держит 409/422/ и остается зеленым без изменений (бэкенд не меняется, impact §6).
- Соответствие dev-диффу (tests/web/test_board_fastline.py, волна 4): кейсы 100/101/106 → TC-p23-101; 102/104/105/107 → TC-p23-102; 103/108 → TC-p23-103; 110 → TC-p23-104 (гейт 2.5); 113 → TC-p23-105 (O1); 117/118 → TC-p23-106 (+ветка пустой зоны); 119 → TC-p23-107; 120 → TC-p23-108 (O2); 115 → наследник TC-dnd-103 в `tests/web/test_r3_dnd_ui.py` (tasks 4.4). ГЭПЫ сьюта (требуют дополнения): 109 (PATCH-нагрузка вставки FR-89), 111 (paste/селект не несет is_fast), 114 (done_at + слот после drop), 116 (цвета приемников), 121 (XSS-векторы).
- Селекторы: зона — `#fastline .fastline-column[data-fastline-stage=todo|in_progress|done]`, канбан — `#board .board-column[data-status=…]`; зона-агностик поиск карточки — `BoardPage.card_in_column` (dataset.status || dataset.fastlineStage, хелперы волны 4, F2); ошибка — `#board-error`; готовность доски — `#board[data-loaded=true]`.
- DnD: только `dnd_dispatch`/`dnd_start` (`tests/web/dnd_helpers.py`) с общим DataTransfer — нативный HTML5 DnD Playwright не эмулирует; «ровно один POST» (113) и «запроса нет» (117–119) — счетчик запросов через `page.expect_request`/route.
- Гонка вкладок (120): вторая вкладка `context.new_page()` того же контекста; падение на 409 валидируется как УСПЕХ кейса.
- XSS (121): `page.on("dialog")` — любой dialog = провал; плюс аудит DOM на on*-атрибуты; векторы через API-создание (UI-путь не зависит от sanitize ввода).
- Границы МСК-дня (103, 114): `done_at`/автоархивация проверяются по `GET /api/board` без ручного перевода часов; долговременная автоархивация — вне кейсов (существующие api-тесты).
- Cleanup: все созданные задачи — через `web_cleanup_created`; кейс 118 создан специально БЕЗ fast-precondition (пустая зона — часть предусловия).
