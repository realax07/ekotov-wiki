# TC-nav-105 — Профиль не вытесняет существующие разделы сайдбара

- **CHK:** CHK-155
- **Change:** add-r3-visual-foundation
- **Источник:** navigation: «Профиль…внизу сайдбара» (FR-33, Д-7); Сценарий «Профиль не нарушает верстку сайдбара»
- **Тип:** поз. | **Приоритет:** Must
- **Среда/предусловия:** web-стенд tests/web; вход owner; открыта /settings (внизу сайдбара — «Настройки» и «Выйти»).
- **Шаги:**
  1. Открыть /settings; зафиксировать порядок элементов внутри `.sidebar`/`.sidebar-footer`: ссылки Доска/Поиск/Wiki/Настройки, кнопка «Выйти», `#sidebar-profile`.
  2. Проверить позицию `#sidebar-profile` в DOM относительно `#logout-button` (following sibling).
  3. Кликнуть поочередно каждую из четырех ссылок — дождаться заголовка соответствующей страницы.
- **Ожидаемый результат:** блок профиля стоит ПОСЛЕ `#logout-button` (внизу сайдбара); все четыре раздела кликабельны и ведут на свои страницы (никто не вытеснен, перекрытий нет).
- **Тестовые данные:** страницы /board, /search, /wiki, /settings; заголовки «Доска», «Поиск», «Wiki», «Настройки».
