## TC-search-010 — Поиск через API с фильтром
- **CHK:** CHK-75
- **Источник:** search: «Поиск через API» (FR-8) / Scenario: Поиск через API с фильтром
- **Тип:** позитивный | **Приоритет:** Should
- **Предусловия:** общие (валидная сессия) + фикстура. Примечание: семантика повторяемого query-параметра `tag` (И/ИЛИ) спекой НЕ определена (sdd §3.5 — «повторяемый» без семантики; design §6 — «условия объединяются по И»; Дефект DS, эскалация ПМ).   2. Повторить с повторяемым параметром: `curl -s -b owner_cookies.txt "{BASE_URL}/api/search?tag=urgent&tag=home"`; зафиксировать фактическую выдачу (какие задачи, сколько) и фактическую семантику И/ИЛИ в протоколе прогона для эскалации.

Фактическая семантика повторяемого `tag` (И/ИЛИ) и состав выдачи фиксируются в протоколе; окончательное ожидание — после решения DS через ПМ.
