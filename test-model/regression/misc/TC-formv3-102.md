# TC-formv3-102 — Выбранные теги отображаются чипами по дизайну V3

- **CHK:** CHK-170
- **Change:** add-r3-visual-foundation
- **Источник:** tasks: «Формы…по дизайну V3» (FR-34, зона 1 — вид выбранных тегов, DEF-005); Сценарий «Выбранные теги отображаются по дизайну V3»
- **Тип:** поз. | **Приоритет:** Must
- **Среда/предусловия:** web-стенд tests/web; вход owner; открыта форма создания задачи.
- **Шаги:**
  1. В поле «Теги» ввести `QAT-тег1, QAT-тег2`; дождаться контейнера `#task-tags-chips` видимым.
  2. Прочитать состав чипов: количество, тексты; computed style чипа (`.chip`): border-radius, background.
  3. Кликнуть крестик первого чипа (кнопка внутри `.chip`); перечитать чипы и значение input.
- **Ожидаемый результат:** контейнер показывает 2 чипа с текстами «QAT-тег1», «QAT-тег2»; чип — пилюля (border-radius ненулевой, фон по токену); после клика по крестику первого чипа остался 1 чип («QAT-тег2»), значение input синхронно `QAT-тег2` — чипы и input консистентны.
- **Тестовые данные:** теги `QAT-тег1, QAT-тег2` (QAT-префикс — изоляция, теги не сохраняются в задачу).
