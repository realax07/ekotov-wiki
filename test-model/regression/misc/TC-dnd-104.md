# TC-dnd-104 — DnD в «Выполнено»: done_at проставлен, архивации мгновенно нет

- **CHK:** CHK-161
- **Change:** add-r3-visual-foundation
- **Источник:** board: «Перемещение карточки перетаскиванием» (FR-31, FR-4, ОГР-14); Сценарий «Перетаскивание в Выполнено подчиняется правилам архивации»
- **Тип:** поз. | **Приоритет:** Must
- **Среда/предусловия:** web-стенд tests/web; вход owner; задача «QAT-dnd-done» в «Ожидает». Механика — dispatchEvent с DataTransfer.
- **Шаги:**
  1. `dispatchEvent('dragstart')` на карточке; `dispatchEvent('dragover')` на `[data-status="done"]`; `dispatchEvent('drop')`.
  2. Автожидание: карточка в `[data-status="done"] [data-cards]`.
  3. `GET /api/tasks/{id}` API-сессией: прочитать `status`, `done_at`, `archived_at`.
- **Ожидаемый результат:** status = `done`; `done_at` непустое и парсится как момент времени перевода в МСК: строка с смещением `+03:00` ИЛИ эквивалент того же МСК-момента в формате `Z` (UTC) — ассерт по моменту времени, не по суффиксу строки; `archived_at` пустое (null) — задача остается в столбце «Выполнено» до ленивой автоархивации следующим МСК-днем (результат идентичен переводу существующим способом, ОГР-14).
- **Тестовые данные:** задача `QAT-dnd-done`; ожидаемый формат done_at: ISO с `+03:00` (справочно: допустим Z-эквивалент того же момента; жесткого требования к суффиксу CHK-161 не содержит).
