# TC-env-001 — Seed справочника категорий до любого прогона (средовое предусловие)

- **CHK:** CHK-139
- **Change:** add-r2-categories-settings
- **Источник:** impact §4.1 (следствие FR-21) — seed справочника — предусловие прогонов
- **Тип:** средовый | **Приоритет:** Must
- **Среда/предусловия:** тестовая БД приложения (env `EKOTOV_WIKI_DB_PATH`); conftest проекта (`tests/api/conftest.py`, `tests/web/`); права на создание seed-фикстуры (qa_automation).
- **Сценарий:**
  - **GIVEN** чистая тестовая БД с мигрированным справочником; seed-фикстура (conftest, session-scope) зарегистрирована
  - **WHEN** стартует ЛЮБОЙ прогон (API и web) до первого теста
  - **THEN** seed-фикстура создает в справочнике `Дом`, `Работа`, `Личное` + автосоздание категорий с префиксом `QAT-*` (или расширяемый seed-список) ДО любого прогона; без seed — setup отказы, не дефекты продукта
- **Шаги:**
  1. Проверить состояние справочника до прогонов: `curl -s -b owner_cookies.txt {BASE_URL}/api/categories` — состав зафиксировать.
  2. Запустить тестовый прогон (минимум: один тест из каждого зависимого файла — TC-002/005/006 (test_tasks), search_fixtures (test_search), TC-arch-008 (test_archive), TC-UI-009/017, QAT-* сьюты test_suggestions*/test_search_suggestions_ui).
  3. Повторить `GET /api/categories` — сверить наличие `Дом`, `Работа`, `Личное`.
  4. Негатив-контроль среды: на копии БД удалить seed-фикстуру (или очистить справочник) → перезапустить зависимые тесты → зафиксировать характер падений (setup, не ассерты).
- **Ожидаемый результат:** шаги 1/3 — после старта прогона справочник содержит `Дом`, `Работа`, `Личное` (seed создан session-scope фикстурой до тестов); шаг 2 — зависимые тесты (8+ тестов в 5 файлах, impact §4.1) проходят setup; шаг 4 — без seed падение происходит на SETUP (fixture/HTTP 422 при подготовке данных), что классифицируется как **средовый отказ, не дефект продукта** — соответствующая маркировка в отчете прогона.
- **Тестовые данные:** seed-список `Дом`, `Работа`, `Личное`; префикс автосоздания `QAT-*`; зависимые файлы: tests/api/test_tasks.py, test_search.py, test_archive.py, tests/web/test_board_tasks_ui.py, test_navigation_search_ui.py, test_search_suggestions_ui.py, test_suggestions*.py.
