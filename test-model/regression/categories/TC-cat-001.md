# TC-cat-001 — Поле категории в форме задачи: выбор только из справочника

- **CHK:** CHK-82
- **Change:** add-r2-categories-settings
- **Источник:** categories: Справочник категорий (FR-19) / Scenario: Поле категории предлагает только значения справочника
- **Тип:** позитивный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); Playwright (Python): `page`, `expect`; выполнен вход owner (логин `owner`, пароль `QaOwner_Pass_1!` — seed, как TC-UI-002 чеклиста e2e-critical-path); seed справочника выполнен (CHK-139 / TC-env-001: `Дом`, `Работа`, `Личное` в справочнике до прогона).
- **Сценарий:**
  - **GIVEN** пользователь авторизован; в справочнике заведены `Дом`, `Работа` (+ seed `Личное`)
  - **WHEN** пользователь открывает форму создания задачи и осматривает поле категории
  - **THEN** поле — select, опции которого ровно совпадают со справочником; ввод произвольного текста невозможен
- **Шаги:**
  1. `GET {BASE_URL}/api/categories` (с куками) → зафиксировать список имен `S`.
  2. Открыть `{BASE_URL}/board`; `page.get_by_role("button", name="Создать задачу").click()`.
  3. Осмотреть поле «Категория»: локатор `page.get_by_label("Категория")`; зафиксировать тег элемента (`evaluate("el => el.tagName")`).
  4. Прочитать опции: `opts = page.get_by_label("Категория").locator("option").all_inner_texts()` (пустую опцию-плейсхолдер исключить из сравнения, зафиксировать ее наличие).
  5. Попытаться ввести произвольный текст: `page.get_by_label("Категория").fill("QAT-ghost-текст")` — зафиксировать исключение (select не поддерживает fill).
- **Ожидаемый результат:** шаг 3 — тег элемента `SELECT` (не INPUT и не элемент с `list="…"`); шаг 4 — множество опций (без пустой опции-плейсхолдера) равно множеству `S` из шага 1; шаг 5 — `fill()` на select падает (`Error: Element is not an <input>`/аналог) — свободный ввод невозможен (sdd §4: поле категории — select из `GET /api/categories`).
- **Тестовые данные:** справочник `Дом`, `Работа`, `Личное`; произвольный текст `QAT-ghost-текст` (должен быть ОТВЕРГНУТ полем).
