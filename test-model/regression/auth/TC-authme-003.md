# TC-authme-003 — GET /api/auth/me read-only: повторные вызовы не меняют состояние

- **CHK:** CHK-150
- **Change:** add-r3-visual-foundation
- **Источник:** auth: «API текущего пользователя» (FR-33, ОГР-13 — read-only, «пароли, логины, профиль — вне скоупа»); дополнение чеклиста (гран., read-only)
- **Тип:** гран. | **Приоритет:** Must
- **Среда/предусловия:** тестовый стенд tests/api; сессия owner.
- **Шаги:**
  1. `GET /api/auth/me` — зафиксировать код и тело.
  2. Повторить вызов 3 раза подряд в той же сессии.
  3. `POST /api/auth/login` с тем же паролем owner — убедиться, что вход по-прежнему работает.
- **Ожидаемый результат:** все 4 ответа — 200 с идентичным телом `{"user": "owner"}` (состояние не меняется: read-only, никаких INSERT/UPDATE — ОГР-13); повторный вход owner успешен (пароль не изменен, профиль не затронут).
- **Тестовые данные:** login `owner` / `QaOwner_Pass_1!`.
