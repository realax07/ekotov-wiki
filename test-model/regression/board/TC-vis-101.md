# TC-vis-101 — Обязательный минимум: hover-переход карточки (пресет В)

- **CHK:** CHK-164
- **Change:** add-r3-visual-foundation
- **Источник:** board: «Визуальные эффекты доски поверх токенов V3» (FR-32, ОГР-12); Сценарий «Обязательный минимум — hover-переходы карточек»
- **Тип:** поз. | **Приоритет:** Must
- **Среда/предусловия:** web-стенд tests/web; вход owner; на доске есть ≥1 карточка (создана тестом, QAT-префикс); контейнер `#board` несет класс `preset-v`.
- **Шаги:**
  1. Убедиться: `#board` имеет класс `preset-v`.
  2. Прочитать computed style карточки до наведения: `transform`, `box-shadow`, `transition`.
  3. `card.hover()`; повторно прочитать computed style.
  4. Прочитать цвет заголовка карточки (`.task-card-title`) до/после hover.
- **Ожидаемый результат:** у `#board` есть `preset-v`; transition содержит ненулевую длительность (переход по токенам, не мгновенный); после hover transform ≠ `none` (подъем −4px / масштаб 1.01) и box-shadow ≠ `none` (тень/глубина); цвет заголовка изменился на терракотовый акцент (`--p-clay-700`).
- **Тестовые данные:** карточка `QAT-vis-hover`; ожидаемые сдвиги: translateY(-4px) scale(1.01).
