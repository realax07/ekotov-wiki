# TC-fast2-007 — Негативный: подделанный клиентский запрос (минуя блокировку поля) отклоняется

- **CHK:** CHK-133
- **Change:** add-r2-categories-settings
- **Источник:** fastline MODIFIED (FR-27, ОГР-10) / Scenario: Негативный: снятие блокировки в UI не меняет приоритет fast-задачи
- **Тип:** негативный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); Playwright (Python): `page`, `expect`; выполнен вход owner (логин `owner`, пароль `QaOwner_Pass_1!` — seed, как TC-UI-002 чеклиста e2e-critical-path); seed справочника выполнен (CHK-139 / TC-env-001).
- **Сценарий:**
  - **GIVEN** вызывающий авторизован (форма задачи открыта)
  - **WHEN** вызывающий отправляет подделанный клиентский запрос (минуя блокировку поля) на создание fast-задачи с приоритетом, отличным от high
  - **THEN** запрос отклоняется серверной валидацией — приоритет fast-задачи не может отличаться от high ни при каких клиентских действиях
- **Шаги:**
  1. Открыть `/board`; форму можно не открывать — запрос подделывается напрямую из контекста страницы.
  2. Выполнить из консоли страницы (минуя disabled-поле): `page.evaluate("fetch('/api/tasks', {method:'POST', headers:{'Content-Type':'application/json'}, body: JSON.stringify({title:'QAT-фаст-подделка', is_fast:true, priority:'low'})}).then(r => r.status).then(s => window.__fast_status = s)")`; прочитать `page.evaluate("window.__fast_status")`.
  3. `GET "/api/search?archived=false"` → посчитать задачи `QAT-фаст-подделка`.
- **Ожидаемый результат:** шаг 2 — статус **422** (серверная валидация отклонила; тело содержит `details.priority="fast requires high"`, при желании расширить evaluate до тела); шаг 3 — 0 совпадений: обход блокировки поля на клиенте не меняет исход — валидация серверная (FR-27/ОГР-10).
- **Тестовые данные:** подделанный payload `{"title":"QAT-фаст-подделка","is_fast":true,"priority":"low"}` (должен быть ОТВЕРГНУТ).
