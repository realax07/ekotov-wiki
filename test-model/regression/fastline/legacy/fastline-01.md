## TC-fast-001 — Fast line отображается на доске
- **CHK:** CHK-28
- **Источник:** fastline: «Выделенная линия fast line» (FR-3) / Scenario: Fast line отображается на доске
- **Тип:** позитивный | **Приоритет:** Must
- **Предусловия:** общие; создана fast-задача `Фаст-визуал` (`is_fast=true`), статус todo.
- **Шаги:**
  1. Открыть `{BASE_URL}/board` в браузере.
  2. Осмотреть разметку/стили: элемент fast line (инспектор DOM: класс/стиль подсветки).
- **Ожидаемый результат:** на доске есть выделенная линия с fast-задачей; подсветка — светло-синий прозрачный цвет (визуально отличим от фонов трех столбцов; в CSS — rgba светло-синего с прозрачностью); линия не является четвертым столбцом (расположена поверх/над столбцами).
- **Тестовые данные:** title=`Фаст-визуал`, is_fast=`true`.

## TC-fast-004 — Автоназначения на fast line нет
- **CHK:** CHK-31
- **Источник:** fastline: «Назначение задачи на fast line вручную при создании» (FR-3, ОГР-5, дополнение: негативный класс)
- **Тип:** негативный | **Приоритет:** Must
- **Предусловия:** общие; создана обычная (не fast) задача `Не-фаст` в todo; активных fast-задач нет.
- **Шаги:**
  1. `POST /api/tasks/{id}/move -d '{"status":"in_progress"}'` → проверить `is_fast`.
  2. `POST /api/tasks/{id}/move -d '{"status":"todo"}'` → проверить `is_fast`.
  3. `PATCH /api/tasks/{id}` с `-d '{"priority":"high"}'` → проверить `is_fast`.
- **Ожидаемый результат:** после всех трех операций `is_fast=false` — ни смена статуса, ни редактирование признаков не назначает задачу на fast line (назначение только при создании).
- **Тестовые данные:** title=`Не-фаст`; последовательность статусов `todo → in_progress → todo`; priority=`high`.

## TC-fast-006 — Вторая fast-задача через API → 409, не создана
- **CHK:** CHK-33
- **Источник:** fastline: «Не более одной fast-задачи в активных статусах» / Scenario: Негативный через API (FR-3, ОГР-5)
- **Тип:** негативный | **Приоритет:** Must
- **Предусловия:** общие; активная fast `Фаст-первая` (todo или in_progress).
- **Шаги:**
  1. `curl -s -i -b owner_cookies.txt -X POST {BASE_URL}/api/tasks -H "Content-Type: application/json" -d '{"title":"Фаст-вторая-API","is_fast":true}'` → код и тело.

- **Тестовые данные:** body: `{"title":"Фаст-вторая-API","is_fast":true}`.

## TC-fast-007 — Повторный запрос создания второй fast → снова 409
- **CHK:** CHK-34
- **Источник:** fastline: «Не более одной fast-задачи в активных статусах» (FR-3, ОГР-5, дополнение: состояние)
- **Тип:** негативный | **Приоритет:** Must
- **Предусловия:** те же, что TC-fast-006; оба отказа выполняются в одной сессии последовательно.
- **Шаги:**

## TC-fast-009 — Новая fast после ухода предыдущей в Выполнено

## TC-fast-012 — Fast-задача визуально первоочередная

- **Предусловия:** общие; fast `Фаст-приоритет` (todo, is_fast=true); в «Ожидает» есть ≥2 обычные задачи (`Обыч-П1`, `Обыч-П2`).
