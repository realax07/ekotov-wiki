## 1. Общее описание

Релиз 2 добавляет в систему справочник категорий, раздел настроек и дорабатывает форму задачи:

- **Справочник категорий (P5):** категории перестают быть свободным текстом — это задаваемый в настройках список. Задача создается/редактируется только с категорией из справочника; сохранение с категорией вне справочника запрещено (решение Заказчика «Жесткая»). Существующие текстовые значения категорий переносятся в справочник при миграции (решение «Мапь в справочник»).
- **Настройки (P2):** новый раздел «Настройки» в сайдбаре (внизу слева, рядом с кнопкой выхода). Настройки общие: оба пользователя видят и меняют их (решение «Общие») — это согласуется с моделью «общая доска» без разграничения прав (основное ТЗ, NFR-4, ОГР-6). Состав настроек первого релиза — управление справочником категорий.
- **Форма задачи (P1):** выбор категории из справочника (не свободный текст); автодополнение тегов из уже заведенных значений; для fast-задач приоритет принудительно «высокий» без возможности смены; крестик закрытия модального окна — в правом верхнем углу; улучшение визуала формы.
- **DEF-001:** селект-поля (категория в форме и в фильтре-конструкторе) заполняются из уникальных значений соответствующих столбцов БД, а не статическими/пустыми списками.
- **P4 (ретро-формализация):** подсказки в поиске уже реализованы (FR-15…FR-18, requirements-p4.md, заархивировано) — в скоуп Релиза 2 не входят; механизм единого эндпоинта подсказок переиспользуется формой задачи (см. FR-26, Д-3).

Назначение системы не меняется (учет задач, основное ТЗ раздел 1). Пользователей по-прежнему двое (владелец и жена).

### Форма задачи (P1, задачи 2.3–2.5)
