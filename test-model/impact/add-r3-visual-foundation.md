1. **Web-стенд** (tests/web/conftest): uvicorn на свободном порту + http.server-статика (реплика nginx-топологии) + временная БД с seed owner/wife + справочник «Дом/Работа/Личное» — существующий, изменений не требует.
2. **Secure-кука**: на http-стенде запросы только с 127.0.0.1 (trustworthy origin) — и браузер Playwright, и LocalhostSession работают; новых зависимостей дельта не вводит.
3. **prefers-reduced-motion**: web-тест эмулирует через Playwright `context.reduce_motion="reduce"` (или emulate_media) — средовая настройка контекста, фикстура в новом файле.
