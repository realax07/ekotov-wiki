## Характер дельты

- **MODIFIED — board «Отображение канбан-доски» (FR-101, санкция ОВ-3 на
  уточнение FR-62):** на ≤480px доска — горизонтальный свайп-контейнер
  колонок (flex ~82vw, `scroll-snap-type: x mandatory`, индикатор точек,
  тап по точке — скролл к колонке без анимации при
  prefers-reduced-motion, ОГР-17); страница вне контейнера MUST быть без
  прокрутки по X; быстрое «Выполнено» доступно с тача (таргет ≥44px,
  NFR-23); тач-DnD — anti-scope. На >480px доска как прежде (NFR-29).
  Формулировка FR-62 «без горизонтальной прокрутки» уточнена — относится
  к странице, не к санкционированному жест-контейнеру.
- **MODIFIED — board «Просмотр карточки задачи» (FR-102, ОВ-4):** на
  ≤480px просмотр и редактирование — одна fullscreen-оболочка
  (`position: fixed; inset: 0`, шапка с крестиком, скролл тела, подложка
  `overflow: hidden`); «Редактировать» заменяет содержимое in place
  (паттерн Д-9 сохранен); закрытие возвращает на доску в прежнюю
  scroll-позицию; поля ≥16px (NFR-24), кнопки ≥44px (NFR-23). Read-only
  семантика, отличие от форм, «Unassigned», tooltips — не тронуты.
- **ADDED — navigation «Мобильная навигация — бургер и drawer»
  (FR-99, ОВ-2):** на ≤768px `.sidebar` переводится в off-canvas drawer
  (`translateX(-100%)` + класс `sidebar-open` на `<body>`, подложка
  `.sidebar-backdrop`); DOM навигации НЕ дублируется; закрытие — пункт,
  подложка, повторный бургер, Esc; сцена на ≤768px — вся ширина
  (`margin-left: 0`); фокус-менеджмент: фокус на первый пункт при
  открытии, возврат на бургер при закрытии.
- **ADDED — navigation «Индикация активного раздела на мобильном»
  (FR-100):** заголовок раздела в шапке (серверный шаблон), читаем на
  375px; активный пункт drawer подсвечен существующим `.active`.
- **ADDED — navigation «Мобильный вид разделов по утвержденным мокапам»
  (FR-106):** ворота дизайн-фазы волны 0 — мокапы утверждены Заказчиком
  ДО dev (decision 2026-10-08-p14-mockups-approve), сверка после dev —
  design_validator (факт: 7/7 APPROVE).
- **MODIFIED — gallery «Full-screen просмотр с листанием» (FR-105,
  ОВ-1/С3):** на тач-устройствах листание ДОПОЛНЯЕТСЯ горизонтальным
  свайпом по области изображения (порог ~50px, |dx|>|dy|, циклично по
  текущей выдаче — паритет стрелок); жест ТОЛЬКО на изображении — скролл
  панели комментариев не перехватывается; короткое/диагональное движение
  = тап; зум-жесты своей реализацией — anti-scope, нативный pinch
  сохранен (NFR-28); стрелки-зоны и клавиатура desktop — без изменений.
- **ADDED — search «Поиск на мобильном — одна колонка» (FR-103):** на
  ≤480px инпут, фильтр-конструктор, advanced и выдача — вертикально
  full-width; без прокрутки страницы по X; строки выдачи читаемы без
  обрезки/зума на 375px; инпуты ≥16px, тач-таргеты ≥44px; функции поиска
