## Решения по открытым вопросам авторов

1. **Favicon-маркер внутри data:URI вместо `?v=`** — кейсы утверждены
   как написаны: TC-P12N-003 корректно фиксирует отклонение от буквы
   spec и проверяет фактическую реализацию; семантика политики design §3
   («любое изменение иконки меняет URL») выполняется — маркер входит в
   href. Рекомендация ПМ сохраняется: мини-правка спеки navigation
   (Scenario «Изменение иконки доходит до браузеров»: «смена URL» без
   указания механизма `?v=`) ПОСЛЕ ревью, вне зоны кейсов.
2. **Esc-конфликт rename vs лайтбокс** — подтверждено кодом ветки 2.5:
   stopPropagation в keydown поля rename (gallery.js:784) — Esc отменяет
   ТОЛЬКО форму, лайтбокс открыт. TC-P12G-05 фиксирует фактическое и
   спеко-соответствующее поведение — согласовано.
3. **Шапка комментария в форме создания** — подтверждено: автор·дата
   рисует task-detail.js (Intl ru-RU), task-form.js волнами не тронут
   (зона 2.1). Исключение в TC-UIP-108 («не считать падением кейса»)
   корректно.
4. **Фикстуры masonry PNG vs SVG** — PNG-база подтверждена кодом:
   validate_upload отклоняет SVG (bad_type, images.py:52–54). Тело
   TC-P12G-07 верно (PNG через PIL, SVG оговорен как недопустимый);
   противоречие только в заголовке кейса — замечание 5.
5. **Опечатка CHK-P12-13 «Контрак запроса»** — вне зоны кейсов (файл
   чеклиста test-model/checklists/add-ui-polish-r8.md:46); передать
   автору чеклиста, на вердикт не влияет.
