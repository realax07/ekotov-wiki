# TC-perf-401 — Страница с 50 rich-блоками открывается в порог 2 с (NFR-37)

- **Change:** add-rich-editor
- **Источник:** wiki-editor (ADDED): Requirement «Производительность рендера rich-страниц» — Scenario «Страница с 50 rich-блоками открывается в порог» (NFR-37)
- **Тип:** НФТ, производительность (класс: эталонная rich-страница) | **Приоритет:** Should
- **Предусловия:** стенд ветки (nginx :18443); сессия автора; страница с РОВНО 50 rich-блоками, состав сбалансирован по всем типам: 10 таблиц 3×3 с заполненными ячейками, 10 блоков `:::columns` (2–3 колонки с содержимым), 10 callout (по 3–4 каждого type), 10 врезок, 5 спойлеров с содержимым, 5 код-блоков по 10–20 строк; читательская сессия без кэша (чистый профиль)
- **Шаги:**
  1. Создать страницу с указанным составом через редактор/API; сохранить (200).
  2. Открыть страницу читателем; замерить время от запроса до отображения (performance API / network idle), 10 повторов с очисткой кэша вкладки.
  3. Зафиксировать min/median/p95; повторить второй круг замеров.
  4. Проверить корректность рендера: все 50 блоков присутствуют (счетчик по типам), спойлеры скрыты.
- **Ожидаемый результат:** время открытия ≤ 2 с на стенде (median и p95 по 10 повторам); рендер полный и корректный (все 50 блоков, 0 JS-ошибок).
- **Статус:** **new**

# TC-perf-402 — Границы NFR-37: 49/50 блоков и повторяемость порога (NFR-37)

- **Change:** add-rich-editor
- **Источник:** wiki-editor (ADDED): Requirement «Производительность рендера rich-страниц» (NFR-37); техника: границы между классами
- **Тип:** НФТ, граничный | **Приоритет:** Should
- **Предусловия:** как TC-perf-401; генератор страниц с параметром числа блоков
- **Шаги:**
  1. Страница с 49 rich-блоками (класс «меньше эталона») → время открытия ≤ 2 с.
  2. Страница с 50 блоками (граница, ровно порог нормы) → ≤ 2 с (перекрестная проверка с TC-perf-401).
  3. Страница с 51 блоком (вне гарантии требования) → замерить и зафиксировать фактическое время; критерий приемки НЕ применяется (вне класса NFR-37), деградация фиксируется информационно для ПМ.
  4. Стабильность: на странице 50 блоков — 3 повторных круга замеров (холодный старт стенда + прогретый) — порог держится на каждом круге.
- **Ожидаемый результат:** 49 и 50 блоков укладываются в 2 с (граница включена в норму); для 51 фактическое время задокументировано без применения порога; результат стабилен между кругами (разброс median < 2×).
- **Статус:** **new**
