  4. Вне whitelist вовсе: `width=0`, `width=-50`, `width=abc` → не сохраняются как валидный атрибут ни одним путем.
  5. Представитель середины класса: `width=50` — позитив-контроль (уже в TC-blocks-114).
- **Ожидаемый результат:** принимается только целое 10..100 включительно; 9 и 101 отклоняются на границе; вне-whitelist значения не приводят к 422 и не применяются к рендеру; лимиты/хранение изображений NFR-34 не изменились.
- **Статус:** **new**
