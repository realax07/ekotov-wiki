# Домен security — санитизация rich-контента, XSS-векторы NFR-35 (FR-126, NFR-35)

- **Change:** add-rich-editor
- **Порядок техник:** классы → границы → негативные → состояния → комбинации (вложенность).
- **Матрица векторов × блоков (NFR-35 «во всех поддерживаемых типах блоков»):** каждый вектор (script / iframe / object / onerror / onclick / javascript:-URL / опасные атрибуты) проверен в блоке из сценария спеки + sweep-кейсом по остальным типам (таблицы, колонки, callout, врезки, спойлеры, код, подписи изображений).
- **N/A-обоснования домена:**
  - Auth-матрица (7 строк) — N/A: новых эндпоинтов нет; санитизация выполняется на существующем пути сохранения, authz покрыт TC-wiki-401/TC-compat-203.
  - Чужой ресурс (403) — N/A: векторы не зависят от владельца ресурса; инъекция проверяется в рамках своей страницы (автор = автор страницы).
  - Rate limiting / нагрузочные негативы — N/A: не входят в NFR пакета (NFR-37 — только порог рендера, домен perf).

# TC-sec-301 — `<script>` в содержимом блока нейтрализован (FR-126)

- **Change:** add-rich-editor
- **Источник:** wiki-sanitize (ADDED): Requirement «Санитизация rich-контента…» — Scenario «Скрипт в содержимом нейтрализован» (FR-126)
- **Тип:** безопасность, негатив | **Приоритет:** Must
- **Предусловия:** сессия автора; страница с rich-контентом; curl для прямого PUT; просмотр в браузере
- **Шаги:**
  1. Ввести в содержимое блока (абзац внутри callout) текст `<script>alert(1)</script>`; сохранить.
  2. Открыть страницу на просмотр; проверить DOM: элемент `script` отсутствует; alert не выполняется (0 pageerror/dialog).
  3. Проверить отображение ввода: безопасный текст (литерально или вырезано) — без исполнения.
- **Ожидаемый результат:** исполняемый скрипт отсутствует в DOM; alert не выполняется; ввод отображен безопасным образом.
- **Статус:** **new**

- **Тип:** безопасность, архитектурная проверка | **Приоритет:** Must

- **Шаги:**
  1. PUT контента с инъекцией (`<img src=x onerror=alert(1)>` внутри спойлера); проверить БД после сохранения: вектор нейтрализован НА ЗАПИСИ (исполняемый атрибут отсутствует в сохраненном контенте).
