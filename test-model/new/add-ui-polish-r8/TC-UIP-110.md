# TC-UIP-110 — Комбобокс: 3 тега подряд и удаление по одному (чип-крестик, поле не блокируется)

- **Change:** add-ui-polish-r8
- **Источник:** tasks Requirement «Кастомный комбобокс тегов» (MODIFIED) / FR-92 (P12 п.4: «множественное добавление подряд и удаление тегов по одному MUST работать»); impact п.6; CHK-P12-15
- **Тип:** позитивный | **Приоритет:** Must
- **Маркер:** new — кейс «3 тега подряд + удаление по одному» (impact п.6; частично покрывается обновленными TC-r6-comb-004/005 — прогон 3.1)
- **Предусловия:** nginx-стенд :18443; seed-теги QAT-префикса; форма задачи открыта; поле «Теги» в фокусе
- **Шаги:**
  1. Выбрать существующий тег QAT-1 (клик) → выбрать второй существующий QAT-2 (Enter) → создать новый QAT-3 (ввод + «создать»).
  2. После каждого из трех добавлений: input пустой (`input_value() == ""`); счетчик чипов = номеру шага; все три чипа с крестиками присутствуют в `#task-tags-chips`.
  3. Удалить чип QAT-2 крестиком → чип исчез, input НЕ заблокирован, можно вводить снова; оставшиеся два чипа на месте.
  4. Вернуть удаленный: ввести фрагмент «QAT-2» в дропдауне — тег СНОВА доступен в списке (исключение только введенных/выбранных, не удаленных); выбрать — три чипа, input пуст.
  5. Сохранить форму → задача содержит ровно три тега.
- **Ожидаемый результат:** шаг 2 — три тега подряд: три чипа с крестиками, поле пустое после каждого добавления; шаг 3 — удаление по одному работает, поле не блокируется, ввод возможен сразу после удаления; шаг 4 — возвращенный тег снова доступен в дропдауне и добавляется; шаг 5 — сохранены все три тега; скролл/лейаут формы не ломается при росте чипов.
