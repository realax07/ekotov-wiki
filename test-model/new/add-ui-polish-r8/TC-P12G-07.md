Набор: 4×квадрат 400×300/300×300, 3×портрет 300×600/400×800, 3×панорама 1200×300/1600×400. Экстремальные — 800×2400 (1:3) и 2000×250 (8:1). Том images-data чистый teardown по QAGAL-
- **Шаги:**
  1. Загрузить 10 фикстур (сиды через `_upload_api`), открыть `/gallery`, включить вариант сетки «В masonry» (переключатель вида, мокап 2.6).
  2. Геометрия колонок: bbox-ассерты — все `.g-card` принадлежат ровно N колонкам (колонки по X-координатам disjoint: пересечений прямоугольников карточек нет), верх карточки каждой колонки одинаков (ритм верхнего ряда).
  3. Наложения/дыры: для каждой пары карточек одной колонки — вертикальные зазоры ≥0 и ≤ константы gutter (без «дыр» между рядами); горизонтальные пересечения = 0.
  4. Пропорции: у каждой карточки естественная высота изображения (не обрезка кропом: rendered aspect-ratio img ≈ исходному w/h в пределах допуска 2%).
  5. Перерисовать сетку (фильтр туда-обратно) — повторить шаги 2–4 (ритм не деградирует после re-render).
- **Ожидаемый результат:** masonry-сетка при 10 разнопропорциональных изображениях держит ритм: карточки выровнены по колонкам, пересечений и «дыр» нет, превью сохраняют пропорции оригинала (без искажения и кропа — семантика masonry-варианта мокапа J), после перерисовки фильтрами геометрия воспроизводима.
