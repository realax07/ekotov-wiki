- **Шаги:**
  1. Бейдж присутствует у каждой карточки с известным mime; текст = uppercase-расширение формата; позиция внутри `.g-thumb` (правый нижний угол): bbox бейджа ⊂ bbox плитки, отступ 6px ± допуск; бейдж не перекрывает счетчики/название (вне `.g-card-body`).

  3. Ховер карточки: до/во время hover — bbox плитки и бейджа НЕ меняются (без сдвига/масштаба; допустимы только тень/рамка/подложка); курсор pointer.
  4. Фокус с клавиатуры (Tab до карточки): focus-ring виден (токен `--focus-ring`), не обрезается overflow'ом плитки/колонки masonry.
  5. Токены: Computed Styles бейджа/ховера — только var(--token) из app.css :root; литеральных цветов нет (галерейная часть CHK-P12-33).
- **Ожидаемый результат:** бейдж формата стабильно в правом нижнем углу плитки, читаем на превью любых пропорций, не перекрывает контент; hover/focus меняют только декоративные состояния (тень/рамка/ring) без сдвига геометрии; все состояния на токенах V3.
