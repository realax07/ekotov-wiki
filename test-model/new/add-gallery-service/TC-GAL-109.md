# TC-GAL-109 — 401 без сессии: все API images недоступны, данные не изменяются

- **Change:** add-gallery-service
- **Источник:** gallery (ADDED): «Лайк/дизлайк» (FR-81) — Scenario «Негативный: без сессии реакция недоступна»; «Доступ к галерее общий» (FR-84) — Scenario «без сессии API недоступен»; CHK-GAL-18
- **Тип:** ФТ, API, нег. | **Приоритет:** Must
- **Маркер:** автоматизирован — `services/images/tests/test_images_service.py::test_endpoints_require_session`, `::test_reaction_no_session_401` (юниты 1.2) + ручной/стендовый — REPORT-2.1 (api-сьют стенда: все эндпоинты через nginx без cookie сессии)
- **Предусловия:** стенд поднят; в галерее есть ≥1 изображение (TC-GAL-107); запросы БЕЗ действующей сессии (анонимный клиент)
- **Шаги:**
  1. `GET /api/images` и `GET /api/images/<id>` без сессии — фиксировать код.
  2. `POST /api/images` (multipart, валидный файл) без сессии — фиксировать код.
  3. `PUT /api/images/<id>/like` и `PUT /api/images/<id>/dislike` без сессии — фиксировать код.
  4. `POST /api/images/<id>/comments` и `DELETE /api/images/<id>/comments/<cid>` без сессии — фиксировать код.
  5. После шагов 2–4 сверить состояние: счетчики реакций, список комментариев, число записей в томе/БД — без изменений.
- **Ожидаемый результат:** шаги 1–4 — ВСЕ API images без действующей сессии отвечают 401 (upload, список, деталь, реакции, комментарии); шаг 5 — данные, голоса и файлы не изменяются (401 не создает частичных эффектов).
