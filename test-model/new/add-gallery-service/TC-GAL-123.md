# TC-GAL-123 — Миграция migrate_gallery: one-shot до подъема app, идемпотентность, автосверка (репетиция на копии БД)

- **Change:** add-gallery-service
- **Источник:** services (ADDED): «Схему создает ядро, сервис не мигрирует» (FR-79 преемственность deploy); deploy (MODIFIED): «Миграции БД — one-shot», design §7, tasks 2.2 (репетиция на свежей копии прод-БД обязательна); CHK-GAL-2, CHK-GAL-29
- **Тип:** ФТ/сред., миграция БД | **Приоритет:** Must
- **Маркер:** ручной/стендовый — REPORT-2.1 (стендовая часть: 1.3 миграция before-app + no-op) / **план 2.2** — репетиция на копии прод-БД ([ops], только с Заказчиком; на стенде 2.1 выполняется репетиция на копии БД стенда, прод-копия — 2.2)
- **Предусловия:** копия БД стенда (2.1) / свежая копия прод-БД (2.2); бэкап-контур: БД + аватары + tar images-data; контейнер app остановлен (миграция строго до подъема app)
- **Шаги:**
  1. Прогон 1: `python -m app.migrate_gallery` на копии БД — зафиксировать exit-код и созданные объекты: 6 таблиц gallery (image_categories, images, gallery_tags, image_tags, image_reactions, image_comments) + индексы (§2 design).
  2. Прогон 2 (идемпотентность): повторить `python -m app.migrate_gallery` на той же БД — no-op (0 изменений), exit 0.
  3. Автосверка: внести контролируемое расхождение в копию (удалить индекс/таблицу), повторить миграцию — exit 1 при расхождении («nginx -t-аналог для БД»).
  4. Подъем app на мигрированной БД — app стартует и healthy; поднять images — стартует БЕЗ миграционных шагов (в контейнере images нет миграционного кода/команд).
  5. Смоук после миграции: `GET /api/images` 200 (пустой список), существующие домены ядра (tasks, wiki, auth) работают — данные ядра не изменены.
  6. (2.2) Повторить шаги 1–2 на свежей копии ПРОД-БД по протоколу [ops] приемки.
- **Ожидаемый результат:** миграция one-shot создает ровно 6 таблиц gallery + индексы, выполняется строго до подъема app; повтор — no-op (идемпотентность); автосверка детектирует расхождение с exit 1; images не содержит миграций (схему создает только ядро); данные ядра не затронуты. Репетиция на прод-копии — обязательный шаг 2.2 до боевой накатки (урок Р4); вне стенда 2.1 — помечено «план 2.2».
