# TC-GAL-110 — Фильтры category/tag: по отдельности, комбинация, пустой фильтр, created_at DESC, tags в списке

- **Change:** add-gallery-service
- **Источник:** gallery (ADDED): «Категории и теги изображений» (FR-80) — Scenario «Фильтр по категории + по тегу + Комбинация + Пустой фильтр», «Загрузка без категории и тегов допустима», «Загрузка с категорией и тегами + Справочник галереи отделен от задач»; tasks 1.6(а) (tags в списке, Э-3); CHK-GAL-13, CHK-GAL-14, CHK-GAL-15
- **Тип:** ФТ, API, поз. + гран. | **Приоритет:** Must
- **Маркер:** автоматизирован — `services/images/tests/test_images_service.py::test_list_filters_combine`, `::test_list_order_and_fields`, `::test_upload_reuses_existing_category_and_tag`, `::test_upload_unknown_category_id_422` + юниты 1.6 `::test_list_includes_tags_of_each_image` (TC-gal-104), `::test_list_tags_empty_when_no_tags` (TC-gal-105) + ручной/стендовый — REPORT-2.1 (api-сьют стенда: комбинация фильтров и сортировка на реальных данных)
- **Предусловия:** стенд поднят; сессия owner; подготовлены данные: ≥3 изображения — (A) категория «семья» + теги «лето»/«дача», (B) категория «семья» без тегов, (C) без категории и тегов; заведомо разные времена загрузки
- **Шаги:**
  1. Загрузка с категорией «семья» и тегами «лето»/«дача»: проверить справочник галереи — значения созданы при отсутствии, переиспользованы при повторной загрузке (дублей в словаре нет); категории задач («work») в справочнике галереи отсутствуют.
  2. `GET /api/images?category=семья` — в выдаче A и B, C отсутствует.
  3. `GET /api/images?tag=лето` — в выдаче только A.
  4. `GET /api/images?category=семья&tag=лето` — изображение удовлетворяет ОБА условиям (A), B отфильтровано.
  5. `GET /api/images` без фильтров — все изображения (A, B, C), сортировка created_at DESC (свежие первыми); у каждого элемента поле `tags: [имена]` (у A оба тега, у C — `[]`).
  6. `GET /api/images?category=<несуществующий id>` / upload с неизвестным category_id — 422.
- **Ожидаемый результат:** шаг 1 — справочник галереи отделен от задач (категории задач не протекают), переиспользование значений; шаг 2–4 — фильтры по категории, тегу и их комбинация работают как конъюнкция; шаг 5 — пустой фильтр возвращает все изображения, сортировка created_at DESC, tags присутствуют в списке-API (паритет с detail, Э-3/1.6); шаг 6 — неизвестный category_id → 422.
