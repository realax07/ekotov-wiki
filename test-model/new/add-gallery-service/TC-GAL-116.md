# TC-GAL-116 — e2e: лайтбокс — открытие, ←/→ циклично, Esc, реакции и комментарий из окна, скачивание оригинала

- **Change:** add-gallery-service
- **Источник:** gallery (ADDED): «Full-screen просмотр с листанием» (FR-83) — Scenario «Открытие + Листание стрелками + Закрытие окна», «Реакции и комментарий из окна просмотра + Скачивание оригинала»; tasks 1.5(г); CHK-GAL-23, CHK-GAL-24
- **Тип:** ФТ, web/e2e, поз. | **Приоритет:** Must
- **Маркер:** ручной/стендовый — REPORT-2.1 (web/e2e лайтбокс); замечание: глобальный перехват ArrowLeft/ArrowRight без guard полей ввода — замечание 2 review-002-1.5 (minor), при прогоне проверить поведение стрелок в textarea комментария и зафиксировать факт
- **Предусловия:** стенд поднят; ≥3 изображения в галерее (порядок листания = текущая отфильтрованная выдача); сессия owner; известно исходное имя файла при загрузке (для проверки скачивания)
- **Шаги:**
  1. Клик по превью в сетке — открывается модальное окно на весь экран.
  2. Листание кнопками ←/→ и клавишами ArrowLeft/ArrowRight — изображение меняется по текущей отфильтрованной выдаче; с последнего элемента → первый и наоборот (цикличность).
  3. Наложить фильтр (одна категория), открыть лайтбокс, полистать — листание идет только внутри отфильтрованной выдачи.
  4. Из модалки поставить лайк — подсветка «мой голос» и счетчики обновляются БЕЗ выхода из окна; добавить комментарий в поле модалки.
  5. Esc и крестик поочередно — окно закрывается, сетка в прежнем состоянии (фильтры и позиция сохранены).
  6. Кнопка «скачать» — файл оригинала (не превью, сверить размеры/байты с томом images-data) под исходным именем загрузки.
- **Ожидаемый результат:** клик по превью открывает full-screen модалку; ←/→ (кнопки и клавиши) листают циклично по текущей отфильтрованной выдаче; Esc/крестик закрывают с сохранением состояния сетки; лайк с подсветкой «мой голос» и комментарий работают из модалки без выхода; «скачать» отдает ОРИГИНАЛ под исходным именем.
