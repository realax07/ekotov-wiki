# TC-GAL-111 — Реакции: один голос (upsert), смена голоса, снятие повторным действием

- **Change:** add-gallery-service
- **Источник:** gallery (ADDED): «Лайк/дизлайк — один голос пользователя» (FR-81) — Scenario «Постановка лайка», «Смена голоса + Снятие голоса повторным действием»; CHK-GAL-16, CHK-GAL-17
- **Тип:** ФТ, API, поз. + гран. | **Приоритет:** Must
- **Маркер:** автоматизирован — `services/images/tests/test_images_service.py::test_reaction_flow`, `::test_list_shows_my_reaction` (юниты 1.2) + ручной/стендовый — REPORT-2.1 (api-сьют стенда: смена/снятие голоса двумя пользователями)
- **Предусловия:** стенд поднят; сессии двух пользователей (owner и PE); изображение с нулевыми счетчиками
- **Шаги:**
  1. owner: `PUT /api/images/<id>/like` — фиксировать тело (счетчики, `my_reaction`); повторить тот же PUT еще раз.
  2. owner: `PUT /api/images/<id>/dislike` — смена голоса.
  3. owner: повторный `PUT .../dislike` (тот же знак) — снятие голоса.
  4. PE: ставит свой лайк; owner ставит лайк снова — проверить, что голоса двух пользователей независимы.
  5. Снять дамп таблицы image_reactions после каждого шага — проверить отсутствие дублей (PK user+image, upsert).
  6. `GET /api/images` и `GET /api/images/<id>` — счетчики и собственный голос (`my_reaction`) корректны для каждой сессии.
- **Ожидаемый результат:** шаг 1 — лайк ставится, повторный same-sign PUT не создает дубль (ровно ОДИН голос на пользователя на изображение, upsert по PK); шаг 2 — лайк→дизлайк: голос изменен, счетчики сместились ровно на один голос (+1 dislike, −1 like); шаг 3 — повторное действие того же знака снимает голос (собственный голос отсутствует, счетчик уменьшился); шаг 4 — голоса независимы, счетчики суммарные; шаг 6 — видны счетчики и собственный голос (базис подсветки «мой голос» в UI).
