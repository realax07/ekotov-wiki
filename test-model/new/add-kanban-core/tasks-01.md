## TC-tasks-015 — Сохранность данных при штатном рестарте (НФТ)
- **CHK:** CHK-55
- **Источник:** tasks: «Данные не теряются при перезапуске сервера» (NFR-3) / Scenario: Сохранность данных после перезапуска
- **Тип:** НФТ | **Приоритет:** Must
- **Метрика:** 0 потерь: после рестарта совпадают до/после — состав задач, статусы, все признаки, комментарии; инвалидирующиеся сессии допустимы (sdd §5, §7 — повторный вход не является потерей данных).
- **Предусловия:** общие. Существует «снимок до»: задача `Рестарт-todo` (todo, priority=`high`, тег `persist`, комментарий `Коммент до рестарта`), `Рестарт-wip` (in_progress), `Рестарт-done` (done сегодня, done_at в день D), `Рестарт-полная` со всеми заполненными признаками (значения из TC-tasks-002). Зафиксировать JSON ответов `GET /api/board` и `GET "/api/search?archived=all"` в файл `before_restart.json`.
- **Шаги:**
  1. Сохранить снимок: `curl -s -b owner_cookies.txt {BASE_URL}/api/board > before_restart.json` (и поиск).
  2. Штатный рестарт: `sudo systemctl restart ekotov-wiki` (локально — перезапуск процесса uvicorn эквивалентной командой deploy/README.md).
  3. Дождаться готовности: `curl -s {BASE_URL}/api/health` → 200 (проверять с интервалом 2 с, не более 60 с).
  4. Войти заново (сессии могли инвалидироваться — допустимо) и повторить снимок: `after_restart.json`.
  5. Сравнить: `diff <(jq -S '.columns' before_restart.json) <(jq -S '.columns' after_restart.json)`.
- **Ожидаемый результат (порог):** health после рестарта ≤ 60 с; diff снимков пуст — состав задач, статусы (`todo`/`in_progress`/`done`), done_at, признаки (описание/приоритет/категория/срок/теги) и тексты комментариев идентичны «до»; расхождение ≥1 поля — дефект NFR-3.
- **Тестовые данные:** titles=`Рестарт-todo`, `Рестарт-wip`, `Рестарт-done`, `Рестарт-полная`; комментарий `Коммент до рестарта`; файлы `before_restart.json`/`after_restart.json`.
