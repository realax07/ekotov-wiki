# TC-cat-005 — Переименование категории применяется ко всем задачам (каскад)

- **CHK:** CHK-86
- **Change:** add-r2-categories-settings
- **Источник:** categories: Управление справочником категорий (FR-20, Д-1) / Scenario: Переименование применяется ко всем задачам
- **Тип:** позитивный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200; `BASE_URL` по умолчанию `http://127.0.0.1:8080`); выполнен вход owner (логин `owner`, пароль `QaOwner_Pass_1!` — seed `tests/api/conftest.py`, куки в `owner_cookies.txt`); seed справочника выполнен (CHK-139 / TC-env-001: `Дом`, `Работа`, `Личное` в справочнике до прогона).
- **Сценарий:**
  - **GIVEN** в справочнике есть категория `QAT-ren-старое`; две задачи имеют категорию `QAT-ren-старое`
  - **WHEN** пользователь переименовывает категорию в `QAT-ren-новое`
  - **THEN** справочник показывает `QAT-ren-новое`; обе задачи отображают `QAT-ren-новое` (атомарный UPDATE, design §1.1)
- **Шаги:**
  1. `POST /api/categories` name=`QAT-ren-старое` → 201, зафиксировать `id`.
  2. Создать две задачи с `category=QAT-ren-старое`: `POST /api/tasks` titles=`QAT-ren-задача-1`, `QAT-ren-задача-2` → 201/201, зафиксировать `id1`, `id2`.
  3. `curl -s -i -b owner_cookies.txt -X PATCH {BASE_URL}/api/categories/{id} -H "Content-Type: application/json" -d '{"name":"QAT-ren-новое"}'` → код и тело.
  4. `GET /api/categories` → `QAT-ren-старое` отсутствует, `QAT-ren-новое` присутствует (ровно одна запись).
  5. `GET /api/tasks/{id1}` и `GET /api/tasks/{id2}` → поле `category` обеих = `QAT-ren-новое`.
  6. UI-контроль: открыть `{BASE_URL}/board` — обе карточки показывают `QAT-ren-новое`.
  7. Cleanup (CHK-140): DELETE задач `id1`, `id2` (→ 204/204); DELETE категории `QAT-ren-новое` (→ 200).
- **Ожидаемый результат:** шаг 3 — HTTP **200**, тело `{"id": …, "name": "QAT-ren-новое"}`; шаги 4–6 — переименование каскадно применилось ко всем задачам (значение заменено у всех, старого нигде нет); ни одна задача не «осиротела». Cleanup вернул систему в исходное состояние.
- **Тестовые данные:** name=`QAT-ren-старое` → `QAT-ren-новое`; задачи `QAT-ren-задача-1`, `QAT-ren-задача-2`.
