# TC-form-009 — Иконки приоритетов inline SVG, без внешних библиотек

- **CHK:** CHK-120
- **Change:** add-r2-categories-settings
- **Источник:** tasks: Визуал формы (FR-29, ОГР-8, Д-4) / Scenario: Иконки приоритетов не требуют внешних библиотек
- **Тип:** НФТ | **Приоритет:** Should
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); Playwright (Python): `page`, `expect`; выполнен вход owner (логин `owner`, пароль `QaOwner_Pass_1!` — seed, как TC-UI-002 чеклиста e2e-critical-path); seed справочника выполнен (CHK-139 / TC-env-001).
- **Сценарий:**
  - **GIVEN** страница формы задачи открыта
  - **WHEN** пользователь просматривает загруженные ресурсы страницы
  - **THEN** иконки приоритетов отрисованы inline SVG; внешние библиотеки иконок/шрифтов не подключаются (ОГР-8)
- **Шаги:**
  1. Сетевой журнал ресурсов: `external = []`, `page.on("request", lambda r: external.append(r.url) if not r.url.startswith((BASE_URL, "data:")) else None)`; открыть `/board`.
  2. Открыть форму задачи (кнопка «Создать задачу») — все ресурсы загрузились.
  3. DOM: `page.locator("svg")` в форме/шаблоне карточек → зафиксировать, что иконки приоритетов — инлайновые `<svg>` в HTML (не `<img src>` на внешний хост, не иконочный шрифт).
  4. Зафиксировать `external`: все хосты, отличные от `{BASE_URL}`; отдельно — подключения шрифтов/иконочных CDN (googleapis, fontawesome, jsdelivr и т.п.).
- **Ожидаемый результат:** `external == []` (ни одного внешнего ресурса — ОГР-8, sdd §1 «новых зависимостей нет»); иконки приоритетов найдены как inline `<svg>`; подключений иконочных шрифтов/CDN-библиотек нет.
- **Тестовые данные:** страницы `/board` + форма задачи; журнал всех запросов страницы.
