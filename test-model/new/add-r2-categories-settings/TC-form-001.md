# TC-form-001 — Подсказки поля «Теги» формы показывают заведенные значения (теги + категории задач)

- **CHK:** CHK-112
- **Change:** add-r2-categories-settings
- **Источник:** tasks: Автодополнение тегов в форме задачи (FR-26, Д-3) / Scenario: Подсказки показывают заведенные значения
- **Тип:** позитивный | **Приоритет:** Should
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); Playwright (Python): `page`, `expect`; выполнен вход owner (логин `owner`, пароль `QaOwner_Pass_1!` — seed, как TC-UI-002 чеклиста e2e-critical-path); seed справочника выполнен (CHK-139 / TC-env-001).
- **Сценарий:**
  - **GIVEN** на существующих задачах заведены теги `QAT-тег-home`, `QAT-тег-urgent` и категория `QAT-кат-work`
  - **WHEN** пользователь вводит текст в поле «Теги» формы задачи
  - **THEN** подсказки содержат все три значения (объединение тегов и категорий); механизм един с подсказками поиска (`GET /api/suggestions`, sdd §3.2)
- **Шаги:**
  1. Создать категорию `QAT-кат-work` (`POST /api/categories` → 201 — FR-21). Создать задачу-носитель: `POST /api/tasks` `{"title":"QAT-носитель-хинтов","category":"QAT-кат-work","tags":["QAT-тег-home","QAT-тег-urgent"]}` → 201. Контроль: `GET /api/suggestions` → все три значения в списке.
  2. Открыть форму создания задачи; осмотреть поле «Теги» (`page.get_by_label("Теги (через запятую)")` или фактический локатор — зафиксировать): зафиксировать атрибут `list` (datalist) и его id.
  3. Ввести префикс `QAT-` в поле «Теги»; прочитать опции соответствующего datalist (`page.locator("#<datalist-id> option").all_inner_texts()` — id из шага 2).
  4. API-контроль единства механизма: `curl -s -b owner_cookies.txt {BASE_URL}/api/suggestions` → тот же набор значений, что в datalist шага 3.
  5. Cleanup: DELETE задачи-носителя → 204; DELETE категории → 200.
- **Ожидаемый результат:** шаг 3 — datalist подсказок формы содержит `QAT-тег-home`, `QAT-тег-urgent`, `QAT-кат-work` (объединение двух столбцов, set-семантика — Д-3); шаг 4 — наборы совпадают с телом `GET /api/suggestions` (единый механизм с поиском). **Пометка «уточнить в sdd» (эскалация б):** источник категорий в подсказках написан по текущей реализации (значения задач); если при реализации переведут на справочник — состав подсказок пересмотреть (CHK-142).
- **Тестовые данные:** теги `QAT-тег-home`, `QAT-тег-urgent`; категория `QAT-кат-work`; задача `QAT-носитель-хинтов`.
