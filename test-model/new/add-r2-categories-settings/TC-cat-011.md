# TC-cat-011 — GET /api/categories: 401 без сессии; 200 с сессией, сортировка по name

- **CHK:** CHK-92
- **Change:** add-r2-categories-settings
- **Источник:** categories: Справочник категорий (FR-19, NFR-7; дополнение: негативный класс, sdd §3.1)
- **Тип:** негативный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200; `BASE_URL` по умолчанию `http://127.0.0.1:8080`); выполнен вход owner (логин `owner`, пароль `QaOwner_Pass_1!` — seed `tests/api/conftest.py`, куки в `owner_cookies.txt`); seed справочника выполнен (CHK-139 / TC-env-001: `Дом`, `Работа`, `Личное` в справочнике до прогона).
- **Сценарий:**
  - **GIVEN** справочник непуст (seed `Дом`, `Работа`, `Личное` + `QAT-*`)
  - **WHEN** вызывающий запрашивает `GET /api/categories` без сессии и с сессией
  - **THEN** без сессии — 401; с сессией — 200 с телом-объектом, список отсортирован по name (источник select-полей, FR-30)
- **Шаги:**
  1. `curl -s -i {BASE_URL}/api/categories` (БЕЗ кук) → код и тело.
  2. `curl -s -b owner_cookies.txt {BASE_URL}/api/categories` → код и тело; извлечь список имен.
  3. Проверить сортировку: `names == sorted(names)` (Python-сверка в протоколе).
- **Ожидаемый результат:** шаг 1 — HTTP **401**, тело `{"error": "unauthorized"}` (sdd §3: общее правило для `/api/*`); шаг 2 — HTTP **200**, тело `{"categories": [{"id": …, "name": …}, …]}`; шаг 3 — список отсортирован по возрастанию name (sdd §3.1).
- **Тестовые данные:** запрос без куков vs запрос с `owner_cookies.txt`.
