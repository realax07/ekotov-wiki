# TC-cat-006 — Удаление используемой категории блокируется (409)

- **CHK:** CHK-87
- **Change:** add-r2-categories-settings
- **Источник:** categories: Управление справочником категорий (FR-20, Д-1) / Scenario: Негативный: удаление используемой категории блокируется
- **Тип:** негативный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200; `BASE_URL` по умолчанию `http://127.0.0.1:8080`); выполнен вход owner (логин `owner`, пароль `QaOwner_Pass_1!` — seed `tests/api/conftest.py`, куки в `owner_cookies.txt`); seed справочника выполнен (CHK-139 / TC-env-001: `Дом`, `Работа`, `Личное` в справочнике до прогона).
- **Сценарий:**
  - **GIVEN** в справочнике есть категория `QAT-используемая`, используемая ровно двумя задачами
  - **WHEN** пользователь пытается удалить категорию `QAT-используемая`
  - **THEN** удаление отклоняется 409 со счетчиком задач и сообщением о необходимости освобождения; категория остается в справочнике
- **Шаги:**
  1. `POST /api/categories` name=`QAT-используемая` → 201, зафиксировать `id`.
  2. Создать две задачи с `category=QAT-используемая` (titles=`QAT-носитель-1`, `QAT-носитель-2`) → 201/201.
  3. `curl -s -i -b owner_cookies.txt -X DELETE {BASE_URL}/api/categories/{id}` → код и тело.
  4. `GET /api/categories` → `QAT-используемая` присутствует.
  5. UI-контроль (опционально, если удаление доступно из настроек): попытка удаления из `/settings` показывает сообщение об ошибке с упоминанием использования задачами; категория остается.
  6. Cleanup: перевести обе задачи на `category=Дом` (PATCH ×2 → 200), DELETE задач → 204/204, DELETE категории → 200.
- **Ожидаемый результат:** шаг 3 — HTTP **409**, тело `{"error": "category in use", "details": {"tasks": 2}}` (sdd §3.1, Д-1); шаг 4 — категория осталась в справочнике; шаг 5 — сообщение об ошибке требует освободить категорию переводом задач (формулировка вида «используется задачами — освободите переводом»). Cleanup завершился успешно (после перевода задач удаление разрешено).
- **Тестовые данные:** name=`QAT-используемая`; задачи `QAT-носитель-1`, `QAT-носитель-2` (обе с этой категорией).
