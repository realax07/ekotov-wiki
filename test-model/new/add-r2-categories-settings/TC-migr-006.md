# TC-migr-006 — Негативный: расхождение сверки останавливает внедрение

- **CHK:** CHK-102
- **Change:** add-r2-categories-settings
- **Источник:** categories: Миграция без потери данных (NFR-8) / Scenario: Негативный: расхождение сверки останавливает внедрение
- **Тип:** негативный | **Приоритет:** Must
- **Среда/предусловия:** тестовая БД приложения (env `EKOTOV_WIKI_DB_PATH`); доступ к `sqlite3` CLI; скрипт миграции из пакета (sdd §5); выполнен вход owner (куки `owner_cookies.txt`); **seed справочника в этом кейсе НЕ выполняется** — справочник должен быть пуст ДО миграции (миграция сама создает категории из значений задач). Кейс — разовая проверка внедрения (метка `candidate-archive`, impact §3 п.2).
- **Сценарий:**
  - **GIVEN** выполнена миграция; автосверка обнаруживает задачу, значение категории которой отсутствует в справочнике
  - **WHEN** сверка завершается
  - **THEN** сверка фиксирует расхождение как провал проверки NFR-8; внедрение не считается завершенным до устранения расхождения
- **Шаги:**
  1. Выполнить миграцию штатно (TC-migr-005).
  2. Смоделировать расхождение: `sqlite3 "$EKOTOV_WIKI_DB_PATH" "UPDATE tasks SET category = 'QAT-m-призрак' WHERE title = 'QAT-m-носитель';"` (имитация «задачи вне справочника», как при нештатной миграции).
  3. Запустить автосверку (скрипт сверки из TC-migr-004/005) → зафиксировать результат.
  4. Зафиксировать реакцию процесса внедрения: отметка о провале в выводе сверки/логе миграции; статус внедрения — НЕ завершено.
  5. Устранить расхождение (вернуть категорию или добавить в справочник), повторить сверку → 0 расхождений. Cleanup.
- **Ожидаемый результат:** шаг 3 — сверка явно фиксирует провал: задача с `QAT-m-призрак` перечислена в списке расхождений, итог сверки — FAIL (NFR-8); шаг 4 — внедрение не помечено завершенным (нет отметки «миграция успешна» в артефактах внедрения); шаг 5 — после устранения сверка PASS. (Если скрипт миграции/сверки не сигнализирует провал различимо — ДЕФЕКТ относительно NFR-8, оформление в `test-model/bugs/`.)
- **Тестовые данные:** подставленное расхождение `QAT-m-призрак`; задача `QAT-m-носитель`.
