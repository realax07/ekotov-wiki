- **Change:** add-r2-categories-settings

- **Тип:** граничный | **Приоритет:** Should
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); Playwright (Python): `page`, `expect`; выполнен вход owner (логин `owner`, пароль `QaOwner_Pass_1!` — seed, как TC-UI-002 чеклиста e2e-critical-path); seed справочника выполнен (CHK-139 / TC-env-001).
- **Сценарий:**
  - **GIVEN** значение `QAT-дубль` заведено и как тег, и как категория на существующих задачах
  - **WHEN** пользователь открывает подсказки поля «Теги»
  - **THEN** `QAT-дубль` присутствует в списке подсказок ровно один раз
- **Шаги:**
  1. `POST /api/categories` name=`QAT-дубль` → 201.
  2. Создать задачу: `POST /api/tasks` `{"title":"QAT-носитель-дубля","category":"QAT-дубль","tags":["QAT-дубль"]}` → 201.
  3. Открыть форму задачи, ввести `QAT-` в поле «Теги»; прочитать опции datalist (как TC-form-001).
  4. Подсчитать вхождения `QAT-дубль` в списке опций. Контроль API: `GET /api/suggestions` → подсчитать вхождения в теле.
  5. Cleanup: DELETE задачи → 204; DELETE категории → 200.
- **Ожидаемый результат:** шаг 4 — `QAT-дубль` встречается в опциях datalist ровно 1 раз и ровно 1 раз в теле `GET /api/suggestions` (set()/UNION без дублей, Д-3).
- **Тестовые данные:** значение `QAT-дубль` (тег + категория одновременно); задача `QAT-носитель-дубля`.
