# TC-redesign-016: Галерея — сетка и лайтбокс в стиле «Пульт» (FR-125)

## Трассировка
- **CHK:** CHK-016
- **Тип:** виз. | **Приоритет:** Must (по CHK-016)
- **FR/Требование:** gallery ADDED — «Сетка галереи и лайтбокс в стиле «Пульт»» (FR-125, волна 2.5)
- **Scenario:** «Сетка галереи на темной теме», «Лайтбокс в визуале «Пульта»»

## Предусловия
- Поднят стенд; вход owner; в галерее есть изображения (≥ 1).
- Эталон: tokens-console.html, волна 2.5 smoke-мокапы. Playwright + `page.evaluate`.

## Шаги
1. Открыть раздел «Галерея». Проверить плитки `.g-card`: фон `--p-bg-200`, граница `--p-border`; hover — `--p-bg-300` + граница `--p-border-2` (ступени фона, без цветной заливки).
2. Подписи плиток — `--p-text-600` (AA); служебные значения (размеры, даты, счетчики) — mono; теги/категории — контурные бейджи; первичные действия — янтарные кнопки.
3. Проверить, что ритм сетки не изменился (masonry/фикс-высота, порядок плиток — как до редизайна по существующим галерейным тестам).
4. Кликнуть по плитке: лайтбокс — фоновая поверхность `--p-bg-000`, затемнение, тень `--shadow-modal` (0 24px 56px rgba(0,0,0,.55)); минимум декора.
5. В лайтбоксе проверить управление: закрытие, листание, лайк, комментарий, переименование — работают как прежде (DOM-хуки сохранены, ОГР-28).
6. Нажать `Tab` внутри лайтбокса: фокусируемые элементы показывают cyan-фокус-ринг `--focus-ring`.

## Ожидаемый результат
- Сетка — на dark-токенах с hover-ступенями фона, подписи AA, данные mono, ритм прежний.
- Лайтбокс — bg-000 с модальной тенью, управление без деградации, cyan-фокус на контролах.
