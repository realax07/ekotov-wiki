# TC-redesign-012: Роли акцентов — янтарь сигнал, cyan актив/фокус (FR-129)

## Трассировка
- **CHK:** CHK-012
- **Тип:** виз. | **Приоритет:** Must (по CHK-012)
- **FR/Требование:** design-tokens ADDED — «Роли акцентов — янтарь сигнал, cyan актив/фокус» (FR-129)
- **Scenario:** «Cyan не используется как декор», «Янтарный glow только на сигнале»

## Предусловия
- Поднят стенд; вход owner; на доске есть fast-задача; эталон — DV-мокапы (design-validation.md, design/redesign-pro).
- Playwright (Python) + инспекция computed styles.

## Шаги
1. Открыть по очереди `/board`, `/search`, `/wiki`, `/gallery`, `/video`, `/weather`. В состоянии покоя (без фокуса, без выделения) инспектировать декоративные поверхности: панели, кнопки, фоны, рамки. Собрать все элементы, у которых computed color/border/box-shadow содержит cyan (`--p-cyan-300`/rgba-cyan).
2. Проверить, что каждый найденный cyan-элемент — один из разрешенных ролей: активный пункт навигации (`aria-current="page"`), элемент в фокусе, `::selection`, открытый спойлер. Иных — нет.
3. На `/board` собрать все элементы с янтарным свечением (`--glow-amber` в box-shadow): ожидание — только панель фастлайна, fast-карточка и кнопка «Новая задача» на hover. На остальных разделах янтарный glow отсутствует.
4. Проверить градиенты: единственный допустимый — трек отсчета фастлайна amber→cyan (градиент на данных); на декоративных поверхностях (панели, фоны, кнопки) градиентов нет.
5. Сверить teal/coral/violet: используются только как статусы (LED) и приоритеты (бейджи), не декор.

## Ожидаемый результат
- Cyan в покое не встречается на декоративных элементах ни одного раздела; только актив/фокус/выделение/открытый спойлер.
- Янтарный glow — только сигнальные элементы фастлайна (панель, fast-карточка, янтарная кнопка на hover).
- Градиенты только на данных (трек фастлайна); teal/coral/violet — только статусы/приоритеты.
