# TC-redesign-028: Настройки пользователя — функции Релиза 4, доступ, адаптив

## Трассировка
- **CHK:** CHK-028
- **Тип:** поз./нег./НФТ | **Приоритет:** Must (по CHK-028)
- **FR/Требование:** settings MODIFIED — «Страница настроек пользователя» (FR-39…FR-42, FR-55/56, NFR-7, СЦ-7/СЦ-8, ОГР-20)
- **Scenario:** «Единая карточка V3» (якорь трассировки — содержание заменено на токены «Пульта»), «Все функции Релиза 4 сохранены», «Открытие страницы настроек пользователя», «Негативный: неавторизованный доступ», «Настройки пользователя — только свои данные», «Адаптив одной колонкой», «Независимость от общих настроек»

## Предусловия
- Поднят стенд; users seed: owner, второй пользователь; отдельная неавторизованная сессия.
- Playwright (Python): десктоп + узкий вьюпорт ~375px.

## Шаги
1. Клик по блоку профиля в сайдбаре → открывается страница настроек пользователя с единой карточкой (аватар, display_name, роль, bio, смена пароля — одна карточка «Пульта», без разнобоя секций).
2. Редактировать display_name/роль/bio, сменить пароль, загрузить аватар с выбором области — все операции успешны (состав Релиза 4 не потерян).
3. Проверить данные: отображаются и редактируются только данные сессионного пользователя (owner); профиль второго пользователя с этой страницы недоступен.
4. Неавторизованным (отдельный контекст) открыть страницу настроек пользователя: редирект на вход, содержимое не отображается (NFR-7).
5. Сузить вьюпорт до ~375px: карточка перестроена в одну колонку, горизонтальной прокрутки нет.
6. Проверить состав страницы: управление справочником категорий ОТСУТСТВУЕТ — оно только в общем разделе «Настройки» (FR-23, ОГР-20).
7. Контроль: прогон `test_r5_profile_card_ui.py` + существующих настроечных тестов — green.

## Ожидаемый результат
- Единая карточка на токенах «Пульта»; все функции Релиза 4 живы; только свои данные; аноним — 302.
- Узкий экран — одна колонка без горизонтальной прокрутки; справочника категорий на странице нет.
