# TC-redesign-026: Форма фильтров на темной теме, тесты поиска без правок

## Трассировка
- **CHK:** CHK-026
- **Тип:** виз./сред. | **Приоритет:** Must (по CHK-026)
- **FR/Требование:** search MODIFIED — «Фильтр-конструктор по признакам задачи» (визуальная часть)
- **Scenario:** «Форма фильтров на темной теме», «Тесты поиска без цветовых правок проходят»

## Предусловия
- Поднят стенд; вход owner. Playwright + `page.evaluate`; доступ к поисковым сьютам.

## Шаги
1. Открыть фильтр-конструктор. Проверить computed styles: select/инпуты — поля `--p-bg-200` с границей `--p-border`; `Tab`-фокус — cyan-ринг `--focus-ring`; `color-scheme: dark` — нативные select'ы рендерятся темными (открыть дропдаун, убедиться в темном рендере).
2. Кнопка «Найти» — янтарная первичная; вторичные кнопки фильтров — контурные; геометрия стабильна при active/focus (преемственность P12 п.8).
3. Подписи/микро-лейблы — капс mono там, где мокап задает; чипы выбранных фильтров — контурные бейджи на токенах.
4. Проверить подсказки тегов/категорий (combobox): работают как прежде (прогон `test_r6_tag_combobox_ui.py` — fixed, green).
5. Прогнать поисковые сьюты (test_navigation_search_ui, test_search_r4_ui, test_search_suggestions_ui, test_bug014_search_task_view — несталевые ассерты): green без правок селекторов; стилевой ассерт BUG-014 (совпадение computed styles окон поиска и доски) выполняется на новых токенах.

## Ожидаемый результат
- Форма фильтров — полностью на dark-токенах с cyan-фокусом и темными нативными контролами; кнопки по паттерну «Пульта».
- Существующие поисковые тесты проходят без правок, включая стилевой ассерт BUG-014.
