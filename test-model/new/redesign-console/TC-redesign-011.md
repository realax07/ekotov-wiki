# TC-redesign-011: V3-токены удалены, кеш статики инвалидирован

## Трассировка
- **CHK:** CHK-011
- **Тип:** НФТ | **Приоритет:** Must (по CHK-011)
- **FR/Требование:** design-tokens ADDED — «Единый источник дизайн-токенов «Пульт»» (FR-128, задача 2.7, design §D1)
- **Scenario:** «Нет ссылок на удаленные V3-токены», «Кеш статики инвалидирован»

## Предусловия
- Редизайн завершен (ЭТАП 2 закрыт, задача 2.7 выполнена); доступ к репозиторию `frontend/static/css/**`, `frontend/templates/**`, `backend/app/pages.py`.

## Шаги
1. Выполнить grep по `frontend/static/css/**` и `frontend/templates/**` (включая inline-стили шаблонов) на: `--p-paper-`, `--p-ink-`, `--p-clay-`, `--p-blue-`, `--p-red-`, `--p-olive-`, `--p-amber-700`. Ожидание — ноль вхождений.
2. Дополнительно убедиться: deprecated-алиасы V3 отсутствуют в `:root` app.css; ни один селектор не ссылается на несуществующий токен (скриптом: собрать все `var(--…)` в CSS/шаблонах и сверить с определениями).
3. Проверить `static_v` в `backend/app/pages.py` = `redesign-1`.
4. Открыть любую страницу и проверить подключения CSS/JS в `base.html`: у всех static-ссылок параметр `?v=redesign-1`.
5. Проверить favicon: data-URI в base.html содержит собственный маркер `?v=` (бампнут отдельно от `redesign-1`).

## Ожидаемый результат
- Ноль ссылок на V3-токены в CSS и шаблонах; нет var() на неопределенные токены.
- `static_v=redesign-1`, все подключения `?v=redesign-1`, favicon-маркер бампнут отдельно — кеш браузера не отдает старую статику (контрольный рефетч страницы показывает новые файлы).
