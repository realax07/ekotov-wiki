# TC-redesign-002: Фокус с клавиатуры — cyan-фокус-ринг (focus-visible)

## Трассировка
- **CHK:** CHK-002
- **Тип:** поз./виз. | **Приоритет:** Must (по CHK-002)
- **FR/Требование:** accessibility ADDED — «Фокус с клавиатуры — cyan-фокус-ринг» (NFR-42)
- **Scenario:** «Таб-навигация видит фокус», «Клик мышью без ринга»

## Предусловия
- Поднят стенд; редизайн применен; вход owner выполнен.
- Playwright (Python): `page.keyboard`, `page.evaluate`; в CSS определен `--focus-ring` (двойное кольцо bg-000 2px + cyan 4px + мягкое cyan-свечение, радиус 4px).

## Шаги
1. Открыть `/board`. Нажимать `Tab` последовательно по всем интерактивным элементам страницы (skip-link → пункты сайдбара → кнопка «Новая задача» → карточки/поля/спойлеры).
2. После каждого `Tab` через `page.evaluate` читать `document.activeElement` и его computed `box-shadow`/`outline`.
3. Повторить шаг 1 на `/search` и `/settings` (поля ввода, select'ы, спойлер wiki на `/wiki`).
4. Кликнуть мышью по кнопке «Новая задача» (`page.click`), прочитать `box-shadow` кнопки в момент фокуса; убедиться, что действие выполнено (открылась модалка).
5. Выделить текст на странице и проверить computed-стиль `::selection` (фон cyan, текст `--p-bg-000`).

## Ожидаемый результат
- Шаги 1–3: каждый сфокусированный табом элемент показывает `--focus-ring` (cyan в box-shadow, outline отсутствует/отключен); таб-порядок логичный, первый — skip-link, ловушек фокуса нет.
- Шаг 4: при клике мышью cyan-ринг НЕ отображается (семантика `:focus-visible`), при этом действие (открытие модалки) выполняется.
- Шаг 5: `::selection` — cyan-фон с текстом bg-000.
