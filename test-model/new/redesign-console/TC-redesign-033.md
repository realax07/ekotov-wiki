# TC-redesign-033: Breadcrumb статьи wiki — семантика и микро-лейбл

## Трассировка
- **CHK:** CHK-033
- **Тип:** поз./виз. | **Приоритет:** Must (по CHK-033)
- **FR/Требование:** wiki MODIFIED — «Breadcrumb на странице статьи» (FR-109, волна 2.3)
- **Scenario:** «Полная цепочка предков», «Breadcrumb корневой страницы», «Breadcrumb в стиле микро-лейбла»

## Предусловия
- Поднят стенд; вход owner; seed: дерево wiki корень → раздел → статья (3 уровня вложенности).
- Playwright + `page.evaluate`; эталон board-console.html §wiki-head.

## Шаги
1. Открыть страницу статьи 3-го уровня: breadcrumb показывает цепочку «корень → раздел → статья»; каждый элемент — кликабельная ссылка на соответствующую страницу (перейти по каждому уровню).
2. Открыть корневую страницу wiki: цепочка из одного элемента — текущая страница, без ссылки на саму себя.
3. Визуальная проверка шапки статьи (адрес «wiki / серверы / домашний кластер»): breadcrumb — mono 11px, uppercase, letter-spacing .08em, цвет `--p-text-500`; заголовок h1 26px `--p-text-900`; лид-абзац `--p-text-600`.
4. Проверить разделитель-трек между статьей и доской/шапкой: пунктирная линия 1px (repeating-linear-gradient), не сплошная.
5. Контроль: прогон `tests/web/test_p15_wiki_tree.py` (fixed, green) — пути и ссылки без изменений.

## Ожидаемый результат
- Цепочка предков полная и кликабельная; корень — один элемент без само-ссылки (FR-109 без изменений).
- Визуал — mono-микролейбл по мокапу §wiki-head, разделитель-трек пунктиром.
