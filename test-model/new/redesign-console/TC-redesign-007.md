# TC-redesign-007: Канбан-доска — семантика без изменений

## Трассировка
- **CHK:** CHK-007
- **Тип:** поз./нег. | **Приоритет:** Must (по CHK-007)
- **FR/Требование:** board MODIFIED — «Отображение канбан-доски» (FR-44/FR-45, ОВ-23/ОВ-24, ОГР-17)
- **Scenario:** «Открытие доски с задачами», «Открытие пустой доски», «Строка исполнителя на карточке без assigned», «Строка исполнителя на карточке с assigned», «Tooltip карточки показывает assigned и creator», «Единый механизм всплывашек»

## Предусловия
- Поднят стенд; вход owner; seed: задачи в разных столбцах, задача с assigned «wife» и creator «owner», задача без исполнителя.
- Playwright (Python).

## Шаги
1. Открыть `/board` с задачами: проверить 3 столбца, задачи в столбцах по статусу; на каждой карточке строка исполнителя с именем (assigned), creator на карточке/в tooltip (FR-45).
2. Проверить карточку без assigned: строка исполнителя присутствует, «Unassigned» курсивом (ОВ-24).
3. Навести курсор на карточку с creator «owner» / assigned «wife»: всплывашка показывает обе роли (FR-44).
4. Навести курсор на карточку и на блок профиля в сайдбаре: обе всплывашки построены одним DOM-механизмом (общий класс/элемент tooltip, ОГР-17).
5. Создать пустое состояние (стенд без задач либо фильтр): доска открывается с тремя пустыми столбцами без ошибок (консоль браузера чистая).
6. Контроль: прогон нецветовых тестов доски (board_tasks_ui, r3_dnd_ui, bug013, bug014) — green, DOM-хуки не менялись.

## Ожидаемый результат
- Семантика доски полностью прежняя: состав данных карточки (assigned/creator, строка Unassigned курсивом), tooltips, пустое состояние — без деградации.
- Всплывашки карточки и профиля — единый механизм; редизайн их содержание не менял.
