# TC-redesign-009: Визуальные эффекты доски на токенах «Пульт» (FR-132)

## Трассировка
- **CHK:** CHK-009
- **Тип:** виз./НФТ | **Приоритет:** Must (по CHK-009)
- **FR/Требование:** board ADDED — «Визуальные эффекты доски на токенах «Пульт»» (FR-132; приемник REMOVED «Визуальные эффекты доски поверх токенов V3»)
- **Scenario:** «Нет окраски столбца и cyan-декора», «Hover карточки — ступенями фона»

## Предусловия
- Поднят стенд; вход owner; на доске есть fast-задача в столбце «В работе» и обычные карточки.
- Playwright (Python): `page.hover`, `page.evaluate`; гейт 2.7 (grep hex вне токенов = 0) зафиксирован в REPORT.

## Шаги
1. Открыть `/board`. Инспектировать столбцы (включая столбец с fast-задачей): через `page.evaluate` проверить, что у столбцов нет фоновых/псевдо-окрасок (псевдоэлементы столбца без контента/без фона), фон колонки — только `--p-bg-100`.
2. Инспектировать декоративные поверхности доски (панели, карточки, кнопки в покое): cyan отсутствует; cyan-элементы только — фокус (TC-redesign-002), активный пункт навигации.
3. Навести курсор на обычную карточку: computed `background-color` → `--p-bg-300`, `border-color` → `--p-border-2`; мета-текст → `--p-text-600` (AA на новой подложке); теней-«глубины» (box-shadow с большим blur/смещением) нет.
4. Убрать курсор: карточка возвращается к bg2/`--p-border`/text-500.
5. Сверить grep-гейт 2.7: в `frontend/static/css/**` нет hex-значений вне токенов (результат в REPORT волны 2.7).

## Ожидаемый результат
- Столбцы не окрашены (в т.ч. при наличии fast-задачи); cyan на доске только актив/фокус.
- Hover — исключительно ступени фона bg2→bg3 и граница border-2, без цветной заливки и теней.
- Токен-дисциплина: hex вне токенов = 0 (гейт 2.7).
