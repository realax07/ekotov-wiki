## Шаги
1. Открыть раздел Wiki. Дерево страниц: панель `--p-bg-100` на bg-токенах; активный узел — cyan-сигнализация по общему паттерну активности (рамка/иконка/LED cyan, фон bg2).
2. Поиск по дереву: совпадения подсвечены инверсной янтарной — фон `--p-amber-900`, текст `--p-amber-400` (AA); `<mark>` в тексте статьи — та же amber-900/amber-400 пара.
3. Проверить отсутствие внешних зависимостей wiki (действующее требование) — подключения только локальной статики.
4. Открыть редактор статьи: поля bg2, cyan-фокус, панели/кнопки на общих токенах (янтарные первичные действия); история версий: те же панели/поля, список версий читаем (AA).
5. Выполнить правку в редакторе и сохранить; открыть историю — новая версия присутствует (функциональность не пострадала).
6. Гейт 2.7 по wiki.css: hex-значений вне токенов = 0 (REPORT волны 2.7); контроль — `tests/web/test_p15_wiki_tree.py` (fixed, green).
