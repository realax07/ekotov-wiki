# TC-redesign-014: Фастлайн — сигнальный янтарный канал

## Трассировка
- **CHK:** CHK-014
- **Тип:** виз./гран. | **Приоритет:** Must (по CHK-014)
- **FR/Требование:** fastline MODIFIED — «Выделенная линия fast line» (FR-89-поведение, визуал волны 2.2)
- **Scenario:** «Fast line отображается на доске», «Фастлайн — сигнальный янтарный канал», «Пустая fast line»

## Предусловия
- Поднят стенд; вход owner; seed: fast-задача со сроком и комментарием; возможность снять назначение fast-задачи (для пустого состояния).
- Эталон: board-console.html §fastline. Playwright + `page.evaluate`.

## Шаги
1. Открыть `/board` с назначенной fast-задачей. Проверить панель фастлайна над канбаном: граница `--p-amber-400`, подложка `--p-amber-900`, glow `--glow-amber`, янтарные HUD-уголки; зона визуально отличима от столбцов.
2. Проверить состав: слева микро-лейбл капсом «Фастлайн · FST-код» (mono, `--tracking-micro`) с янтарной LED-точкой (blink 2s step-end); задача 14px 600 `--p-text-900`; под ней комментарий/служебная строка 400 `--p-text-600` (обе читаемы, AA — по REPORT CHK-001).
3. Справа — mono-отсчет «T-ЧЧ:ММ до срока»; внизу панели трек: полоса 2px, фон rgba-amber 16%, заполнение градиентом amber→cyan пропорционально прошедшей части окна до дедлайна.
4. Снять fast-задачу (перенос/снятие назначения), обновить доску: пустая зона — задача не отображается; если панель показывается — БЕЗ янтарного сигнала и LED-blink.
5. Сравнить вид с мокапом §fastline (скриншот или чек-лист по шагам 1–3).

## Ожидаемый результат
- Шаги 1–3: фастлайн — полный сигнальный набор по мокапу; тексты AA; трек отражает прогресс градиентом на данных.
- Шаг 4: без fast-задачи сигнал гаснет (нет подложечных подсказок, glow, blink) — янтарь только при наличии задачи.
