# TC-dnd-103 — DnD: 409 fast line занята — ошибка в UI, плитка возвращена

- **CHK:** CHK-159
- **Change:** add-r3-visual-foundation
- **Источник:** board: «Перемещение карточки перетаскиванием» (FR-31, Д-6); Сценарий «Результат перетаскивания равнозначен переводу прежним способом»
- **Тип:** нег. | **Приоритет:** Must
- **Среда/предусловия:** web-стенд tests/web; вход owner; через API созданы: активная fast-задача «QAT-fast-занято» (is_fast=true, статус todo — fast line занята) и вторая fast-задача «QAT-fast-возврат» в статусе done. Обе — с QAT-префиксом, удаление в teardown (DELETE, включая архивную). Механика — dispatchEvent с DataTransfer.
- **Шаги:**
  1. Найти карточку «QAT-fast-возврат» в столбце «Выполнено».
  2. `dispatchEvent('dragstart')` на ней; `dispatchEvent('dragover')` на столбце «Ожидает»; `dispatchEvent('drop')` на нем.
  3. Автожидание: `#board-error` видим (p#board-error), прочитать текст.
  4. Автожидание: карточка «QAT-fast-возврат» снова в `[data-status="done"]`.
  5. `GET /api/board` API-сессией: посчитать fast-задачи в активных статусах.
- **Ожидаемый результат:** сервер отклонил перевод (409 `{"error": "fast line occupied"}` — в перехваченном ответе); в `#board-error` показано сообщение об ошибке; плитка возвращена на исходное место («Выполнено», перерисовка из серверного состояния); в активных статусах ровно одна fast-задача — инвариант ≤1 сохранен (Д-6).
- **Тестовые данные:** `QAT-fast-занято` (is_fast, todo); `QAT-fast-возврат` (is_fast, done → попытка в todo).
