# TC-dnd-105 — Touch: перетаскивание не срабатывает, перенос прежним способом работает

- **CHK:** CHK-162
- **Change:** add-r3-visual-foundation
- **Источник:** board: «Перемещение карточки перетаскиванием» (ОВ-19 «принимаю»); Сценарий «На touch-устройстве перенос выполняется прежним способом»
- **Тип:** нег. | **Приоритет:** Must
- **Среда/предусловия:** web-стенд tests/web; контекст Playwright с touch-эмуляцией (`has_touch=True`); вход owner; задача «QAT-dnd-touch» в «Ожидает».
- **Доработка по review-001 №2:** убран самопротиворечащий dispatchEvent; touch-жест выполняется touchscreen API.
- **Шаги:**
  1. В touch-контексте открыть /board; найти карточку задачи; перехватывать запросы (счетчик POST /api/tasks/*/move).
  2. Выполнить touch-жест по карточке: `page.touchscreen.tap(x, y)` и удержание (long-press) — НИКАКИХ drag-событий синтетически не возбуждать.
  3. Проверить карточку: класс `drag-ghost` отсутствует; счетчик POST move = 0.
  4. Перенести задачу прежним способом: тап по карточке → карточка задачи → селект «Столбец» → `in_progress` (механика `move_via_card_select`).
  5. Автожидание: карточка в «В работе».
- **Ожидаемый результат:** touch-жест не открывает drag-сессию (нет `drag-ghost`, нет POST move — HTML5 DnD не срабатывает на touch, перенос прежним способом, ОВ-19); перенос через карточку задачи (селект «Столбец») работает и меняет статус на `in_progress`.
- **Тестовые данные:** задача `QAT-dnd-touch`; селект значения: `in_progress`.
