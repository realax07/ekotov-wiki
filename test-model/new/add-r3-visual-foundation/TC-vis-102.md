# TC-vis-102 — Оформленный пустой state пустого столбца

- **CHK:** CHK-165
- **Change:** add-r3-visual-foundation
- **Источник:** board: «Визуальные эффекты доски поверх токенов V3» (FR-32); Сценарий «Обязательный минимум — оформленный пустой state столбца»
- **Тип:** поз. | **Приоритет:** Must
- **Среда/предусловия:** web-стенд tests/web; вход owner; свежий стенд: столбец «В работе» пуст (задачи теста создаются в «Ожидает»). Точка проверки — класс `.board-column-empty`, не текст (селектор зафиксирован код-ревью 3.1 №2: текст живет в CSS ::before).
- **Шаги:**
  1. Открыть /board, дождаться `data-loaded=true`.
  2. Прочитать class секции `[data-status="in_progress"]`.
  3. Прочитать computed style секции: `border-style`, `border-width`, `min-height`; наличие непустого `::before` контента (`getComputedStyle(el, '::before').content`).
  4. Создать задачу в «В работе» (перезапись доски) — класс у столбца должен сняться.
- **Ожидаемый результат:** пустой столбец имеет класс `board-column-empty`; border-style `dashed`, ширина 2px, min-height ≥ 48px; ::before-контент не `none` (оформленный state, градиент пресета В — background содержит linear-gradient); после появления задачи класс снят.
- **Тестовые данные:** столбцы `[data-status="in_progress"]`; задача `QAT-vis-заполнение`.
