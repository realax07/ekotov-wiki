# TC-vid-039 — p95 API < 500 мс при конвертации ~300 МБ

- **Change:** video-hosting
- **Источник:** video-service: «Отзывчивость при фоновой конвертации» (NFR-37) / Scenario: Замер отзывчивости на стенде
- **Тип:** НФТ | **Приоритет:** Must
- **Среда/предусловия:** стенд; запущена конвертация файла ~300 МБ; скрипт замера (20 запросов списка + 5 загрузок малого файла)
- **Шаги:**
  1. Дождаться подтверждения идущей конвертации (статус «конвертируется»).
  2. Выполнить 20× `GET {BASE_URL}/api/videos`, записать времена.
  3. В ходе той же конвертации выполнить 5× загрузку `small.mp4` (5 МБ), записать времена.
  4. Вычислить p95 обоих наборов.
- **Ожидаемый результат:** шаг 4 — p95 ответов списка < 500 мс и p95 загрузок < 500 мс; ни один запрос не ожидал завершения конвертации (максимум времени < длительности конвертации).
- **Тестовые данные:** файл ~300 МБ; `small.mp4` 5 МБ × 5 (с уникальными именами).
