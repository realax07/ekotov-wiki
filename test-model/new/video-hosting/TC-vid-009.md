# TC-vid-009 — Playback готового видео, прямая ссылка без сессии запрещена

- **Change:** video-hosting
- **Источник:** video-service: «Список видео и playback» (ОВ-2) / Scenario: Playback готового видео
- **Тип:** негативный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); Playwright (Python): `page`, `expect`, `api_request_context`; видео в статусе «готово» (id=T1); известен URL файла
- **Шаги:**
  1. Открыть `/video` под owner, найти T1, кликнуть — воспроизведение в `<video>`.
  2. Извлечь прямую ссылку на mp4 из `network`/атрибута `src`.
  3. Запросить ссылку шага 2 из нового контекста без сессии.
  4. Повторить шаг 3 с валидной сессией.
  5. Повторить шаги 1–4 под pe.
- **Ожидаемый результат:** шаг 1 — видео воспроизводится во встроенном HTML5-плеере; шаг 3 — HTTP 401 или редирект на `/login` (публичной ссылки не существует); шаг 4 — 200, файл отдается; шаг 5 — паритет обоих пользователей.
- **Тестовые данные:** видео T1 «готово»; прямая ссылка вида `/videos/<id>/<file>.mp4`.
