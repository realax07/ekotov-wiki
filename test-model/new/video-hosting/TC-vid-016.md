# TC-vid-016 — Исчерпание повторов по таймауту конвертации — «ошибка»

- **Change:** video-hosting
- **Источник:** video-service: «Серверная конвертация в mp4 со статусами» / Scenario: Неудача и автоматический ретрай (таймаут)
- **Тип:** негативный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); Playwright (Python): `page`, `expect`, `api_request_context`; подготовлен файл, конвертация которого превышает таймаут задачи (медианный поток высокой длительности/битрейта); известен настроенный таймаут задачи конвертации
- **Шаги:**
  1. Загрузить файл; дождаться в логах первого прерывания задачи по таймауту.
  2. Зафиксировать автоматический повтор.
  3. Дождаться второго прерывания по таймауту и финального статуса; проверить том.
- **Ожидаемый результат:** шаг 1 — задача прервана по таймауту (лог), запущен ровно один повтор; шаг 3 — после второй неудачи статус «ошибка», оригинал сохранен в томе, mp4 отсутствует.
- **Тестовые данные:** файл с длительной конвертацией; таймаут фоновой задачи (из конфигурации сервиса).
