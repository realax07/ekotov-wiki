# TC-vid-029 — Постановка лайка: счетчик +1, голос виден

- **Change:** video-hosting
- **Источник:** video-service: «Лайки и дизлайки — один голос на пользователя» (FR-81) / Scenario: Постановка лайка
- **Тип:** позитивный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (оба — фикстуры стенда); Playwright (Python): `page`, `expect`, `api_request_context`; видео T9 существует, готово к просмотру и не имеет голосов от owner и pe (счетчики 0 лайков / 0 дизлайков — исходное состояние, без предсозданных голосов: все голоса создаются шагами настоящего кейса)
- **Шаги:**
  1. Под pe через API отправить `PUT {BASE_URL}/api/videos/<T9>/reaction` с `{"value": -1}` (дизлайк — подготовка ненулевого базового состояния) и перечитать счетчики T9.
  2. Под owner нажать лайк у T9 (UI или `PUT {BASE_URL}/api/videos/<T9>/reaction` с `{"value": 1}`).
  3. Перечитать `GET {BASE_URL}/api/videos/<T9>` (или UI-счетчики).
- **Ожидаемый результат:** шаг 1 — 2xx; счетчики: лайков = 0, дизлайков = 1; шаг 2 — 2xx; шаг 3 — счетчик лайков = 1, дизлайков = 1 (счетчик лайков изменился ровно на +1 относительно шага 1, дизлайки не тронуты), собственный голос owner = «+1» отображается; инвариант «≤ 1 голоса на пользователя» (в паре пользователь×видео) выполнен: у owner ровно один голос («лайк»), у pe ровно один голос («дизлайк») — суммарно 1 лайк / 1 дизлайк, двойных голосов нет.
- **Тестовые данные:** видео T9 без голосов на старте; эндпоинт reaction; начальное состояние 1 лайк / 1 дизлайк собирается самим кейсом (шаги 1–2), а не задается данностью.
