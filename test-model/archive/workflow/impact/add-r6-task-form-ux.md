## 3. Новые тестовые требования дельты (вход для чеклиста → кейсов)

По сверке 30 сценариев дельт + СЦ-1…СЦ-11 с существующим набором:

1. **Адаптив 375px** (СЦ-9, сценарий «Адаптив одной колонкой… проверка
   ~375px»; задача 4.3 дословно: «проверка на ~375px») — wave2-004 гоняет
   ровно 480 (граница media). Гэп: 375×720 — одна колонка, full-width,
   без h-скролла, ОТКРЫТЫЙ дропдаун в вьюпорте и не шире поля. → NEW
   TC-r6-gaps-001 (web).
2. **Escape при открытой view-модалке** (СЦ-8, сценарий «Escape не
   срабатывает при открытой view-модалке») — комбинированный тест
   wave2-004 покрывает только дропдаун-ветку. Гэп: view открыта, форма
   закрыта → view закрывается прежней логикой, r6-обработчик молчит.
   → NEW TC-r6-gaps-002 (web).
3. **kind=tags исключает ВСЕ активные категории** (СЦ-1 «в подсказках
   нет имен категорий» + сценарий дельты «kind=tags — только теги»):
   sugg-r6-002 сеет тег и категорию одной задачей, но не фиксирует
   отсутствие ДРУГИХ категорий справочника (несенных другой задачей).
   Гэп: активные данные обоих kind одновременно. → NEW TC-r6-gaps-003 (API).

Не-пробелы (закрыты существующими, новых кейсов не требуют): 422/401/
UNION (sugg-r6-001…005), фильтрация/подсветка/исключение/«+ Добавить»/
клавиатура/aria/XSS/тач/сбой (comb-001…010), состав зоны/id/destructive/
подтверждение удаления (wave2-001/002), Escape чистая/грязная/дропдаун/
сервер (wave2-003/004), адаптив на границе 480 (wave2-004), payload тегов
(comb-004/009 — сохранение через форму, ОГР-27).
