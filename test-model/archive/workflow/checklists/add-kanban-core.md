# Чеклист проверок: add-kanban-core

Change-пакет: `openspec/changes/add-kanban-core/` (дельты 7 доменов: auth, board, fastline, tasks, archive, search, navigation).
ТЗ для сверки: `requirements.md` r3 (FR-1…FR-14, NFR-1…NFR-7, ОГР-1…ОГР-6, MoSCoW).
Инвентаризация: 31 Requirement, 64 Scenario. Каждый Requirement и каждый Scenario покрыты ≥1 пунктом; для требований с валидацией добавлены негативные/граничные пункты (техники: границы, негативные классы, состояние). Пункты-дополнения помечены «дополнение» — источник: тот же Requirement + техника test-case-design.
Приоритет наследуется от MoSCoW источника: Must-требования → Must, Should (FR-8) → Should.

Типы: **поз.** — позитивная, **нег.** — негативная, **гран.** — граничное значение, **НФТ** — нефункциональная.
