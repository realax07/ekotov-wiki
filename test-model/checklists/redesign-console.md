# Чеклист проверок: redesign-console

Change-пакет: `openspec/changes/redesign-console/` — редизайн консоли на
токены «Пульт» (весь фронт: 10 шаблонов + 8 CSS, static_v → `redesign-1`,
favicon; бэкенд не меняется, кроме 1 строки pages.py). Дельты: 12 capability,
25 Requirement, 105 Scenario (MODIFIED: auth, board, fastline, navigation,
search, settings, wiki; ADDED: accessibility, design-tokens, gallery,
video-ui, weather-ui + board/navigation/wiki). Трассировка: FR-123…FR-132,
NFR-41…44. Зоны воздействия: `impact.md` пакета (J58) +
`test-model/impact/redesign-console.md` (задача 3.1, вердикты по
существующим тестам). ТЗ для сверки: дельты `specs/*/spec.md`, design.md
§D1–D4, tasks.md 2.1–2.7 (выполнены), requirements.md пакета.

Статус: задачи 3.3 (кейсы TC-redesign-NNN из дельт) и 3.4 (автоматизация +
фикс Д1) впереди — колонка «Автотест/прогон» содержит существующие тесты
(после волновых фиксов, вердикты — impact/redesign-console.md) и планы
3.3/3.4; колонка «Покрытие» — план regress-final (4.1). Типы: **поз.**,
**нег.**, **гран.**, **НФТ**, **сред.** (стенд/браузер), **виз.** (визуальная
проверка по мокапам design/redesign-pro).
