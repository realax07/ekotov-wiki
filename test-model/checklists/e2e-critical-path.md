# Чеклист E2E-сценариев критического пути (G1) — Playwright-сьют

Источник: master-specs `openspec/specs/` (auth, board, tasks, fastline, navigation, search, archive, regression) — change-пакет add-kanban-core заархивирован, дельты слиты.
Отличие от чеклиста `add-kanban-core.md`: пункты — СКВОЗНЫЕ бизнес-сценарии (путь пользователя через несколько доменов), а не атомарные проверки модуля. Доменные проверки (API, валидация, состояние БД) уже покрыты API-сьютом `tests/api` — здесь ТОЛЬКО UI: DOM, формы, модалки, редиректы, подсветка.
Инвентаризация: 18 сквозных сценариев; критический путь логин → создание → fast line → перенос → ленивая архивация покрыт полностью (E-1 → E-2 → E-7 → E-10 → E-12 → E-18). Домен regression — процессный (регресс-прогон сьюта), UI-сценариев не имеет, в чеклист не входит; продовые дефекты 2026-09-19 включены как пункты E-6, E-13, E-15.
Типы: **поз.** — позитивная, **нег.** — негативная. Приоритет — MoSCoW источника.

| № | Дефект | Влияние на чеклист |

| 1 | archive: ленивая автоархивация наступает «с наступлением следующего календарного дня по МСК» — механизм управления временем (мок/перемотка серверных часов) спекой не определён; через чистый UI без ожидания суток CHK-E-18 (граница дня) невоспроизводим | CHK-E-18 частично требует тестового крюка (управляемое время сервера); без него проверяется только «выполнена сегодня — видима» |
