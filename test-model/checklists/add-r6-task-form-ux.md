## Дефекты спеки

Нет. Замечания (не дефекты):
1. Сценарий «Escape не срабатывает при открытой view-модалке» описывает
   состояние «форма открыта + view открыта», недостижимое в UI
   (openEditForm скрывает view-оверлей — task-form.js:718): guard
   проверен через взаимоисключающие состояния (CHK-R6-14/TC-r6-gaps-002).
2. Сценарий адаптива говорит «≤480px (проверка ~375px)» —
   существующий wave2-004 покрывает только границу 480; 375 закрыт
   гэпом CHK-R6-23b (recovery-ревью отмечало то же).

Итог: 36 CHK (35 + 2 дополнения − 1 объединение); покрыто существующими
32, новых кандидатов 3 (CHK-R6-1b, 14, 23b → TC-r6-gaps-003/002/001).
