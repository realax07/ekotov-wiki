# Чеклист проверок: add-responsive-mobile

Change-пакет: `openspec/changes/add-responsive-mobile/` — адаптив P14
(мобильный вид всех разделов ≤480px, drawer ≤768px): FR-99/FR-100
(бургер+drawer, индикация раздела), FR-101 (свайп-колонки доски, санкция
ОВ-3 на уточнение FR-62), FR-102 (fullscreen-модалка тикета, ОВ-4),
FR-103 (поиск одной колонкой), FR-104 (настройки/профиль, сохранение
FR-56), FR-105 (свайпы лайтбокса), FR-106 (мокапы-ворота); NFR-23…NFR-29.
ТЗ для сверки: requirements.md пакета, design.md §1–§8, дельты
`specs/{board,navigation,gallery,search,settings,tasks}`, утвержденные
мокапы `design/mobile-p14/01–07` (decision 2026-10-08-p14-mockups-approve).
Статус реализации: волны 0–4 влиты (main 9b08d99, static_v
p14-responsive-1); QA 5.1 прогнан — mobile ~185p / desktop ~133p /
API 229p, design_validator 7/7 APPROVE
(`test-model/reviews/add-responsive-mobile/review-001-design.md`).
Вход 5.1: `test-model/impact/add-responsive-mobile.md` (correlation
43cc91005d1f4b9f9d7c0ee64490748c).

Типы: **поз.** — позитивная, **нег.** — негативная, **гран.** — граничное
значение, **НФТ** — нефункциональная, **сред.** — средовое предусловие
(device-эмуляция/живое устройство).
Покрытие: «5.1 mobile/desktop/API» — факт прогона 5.1 (сьюты
device-эмуляции 375×812 и 480×800, desktop ≥1024px, API-смок); «DV» —
design_validator review-001 (мокап 0N); «5.2» — живая приемка Заказчика
на проде с телефона (план, iPhone 11 / Z Fold 7).
