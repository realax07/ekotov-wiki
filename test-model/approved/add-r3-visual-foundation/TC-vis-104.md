- **Шаги:**
  1. Создать задачу «QAT-vis-появление» через UI-форму (только название).
  2. Автожидание появления карточки в «Ожидает»; немедленно прочитать computed style карточки: `animation-name`, `animation-duration`, `animation-timing-function`.
  3. Дождаться окончания анимации; убедиться, что карточка отрисована (opacity 1, без смещения) — «пружинка» не оставляет artifact-кадра.
- **Ожидаемый результат:** карточка появляется с анимацией `v-in` (computed animation-name `v-in`, duration ~0.32s); timing-function — cubic-bezier (не мгновенный `linear`/`step*` на весь переход — есть выраженная кривая); после отыгрыша карточка в кадре без смещений (fill-mode backwards не «замораживает» финальный кадр поверх hover-состояний — урок fill both из ревью 3.2).
- **Тестовые данные:** задача `QAT-vis-появление`; ожидаемый keyframes `v-in` (from: translateY(14px) scale(0.97) opacity 0 → to: none) — справочное примечание, ассерты по computed.
- **Справочное примечание (не ассерт):** пружинка мокапа — cubic-bezier с коэффициентом >1 (мокап `design/p8-presets.html`, пресет В); конкретные коэффициенты не ассертятся — при смене кривой в рамках утвержденного пресета кейс не должен давать ложный негатив (арбитр CHK-167: «анимация v-in, только CSS»).
