# TC-redesign-004: Skip-link — первый в таб-порядке, невидим без фокуса

## Трассировка
- **CHK:** CHK-004
- **Тип:** поз. | **Приоритет:** Must (по CHK-004)
- **FR/Требование:** accessibility ADDED — «Skip-link» (NFR-44)
- **Scenario:** «Skip-link первый в таб-порядке», «Skip-link невидим без фокуса»

## Предусловия
- Поднят стенд; редизайн применен; вход owner выполнен.
- Playwright (Python): `page.keyboard`.

## Шаги
1. Открыть `/board` (затем повторить на `/search`, `/wiki`, `/settings`). Без фокуса через `page.evaluate` проверить положение/видимость элемента `.skip` (skip-link): вынесен за экран (`position`/координаты за viewport), не читается как видимый контент, не влияет на верстку.
2. Нажать `Tab` первый раз: прочитать `document.activeElement` — ожидается skip-link; проверить, что он появился в левом верхнем углу (bg1-панель, видимый текст AA, z-index над контентом).
3. Нажать `Enter` на skip-link: прочитать `document.activeElement` / позицию скролла — фокус переведен в основной контент раздела (main), минуя сайдбар.
4. Повторить шаги 2–3 на второй странице — skip-link первый на каждой.

## Ожидаемый результат
- Шаг 1: без фокуса skip-link невидим (за пределами экрана), верстка не сдвинута.
- Шаги 2–4: первый `Tab` на любой странице фокусирует skip-link «К основному содержимому»; `Enter` переводит фокус в main-контент раздела, сайдбар пропущен.
