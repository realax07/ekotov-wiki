# TC-redesign-019: Сайдбар в визуале «Пульта», активный раздел — cyan

## Трассировка
- **CHK:** CHK-019
- **Тип:** виз. | **Приоритет:** Must (по CHK-019)
- **FR/Требование:** navigation MODIFIED — «Навигация через сайдбар» (визуальная часть, волна 2.1)
- **Scenario:** «Сайдбар в визуале «Пульта»», «Активный раздел читается по cyan»

## Предусловия
- Поднят стенд; вход owner; эталон — board-console.html §sidebar. Playwright + `page.evaluate`.

## Шаги
1. Открыть `/board`. Проверить каркас: grid 232px + 1fr; сайдбар — панель `--p-bg-100` с правой границей `--p-border`.
2. Бренд: `ekotov.wiki` с teal-LED-точкой со свечением + микро-подзаголовок капсом (mono, SYS-стиль).
3. Пункты: 7 основных (порядок и пути прежние) + Настройки/Профиль в футере; каждый — inline-SVG-иконка 16px `stroke="currentColor"` + подпись 14px `--p-text-600`; hover — фон `--p-bg-200` + текст `--p-text-900`.
4. Активный пункт «Доска»: атрибут `aria-current="page"`, фон `--p-bg-200`, рамка rgba-cyan 45%, иконка cyan, cyan-LED справа со свечением. Остальные пункты — `--p-text-600`, без подсветки.
5. kbd-блок внизу (если присутствует): декоративный `aria-hidden`, mono, отделен границей; перечисляет ТОЛЬКО реально обрабатываемые глобальным JS хоткеи (проверить: глобальных обработчиков `n`/`/`/`f` нет — таких подсказок быть не должно).
6. Перейти в «Wiki» (или «Поиск»): cyan-подсветка переехала на новый активный пункт, у «Доска» снята.

## Ожидаемый результат
- Сайдбар соответствует мокапу §sidebar (цвета, отступы, иконки, состав 7+2).
- Активный раздел однозначно читается по cyan-паттерну (aria-current + фон + рамка + LED); при смене раздела подсветка следует за активным пунктом.
- kbd-блок — aria-hidden и без ложных аффордансов (нет подсказок нереализованных хоткеев).
