# TC-redesign-008: Доска в визуале «Пульта» — колонки, LED, приоритеты, fast-карточка

## Трассировка
- **CHK:** CHK-008
- **Тип:** виз. | **Приоритет:** Must (по CHK-008)
- **FR/Требование:** board MODIFIED — «Отображение канбан-доски» (визуальная часть, волна 2.2)
- **Scenario:** «Доска в визуале «Пульта»», «Статусы колонок читаются по LED», «Приоритеты различимы на темной теме», «Fast-карточка сигнальна», «Существующее поведение доски не деградировало»

## Предусловия
- Поднят стенд; вход owner; seed: колонки «Ожидает»/«В работе»/«Выполнено» с задачами, приоритеты высоко/средне/низко, одна fast-задача, одна выполненная карточка.
- Эталон: `design/redesign-pro/board-console.html` §board. Playwright + `page.evaluate`.

## Шаги
1. Открыть `/board`. Через computed styles проверить: сетка колонок 3×1fr с зазором 16px; колонка — панель `--p-bg-100`, граница `--p-border`, радиус 8px, HUD-уголки; заголовок колонки — LED-точка + название капсом 12px `--p-text-600` + mono-код (QUE-01/RUN-02/DN-03) + mono-счетчик справа.
2. Проверить LED статусов: «Ожидает» — нейтральная t500; «В работе» — янтарная со свечением и blink; «Выполнено» — teal со свечением.
3. Карточка: фон `--p-bg-200`, граница `--p-border`, заголовок 14px `--p-text-900`, мета-строка mono 11px `--p-text-500`; выполненная карточка — заголовок зачеркнут, `--p-text-500`.
4. Бейджи приоритетов: высокий — coral, средний — violet, низкий — teal, контурные (не заливка); цвета берутся из токенов.
5. Fast-карточка: янтарная граница, подложка `--p-amber-900`, мягкое янтарное свечение, маркер «▲»; иных отличий от обычной карточки нет.
6. Pagehead: h1 22px + терминальный readout (mono: дата, ACT/DONE, teal-LED) + янтарная кнопка «Новая задача» справа.
7. Сверить общий вид с мокапом board-console.html §board (скриншот-сравнение или чек-лист по пунктам 1–6).

## Ожидаемый результат
- Все пункты 1–6 соответствуют мокапу и токенам; LED и контурные бейджи различимы без опоры только на цвет (форма/подпись + цвет).
- Поведение доски (DnD, быстрое «Выполнено», модалка) не деградировало — подтверждается прогоном нецветовых тестов (см. TC-redesign-007 шаг 6).
