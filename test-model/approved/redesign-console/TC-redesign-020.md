# TC-redesign-020: Раздел «Настройки» в сайдбаре — положение, переходы, стиль

## Трассировка
- **CHK:** CHK-020
- **Тип:** поз./виз. | **Приоритет:** Must (по CHK-020)
- **FR/Требование:** navigation MODIFIED — «Раздел «Настройки» в сайдбаре» (FR-23)
- **Scenario:** «Раздел настроек отображается внизу слева», «Переход в настройки через сайдбар», «Раздел настроек доступен со всех страниц функционала», «Пункт настроек в стиле «Пульта»»

## Предусловия
- Поднят стенд; вход owner. Playwright (Python).

## Шаги
1. С каждой из страниц `/board`, `/search`, `/settings`: проверить, что пункт «Настройки» присутствует в футере сайдбара (внизу слева, рядом с профилем/выходом).
2. С `/board`: клик по «Настройки» → URL `/settings`, страница настроек открывается.
3. С `/settings`: активное состояние пункта — по общему cyan-паттерну навигации (`aria-current`, фон bg2, cyan-рамка); геометрия стабильна — текст/иконка не смещаются при active/focus (преемственность P12 п.1).
4. Визуальная проверка пункта: иконка 16px `stroke="currentColor"`, подпись `--p-text-600`, hover `--p-bg-200` — паттерн «Пульта»; маршрут `/settings` не менялся.
5. Контроль прогоном `tests/web/test_p12n004_sidebar_footer*` — green без правок.

## Ожидаемый результат
- «Настройки» — в футере сайдбара на всех страницах, переход ведет на /settings со всех разделов.
- Активное состояние — cyan по общему паттерну, геометрия не «прыгает», визуал «Пульта», тесты green.
