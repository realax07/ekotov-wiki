# TC-redesign-018: Навигация через сайдбар — переходы и хуки без изменений

## Трассировка
- **CHK:** CHK-018
- **Тип:** поз. | **Приоритет:** Must (по CHK-018)
- **FR/Требование:** navigation MODIFIED — «Навигация через сайдбар» (FR-39…FR-43, ОГР-28)
- **Scenario:** «Переход на доску через сайдбар», «Переход на вкладку поиска через сайдбар», «Сайдбар доступен со всех страниц функционала», «Хуки навигации сохранены»

## Предусловия
- Поднят стенд; вход owner; владелец дополнительно видит ссылку «Мониторинг» (owner-роль — без изменений).
- Playwright (Python).

## Шаги
1. С каждой из страниц `/board`, `/search`, `/wiki`, `/gallery`, `/video`, `/weather`, `/settings`: проверить наличие сайдбара `#sidebar` и пунктов `.nav-item-*` (7 основных: Доска, Wiki, Галерея, Видео, Погода, Поиск, Игры + Настройки/Профиль в футере).
2. С `/search`: клик по «Доска» → URL `/board`, доска отображается.
3. С `/board`: клик по «Поиск» → открывается вкладка поиска старых задач.
4. Прогнать существующие навигационные тесты (games_nav, navigation_search_ui, p12n004_sidebar_footer) — green без правок селекторов: `.nav-item-*`, `#sidebar`, aria-атрибуты работают (ОГР-28).
5. Проверить состав пунктов по ролям: у owner есть «Мониторинг», у второй роли (жена) — нет (действующее поведение без изменений).

## Ожидаемый результат
- Сайдбар доступен со всех страниц функционала, переходы доска↔поиск и все разделы работают как прежде.
- DOM-хуки навигации сохранены, существующие тесты green без правок; состав пунктов по ролям не изменился.
