# TC-redesign-006: Форма входа в визуале «Пульта»

## Трассировка
- **CHK:** CHK-006
- **Тип:** виз./поз. | **Приоритет:** Must (по CHK-006)
- **FR/Требование:** auth MODIFIED — «Вход по логину и паролю» (визуальная часть, волна 2.4)
- **Scenario:** «Форма входа в визуале «Пульта»», «Фокус в поле читается по cyan», «Ошибка авторизации в новом визуале», «Хуки формы входа сохранены»

## Предусловия
- Поднят стенд; пользователь `owner` существует (seed); редизайн применен.
- Playwright (Python): `page.evaluate` для computed styles; эталоны — `design/redesign-pro/tokens-console.html`, `board-console.html` (панель login).

## Шаги
1. Открыть `/login` неавторизованным. Через `page.evaluate` прочитать computed-стили: фон страницы (`--p-bg-000` + микро-сетка `--texture-grid`), панель формы (`--p-bg-100`, граница `--p-border`), поля ввода (`--p-bg-200`), кнопку входа (`--p-amber-400`, текст `--p-bg-000`), микро-лейблы полей (caps, mono).
2. Проверить наличие HUD-уголков на панели (8 отрезков, `::after`/псевдоэлементы) и teal-LED у бренда над формой; сверить вид с мокапом board-console.html.
3. Нажать `Tab` в поле «Логин»: прочитать box-shadow поля — cyan-фокус-ринг `--focus-ring`; кликнуть мышью в поле — ринг не рисуется, рамка поля не исчезает.
4. Ввести `owner` + неверный пароль, отправить: сообщение об ошибке отображается цветом `--status-error` (coral `--p-coral-400`), контраст AA (по REPORT CHK-001); поле «Логин» НЕ очищено.
5. Прогнать `tests/web/test_auth_ui.py` (или проверить в REPORT волны 2.4): селекторы id полей/кнопки/блока ошибки не изменились, тесты green без правок.
6. Контрольная проверка: hover кнопки — `#f6c17a` + янтарное свечение; `color-scheme: dark` объявлен (нативные контролы темные).

## Ожидаемый результат
- Шаги 1–2: панель login — темная с HUD-уголками, поля на bg-200, янтарная кнопка, капс-микролейблы mono; вид соответствует мокапу.
- Шаг 3: фокус табом — cyan-ринг; mouse-фокус без ринга.
- Шаг 4: ошибка — coral на подложке, AA; функциональное поведение прежнее (логин сохранен).
- Шаги 5–6: DOM-хуки формы сохранены (ОГР-28), тесты авторизации проходят без правок.
