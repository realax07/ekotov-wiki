# TC-redesign-025: Фильтр-конструктор — функциональность без деградации (FR-45/46)

## Трассировка
- **CHK:** CHK-025
- **Тип:** поз./нег./гран. | **Приоритет:** Must (по CHK-025)
- **FR/Требование:** search MODIFIED — «Фильтр-конструктор по признакам задачи» (FR-45/FR-46, FR-35/DEF-001)
- **Scenario:** «Фильтр по одному признаку», «Фильтр по исполнителю», «Фильтр по создателю», «Фильтр «без исполнителя»», «Подсказки значений фильтров assigned/creator — из БД», «Комбинация условий по нескольким признакам», «Поиск без заданных условий»

## Предусловия
- Поднят стенд; вход owner; seed: задачи с разными приоритетами, assigned «wife»/пусто, creator «owner», разные категории; архивные задачи.
- Playwright (Python).

## Шаги
1. Фильтр по одному признаку (приоритет): выбрать значение, выполнить поиск — в результатах только задачи с этим приоритетом.
2. Фильтр по assigned = «wife»: только задачи с исполнителем «wife».
3. Фильтр по creator = «owner»: только задачи, созданные «owner».
4. Фильтр assigned = «без исполнителя» (Unassigned): только задачи без исполнителя.
5. Раскрыть подсказки полей assigned и creator: значения — из уникальных значений столбцов БД (owner, wife), не статические списки (механизм FR-35/DEF-001).
6. Комбинация двух условий (assigned + категория): только задачи, удовлетворяющие обоим.
7. Поиск без единого условия: отображаются все задачи (пустой фильтр не ограничивает выборку).

## Ожидаемый результат
- Все 7 фильтрационных поведений работают как прежде (контракт FR-45/46 без деградации); подсказки — из БД.
- Контроль: существующие поисковые тесты (keep) green — подтверждает нецветовой регресс.
