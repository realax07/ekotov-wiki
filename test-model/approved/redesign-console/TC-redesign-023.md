# TC-redesign-023: Мобильная раскладка каркаса ≤ 860px (FR-131)

## Трассировка
- **CHK:** CHK-023
- **Тип:** НФТ | **Приоритет:** Must (по CHK-023)
- **FR/Требование:** navigation ADDED — «Мобильная раскладка каркаса (≤ 860px)» (FR-131)
- **Scenario:** «Каркас на узком экране», «Пункты навигации кликабельны на тач»

## Предусловия
- Поднят стенд; вход owner; мобильный профиль Playwright (viewport 860px и уже, тач-эмуляция; прецедент p23-мобильных маркеров).
- Эталон: board-console.html `@media (max-width:860px)`.

## Шаги
1. Открыть `/board` на вьюпорте 860px (затем 375px). Проверить `@media`-перестройку: сайдбар наверху одной колонкой, основная группа навигации — горизонтальная строка с переносом.
2. Проверить скрытие на мобильной раскладке: kbd-блок отсутствует (display:none), LED активного пункта скрыта.
3. Проверить содержимое: одна колонка, отступы 16px (computed padding основной области), горизонтальной прокрутки нет (`document.documentElement.scrollWidth <= innerWidth`).
4. Через `page.evaluate` измерить высоты (bounding box) всех пунктов навигации: каждая ≥ 44px.
5. Тап по пункту «Wiki»: переход с первого тапа (URL и заголовок раздела), hit-target ≥ 44px.
6. Проверить сохранение бургера: `#burger-button` присутствует, `aria-expanded` переключается, класс `sidebar-open` управляет состоянием (действующее поведение).

## Ожидаемый результат
- На ≤ 860px каркас — по мокапу: сайдбар сверху, горизонтальная навигация, kbd/LED скрыты, контент в одну колонку с отступами 16px, тач-таргеты ≥ 44px, переходы с первого тапа.
- Бургер-поведение (aria-expanded, sidebar-open) не регрессировало.
