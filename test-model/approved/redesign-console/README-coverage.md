# Отчет задачи 3.3: кейсы TC-redesign-NNN (redesign-console)

Дата: 2026-10-24 · Автор: qa_case_author (Флоу 1, задача 3.3) · Ветка:
`pipeline/redesign-cases`, worktree /tmp/wt-red-cases.

## Объем

36 кейсов `test-model/new/redesign-console/TC-redesign-001…036.md` — один кейс
= один файл (H1 `# TC-redesign-NNN: <название>`), секции: трассировка
(FR/Требование, Scenario, CHK, тип), предусловия, шаги, ожидаемый результат,
приоритет по CHK.

Источники: дельты `openspec/changes/redesign-console/specs/` (12 capability,
25 Requirement, 105 Scenario — числа сверены парсером дельт) + чеклист
`test-model/checklists/redesign-console.md` (CHK-001…036). Кейсы проверяют
визуальное/поведенческое соответствие «Пульту 2.0»: токены, HUD, LED,
cyan=актив/фокус, amber=фастлайн, состояния, мобильная ≤860px, доступность.

## Покрытие (самопроверка скриптом, не вручную)

- **CHK: 36/36** — каждый пункт чеклиста трассирован хотя бы в один кейс;
  внеплановых CHK-ссылок нет. Раскладка 1:1 (TC-redesign-NNN ↔ CHK-NNN).
- **Requirement: 25/25** — каждая Requirement дельт упомянута в трассировке
  кейсов (программная сверка — пропуск 0).
- **Scenario: 105/105** — каждый сценарий дельт покрыт кейсом своей CHK-группы
  (в кейсах используются полные имена сценариев; сокращения чеклиста
  «Комбинация условий», «Открытие страницы» покрыты полными формами;
  совпадения «Пульт»/«Погода» в колонке «Источник» — вложенные кавычки
  названия Requirement, не сценарии). **Непокрытых сценариев нет.**
- **Приоритеты:** Must 35 кейсов (CHK-001…031, 033…036), Should 1
  (TC-redesign-032 ↔ CHK-032, единственный Should чеклиста). Приоритет кейса =
  приоритету CHK во всех 36 (сверено скриптом).

## Дублирование с автотестами

Кейсы, чей сценарий уже закрыт существующими green-тестами (колонка
«Автотест/прогон» чеклиста: CHK-005, 007, 014, 015, 018, 020–021, 024–025,
027–028, 030–033, 035), оставлены как приемочные: шаг проверки автотеста
включен в кейс, но добавляет визуальную/приемочную сторону (токены, AA,
computed styles), которой в нецветовых ассертах нет. Автонабор не дублируется
дословно.
