# TC-redesign-029: Карточка профиля и кроп-виджет на токенах «Пульта»

## Трассировка
- **CHK:** CHK-029
- **Тип:** виз./гран. | **Приоритет:** Must (по CHK-029)
- **FR/Требование:** settings MODIFIED — «Страница настроек пользователя» (визуальная часть, волна 2.4)
- **Scenario:** «Карточка профиля на токенах «Пульта»», «Кроп-виджет работает на dark»

## Предусловия
- Поднят стенд; вход owner; тестовое изображение для аватара; эталон tokens-console.html.
- Playwright + `page.evaluate`.

## Шаги
1. Открыть настройки пользователя. Проверить computed styles карточки: поверхность = `--color-bg-surface` (bg2, `--p-bg-200`), панельные границы `--p-border` + HUD-приемы; акценты из токенов; поля bg2, `Tab`-фокус — cyan-ринг; AA соблюден (по REPORT CHK-001).
2. Проверить кнопки: первичные (сохранить/загрузить) — янтарные; сообщения об успехе/ошибке — статусные токены teal/coral (выполнить успешное сохранение и, для ошибки, невалидный ввод).
3. Загрузить новый аватар → открывается кроп-виджет: подложка `--p-bg-000`, рамки `--p-border`; область выделения и ручки различимы на темной подложке (computed цвета ручек ≠ фон, контраст достаточен); hit-targets ручек ≥ 44px на тач-вьюпорте.
4. Полный цикл кропа на dark: перемещение области, зум, подтверждение — аватар сохраняется и отображается (в т.ч. в блоке профиля сайдбара после обновления).
5. Контроль: прогон `test_r5_crop_ui` — green без правок селекторов; сверка вида с волной 2.4 smoke.

## Ожидаемый результат
- Карточка профиля — на общих dark-токенах (bg2-поверхность, cyan-фокус, teal/coral-статусы).
- Кроп-виджет полнофункционален на dark (маска/перемещение/зум/сохранение), ручки различимы, тесты кропа green.
