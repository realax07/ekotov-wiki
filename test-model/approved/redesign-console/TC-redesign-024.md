# TC-redesign-024: Вкладка поиска — выдача, пустой результат, темная тема

## Трассировка
- **CHK:** CHK-024
- **Тип:** поз./виз. | **Приоритет:** Must (по CHK-024)
- **FR/Требование:** search MODIFIED — «Вкладка поиска старых задач» (FR-35/FR-45, ОВ-24)
- **Scenario:** «Переход на вкладку поиска через сайдбар», «Выдача поиска отображает assigned и creator», «Пустой результат оформлен», «Результаты поиска на темной теме»

## Предусловия
- Поднят стенд; вход owner; seed: задачи с исполнителем и без, архивная задача для пустого результата поиска.
- Playwright + `page.evaluate`.

## Шаги
1. С `/board` клик по «Поиск» в сайдбаре: открывается вкладка поиска старых задач.
2. Выполнить поиск без условий: каждая строка/карточка выдачи показывает creator и assigned; задачи без исполнителя — курсивная строка «Unassigned» (FR-45, ОВ-24).
3. Визуальная проверка выдачи: карточки результатов на `--p-bg-200`, hover — ступень bg3; даты/счетчики mono; совпадения подсвечены янтарной инверсией (фон `--p-amber-900`, текст `--p-amber-400`, AA).
4. Открыть задачу из поиска: окно просмотра — тот же модальный стиль «Пульта», что и с доски; сверить computed styles окна из поиска и с доски (совпадают — преемственность BUG-014).
5. Выполнить поиск с заведомо пустым результатом: состояние «ничего не найдено» оформлено на токенах, читаемо (AA), без «голого» экрана.

## Ожидаемый результат
- Переход и состав выдачи (creator/assigned, Unassigned курсивом) — как прежде.
- Результаты и пустой state — на dark-токенах, подсветка янтарной инверсией AA; окно задачи из поиска визуально идентично окну с доски.
