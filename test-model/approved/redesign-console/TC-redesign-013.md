# TC-redesign-013: Техноязык «Пульт» — HUD, LED, микро-лейблы, mono-данные, сетка

## Трассировка
- **CHK:** CHK-013
- **Тип:** виз. | **Приоритет:** Must (по CHK-013)
- **FR/Требование:** design-tokens ADDED — «Техноязык «Пульт» — HUD, LED, микро-лейблы, сетка» (FR-130)
- **Scenario:** «Панель с HUD-уголками», «LED отражает состояние», «Данные — моноширинно»

## Предусловия
- Поднят стенд; вход owner; на доске — 3 колонки с задачами и фастлайн; login и pagehead доступны.
- Эталоны: board-console.html, tokens-console.html. Playwright + `page.evaluate`.

## Шаги
1. Открыть `/board`. Проверить HUD-уголки (8 отрезков по углам через `::after`) на панелях: колонки доски, фастлайн (углы янтарные `--p-amber-400`, остальные `--p-border-2`), pagehead; затем на login (TC-redesign-006) и панелях других разделов, где мокап задает прием.
2. Проверить LED-точки со свечением в местах, заданных мокапом: бренд сайдбара (teal), заголовки колонок доски, readout pagehead, метка фастлайна (amber, blink 2s step-end); соответствие состояниям (см. TC-redesign-008 шаг 2).
3. Проверить шрифты данных: счетчики колонок, даты карточек, T-отсчет фастлайна, readout-строка — `font-family` = `--font-family-data` (mono).
4. Проверить микро-лейблы: `text-transform: uppercase` + `letter-spacing` = `--tracking-caps`/`--tracking-micro` (0.14em для микро-лейблов данных).
5. Проверить фон страниц: микро-сетка `--texture-grid` (ячейка 32px) присутствует в computed `background-image` каркаса.

## Ожидаемый результат
- HUD-уголки отрисованы на всех панелях по мокапу (у фастлайна — янтарные).
- LED отражают состояние (нейтраль/amber blink/teal) и стоят во всех заданных местах.
- Все данные — mono; микро-лейблы — капс с трекингом; фон — микро-сетка 32px.
