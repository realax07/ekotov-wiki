# TC-redesign-030: Экран «Видео» в стиле «Пульт» + функциональность (FR-126)

## Трассировка
- **CHK:** CHK-030
- **Тип:** виз./поз. | **Приоритет:** Must (по CHK-030)
- **FR/Требование:** video-ui ADDED — «Экран «Видео» в стиле «Пульт»» (FR-126, волна 2.5)
- **Scenario:** «Список видео в визуале «Пульта»», «Функциональность видео не деградировала»

## Предусловия
- Поднят стенд; вход owner; в видео-разделе записи в разных статусах обработки (готово / в обработке / ошибка).
- Playwright + `page.evaluate`.

## Шаги
1. Открыть экран «Видео». Проверить карточки/список: панели `--p-bg-200` с границей `--p-border`, hover-ступень bg3; продолжительность/даты/размеры — mono (`--font-family-data`).
2. Статусы обработки — LED-точками: teal «готово», янтарь blink «в обработке», coral «ошибка» (соответствие состоянию записи).
3. Pagehead: h1 + терминальный readout (mono); первичные действия (загрузить и т.п.) — янтарные кнопки.
4. Открыть просмотр видео: темная поверхность с модальной тенью; плеер управляется как прежде.
5. Функциональный блок: загрузка нового видео, конвертация (статус меняется), переименование, комментарии — работают как прежде; DOM-хуки экрана сохранены (ОГР-28).
6. Контроль: прогон видео-сьюта (test_video_ui, test_video_convert_ui, test_video_rename_ui, test_video_social_ui — нецветовые ассерты) — green.

## Ожидаемый результат
- Экран — на снимке токенов «Пульта» (панели, mono-данные, LED-статусы, pagehead-readout, янтарные действия).
- Функциональность видео без деградации, существующие тесты green без правок.
