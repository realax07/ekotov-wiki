# TC-redesign-015: Фастлайн — поведение не изменилось, мобильная раскладка ≤860px

## Трассировка
- **CHK:** CHK-015
- **Тип:** поз./НФТ | **Приоритет:** Must (по CHK-015)
- **FR/Требование:** fastline MODIFIED — «Выделенная линия fast line» (поведенческая часть + ≤860px)
- **Scenario:** «Поведение fast line не изменилось», «Фастлайн на мобильной раскладке»

## Предусловия
- Поднят стенд; вход owner; fast-задача назначена; мобильный профиль Playwright (viewport ≤ 860px, тач).
- Доступ к нецветовым fastline-сьютам (test_board_fastline, dnd-сьют).

## Шаги
1. Поведенческий блок (десктоп-вьюпорт): проверить действующий контракт — единственность fast-задачи в активных статусах (вторая не назначается, 409-семантика/блокировка приоритета), назначение при создании/редактировании, ручной перенос, комментарий; DOM-хуки зоны фастлайна сохранены. Подтверждение: прогон test_board_fastline / test_fastline_ui (нестандартные, нецветовые) — green.
2. Переключиться в мобильный вьюпорт (≤ 860px), открыть `/board` с fast-задачей.
3. Проверить раскладку панели: складывается в столбец (лейбл → задача → отсчет под задачей); янтарная сигнализация (граница/подложка/glow) сохранена.
4. Через `page.evaluate` измерить высоты интерактивных элементов зоны: hit-targets ≥ 44px.
5. Тап по задаче/действию фастлайна: реакция с первого тапа.

## Ожидаемый результат
- Контракт fast line (единственность, 409, перенос, комментарий, приоритетный порядок) без изменений; тесты green без правок.
- На ≤ 860px панель в столбец, сигнал сохранен, тач-таргеты ≥ 44px, кликабельность с первого тапа.
