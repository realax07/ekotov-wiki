# TC-redesign-003: prefers-reduced-motion отключает анимации «Пульта»

## Трассировка
- **CHK:** CHK-003
- **Тип:** НФТ | **Приоритет:** Must (по CHK-003)
- **FR/Требование:** accessibility ADDED — «prefers-reduced-motion» (NFR-43)
- **Scenario:** «Сокращенное движение отключает анимации» (доска); смежный сценарий board «Уменьшение движения отключает анимации всплывашек» (CHK-007) закрывается этим же прогоном

## Предусловия
- Поднят стенд; вход owner; на доске есть fast-задача, колонка «В работе» (LED blink), карточки с всплывашками.
- Playwright (Python): `page.emulate_media(reduced_motion="reduce")`.

## Шаги
1. Открыть контекст Playwright с `reduced_motion="reduce"`, зайти на `/board` с fast-задачей.
2. Через `page.evaluate` проверить computed `animation`/`transition` на: LED «в работе» (заголовок колонки), метке фастлайна, треке отсчета, карточках (hover-переходы), всплывашке (навести курсор на карточку и на блок профиля).
3. Визуально/по DOM убедиться: LED «в работе» и фастлайн остаются различимы статично — янтарный цвет + свечение без мигания; содержание всплывашек не изменилось и появляется без анимации.
4. Повторить шаг 2 в контексте БЕЗ reduce (контроль): анимации (blink LED, трек) присутствуют — фикс не «выключил» анимации всем.

## Ожидаемый результат
- При reduce: ни один элемент не анимируется (`animation: none`, `transition: none` — паттерн мокапа), включая blink LED, трек фастлайна, всплывашки, hover-переходы, модальные анимации, v-in.
- Информативность не потеряна: LED «в работе» и fast-карточка различимы цветом/свечением без движения.
- Без reduce анимации работают как прежде (отрицательный контроль).
