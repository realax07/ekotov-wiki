- **Scenario:** «Rich-контент не ломается санитизацией и редактором»

## Предусловия
- Поднят стенд; вход owner; тестовая статья со всеми rich-блоками (h2/h3, спойлер, код-блок, таблица).

## Шаги
1. Открыть статью с rich-блоками в редакторе, внести правку в каждый тип блока (текст h2/h3, содержимое спойлера, строку кода, ячейку таблицы), сохранить.
2. Переоткрыть статью: все блоки пережили save/load (кругосветка sanitize → render): структура и содержимое на месте, классы (`details.spoiler` и др.) сохранены.
3. Негативная проверка санитизации: попытка вставить запрещенный контент (script/онклик-атрибут) — whitelist не расширился (запрещенное вырезано), легитимные блоки не пострадали.
4. Убедиться, что редизайн не влиял на whitelist: сравнение sanitizer-конфига/поведения с до-редизайн прогоном.
5. Контроль: прогон `tests/api/test_wiki_rich*.py` и web rich-сьют (keep, функциональные ассерты) — green.

## Ожидаемый результат
- Создание/просмотр/редактирование всех rich-блоков работают как прежде — редизайн меняет только CSS отображения, не модель контента и не whitelist санитайзера.
- Существующие rich-тесты green без правок.
