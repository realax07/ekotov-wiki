# TC-redesign-031: Экран «Погода» — readout панели, ошибка/пустые данные (FR-127)

## Трассировка
- **CHK:** CHK-031
- **Тип:** виз./нег. | **Приоритет:** Must (по CHK-031)
- **FR/Требование:** weather-ui ADDED — «Экран «Погода» в стиле «Пульт»» (FR-127, волна 2.5)
- **Scenario:** «Текущая погода как readout панели», «Ошибка/пустые данные в стиле «Пульта»»

## Предусловия
- Поднят стенд; вход owner; сервис погоды: (а) возвращает данные, (б) недоступен/пустые данные (стенд-мок или отключение бэкенда погоды).
- Эталон: board-console.html (панели/readout). Playwright + `page.evaluate`.

## Шаги
1. Открыть экран «Погода» при работающем сервисе. Проверить: карточка текущей погоды — панель `--p-bg-100` с HUD-уголками; температура — крупное mono-значение (`--font-size-display`).
2. Параметры (ветер, влажность, давление) — микро-лейблами капсом с mono-значениями; экстремальные значения (если есть) подсвечены статусными цветами, не декоративно.
3. Pagehead: readout с точкой наблюдения, временем обновления, teal-LED.
4. Прогноз — ряд/таблица на токенах (капс-заголовки, mono-числа — паттерн wiki-таблиц).
5. Перевести сервис погоды в недоступное состояние (или пустые данные), обновить страницу: существующее сообщение о недоступности отображается на токенах (`--status-error`, AA), верстка не «ломается» (нет переполнений/наложения).
6. Сверить вид шагов 1–4 с мокапами волны 2.5.

## Ожидаемый результат
- Текущая погода — readout-панель миссия-контроля (HUD, mono-дисплей, капс-параметры, teal-LED в pagehead).
- Ошибка/пустые данные — coral на токенах, AA, без поломанной верстки.
