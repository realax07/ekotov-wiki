# TC-GAL-112 — Комментарии: добавление/просмотр, пустой 422, удаление своего 200, чужого 403, несуществующего 404

- **Change:** add-gallery-service
- **Источник:** gallery (ADDED): «Комментарии к изображениям» (FR-82) — Scenario «Добавление и просмотр комментария», «Негативный: пустой + Удаление своего + Негативный: чужой комментарий удалить нельзя»; CHK-GAL-19, CHK-GAL-20
- **Тип:** ФТ, API, поз. + нег. | **Приоритет:** Must
- **Маркер:** автоматизирован — `services/images/tests/test_images_service.py::test_comment_add_and_visible_to_both`, `::test_comment_empty_422`, `::test_comment_delete_own`, `::test_comment_delete_foreign_403`, `::test_comment_delete_missing_404` (юниты 1.2) + ручной/стендовый — REPORT-2.1 (api-сьют стенда)
- **Предусловия:** стенд поднят; сессии двух пользователей (owner и PE); изображение без комментариев
- **Шаги:**
  1. owner: `POST /api/images/<id>/comments` с непустым текстом — фиксировать код и тело (id комментария, текст, автор, время).
  2. PE: `GET /api/images/<id>` — комментарий виден в списке с текстом, автором и временем.
  3. owner: `POST .../comments` с текстом из одних пробелов — фиксировать код.
  4. owner: `DELETE /api/images/<id>/comments/<свой cid>` — фиксировать код; повторный GET — комментарий исчез.
  5. PE: `DELETE /api/images/<id>/comments/<чужой cid>` (комментарий owner) — фиксировать код; GET — комментарий ОСТАЛСЯ.
  6. owner: `DELETE .../comments/<несуществующий cid>` — фиксировать код.
- **Ожидаемый результат:** шаг 1–2 — комментарий с непустым текстом создан, виден ОБОИМ пользователям с текстом, автором и временем; шаг 3 — пустой/из одних пробелов текст → 422, комментарий не создан; шаг 4 — удаление своего → 200/204, комментарий исчез; шаг 5 — удаление ЧУЖОГО → 403, комментарий остался; шаг 6 — несуществующий cid → 404.
