# TC-GAL-121 — Инфра/НФТ: RAM images ≤128m (docker stats), суммарные лимиты стека и резерв хоста

- **Change:** add-gallery-service
- **Источник:** gallery (ADDED): «Ресурсы сервиса изображений ограничены» (NFR-20); deploy (MODIFIED): «Лимиты памяти контейнеров» — + images 128m, суммарные лимиты 1.54 GB, резерв хоста ≥ 2 GB (impact: revalidate числа лимитов); tasks 2.1(г); CHK-GAL-28
- **Тип:** НФТ, инфраструктура/среда | **Приоритет:** Must
- **Маркер:** ручной/стендовый — REPORT-2.1 (инфра-чеки docker stats) — **требует docker-доступа Заказчика** (замер на стенде выполняется при участии Заказчика/оператора; без доступа фиксируется «замер отложен» и эскалация в REPORT-2.1)
- **Предусловия:** доступ к хосту стенда (docker CLI); контейнеры подняты по compose 1.3 (mem_limit images 128m); в галерее загружены изображения с генерацией превью (нагрузка на Pillow)
- **Шаги:**
  1. `docker compose config` — зафиксировать mem_limit images = 128m; суммарные лимиты по compose-файлу: 1280 MB (app 512 + frontend 64 + search 512 + images 128 + backup 64) — netdata 256m в compose-файле ОТСУТСТВУЕТ (это прод-матрица design §5, контур add-netdata-monitoring; расхождение с 1.54 GB — не дефект compose, источник указать в REPORT-2.1).
  2. Нагрузить images: загрузить несколько изображений (включая крупные ~10 МБ), генерация превью.
  3. `docker stats --no-stream` — зафиксировать фактическое потребление RAM images (MEM USAGE) после нагрузки; повторить замер через 5 минут (стабильность).
  4. Зафиксировать свободную память хоста (`free -m`) — резерв ≥ 2 GB.
- **Ожидаемый результат:** лимит images 128m применен в compose; фактическое потребление RAM images после загрузок и генерации превью — в пределах 128m (допуск —.mem_limit ceil); суммарные compose-лимиты 1280 MB (app 512 + frontend 64 + search 512 + images 128 + backup 64), 1.54 GB — только с netdata 256m прод-матрицы design §5 (вне данного compose); свободная память хоста ≥ 2 GB. Стабильное превышение 128m — БЛОКЕР до решения Заказчика (эскалация до прод-выкатки, NFR-20), фиксируется в REPORT-2.1.
