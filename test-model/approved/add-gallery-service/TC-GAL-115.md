# TC-GAL-115 — e2e: сетка карточек и фильтры на /gallery (owner и PE — паритет ОВ-4)

- **Change:** add-gallery-service
- **Источник:** gallery (ADDED): «Доступ к галерее общий для всех пользователей» (FR-84) — Scenario «PE видит и загружает как owner»; «Категории и теги изображений» (FR-80) — web-фильтры; tasks 2.1(в); CHK-GAL-15, CHK-GAL-21
- **Тип:** ФТ, web/e2e, поз. | **Приоритет:** Must
- **Маркер:** ручной/стендовый — REPORT-2.1 (web/e2e, оба пользователя); юнит-базис фильтров — TC-gal-104/105 + `::test_list_filters_combine`
- **Предусловия:** стенд поднят; в галерее подготовлены ≥3 изображения с разными категориями/тегами (TC-GAL-110); сессии owner и PE
- **Шаги:**
  1. Открыть `/gallery` под owner: зафиксировать сетку карточек — каждая карточка содержит превью, название, категорию, теги (пилюли, 1.6), счетчики лайков/комментариев.
  2. Применить фильтр по категории, затем по тегу, затем комбинацию — сетка перерисовывается в соответствии с API-логикой (TC-GAL-110); сброс фильтров возвращает полный список.
  3. Открыть `/gallery` под PE: зафиксировать идентичность сетки/фильтров/данных (паритет — PE видит всю галерею).
  4. Проверить счетчики на карточках соответствуют API-данным (лайки/комментарии из TC-GAL-111/112).
- **Ожидаемый результат:** сетка карточек (превью, название, категория, теги-пилюли, счетчики) отрисовывается из `GET /api/images`; фильтры категория/тег и комбинация работают в UI идентично API-контракту; владелец и PE видят одинаковую полную галерею и одинаковые возможности (паритет ОВ-4, без разделения прав).
