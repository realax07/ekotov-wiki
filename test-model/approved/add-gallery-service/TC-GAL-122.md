# TC-GAL-122 — design_validator: фактический вид /gallery против утвержденных мокапов (токены V3, состояния, компоновка)

- **Change:** add-gallery-service
- **Источник:** navigation (ADDED): «Вид пункта по утвержденным мокапам» (FR-86) + design §0 п.4; tasks 2.1(д) (design_validator, вердикт approve/return); утвержденные Заказчиком мокапы 1.1: `design/gallery-grid.html` + `gallery-lightbox.html` + `gallery-upload.html`; CHK-GAL-27
- **Тип:** НФТ, дизайн/сред., сводный | **Приоритет:** Must
- **Маркер:** ручной/стендовый — REPORT-2.1 (design_validator); известные отступления к проверке с учетом вердикта: О-1 (мокап лайтбокса «загружено сегодня, ekotov» vs факт без логина) и упрощенный combobox тегов (замечание 4 review-002-1.5) — расхождения фиксируются, вердикт по совокупности
- **Предусловия:** стенд поднят, `/gallery` работоспособна (TC-GAL-114/115); утвержденные мокапы 1.1 доступны; браузер с инструментами инспекции (Computed Styles)
- **Шаги:**
  1. Открыть `/gallery`, построчно сверить с `design/gallery-grid.html`: компоновка (фильтры над сеткой, кнопка/форма загрузки), карточки (название, категория, теги-пилюли, счетчики), отступы по 8px-сетке.
  2. Токены V3 «Бумага» (не хардкод): инспекция Computed Styles карточек/кнопок/фильтров — цвета paper/ink/clay, Georgia display, радиусы 6/10px, focus-ring берутся из `app.css :root`-переменных (значения не зашиты в gallery.css/js литералами).
  3. Сверить с `design/gallery-lightbox.html`: full-screen модалка, панель лайк/дизлайк (счетчики + «мой голос»), подсказка клавиш, кнопка скачать, комментарии, закрытие.
  4. Сверить с `design/gallery-upload.html`: форма (выбор файла, категория, теги), состояния ошибок (лимит 10 МБ, тип файла) — на фактических 422 (TC-GAL-118).
  5. Состояния: hover/focus-visible на карточках и кнопках (фокус с клавиатуры виден, контраст AA), подсветка «мой голос», ошибки 422.
  6. Пункт сайдбара «Галерея»: вид по мокапу 1.1(д) — 4-й, иконка inline-SVG.
- **Ожидаемый результат:** фактический вид сетки, лайтбокса, формы загрузки и пункта сайдбара соответствует утвержденным мокапам 1.1 по компоновке, токенам V3 (подтверждено: значения из CSS-переменных, не хардкод) и состояниям (hover/focus-visible, мой голос, ошибки 422). Задокументированные отступления (О-1, combobox тегов) сопоставлены с вердиктом СА. Итог — вердикт **approve/return** в `test-model/reviews/add-gallery-service/review-NNN-design.md`; return → баг-репорт в `test-model/bugs/`.
