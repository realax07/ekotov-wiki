# TC-form-010 — Подсветка невалидной категории при отклонении по FR-21

- **CHK:** CHK-121
- **Change:** add-r2-categories-settings
- **Источник:** tasks: Визуал формы (FR-29, FR-21) / Scenario: Подсветка невалидной категории
- **Тип:** негативный | **Приоритет:** Should
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); Playwright (Python): `page`, `expect`; выполнен вход owner (логин `owner`, пароль `QaOwner_Pass_1!` — seed, как TC-UI-002 чеклиста e2e-critical-path); seed справочника выполнен (CHK-139 / TC-env-001).
- **Сценарий:**
  - **GIVEN** пользователь заполняет форму задачи с категорией, которая была удалена из справочника (значение отклонено серверной валидацией FR-21)
  - **WHEN** пользователь пытается сохранить задачу и сохранение отклоняется
  - **THEN** поле категории визуально подсвечено как невалидное с сообщением об ошибке; задача не сохранена
- **Шаги:**
  1. Подготовка: `POST /api/categories` name=`QAT-Врем-подсветка` → 201, зафиксировать `id`; открыть форму задачи, выбрать в select категории `QAT-Врем-подсветка`, название `QAT-подсветка-422`.
  2. Удалить категорию через API в этот момент: `DELETE /api/categories/{id}` → 200 (справочник изменился ПОСЛЕ выбора в открытой форме — достижимый путь «значение отклонено сервером»).
  3. Нажать «Создать» → форма получает 422 с `details.category`.
  4. Зафиксировать состояние поля категории: класс/атрибут невалидности (`evaluate("el => el.className + '|' + el.getAttribute('aria-invalid')")`) и наличие сообщения об ошибке (`#task-form-error` или элемент рядом с полем — фактический локатор зафиксировать).
  5. `GET "/api/search?archived=false"` → 0 задач `QAT-подсветка-422`.
- **Ожидаемый результат:** шаги 3–4 — сохранение отклонено (422 `details.category="not in categories"`), поле категории визуально подсвечено (aria-invalid/класс — фактический механизм в протоколе) с сообщением об ошибке; шаг 5 — задача не создана. Подсветка driven by `details` 422-ответа (sdd §4).
- **Тестовые данные:** категория `QAT-Врем-подсветка` (создается и удаляется в кейсе); title=`QAT-подсветка-422` (не создается).
