# TC-nav-007 — Переход в настройки через сайдбар

- **CHK:** CHK-110
- **Change:** add-r2-categories-settings
- **Источник:** navigation: Раздел «Настройки» в сайдбаре (FR-23) / Scenario: Переход в настройки через сайдбар
- **Тип:** позитивный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); Playwright (Python): `page`, `expect`; выполнен вход owner (логин `owner`, пароль `QaOwner_Pass_1!` — seed, как TC-UI-002 чеклиста e2e-critical-path); seed справочника выполнен (CHK-139 / TC-env-001).
- **Сценарий:**
  - **GIVEN** пользователь авторизован и видит сайдбар
  - **WHEN** пользователь выбирает раздел «Настройки»
  - **THEN** открывается страница настроек
- **Шаги:**
  1. Открыть `{BASE_URL}/board`.
  2. `page.get_by_role("link", name="Настройки").click()`.
  3. Зафиксировать `page.url`; дождаться `page.get_by_role("heading", name="Настройки")`.
  4. Проверить содержимое: список категорий seed (`Дом`, `Работа`, `Личное`) виден.
- **Ожидаемый результат:** шаг 3 — URL = `{BASE_URL}/settings`, заголовок «Настройки» виден; шаг 4 — блок управления справочником отображается — переход ведет именно на страницу настроек (не на заглушку).
- **Тестовые данные:** ссылка «Настройки» сайдбара; целевой URL `{BASE_URL}/settings`.
