# TC-cat-003 — Категория вне справочника недоступна для выбора ни в одном месте ввода

- **CHK:** CHK-84
- **Change:** add-r2-categories-settings
- **Источник:** categories: Справочник категорий (FR-19) / Scenario: Негативный: категория вне справочника не доступна для выбора
- **Тип:** негативный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); Playwright (Python): `page`, `expect`; выполнен вход owner (логин `owner`, пароль `QaOwner_Pass_1!` — seed, как TC-UI-002 чеклиста e2e-critical-path); seed справочника выполнен (CHK-139 / TC-env-001: `Дом`, `Работа`, `Личное` в справочнике до прогона).
- **Сценарий:**
  - **GIVEN** пользователь авторизован; значение `QAT-old-project` в справочнике отсутствует
  - **WHEN** пользователь ищет `QAT-old-project` в местах ввода категории (форма создания, форма редактирования, фильтр-конструктор)
  - **THEN** значение нигде не может быть выбрано/сохранено — выбор ограничен списком справочника
- **Шаги:**
  1. Контроль: `GET {BASE_URL}/api/categories` — `QAT-old-project` в списке нет.
  2. Форма создания: открыть форму, прочитать опции поля «Категория» → `QAT-old-project` среди опций нет.
  3. Форма редактирования: открыть карточку любой задачи → «Редактировать»; прочитать опции поля «Категория» → `QAT-old-project` нет.
  4. Фильтр-конструктор: `/search`, прочитать опции поля «Категория» → `QAT-old-project` нет.
- **Ожидаемый результат:** во всех трех местах значение `QAT-old-project` отсутствует в опциях select (шаги 2–4 — по 0 совпадений); выбрать/сохранить его через UI невозможно (негативный класс «чужое значение», sdd §4: select не позволяет значение вне списка).
- **Тестовые данные:** отсутствующее значение `QAT-old-project`.
