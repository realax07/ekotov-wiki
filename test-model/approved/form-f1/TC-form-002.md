# TC-form-002: Quick-чипы срока пишут дату в нативный date-инпут

- **Change:** form-f1
- **Источник:** tasks ADDED — «Quick-чипы срока (F1)» / Scenario: «Чип пишет дату в инпут», «Ручной ввод — источник истины»
- **Тип:** функциональный UX | **Приоритет:** Must
- **Среда/предусловия:** автостенд conftest; Playwright (chromium); PO-локатор `tests/web/pages/task_form.py::TaskForm.due_chip`
- **Шаги:**
  1. Открыть форму создания, поле срока пусто; чипы `.qchip[data-due-quick=today|tomorrow|week]` видны рядом с `#task-due-date` (ручная сверка, скриншоты /tmp/form-shots/mobile-create-390.png, desktop-create-light.png).
  2. Клик «Завтра» → `#task-due-date` = завтрашняя дата ISO `YYYY-MM-DD`, чип `.is-checked` + `aria-pressed="true"`.
  3. Ввести в инпут произвольную дату вручную → ни один чип не подсвечен; ввести дату «сегодня» → подсвечен чип «Сегодня» (перерисовка на input/change).
  4. Сохранить задачу → due в payload соответствует инпуту (коллект не изменился).
- **Ожидаемый результат:** дата-инпут — источник истины; чипы только пишут дату и отражают совпадение; формат payload прежний. Покрытие: ручная браузерная сверка (impact Д1) + PO-локатор готов для попутного автотеста.
- **Тестовые данные:** эталон `design-forge/extra/form-v1/create.html` (.chips-row).
