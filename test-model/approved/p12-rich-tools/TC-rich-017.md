# TC-rich-017 — Состояние H-кнопок отражает блок под курсором

- **Change:** p12-rich-tools
- **Источник:** p12-rich-tools: «H-заголовки как переключатель (FR-121)» / Scenario: Состояние кнопок отражает позицию курсора
- **Тип:** позитивный | **Приоритет:** Should
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); тестовая страница wiki, созданная через `POST {BASE_URL}/api/wiki/pages`; Playwright (Python): `page`, `expect`, `api_request_context`; страница открыта в режиме редактирования (WYSIWYG-редактор)
- **Шаги:**
  1. Создать три подряд блока: H1, H2, обычный абзац (каждый с текстом).
  2. Кликнуть в блок H1, осмотреть aria-pressed.
  3. Повторить для H2 и для обычного абзаца.
- **Ожидаемый результат:** при курсоре в H1 нажата ровно кнопка H1; в H2 — ровно H2; в обычном абзаце не нажата ни одна (aria-pressed=false у всех трех); синхронизация следует за движением курсора без клика по кнопкам.
- **Тестовые данные:** aria-pressed кнопок H1/H2/H3
