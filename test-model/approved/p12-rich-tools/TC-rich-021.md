# TC-rich-021 — Tab — следующая ячейка, Enter — перенос внутри ячейки (дискриминатор «один<br>два»)

- **Change:** p12-rich-tools
- **Источник:** p12-rich-tools: «Редактирование таблиц — строки и столбцы (FR-122)» / Scenario: Навигация и ввод в ячейках
- **Тип:** граничный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); тестовая страница wiki, созданная через `POST {BASE_URL}/api/wiki/pages`; Playwright (Python): `page`, `expect`, `api_request_context`; страница открыта в режиме редактирования (WYSIWYG-редактор)
- **Шаги:**
  1. Курсор в первую ячейку таблицы 2×2, ввести «один», нажать Enter, ввести «два».
  2. Осмотреть DOM ячейки после Enter.
  3. Нажать Tab, ввести текст во вторую ячейку.
  4. Сохранить, осмотреть `GET`-контент, открыть статью.
- **Ожидаемый результат:** шаг 2 — Enter дал перенос ВНУТРИ ячейки (insertLineBreak), новой строки/ячейки таблицы не создано; шаг 3 — Tab перевел курсор в следующую ячейку; шаг 4 — в сохраненном контенте ячейка содержит ровно `один<br>два` (один `<br>` — дискриминатор против дублирования/потери переноса); в статье перенос отображается; количество tr/td не изменилось.
- **Тестовые данные:** текст «один<br>два» — чувствительный к способу вставки переноса
