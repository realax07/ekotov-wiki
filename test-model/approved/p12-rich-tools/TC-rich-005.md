# TC-rich-005 — Свернутый спойлер сохраняет содержимое, состояние не хранится

- **Change:** p12-rich-tools
- **Источник:** p12-rich-tools: «Спойлер (FR-118)» / Scenario: Свернутый спойлер сохраняет содержимое
- **Тип:** граничный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); тестовая страница wiki, созданная через `POST {BASE_URL}/api/wiki/pages`; Playwright (Python): `page`, `expect`, `api_request_context`; страница открыта в режиме редактирования (WYSIWYG-редактор)
- **Шаги:**
  1. Вставить спойлер с текстом «Секретный текст», свернуть его в редакторе.
  2. Сохранить страницу, переоткрыть её в статье и в редакторе.
  3. Осмотреть сохраненный контент через `GET`.
- **Ожидаемый результат:** шаг 2 — содержимое «Секретный текст» присутствует и в статье, и в редакторе; спойлер при открытии развернут (состояние отображения в контенте не хранится — в HTML нет атрибутов свернутости); шаг 3 — текст в `data-block-part="body"` цел.
- **Тестовые данные:** текст «Секретный текст»
