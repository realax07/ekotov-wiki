# TC-rich-027 — Активация 20 блоков с крупным листингом ≤150 мс без блокировки UI

- **Change:** p12-rich-tools
- **Источник:** p12-rich-tools: «Рендер блоков без внешних зависимостей (NFR-40)» / Scenario: Активация не блокирует отображение статьи
- **Тип:** граничный | **Приоритет:** Should
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); тестовая страница wiki, созданная через `POST {BASE_URL}/api/wiki/pages`; Playwright (Python): `page`, `expect`, `api_request_context`
- **Шаги:**
  1. Через `PUT` записать статью с 20 rich-блоками, среди них код-блок на 1000+ строк (сгенерированный python-листинг).
  2. Открыть статью; замерить время активации блоков (JS-метка вокруг инициализации, `performance.now`), зафиксировать момент отображения текста статьи.
  3. Во время подсветки крупного листинга прокрутить страницу.
  4. Повторить прогон 3 раза, взять максимум.
- **Ожидаемый результат:** текст статьи отображается ДО завершения подсветки крупного листинга; активация блоков ≤150 мс (максимум из 3 прогонов); прокрутка во время подсветки не «замораживается» (крупные листинги — вне основного потока, NFR-40).
- **Тестовые данные:** 20 блоков; листинг 1000+ строк; 3 прогона замера
