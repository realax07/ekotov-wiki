# TC-rich-035 — Разрешенные теги whitelist проходят без искажений

- **Change:** p12-rich-tools
- **Источник:** p12-rich-tools: wiki: «Санитизация HTML контента» / Scenario: Разрешенные теги проходят
- **Тип:** позитивный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); тестовая страница wiki, созданная через `POST {BASE_URL}/api/wiki/pages`; Playwright (Python): `page`, `expect`, `api_request_context`
- **Шаги:**
  1. Через `PUT` записать контент только из whitelist редактора: H1–H3, B/I/U, оба списка, цитата, код-блок, ссылки, таблица, изображение.
  2. Получить `GET`-контент.
  3. Сравнить разметку с отправленной (структура, атрибуты, текст).
- **Ожидаемый результат:** разметка сохранена без искажений: теги, вложенность и допустимые атрибуты совпадают с отправленными; текст без изменений (NFR-31).
- **Тестовые данные:** эталонный HTML из тегов whitelist
