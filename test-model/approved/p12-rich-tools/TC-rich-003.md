# TC-rich-003 — Спойлер в ячейке таблицы — компактный вариант

- **Change:** p12-rich-tools
- **Источник:** p12-rich-tools: «Спойлер (FR-118)» / Scenario: Спойлер внутри ячейки таблицы
- **Тип:** позитивный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); тестовая страница wiki, созданная через `POST {BASE_URL}/api/wiki/pages`; Playwright (Python): `page`, `expect`, `api_request_context`; страница открыта в режиме редактирования (WYSIWYG-редактор)
- **Шаги:**
  1. Вставить таблицу, курсор в ячейку [1,1].
  2. Нажать «Спойлер» тулбара, заполнить название и тело, сохранить, открыть статью.
  3. Свернуть/развернуть спойлер в ячейке.
  4. Осмотреть сохраненный контент через `GET`.
- **Ожидаемый результат:** шаг 2 — спойлер в ячейке в компактном варианте (без внешних отступов, уменьшенный шрифт названия — сверка с мокапом); шаг 3 — toggle работает, раскладка таблицы не сломана; шаг 4 — компактность в контенте НЕ хранится (класс компактного вида появляется только при активации по `closest('td,th')`) — в HTML нет compact-маркера.
- **Тестовые данные:** мокап tool-1; таблица 2×2 со спойлером в [1,1]
