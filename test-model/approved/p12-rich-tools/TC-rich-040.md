# TC-rich-040 — Rename-гейт спойлера: только в редакторе, гонка Escape/blur (фикс F-3)

- **Change:** p12-rich-tools
- **Источник:** p12-rich-tools: «Спойлер (FR-118)» (переименование инлайн — только редактор, ОВ) + design §3; ревью находка F-3 (rename спойлера только в редакторе, гонка Escape/blur) — дискриминатор фикса
- **Тип:** граничный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); тестовая страница wiki, созданная через `POST {BASE_URL}/api/wiki/pages`; Playwright (Python): `page`, `expect`, `api_request_context`; страница открыта в режиме редактирования (WYSIWYG-редактор)
- **Шаги:**
  1. В редакторе кликнуть по названию спойлера «Старое», ввести «Черновик», нажать Escape.
  2. Осмотреть название; снова открыть ввод, ввести «Финал», убрать фокус (blur).
  3. Быстро: открыть ввод и нажать Escape, сразу вызвав blur (гонка Escape→blur).
  4. Сохранить, осмотреть `GET`-контент; открыть статью и кликнуть по названию спойлера.
- **Ожидаемый результат:** шаг 1 — Escape отменяет правку: название осталось «Старое»; шаг 2 — blur коммитит: название «Финал» в редакторе и в контенте; шаг 3 — при гонке Escape+blur название не двоится и не теряется: ровно один input, итог детерминирован (значение до правки — «Финал»), в контенте один `data-title` без дублей; шаг 4 — в СТАТЬЕ название не редактируется (клик по названию работает как toggle, инлайн-input не открывается — rename только в редакторе).
- **Тестовые данные:** названия «Старое», «Черновик» (отмененный), «Финал»; быстрый Escape+blur
