# TC-rich-004 — Спойлер в спойлере — независимая работа, без потери контента

- **Change:** p12-rich-tools
- **Источник:** p12-rich-tools: «Спойлер (FR-118)» / Scenario: Спойлер в спойлере
- **Тип:** позитивный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); тестовая страница wiki, созданная через `POST {BASE_URL}/api/wiki/pages`; Playwright (Python): `page`, `expect`, `api_request_context`; страница открыта в режиме редактирования (WYSIWYG-редактор)
- **Шаги:**
  1. Вставить спойлер «Внешний», в его тело — второй спойлер «Внутренний», в тело каждого — уникальный текст.
  2. Сохранить, открыть статью.
  3. Свернуть внутренний спойлер, затем свернуть внешний.
  4. Развернуть внешний.
  5. Сверить контент через `GET`.
- **Ожидаемый результат:** оба спойлера работают независимо; сворачивание внешнего скрывает внутренний целиком; после разворачивания внешнего внутренний остался в своем состоянии (свернут); тексты обоих сохранены без потерь; в контенте — вложенный `div[data-block=spoiler]` внутри `data-block-part="body"` (урок rich-v1 «потеря контента при вложении» не воспроизводится).
- **Тестовые данные:** тексты уровней: «Текст внешний», «Текст внутренний»
