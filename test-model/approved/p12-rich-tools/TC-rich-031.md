# TC-rich-031 — Кнопки заголовков не залипают — снятие и замена без двойного состояния

- **Change:** p12-rich-tools
- **Источник:** p12-rich-tools: wiki: «WYSIWYG-редактор страниц» / Scenario: Кнопки заголовков не залипают
- **Тип:** негативный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); тестовая страница wiki, созданная через `POST {BASE_URL}/api/wiki/pages`; Playwright (Python): `page`, `expect`, `api_request_context`; страница открыта в режиме редактирования (WYSIWYG-редактор)
- **Шаги:**
  1. Оформить абзац как H1.
  2. Повторно нажать H1; осмотреть все H-кнопки.
  3. Нажать H2; затем H3.
  4. Попытаться получить состояние с двумя нажатыми H-кнопками (быстрые клики H1→H2 в разных абзацах).
- **Ожидаемый результат:** шаг 2 — формат снят (текст → абзац), все H1–H3 отжаты; шаг 3 — после H2 нажата только H2, после H3 — только H3; шаг 4 — одновременное нажатие двух уровней недостижимо: состояние кнопок строго следует за блоком курсора (регресс бага «отжимание H заголовков», PRODUCT_BACKLOG P12 п.4).
- **Тестовые данные:** aria-pressed кнопок; быстрые смены позиции курсора
