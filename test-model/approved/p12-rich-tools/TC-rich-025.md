# TC-rich-025 — Неизвестный блок деградирует без ошибок

- **Change:** p12-rich-tools
- **Источник:** p12-rich-tools: «Безопасность и деградация rich-блоков (NFR-39)» / Scenario: Неизвестный блок деградирует без потери контента
- **Тип:** негативный | **Приоритет:** Should
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); тестовая страница wiki, созданная через `POST {BASE_URL}/api/wiki/pages`; Playwright (Python): `page`, `expect`, `api_request_context`
- **Шаги:**
  1. Через `PUT` записать страницу с блоком `<div data-block="future-widget">Будущее содержимое</div>` рядом с рабочим спойлером.
  2. Открыть статью, осмотреть консоль.
  3. Проверить, что соседний спойлер активировался.
- **Ожидаемый результат:** содержимое «Будущее содержимое» показано как обычный контент; ошибок в консоли нет (неизвестный `data-block` пропускается, try/catch per-block); соседний спойлер работает — ошибка одного блока не роняет активацию остальных (NFR-39, design §4).
- **Тестовые данные:** `data-block="future-widget"`
