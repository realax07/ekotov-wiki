# TC-rich-030 — Тулбар содержит инструменты rich-контента, тулбар один

- **Change:** p12-rich-tools
- **Источник:** p12-rich-tools: wiki: «WYSIWYG-редактор страниц» / Scenario: Тулбар содержит инструменты rich-контента
- **Тип:** позитивный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); тестовая страница wiki, созданная через `POST {BASE_URL}/api/wiki/pages`; Playwright (Python): `page`, `expect`, `api_request_context`; страница открыта в режиме редактирования (WYSIWYG-редактор)
- **Шаги:**
  1. Открыть редактор, осмотреть тулбар.
  2. Кликнуть «Спойлер», «Блок кода», «Табуляция» — каждый раз с курсором в новой позиции.
  3. Вставить таблицу, осмотреть её контекстную панель.
  4. Осмотреть DOM на предмет плавающих панелей/вторых рядов тулбара.
- **Ожидаемый результат:** кнопки «Спойлер», «Блок кода», «Табуляция» и кнопка удаления таблицы доступны; каждая блоковая кнопка вставляет свой блок в позицию курсора с фокусом в зоне содержимого; тулбар ОДИН, контекстные контролы — inline-панели внутри блоков, новых рядов тулбара нет (урок rich-v1 «конфликт toolbar»).
- **Тестовые данные:** FR-118/119/120/122
