# TC-rich-010 — Переключение вкладок в статье

- **Change:** p12-rich-tools
- **Источник:** p12-rich-tools: «Табуляция (FR-120)» / Scenario: Переключение вкладок в статье
- **Тип:** позитивный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); тестовая страница wiki, созданная через `POST {BASE_URL}/api/wiki/pages`; Playwright (Python): `page`, `expect`, `api_request_context`
- **Шаги:**
  1. Открыть статью с таб-виджетом из трех заполненных вкладок («Обзор», «Детали», «Пример»).
  2. Кликнуть по второй вкладке.
  3. Кликнуть по третьей, затем по первой.
- **Ожидаемый результат:** шаг 2 — активна вторая вкладка: терракотовая черта переместилась, в зоне содержимого — содержимое именно второй вкладки (мокап tool-3-tabs-view.png); шаг 3 — переключение на каждую вкладку показывает её собственный контент; активная вкладка в контент не сохраняется.
- **Тестовые данные:** мокап tool-3-tabs-view.png; уникальный маркер в каждой вкладке
