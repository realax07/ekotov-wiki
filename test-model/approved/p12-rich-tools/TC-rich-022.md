# TC-rich-022 — Скрипт и onclick внутри блока вырезаются с содержимым (XSS)

- **Change:** p12-rich-tools
- **Источник:** p12-rich-tools: «Безопасность и деградация rich-блоков (NFR-39)» / Scenario: Скрипт внутри блока вырезается
- **Тип:** негативный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); тестовая страница wiki, созданная через `POST {BASE_URL}/api/wiki/pages`; Playwright (Python): `page`, `expect`, `api_request_context`
- **Шаги:**
  1. Через `PUT {BASE_URL}/api/wiki/pages/<id>` записать страницу со спойлером, в теле которого `<script>alert(1)</script>`, а на шапке — атрибут `onclick="alert(2)"`.
  2. Получить `GET`-контент страницы.
  3. Открыть статью, осмотреть консоль браузера.
  4. Кликнуть по шапке спойлера.
- **Ожидаемый результат:** шаг 2 — в отдаваемом HTML `script` отсутствует ВМЕСТЕ с содержимым (alert(1)), `onclick` снят; сам спойлер (шапка, тело) сохранен и работает; шаг 3 — alert не исполнялся, ошибок в консоли нет; шаг 4 — toggle работает без исполнения кода (NFR-39, NFR-31).
- **Тестовые данные:** XSS-векторы: `<script>alert(1)</script>`, `onclick="alert(2)"`
