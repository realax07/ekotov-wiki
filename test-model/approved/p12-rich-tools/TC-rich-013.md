# TC-rich-013 — Табы внутри вкладки — независимые виджеты

- **Change:** p12-rich-tools
- **Источник:** p12-rich-tools: «Табуляция (FR-120)» / Scenario: Табы внутри вкладки
- **Тип:** позитивный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); тестовая страница wiki, созданная через `POST {BASE_URL}/api/wiki/pages`; Playwright (Python): `page`, `expect`, `api_request_context`; страница открыта в режиме редактирования (WYSIWYG-редактор)
- **Шаги:**
  1. Вставить таб-виджет (2 вкладки), в содержимое первой вкладки вставить второй таб-виджет (2 вкладки), заполнить все четыре уникальным текстом.
  2. Сохранить, открыть статью.
  3. Переключить вкладки внешнего виджета, затем внутреннего.
  4. Сверить `GET`-контент.
- **Ожидаемый результат:** оба виджета работают независимо: переключение внешнего не сбрасывает внутренний и наоборот; контент всех четырех вкладок сохранен без потерь (4 таб-части в контенте, design §6).
- **Тестовые данные:** маркеры «В1.1», «В1.2», «В2.1», «В2.2»
