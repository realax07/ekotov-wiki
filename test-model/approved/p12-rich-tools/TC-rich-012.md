# TC-rich-012 — Лимит 8 вкладок и горизонтальный скролл переполнения (ОВ-3)

- **Change:** p12-rich-tools
- **Источник:** p12-rich-tools: «Табуляция (FR-120)» / Scenario: Лимит вкладок и переполнение таб-бара
- **Тип:** граничный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); тестовая страница wiki, созданная через `POST {BASE_URL}/api/wiki/pages`; Playwright (Python): `page`, `expect`, `api_request_context`; страница открыта в режиме редактирования (WYSIWYG-редактор)
- **Шаги:**
  1. Создать таб-виджет и добавить «+» восемь вкладок с длинными названиями (30+ символов).
  2. Нажать «+» девятый раз.
  3. Сузить viewport до 1024 px, чтобы таб-бар переполнился.
  4. Сохранить, сверить `GET`-контент.
- **Ожидаемый результат:** шаг 2 — девятая вкладка не создается (в DOM и в контенте ровно 8 `data-block-part="tab"`); шаг 3 — переполненный таб-бар прокручивается горизонтально: без переноса строк вкладок и без выпадающего списка (ОВ-3); вкладки не срезаются визуально (достижимы скроллом).
- **Тестовые данные:** 8 названий по 30+ символов; viewport 1024 px
