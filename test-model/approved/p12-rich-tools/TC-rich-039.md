# TC-rich-039 — Гуттер нумерации строк: соответствие, синхронный скролл, не в сохранении (фикс F-2)

- **Change:** p12-rich-tools
- **Источник:** p12-rich-tools: «Блок кода с подсветкой синтаксиса (FR-119)» + design §3 (data-editor-узлы), §5; ревью находка F-2 (buildGutter(code, block)) — дискриминатор фикса
- **Тип:** граничный | **Приоритет:** Should
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); тестовая страница wiki, созданная через `POST {BASE_URL}/api/wiki/pages`; Playwright (Python): `page`, `expect`, `api_request_context`; страница открыта в режиме редактирования (WYSIWYG-редактор)
- **Шаги:**
  1. Вставить код-блок с 10 строками, среди них пустые; в редакторе и в статье осмотреть гуттер.
  2. Сравнить количество и значения номеров с фактическими строками кода (включая пустые).
  3. Заполнить блок так, чтобы появилась вертикальная прокрутка; проскроллить код.
  4. Сохранить страницу, осмотреть `GET`-контент.
- **Ожидаемый результат:** номера в гуттере 1..N точно по строкам — пустая строка имеет номер, нумерация не «плывет» после пустых строк и переносов (buildGutter строится по блоку кода); при прокрутке гуттер синхронен коду (номера не уезжают относительно строк); в сохраненном контенте гуттера НЕТ — он editor-only (`data-editor`), вырезается при сериализации (в БД только `pre/code` текст).
- **Тестовые данные:** код 10 строк с пустыми; эталонный список строк
