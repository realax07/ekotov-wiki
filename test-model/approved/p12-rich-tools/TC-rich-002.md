# TC-rich-002 — Сворачивание/разворачивание кликом по всей шапке (ОВ-1)

- **Change:** p12-rich-tools
- **Источник:** p12-rich-tools: «Спойлер (FR-118)» / Scenario: Сворачивание и разворачивание кликом по шапке
- **Тип:** граничный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); тестовая страница wiki, созданная через `POST {BASE_URL}/api/wiki/pages`; Playwright (Python): `page`, `expect`, `api_request_context`
- **Шаги:**
  1. Открыть статью со спойлером с непустым содержимым.
  2. Кликнуть по правому краю шапки спойлера (не по шеврону и не по названию).
  3. Кликнуть по названию, затем по пустому месту шапки рядом с шевроном.
  4. Кликнуть по зоне содержимого развернутого спойлера.
- **Ожидаемый результат:** каждый клик по ЛЮБОЙ точке шапки сворачивает/разворачивает спойлер: свернут — содержимое скрыто, шеврон повернут; развернут — то же содержимое без потерь; клик по зоне содержимого (шаг 4) спойлер НЕ сворачивает.
- **Тестовые данные:** зона клика: шеврон / название / пустое место шапки / тело
