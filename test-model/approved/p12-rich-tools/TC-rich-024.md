- **Change:** p12-rich-tools
- **Источник:** p12-rich-tools: «Безопасность и деградация rich-блоков (NFR-39)» / Scenario: Глубина вложенности ограничена
- **Тип:** граничный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); тестовая страница wiki, созданная через `POST {BASE_URL}/api/wiki/pages`; Playwright (Python): `page`, `expect`, `api_request_context`
- **Шаги:**
  1. Через `PUT` записать цепочку из 7 вложенных спойлеров, каждый с уникальным текстом уровня («У1»…«У7»).
  2. Открыть статью: свернуть/развернуть спойлеры первых уровней.
  3. Осмотреть `GET`-контент (теги уровней 6–7).
  4. Повторить шаги 1–2 для цепочки ровно из 5 вложенных спойлеров.
- **Ожидаемый результат:** цепочка 7: уровни 1–5 работают как спойлеры; на уровнях 6–7 теги unwrap'нуты — содержимое «У6», «У7» видно как обычный контент без виджета; ВСЕ тексты «У1»…«У7» присутствуют (потери нет); цепочка 5 (граница): все 5 уровней — работающие спойлеры (счетчик глубины: >5 → unwrap).
