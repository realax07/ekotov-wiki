# TC-rich-015 — Замена уровня заголовка H1 → H3 без двойного нажатия

- **Change:** p12-rich-tools
- **Источник:** p12-rich-tools: «H-заголовки как переключатель (FR-121)» / Scenario: Замена уровня заголовка
- **Тип:** позитивный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); тестовая страница wiki, созданная через `POST {BASE_URL}/api/wiki/pages`; Playwright (Python): `page`, `expect`, `api_request_context`; страница открыта в режиме редактирования (WYSIWYG-редактор)
- **Шаги:**
  1. Оформить абзац как H1.
  2. Нажать кнопку H3.
  3. Осмотреть aria-pressed всех кнопок H1/H2/H3 и тег блока в DOM.
  4. Нажать Ctrl+Z.
- **Ожидаемый результат:** абзац стал H3 (тег h3 в DOM); нажата ровно кнопка H3 — одновременных нажатий нет (DON'T-состояние мокапа недостижимо); текст не изменен; Ctrl+Z откатывает замену уровня.
