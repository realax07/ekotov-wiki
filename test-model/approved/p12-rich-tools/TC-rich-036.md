# TC-rich-036 — Блочные конструкции проходят, подмененные значения снимаются

- **Change:** p12-rich-tools
- **Источник:** p12-rich-tools: wiki: «Санитизация HTML контента» / Scenario: Блочные конструкции проходят, подмененные значения снимаются
- **Тип:** позитивный + негативный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); тестовая страница wiki, созданная через `POST {BASE_URL}/api/wiki/pages`; Playwright (Python): `page`, `expect`, `api_request_context`
- **Шаги:**
  1. Через `PUT` записать страницу с валидными спойлером, код-блоком и таб-виджетом (data-атрибуты по словарю §1) и рядом `<div data-block="evil">Подмена</div>`.
  2. Получить `GET`-контент, открыть статью.
  3. Проверить активацию всех трех блоков и вид блока-подмены.
- **Ожидаемый результат:** валидные блоки сохранены и активируются клиентом (спойлер toggle, код подсвечен, табы переключаются); блок с невалидным `data-block` деградировал в обычный контент «Подмена» (NFR-39, NFR-31).
- **Тестовые данные:** 3 валидных блока + `data-block="evil"`
