# TC-rich-029 — Тулбар применяет форматирование — WYSIWYG round-trip

- **Change:** p12-rich-tools
- **Источник:** p12-rich-tools: wiki: «WYSIWYG-редактор страниц» / Scenario: Тулбар применяет форматирование
- **Тип:** позитивный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); тестовая страница wiki, созданная через `POST {BASE_URL}/api/wiki/pages`; Playwright (Python): `page`, `expect`, `api_request_context`; страница открыта в режиме редактирования (WYSIWYG-редактор)
- **Шаги:**
  1. В редакторе применить к разным фрагментам: H2, жирный, курсив, подчеркнутый, нумерованный и маркированный списки, цитату, код-блок, ссылку, таблицу, изображение.
  2. Сохранить страницу, открыть статью.
  3. Сравнить вид статьи с видом редактора (последовательный визуальный и DOM-сравнение).
- **Ожидаемый результат:** форматирование применилось к выделению в поле редактирования; сохраненная страница отображает тот же вид без расхождений (WYSIWYG): те же уровни, стили, структура списков/цитат/таблицы; в контенте нет артефактов, отсутствующих в редакторе (FR-110).
- **Тестовые данные:** эталонный набор форматирований на одной странице
