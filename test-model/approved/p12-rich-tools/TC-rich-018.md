# TC-rich-018 — Добавление/удаление строк и столбцов относительно целевой ячейки

- **Change:** p12-rich-tools
- **Источник:** p12-rich-tools: «Редактирование таблиц — строки и столбцы (FR-122)» / Scenario: Добавление и удаление строки и столбца
- **Тип:** позитивный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); тестовая страница wiki, созданная через `POST {BASE_URL}/api/wiki/pages`; Playwright (Python): `page`, `expect`, `api_request_context`; страница открыта в режиме редактирования (WYSIWYG-редактор)
- **Шаги:**
  1. Вставить таблицу 3×3, заполнить все ячейки маркерами rNcM, курсор в ячейку [2,2].
  2. Нажать «+» строки, затем «+» столбца (осмотреть подсветку целевого столбца).
  3. Заполнить новые ячейки маркерами.
  4. Нажать «−» добавленной строки, затем «−» добавленного столбца.
  5. Сохранить, сверить `GET`-контент.
- **Ожидаемый результат:** шаг 2 — строка добавилась НИЖЕ [2,2], столбец ПРАВЕЕ [2,2], целевой столбец подсвечен (мокап tool-5-table-edit.png); шаг 4 — удалились именно добавленные строка и столбец; шаг 5 — таблица 3×3, содержимое остальных ячеек посимвольно исходное.
