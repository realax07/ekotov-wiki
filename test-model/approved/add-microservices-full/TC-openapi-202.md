  4. Запустить search. Через ≤0.5с `GET /api/search` → 200 (без stale-DNS); задача из шага 3 находима поиском.
- **Ожидаемый результат:** деградация управляемая (503 JSON + Retry-After, ~1мс), запись в ядро не блокируется упавшим сервисом, восстановление автоматическое ≤0.5с.
