# TC-P12N-004 — сайдбар-viewport: footer («Настройки»/«Выйти») виден на галерее с длинной сеткой (микрофикс sticky/100vh)

- **Change:** add-ui-polish-r8 (контекст волны 2.4; сам фикс — микрофикс Заказчика 2026-10-06, PR #50, в main)
- **Источник:** navigation: «Навигация через сайдбар» (FR-13/FR-94 — сайдбар доступен на страницах функционала); микрофикс #50: `.sidebar` height 100vh + sticky + overflow-y auto, `.content` height 100vh + внутренний скролл; CHK-P12-18 (состояния не меняются) / NFR-22 (DOM-геометрия)
- **Тип:** ФТ, web/стендовый, поз./сред. | **Приоритет:** Must
- **Маркер:** автотест (playwright, nginx-стенд С ИЗОБРАЖЕНИЯМИ images :8379, прогон R3/R4) — new-кейс; прецедент воспроизведения — проверка микрофикса на стенде (60 плиток)
- **Предусловия:** маршрутизированный стенд с сервисом images; том галереи содержит ≥N изображений, дающих документ ВЫШЕ viewport (≥30–60 плиток; загрузить фикстурные PNG при пустом томе, teardown по префиксу QAGAL-); сессия owner; viewport 1280×720 (или дефолт сьюта)
- **Шаги:**
  1. Открыть `/gallery`: документ длинный — `document.documentElement.scrollHeight > window.innerHeight` (сетка растягивает контент; на коротких страницах кейс невалиден — precondition-check).
  2. Геометрия в исходном скролле: bbox `.sidebar-footer` (содержит «Настройки» и «Выйти») полностью в viewport — `y + height ≤ window.innerHeight` и `y ≥ 0`; «Настройки» и «Выйти» кликабельны (elementFromPoint — элемент footer'а).
  3. Прокрутка сетки колесом внутри `.content`: контент-область скроллится, `.sidebar` НЕ смещается (`position: sticky; top: 0`), bbox footer'а до/после прокрутки идентичен (допуск ≤1px).
  4. Функциональность на длинной странице: клик «Настройки» → `/settings` открывается; клик «Выйти» — POST logout с редиректом на `/login` (кнопка не «уехала» и работает).
  5. Регресс-паритет на короткой странице `/board`: сайдбар во всю высоту экрана, footer на месте, скролл доски внутри `.content` работает; внутреннее переполнение сайдбара (малый viewport, напр. 1280×600) — у `.sidebar` собственный скролл (overflow-y: auto), footer достижим прокруткой сайдбара.
- **Ожидаемый результат:** на галерее с длинной сеткой footer сайдбара («Настройки»/«Выйти») остается в viewport при любой прокрутке контента, оба элемента кликабельны; прокрутка длинных страниц идет внутри `.content`, сайдбар прижат к viewport (sticky, без смещения footer'а); на коротких страницах и при малом viewport поведение корректно (внутренний скролл сайдбара).
