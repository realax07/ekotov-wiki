- **Шаги:**
  1. Открыть `/gallery`, клик по превью → full-screen лайтбокс; зафиксировать имя в шапке.
  2. У имени нажать иконку «переименовать» → инлайн-поле; ввести «QAGAL-Дача лето», подтвердить Enter (и второй прогон — кнопкой ✓).
  3. БЕЗ перезагрузки страницы: имя в шапке лайтбокса; закрыть лайтбокс — заголовок карточки сетки (`.g-card-title`).
  4. Перезагрузить страницу, открыть тот же лайтбокс — имя.
  5. Сторожевой XSS: имя «QAGAL-<img src=x onerror=window.__pwned=1>» — после обновления DOM (шапка/карточка) `window.__pwned` не установлен, имя отрисовано текстом.
- **Ожидаемый результат:** шаг 2 — форма принимает имя, инлайн у имени (без ухода из лайтбокса); шаг 3 — имя обновлено в шапке лайтбокса И в карточке сетки без перезагрузки (textContent, не innerHTML); шаг 4 — после перезагрузки и повторного открытия — новое имя (persist на API); шаг 5 — XSS-инъекция не исполняется, дисциплина design §4 соблюдена.
