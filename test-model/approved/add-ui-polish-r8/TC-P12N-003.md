# TC-P12N-003 — favicon: data-URI декодируется, кеш-маркер внутри URI (отклонение от буквы ТЗ зафиксировано), стиль V3 по design §3

- **Change:** add-ui-polish-r8
- **Источник:** navigation (ADDED): «Favicon страницы» — Scenario «Favicon присутствует на страницах», «Изменение иконки доходит до браузеров» (FR-95); design §3 (терракотовый акцент clay на бумажном фоне, читаемость 16px); CHK-P12-19; CHK-P12-32 (частично)
- **Тип:** ФТ, web/стендовый, поз./НФТ | **Приоритет:** Must
- **Маркер:** автотест (playwright, nginx-стенд, прогон R3 — new favicon-кейс рядом с e2e/test_stand_smoke); фактическое отображение во вкладке — ручной смоук приемки (слепой контур E10: внешний браузерный кеш не эмулируется)
- **Предусловия:** стенд поднят; сессия owner; волна 2.4 в merge-ветке (favicon в base.html)
- **ОТКЛОНЕНИЕ ОТ БУКВЫ ТЗ (зафиксировано, сверено с design §3):** ТЗ/spec требует cache-busting через query-параметр `?v=` в URL. Реализация зашивает маркер комментарием `<!--cache:v=1-->` ВНУТРЬ data:URI: data:URI — непарсимый URL, хвост `?v=1` после `</svg>` ломает XML-парсинг (проверено в Chromium: naturalWidth=0 — иконка не рендерится). Семантика политики design §3 («при ЛЮБОМ изменении иконки менять URL») соблюдена: бамп маркера меняет URL. Проверка кейса — по фактической реализации; при возврате к `?v=`-хвосту шаг 3 переформулировать.
- **Шаги:**
  1. На каждой странице функционала (`/board`, `/search`, `/wiki`, `/gallery`, `/settings`) в `<head>` присутствует ровно один `<link rel="icon" type="image/svg+xml">`, `href` начинается с `data:image/svg+xml,` — внешнего файла нет (сетевой лог: 0 запросов favicon к хостам/файлам, CHK-P12-32-паритет).
  2. Декодируемость: извлечь SVG из href, загрузить в `Image` / отрендерить в изолированном документе — SVG парсится, `naturalWidth > 0` (иконка валидна; на грязном `?v=`-хвосте было naturalWidth=0).
  3. Кеш-маркер: внутри декодированного SVG присутствует `<!--cache:v=1-->`; маркер входит в состав URL → любое изменение маркера меняет весь href (кеш-бастинг достижим без внешних файлов).
  4. Стиль V3 (сверка с design §3 и эскизом design/polish-favicon.svg): терракотовый акцент `#a8432c` (токен clay) на бумажном фоне `#faf7f2`, мотив «лист вики», без текста; теги в SVG сущности-экранированы (`%23` для #) — href валиден как значение атрибута.
  5. Разметка не зависит от сессии: на `/login` favicon-ссылка присутствует тоже (base-механизм head).
- **Ожидаемый результат:** на всех страницах — ровно один inline `<link rel="icon">` с валидным декодируемым SVG data-URI (naturalWidth>0); кеш-маркер `<!--cache:v=1-->` внутри URI, смена маркера меняет URL (политика design §3 выполнена при зафиксированном отклонении от буквы spec `?v=`); стиль — терракотовый акцент V3 по design §3.
