# TC-weather-007 — Граница: «сегодня» — первая карточка прогноза, согласована с карточкой «Сегодня»

- **Change:** weather-service
- **Источник:** weather-service: «Прогноз на 7 дней» / Scenario: Сегодня входит в прогноз недели
- **Тип:** граничный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); Playwright (Python): `page`, `expect`, `api_request_context`; unit/integration-уровень: `services/weather` pytest с httpx.MockTransport (провайдер мокается, т.к. URL Open-Meteo зашит в конфиге); кэш — временный файл через env `EKOTOV_WEATHER_CACHE_PATH`
- **Шаги:**
  1. Зафиксировать текущую дату X в `Europe/Moscow` (`date` на стенде).
  2. Получить данные (кэш или провайдер), открыть `/weather`.
  3. Сравнить первую карточку прогноза с карточкой «Сегодня».
- **Ожидаемый результат:** первая карточка прогноза — день X; максимум/минимум первой карточки совпадают с максимумом/минимумом карточки «Сегодня» (тот же daily[0]); окно прогноза ровно [X .. X+6], ни дня до X, ни дня после X+6.
- **Тестовые данные:** текущая московская дата; фикстура daily, где daily[0] заведомо отличается от остальных дней.
