# TC-weather-004 — Полная карточка «Сегодня»: 8 метрик, единицы по design §3

- **Change:** weather-service
- **Источник:** weather-service: «Карточка «Сегодня» с 8 метриками» / Scenario: Полная карточка по мокапу A
- **Тип:** позитивный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); Playwright (Python): `page`, `expect`, `api_request_context`; unit/integration-уровень: `services/weather` pytest с httpx.MockTransport (провайдер мокается, т.к. URL Open-Meteo зашит в конфиге); кэш — временный файл через env `EKOTOV_WEATHER_CACHE_PATH`
- **Шаги:**
  1. Обеспечить свежий ответ провайдера со всеми current- и daily-полями (unit: mock с полным фикстурным JSON; e2e: прогреть кэш живым запросом).
  2. Открыть `/weather` под owner.
  3. Сверить каждую метрику с данными ответа `/api/weather`.
- **Ожидаемый результат:** карточка «Сегодня» показывает все 8 метрик в компоновке мокапа A: температура (°C), описание по WMO-коду на русском, «ощущается как», максимум/минимум дня, осадки (%) из daily[0], ветер «ЮЗ, 5 м/с» (русский румб + м/с), влажность (%), давление в мм рт. ст. (конвертация гПа × 0.750062, расхождение с формулой ≤ 0,1 мм); лишних метрик нет.
- **Тестовые данные:** фикстура полного ответа Open-Meteo (current + daily), контрольные значения давления/ветра для пересчета единиц.
