# TC-P14-101 — Мобильный drawer: бургер, закрытие 4 способами, единый DOM, сцена во всю ширину

- **Change:** add-responsive-mobile
- **Источник:** navigation (ADDED): «Мобильная навигация — бургер и drawer» (FR-99, ОВ-2) — Scenario «Открытие drawer по бургеру», «Закрытие drawer», «Навигация не дублируется», «Сцена занимает всю ширину», «Desktop-вид не меняется»; design §2; CHK-P14-1, CHK-P14-2, CHK-P14-3, CHK-P14-4, CHK-P14-5
- **Тип:** ФТ, UI/адаптив | **Приоритет:** Must
- **Маркер:** автоматизирован + DV — 5.1 mobile-сьют (~185p, device-эмуляция 375×812 touch) + design_validator review-001 (мокапы 01 frame-drawer-closed, 02 frame-drawer-open — APPROVE)
- **Предусловия:** пользователь авторизован; вьюпорт 375×812, device-эмуляция touch (Playwright-профиль); стенд nginx :18443 (app/search/images, свежая БД, seed)
- **Шаги:**
  1. Открыть любой раздел на 375×812: сайдбар скрыт, в шапке кнопка-бургер (тач-таргет 44×44), контент занимает всю ширину вьюпорта (`margin-left: 0`, пустой колонки нет).
  2. Нажать бургер: `.sidebar` выезжает (292.5px = min(78vw,300px)) поверх подложки `.sidebar-backdrop` rgba(61,54,48,0.45); доступны все разделы, footer-зона профиля, Мониторинг (owner).
  3. Закрыть Escape → drawer закрыт, фокус возвращен на бургер. Повторить: открытие → клик по подложке → закрыто; открытие → повторный бургер → закрыто (z-фикс: бургер над панелью, тап закрывает).
  4. Открыть drawer и выбрать пункт → переход в раздел, drawer закрыт.
  5. Инспекция DOM: список разделов в drawer — тот же элемент `.sidebar` (второго независимого списка навигации нет, ОВ-2).
  6. Вьюпорт ≥1024px: сайдбар постоянный, бургер отсутствует (NFR-29).
- **Ожидаемый результат:** на ≤768px drawer открывается/закрывается всеми четырьмя способами, переход по пункту выполняется, DOM навигации единственный, сцена во всю ширину; на desktop вид прежний. Факт 5.1: green (мокапы 01/02 APPROVE).
