# TC-P14-108 — Лайтбокс на таче: свайп листает, короткое/диагональное движение — тап, скролл комментариев независим

- **Change:** add-responsive-mobile
- **Источник:** gallery (MODIFIED): «Full-screen просмотр с листанием» (FR-105, ОВ-1/С3) — Scenario «Листание свайпом по изображению», «Короткое или диагональное движение — это тап», «Скролл комментариев не перехватывается жестом листания», «Desktop-способы листания не деградировали»; design §5; CHK-P14-30, CHK-P14-31, CHK-P14-32, CHK-P14-33
- **Тип:** ФТ, UI/адаптив, жесты | **Приоритет:** Should
- **Маркер:** автоматизирован + DV — 5.1 mobile-сьют (синтетический touch-свайп) + design_validator review-001 (мокап 07 lightbox+свайп — APPROVE: `touch-action:none` на изображении, navigated=true, файлы до/после разные)
- **Предусловия:** пользователь авторизован; в галерее ≥3 изображений, у текущего есть комментарии (панель скроллится); вьюпорт 375×812, device-эмуляция touch
- **Шаги:**
  1. Открыть превью → full-screen лайтбокс (fixed, фон rgba(61,54,48,0.4), изображение + панель действий).
  2. Свайп по ИЗОБРАЖЕНИЮ влево (сдвиг ≥50px, |dx|>|dy|): показано следующее изображение циклично по текущей выдаче; свайп вправо — предыдущее (паритет стрелкам).
  3. Провести короче порога (~50px) и по диагонали (|dy|>|dx|): листания НЕТ — обрабатывается как тап (существующее поведение тапа не меняется).
  4. Прокрутить панель комментариев вертикально: панель скроллится, листания не происходит (touch-обработчики только на элементе изображения).
  5. Вьюпорт ≥1024px: стрелки-зоны и клавиатура (←/→, Esc) работают как прежде; лайк/дизлайк, скачивание, комментарии — без изменений (NFR-29).
- **Ожидаемый результат:** свайп листает по зоне изображения с порогом ~50px, тап-семантика и скролл комментариев не нарушены, desktop-листание сохранено. Факт 5.1: green (мокап 07 APPROVE).
