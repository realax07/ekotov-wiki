# TC-P14-105 — Форма задачи на мобильном: одна колонка, поля ≥16px без авто-зума, тач-таргеты, Escape-семантика

- **Change:** add-responsive-mobile
- **Источник:** tasks (MODIFIED): «Формы создания и редактирования по дизайну V3» (дельта FR-62 + NFR-23/24) — Scenario «Адаптив одной колонкой на узких экранах», «Поля без авто-зума на мобильном», «Тач-таргеты элементов формы», «Escape закрывает чистую форму сразу / грязную с подтверждением»; design §3; CHK-P14-17, CHK-P14-18, CHK-P14-19, CHK-P14-20
- **Тип:** ФТ, UI/адаптив + НФТ (NFR-23/24) | **Приоритет:** Must
- **Маркер:** автоматизирован — 5.1 mobile-сьют (~185p; FR-56/FR-61/FR-62 «не регрессировали» — явный пункт 5.1а tasks.md)
- **Предусловия:** пользователь авторизован; вьюпорт 375×812 (проверка и 480×800), device-эмуляция touch
- **Шаги:**
  1. Открыть форму создания задачи на 375px: одна колонка, все поля full-width, модалка без горизонтальной прокрутки; дропдаун подсказок (теги) позиционируется корректно.
  2. Сфокусировать каждое поле (input/textarea/select): font-size ≥16px — авто-зум iOS не включается.
  3. Осмотреть интерактивные элементы (поля, кнопки, крестики, селекты, чипы тегов): эффективная тач-область ≥44×44px.
  4. Esc на чистой форме → закрывается сразу; Esc на грязной (изменить поле) → подтверждение «Закрыть без сохранения?»; отмена — форма с введенными значениями; подтверждение — закрыто без сохранения, данные на сервере не изменились (FR-61).
  5. Вьюпорт ≥1024px: форма — desktop-вид по токенам V3 без изменений.
- **Ожидаемый результат:** форма на ≤480px одноколоночная, поля без авто-зума, таргеты ≥44px, Escape-семантика FR-61 сохранена; desktop не регрессировал. Факт 5.1: green.
