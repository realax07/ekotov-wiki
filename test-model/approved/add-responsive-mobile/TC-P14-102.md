- **Шаги:**
  1. Последовательно открыть разделы: доска, поиск, wiki, галерея, настройки — при каждом закрытом drawer фиксировать заголовок раздела в шапке (серверный шаблон): читаемость на 375px без зума (размер/контраст по мокапу 01, Titul 17px).

- **Ожидаемый результат:** при закрытой навигации пользователь всегда видит текущий раздел (заголовок в шапке, читаемо на 375px); активный пункт drawer подсвечен существующим стилем. Факт 5.1: green.
