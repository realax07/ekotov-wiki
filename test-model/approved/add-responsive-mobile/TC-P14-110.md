# TC-P14-110 — Живая приемка Заказчика на проде с телефона (С1–С3): iPhone 11 и Z Fold 7

- **Change:** add-responsive-mobile
- **Источник:** tasks.md 5.2 [ops] (приемка «вживую», критерий галереи); requirements.md §2 (сценарии С1–С5, ОВ-1/ОВ-6), design §7; CHK-P14-41 (+ живые повторения CHK-P14-22, CHK-P14-28, CHK-P14-30, CHK-P14-34, CHK-P14-35)
- **Тип:** ФТ, сред./эксплуатационный | **Приоритет:** Must
- **Маркер:** ручной, живое устройство — план 5.2 (только с Заказчиком; протокол по образцу acceptance-протокола галереи)
- **Предусловия:** релиз со статикой выкачен на прод (кеш-бастинг `?v=` бамп — урок DEF-002/3); смоук прода пройден; устройства Заказчика: iPhone 11 (375×812) и Z Fold 7 раскрытый («не разваливается», ОВ-6)
- **Шаги:**
  1. **С1 (Must):** с телефона вечером открыть доску, свайпнуть колонки, закрыть задачу быстрым «Выполнено» — без drag-and-drop, таргеты удобны пальцу.
  2. **С2 (Must):** найти задачу или wiki-заметку одной рукой через поиск — инпут без авто-зума, выдача читается без обрезки (живой повтор CHK-P14-22).
  3. **С3 (Should):** открыть галерею, листать лайтбокс свайпами по изображению; панель комментариев скроллится независимо (живой повтор CHK-P14-30).
  4. Доска/модалка тикета на 375px: fullscreen-модалка, «Редактировать» в той же оболочке, возврат на прежнее место.
  5. Drawer: бургер, закрытие подложкой/Esc, индикация текущего раздела в шапке.
  6. Z Fold 7 раскрытый: все разделы «не разваливаются», действия доступны (NFR-26, ОВ-5/ОВ-6).
  7. Зафиксировать результат протоколом приемки (вердикт Заказчика); откат при отказе — предыдущий тег матрицы.
- **Ожидаемый результат:** сценарии С1–С3 выполнены Заказчиком на обоих устройствах без замечаний («вживую» — критерий приемки пакета, преемственность галереи); протокол подписан.
