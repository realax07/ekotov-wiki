# TC-P14-103 — Доска на мобильном: свайп-колонки scroll-snap, индикатор точек, быстрое «Выполнено»

- **Change:** add-responsive-mobile
- **Источник:** board (MODIFIED): «Отображение канбан-доски» (FR-101, ОВ-3) — Scenario «Свайп колонок на мобильном», «Индикатор синхронен позиции и управляет прокруткой», «Страница без горизонтальной прокрутки вне контейнера колонок», «Быстрое «Выполнено» доступно с тача», «Desktop-доска не меняется»; design §3; CHK-P14-8, CHK-P14-9, CHK-P14-10, CHK-P14-11, CHK-P14-12
- **Тип:** ФТ, UI/адаптив + НФТ (NFR-23/26) | **Приоритет:** Must
- **Маркер:** автоматизирован + DV — 5.1 mobile-сьют (X-скролл смоук + синтетический свайп) + design_validator review-001 (мокап 03 board-swipe — APPROVE)
- **Предусловия:** пользователь авторизован; на доске задачи в нескольких столбцах; вьюпорт 375×812, device-эмуляция touch
- **Шаги:**
  1. Открыть доску на 375px: колонки фиксированной ширины ~82vw (307.5px), виден край следующей колонки; `scroll-snap-type: x mandatory` (DV: computed).
  2. Свайпнуть колонки горизонтально: прилипание по колонке (snap), прокрутился ровно соседний столбец.
  3. Проверить индикатор точек: активная точка следует за scroll-позицией; тап по точке — скролл к соответствующей колонке; точки — табы 44×44 с `aria-current`; при prefers-reduced-motion скролл без анимации (ОГР-17).
  4. `document.documentElement.scrollWidth <= innerWidth` — прокрутки СТРАНИЦЫ по X нет (горизонталь только в контейнере колонок, санкция ОВ-3).
  5. Нажать быстрое «Выполнено» на карточке: задача перемещается без drag-and-drop; тач-таргет ≥44×44px (DV: quick-done 44px olive).
  6. Вьюпорт ≥1024px: три колонки рядом, drag-and-drop и tooltips работают как прежде (NFR-29).
- **Ожидаемый результат:** свайп-колонки со snap и индикатором работают, страница без X-скролла, «Выполнено» доступно с тача, desktop-доска не изменена. Факт 5.1: green (мокап 03 APPROVE).
