# TC-ui-a-008: Переключатель темы в каркасе (ADDED, navigation)

- **Change:** redesign-ui-a
- **Источник:** navigation ADDED — «Переключатель темы в каркасе» / Scenario: «Переключение темы без перезагрузки», «Первый вход — системная тема», «localStorage недоступен»
- **Тип:** поз. | **Приоритет:** Must
- **Среда/предусловия:** каркас с `#theme-toggle`; обе темы определены (`:root` dark + `:root[data-theme="light"]`)
- **Шаги:**
  1. Клик `#theme-toggle`: тема меняется без перезагрузки (DOM-снапшот `data-theme` + computed фона body), `aria-pressed`/иконка обновляются; повторный клик — возврат.
  2. Первый вход: инлайн-инициализатор base.html применяет системную тему до рендера (без FOUC-класса/вспышки); выбор пользователя в localStorage приоритетен.
  3. Hit-target переключателя ≥ 44px на мобильном каркасе 390 (автотест `test_tc_redesign_023_mobile_frame_860` — `#theme-toggle` bounding box).
  4. localStorage недоступен (частное покрытие — ручное): заблокировать storage, перезагрузить страницу — инициализатор try/catch, дефолтная тема, страницa рендерится (QA §3: тумблер без FOUC, обе темы ✓).
- **Ожидаемый результат:** переключение мгновенное, обе темы инвертируются корректно; light-блок токенов полный (TC-010 снапшот); контраст обеих тем — TC-ui-a-001. Авто-покрытие: TC-redesign-010/023 + ручная QA §3 (см. review-001: «localStorage недоступен» — ручное, minor).
- **Тестовые данные:** системная тема ОС (prefers-color-scheme), localStorage «theme».
