# TC-vid-028 — Чужой комментарий удалить нельзя

- **Change:** video-hosting
- **Источник:** video-service: «Комментарии к видео» / Scenario: Чужой комментарий удалить нельзя
- **Тип:** негативный | **Приоритет:** Must
- **Среда/предусловия:** owner и pe авторизованы (раздельные сессии); видео T8
- **Шаги:**
  1. Под pe добавить комментарий «Чужой».
  2. Под owner выполнить `DELETE {BASE_URL}/api/videos/<T8>/comments/<comment_id_pe>`.
  3. Под owner открыть UI T8, попытаться удалить чужой комментарий (если UI скрывает кнопку — зафиксировать отсутствие).
  4. Проверить список комментариев.
- **Ожидаемый результат:** шаг 2 — HTTP 403 (запрещено; спека: «отклоняется» — см. эскалацию E-3 по точному коду); шаг 3 — у owner нет возможности удаления чужого комментария; шаг 4 — комментарий «Чужой» остался.
- **Тестовые данные:** комментарий pe с известным `comment_id`.
