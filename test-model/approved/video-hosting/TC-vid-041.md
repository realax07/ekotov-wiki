# TC-vid-041 — Идемпотентный PUT реакции: сетевой ретрай не снимает голос

- **Change:** video-hosting / PLAN-TD-CLOSEOUT (TD-B, TD-5)
- **Источник:** TD-5 (PRODUCT_BACKLOG.md, аудит Kimi 2026-10-31): «PUT реакции сделать идемпотентным (сетевой retry сейчас снимает голос)»; паритет BUG-026 (галерея, PR #266). Решение Заказчика 2026-11-15 — PLAN-TD-CLOSEOUT.md, пакет TD-B. Supersedes TC-vid-031 (toggle-семантика «повторный клик снимает» упразднена: PUT по семантике HTTP идемпотентен)
- **Тип:** позитивный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner авторизован (seed `owner/QaOwner_Pass_1!`); видео T13 существует и не имеет голосов от owner (счетчики 0/0); HTTP-клиент с сессией owner (API); ключ идемпотентности — пара (user_id, video_id), PK(video_id, user_id)
- **Шаги:**
  1. `PUT {BASE_URL}/api/videos/<T13>/reaction` с `{"value": 1}` — зафиксировать ответ (статус, my_reaction, likes, dislikes).
  2. Повторить шаг 1 дословно 3 раза (имитация сетевого ретрая / двойного клика).
  3. Перечитать счетчики и собственный голос; проверить строки БД по паре (T13, owner).
  4. `PUT ... {"value": -1}` (смена голоса), затем повтор с тем же `{"value": -1}`.
  5. Повторить шаги 1–2 в обратную сторону (дизлайк → лайк, ретрай после переноса).
- **Ожидаемый результат:** шаг 1 — 200, `my_reaction=1`, likes=1, dislikes=0; шаг 2 — каждый повтор 200 и ответ ПОЛНОСТЬЮ равен ответу шага 1 (no-op: состояние не меняется, голос НЕ снимается, счетчик не растет); шаг 3 — в БД ровно одна строка `value=1` на пару (user+video), счетчики без двойных голосов; шаг 4 — смена голоса переносит ровно на единицу (лайков 0, дизлайков 1, `my_reaction=-1`), повтор same-sign — снова no-op; шаг 5 — симметричный перенос и ретрай-но-оп обратно. Инвариант «≤ 1 голоса на пользователя» при любом числе повторов PUT.
- **Тестовые данные:** видео T13 без голосов на старте; эндпоинт `PUT /api/videos/{id}/reaction`; автоматизация — `services/video/tests/test_social.py::test_reaction_put_idempotent` (TestClient) + `test_reaction_put_toggle_move` (шаг no-op).
