# TC-vid-040 — Социальные операции и категории без сессии — 401

- **Change:** video-hosting
- **Источник:** video-service: «Операции социального слоя — только авторизованные» (NFR-38) / Scenario: Комментарий и реакция без сессии + Список категорий без сессии
- **Тип:** негативный | **Приоритет:** Must
- **Среда/предусловия:** стенд поднят; известны видео T12 и id комментария; HTTP-клиент без сессии
- **Шаги:**
  1. `GET {BASE_URL}/api/videos/<T12>/comments` без сессии.
  2. `POST .../comments` без сессии с `{"text": "аноним"}`.
  3. `DELETE .../comments/<cid>` без сессии.
  4. `PUT {BASE_URL}/api/videos/<T12>/reaction` без сессии с `{"value": 1}`.
  5. `GET {BASE_URL}/api/videos/categories` без сессии.
  6. Проверить состояние комментариев и счетчиков T12.
- **Ожидаемый результат:** шаги 1–5 — каждый ответ HTTP 401 `{"error": "unauthorized"}`; шаг 6 — состояние не изменилось: комментариев не добавлено/не удалено, счетчики без изменений, справочник категорий анонимно не раскрыт.
- **Тестовые данные:** эндпоинты comments/reaction/categories; T12; существующий cid.
