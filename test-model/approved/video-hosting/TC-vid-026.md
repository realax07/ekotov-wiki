# TC-vid-026 — Пустой комментарий и из одних пробелов отклоняется

- **Change:** video-hosting
- **Источник:** video-service: «Комментарии к видео» / Scenario: Пустой комментарий отклоняется
- **Тип:** негативный | **Приоритет:** Must
- **Среда/предусловия:** стенд поднят; сессия owner; видео T8
- **Шаги:**
  1. `POST {BASE_URL}/api/videos/<T8>/comments` с телом `{"text": ""}`.
  2. `POST .../comments` с телом `{"text": "   "}` (только пробелы).
  3. `POST .../comments` без поля `text`.
  4. Открыть список комментариев T8.
- **Ожидаемый результат:** шаги 1–3 — каждый ответ HTTP 422 (валидация), комментариев не создано; шаг 4 — список пуст (новых записей нет).
- **Тестовые данные:** тела `{"text": ""}`, `{"text": "   "}`, `{}`.
