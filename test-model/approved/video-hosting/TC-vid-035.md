# TC-vid-035 — Справочник один: только категории галереи, без «work» и произвольных

- **Change:** video-hosting
- **Источник:** video-service: «Категории видео — общий справочник с галереей» / Scenario: Значения — только из справочника галереи
- **Тип:** негативный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); Playwright (Python): `page`, `expect`, `api_request_context`; в галерее создана «семья»; в справочнике категорий задач есть «work»
- **Шаги:**
  1. Открыть выбор категории в форме загрузки видео.
  2. Осмотреть полный список предлагаемых значений.
  3. Попытаться отправить `POST {BASE_URL}/api/videos` с `category: "work"` и с произвольной новой `"новая_категория"`.
  4. В галерее создать категорию «дача»; повторить шаг 1.
- **Ожидаемый результат:** шаг 2 — предложены только категории галереи («семья»); «work» и произвольные имена отсутствуют; шаг 3 — запросы отклонены (422/400: значение вне справочника) либо категория игнорируется со значением «Без категории» — см. эскалацию E-4 по точному контракту; шаг 4 — «дача» сразу доступна в выборе видео (общий справочник).
- **Тестовые данные:** категории: «семья» (галерея), «work» (задачи), «дача» (создается в ходе шага 4).
