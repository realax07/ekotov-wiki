# TC-vid-038 — Файл не отдается без сессии (mp4 и preview)

- **Change:** video-hosting
- **Источник:** video-service: «Доступ только авторизованный, без публичных ссылок» (NFR-36, ОВ-2) / Scenario: Файл не отдается без сессии
- **Тип:** негативный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); Playwright (Python): `page`, `expect`, `api_request_context`; известны URL mp4 и preview.jpg видео T11
- **Шаги:**

  2. Запросить URL preview.jpg без сессии.
  3. Открыть страницу `/video` без сессии.
  4. Повторить шаги 1–2 с валидной сессией.
  5. Проверить отсутствие механизма публичных ссылок по токену (в UI и API нет генерации публичной ссылки).
