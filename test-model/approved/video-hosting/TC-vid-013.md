# TC-vid-013 — Негативы удаления: несуществующее id — 404, без сессии — 401

- **Change:** video-hosting
- **Источник:** video-service: «Удаление видео» / Scenario: Удаление готового видео (негативные классы)
- **Тип:** негативный | **Приоритет:** Must
- **Среда/предусловия:** стенд поднят; известен id ранее удаленного видео T6
- **Шаги:**
  1. `DELETE {BASE_URL}/api/videos/<T6>` с сессией (видео уже удалено).
  2. `DELETE {BASE_URL}/api/videos/<T6>` без сессии.
  3. `DELETE {BASE_URL}/api/videos/00000000-0000-0000-0000-000000000000` с сессией.
- **Ожидаемый результат:** шаг 1 — HTTP 404 (повторная операция); шаг 2 — HTTP 401 `{"error": "unauthorized"}`; шаг 3 — HTTP 404; состояние списка не изменилось.
- **Тестовые данные:** id T6 (после удаления), синтетический несуществующий id.
