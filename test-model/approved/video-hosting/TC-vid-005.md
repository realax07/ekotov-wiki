# TC-vid-005 — Файлы в томе videos-data, метаданные в БД

- **Change:** video-hosting
- **Источник:** video-service: «Отдельный контейнерный сервис video, файлы вне БД» / Scenario: Файлы в томе, метаданные в БД
- **Тип:** позитивный | **Приоритет:** Must
- **Среда/предусловия:** поднятый стенд (`GET {BASE_URL}/api/health` → 200); owner `owner/QaOwner_Pass_1!`, второй пользователь `pe/QaPe_Pass_1!` (seed); Playwright (Python): `page`, `expect`, `api_request_context`; доступ к хосту; загружен валидный файл 10 МБ (mp4)
- **Шаги:**
  1. Загрузить видео через `POST {BASE_URL}/api/videos` (multipart).
  2. Найти новый `id` в ответе; проверить том: `docker exec <video> ls /data/videos/<id>/` (путь тома `videos-data`).
  3. `grep -ri <id> <репозиторий>` — убедиться в отсутствии файла в репо.
  4. Проверить запись БД: статус метаданных.
  5. `docker compose up -d --force-recreate video`; повторить шаг 2.
- **Ожидаемый результат:** шаг 2 — файл(ы) присутствуют в томе `videos-data` (оригинал/mp4/превью), не BLOB; шаг 3 — файла в репозитории нет; шаг 4 — запись метаданных со статусом существует; шаг 5 — файлы пережили пересоздание контейнера.
- **Тестовые данные:** файл `sample_10mb.mp4` (10 МБ); том `videos-data`; БД сервиса video.
