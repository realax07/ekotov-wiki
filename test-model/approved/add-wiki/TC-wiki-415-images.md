# TC-wiki-415 — Изображения в контенте через images-сервис: галерея и диск, лимиты (FR-111, NFR-34)

- **Change:** add-wiki
- **Источник:** wiki (ADDED): Requirement «Изображения в контенте через images-сервис» (решение 3, FR-111, NFR-34, лимиты NFR-21) — Scenario «Вставка изображения из галереи», «Загрузка изображения с диска», «Нарушение лимитов загрузки»; design §5, мокап wiki-editor (05c); CHK-wiki-19, CHK-wiki-20
- **Тип:** ФТ, интеграция + негатив | **Приоритет:** Must
- **Предусловия:** авторизованный пользователь; в галерее есть изображения (GET /api/images отвечает); тестовый файл ≤10 МБ JPEG/PNG/GIF/WebP и файл-нарушитель (>10 МБ / недопустимый тип); images-сервис поднят (на web-стенде 4.2 images-API не поднимался — 404 артефакт стенда, см. DV-8)
- **Шаги:**
  1. Редактор → «Изображение» → диалог с радио «Из галереи»/«Загрузить с диска».
  2. «Из галереи»: выбрать изображение из грида `.img-pick-grid` → в контент вставлена ссылка `/images/{id}`; файл в БД wiki не дублируется.
  3. «Загрузить с диска»: file input → POST /api/images (multipart) → вставка `/images/{id}`.
  4. Нарушение лимитов (переиспользованы от images-сервиса) → 422, в контент ничего не вставляется; ошибка человекочитаемая («Не удалось загрузить данные (HTTP …).» — DV-8), не сырой detail.
- **Ожидаемый результат:** вставка изображения работает обоими путями через существующий images-сервис, в контенте только ссылки /images/{id}, лимиты переиспользованы, ошибки читаемы. Факт прогона 4.2: green (TC-wiki-305/306 в составе 29 passed; DV 05c, 06-image-dialog.png, DV-8 OK); 4.4 смок п.3 — images-сервис жив (200).
