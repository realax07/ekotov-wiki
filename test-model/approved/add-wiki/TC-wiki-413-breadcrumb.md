# TC-wiki-413 — Breadcrumb на странице статьи: полная цепочка, корень, кликабельность (FR-109)

- **Change:** add-wiki
- **Источник:** wiki (ADDED): Requirement «Breadcrumb на странице статьи» (FR-109) — Scenario «Полная цепочка предков», «Breadcrumb корневой страницы»; design §6, мокап wiki-page.html; CHK-wiki-11, CHK-wiki-12
- **Тип:** ФТ, UI | **Приоритет:** Must
- **Предусловия:** авторизованный пользователь; страница 3-го уровня вложенности (корень → раздел → статья) и корневая страница; для mobile-прогона — цепочка 5 уровней с длинными заголовками
- **Шаги:**
  1. Открыть страницу статьи 3-го уровня → breadcrumb `nav.wiki-breadcrumb > ol.breadcrumb`: «корень / раздел / статья»; каждый предок — кликабельная ссылка на соответствующую страницу.
  2. Текущая страница — `aria-current="page"`, без ссылки на саму себя.
  3. Клик по элементу цепочки → переход на соответствующую страницу.
  4. Открыть корневую страницу → breadcrumb из одного элемента (текущая, без ссылки).
  5. Mobile 375px: цепочка 5 длинных звеньев переносится flex-wrap (высота nav растет), scrollWidth=375 — развала нет.
- **Ожидаемый результат:** цепочка предков от корня до текущей страницы, все элементы кликабельны, текущая не ссылается на себя; корень — один элемент; на 375px переносится без развала.
