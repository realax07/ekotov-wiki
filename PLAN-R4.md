# PLAN Р4 — «Карточка: просмотр + профиль пользователя»

> План по распоряжению Заказчика 2026-09-28 («Давай все сразу»). Флоу: **1 (полный)** — БА → СА (+ architect) → dev-цикл → QA-контур → деплой. Источник: PRODUCT_BACKLOG.md (P3, P9, DEF-005) + решения Заказчика этого числа.

## Решения Заказчика (дословно, 2026-09-28)

1. Аватарка: «Только png/jpg. Автосжатие еще нужно, чтобы пользователь не мучился.»
2. Состав профиля: «display name кладем да, верное замечание. Еще блок роль, и о себе. Так же добавь что при наведении внизу слева, должна быть всплывашка с инфой о пользователе. Добавь задачам assigned и creator. Там так же всплывашка при наведении. Учти новые поля во всех карточках и в поиске.»
3. Просмотр тикета: «модальным окном».
4. Объем: «Давай все сразу» — Релиз 4 целиком, без нарезки.

## Ключевые следствия решений (для БА/СА)

- **Отмена ОГР-13 (Won't)**: дельта MODIFIED в navigation — «в профиле НЕТ аватарок и смены пароля» больше не действует; появляется страница настроек пользователя.
- **Схема users**: + display_name, + role, + bio (о себе), + avatar_path. Схема tasks: + creator_id (бэкфилл = существующие задачи созданы owner), + assigned_to_id (nullable).
- **Поиск**: новые поля задач (assigned/creator) — в фильтрах/выдаче поиска.
- **Всплывашки (tooltip/popover)**: профиль внизу слева (инфа о пользователе) и карточки задач (assigned/creator). Единый механизм.
- **Аватарки**: png/jpg only, серверное автосжатие (квадрат, разумный размер, напр. ≤256px/WebP-альтернатива не требуется), хранение в проде (nginx static), NFR: лимит размера исходника.
- **Просмотр тикета**: read-only модалка поверх V3, отличная от создания/редактирования; закрытие DEF-005 (формы по мокапу V3) входит в этот же пакет.
