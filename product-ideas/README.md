# product-ideas/ — стратегический бэклог продукта

Каждый файл в этой папке — **одна идея нового продукта/фичи стратегического уровня** для ekotov-wiki.

## Правила

- **По идеям из этой папки по умолчанию не работаем.** Идея превращается в работу только после прямого указания Заказчика (идея → утверждена → в работу по флоу конвейера / отклонена / заморожена). Статус — в шапке файла идеи.
- **Отличие от PRODUCT_BACKLOG.md:** там дефекты и технические улучшения существующего продукта; здесь — новые продукты/фичи.
- **Детальная архитектура и декомпозиция задач — не здесь:** разрабатываются отдельно на этапе реализации (БА/СА конвейера). В файле идеи допустимы пожелания Заказчика к реализации как ограничения/принципы.
- Нейминг: `product-ideas_<slug>.md` (slug — короткое имя продукта).
