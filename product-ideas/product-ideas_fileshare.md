# IDEA-002. Файловая шара

**Статус:** идея (Заказчик, 2026-09-23)

**Суть:** возможность загружать и скачивать файлы с машины через понятный интерфейс.

## MVP

- Добавить «Файлы» в sidebar.
- Список файлов с понятным интерфейсом (имя, размер, дата).
- Загрузка файла с машины пользователя на сервер через UI.
- Скачивание файла с сервера через UI.
- Удаление файла.

## Критерий MVP

Зашел в раздел → загрузил файл → вижу его в списке → скачал обратно.
